# いまいち人生に張りがない……を解決するメンタルエクササイズ「ブルズアイ価値査定」

![記事サムネイル](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F1802740%2F471c96476c6cdeedca81462e8146039c5c065030.jpg?alt=media&token=00b87a9f-1670-4ce3-95c1-e689b58f4011)

「最高の体調」には「幸福に生きるには価値観が大事よねー」みたいな話を書いております。

価値観ってのは「もし地位と金と名誉をすべて手に入れてたとしてもやりたいことは？」みたいなことで、人によっては「他者を助ける」が最高の価値かもしれないし、人によっては「斬新なアイデアを生む」が最高かもしれません。

その種類は個人によって大きく違いますが、とにかく自分の価値観をハッキリさせておく作業には大きなメリットがありまして、

学習の効率が上がる\
人生の満足度が上がる\
かなりストレスに強くなる

といったあたりはかなりのとこまで実証されてます。そりゃあ自分の根っこの価値観に沿わないことをやっててもモチベーションが上がらないですもんね。

ただ、価値観にもとづいて行動するってのはなかなか難しくて、一朝一夕には見つからないのが難点。「最高の体調」でも書いたとおり、「価値観」ってのは原始の世界にはなかった概念なんで、そもそも人類は取り扱いに慣れてないんですよ。

実際、「最高の体調」でもいくつか手法を取り上げてるんですけど、「複雑すぎて……」とか「めんどうでやる気が出ない……」みたいなお声をいただいております。まぁ実際ややこしいテクニックばっか紹介してますからね（笑）

といっても、そこで自分の価値観を掘り下げないのももったいない話なんで、今回はもうちょい簡単な手法をご紹介します。「自分の人生をどうしたいかわからない……」みたいな方は、お試しいただくといいんじゃないかと。
