# 筋トレメニューが思いつかない！あなたに向けたシンプルメソッド「5/3/1」とは？ #1「基礎編」

![7488f898b6254683bbea7b14c047d3425b7a2e83](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2033097%2F7488f898b6254683bbea7b14c047d3425b7a2e83.jpg?alt=media&token=86f64f83-d1e0-49f7-b944-3e2998c2566d)

定期的にいろんな筋トレ法を試してるんですが、ここのところ試していた「**5/3/1**」ってのが良かったのでまとめておきます。

---

これは、ジム・ウェンドラーさんという伝説的なパワーリフターが開発したプログラム([R](https://amzn.to/3AkCX9G))で、ポイントとしては、

- 他の筋トレメニューにくらべて、めちゃくちゃシンプルで管理しやすい
- 定期的に負荷を下げる週を作るので、精神的にわりと楽

- 負荷が低い週も作るので、初心者はフォーム改善もできる

ってのがあります。詳しくは後述しますが、「自分ができる最大の重量」さえ計算しちゃえばあとは4つの種目を決まった回数やるだけなんで、**細かいことを考えずに済むのが一番のメリット**でしょう。筋トレメニューってのはどうしても複雑になりがちなんで、このシンプルさは非常にありたがたいですね。

決してパワーリフティングに特化したプログラムではなく、筋力、筋肉量、柔軟性などを改善するのに向いており、ジムの初心者から中級者にまで対応した内容になってるんじゃないかと。

では、「**5/3/1**」のやり方を見てみましょうー。

## **「5/3/1」の実践法は超シンプル**

### 「5/3/1」のセット数と回数

「**5/3/1**」のメソッドは、週ごとにセット数と回数を変えていくのが最大のポイント。具体的には、4週間を1サイクルと考えて以下のように変えていきます。

- **1週目**：1セット5回のトレーニングを3セットを行う（最終セットは5回以上やってもOK。やらなくてもOK）
- **2週目**：1セット3回のトレーニングを3セットを行う（最終セットは5回以上やってもOK。やらなくてもOK）
- **3週目**：1セット5回 → 1セット3回 → 1セット1回を行う（最終セットは5回以上やってもOK。やらなくてもOK）
- **4週目**：1セット5回のトレーニングを3セットを行う（ただし負荷は軽くする）

ご覧の通り、531の数字を基準にしてトレーニングの回数とセット数を決めてまして、これが名前の由来になっております。

### 「5/3/1」のトレーニングメニュー

でもって、「**5/3/1**」では週に4日のトレーニングを行いまして、それぞれメニューはこんな感じになってます。

- **1日目**：[スタンディング・ミリタリー・プレス](https://www.youtube.com/watch?v=2yjwXTZQDDI&feature=emb_title)
- **2日目**：スクワット
- **3日目**：デッドリフト
- **4日目**：ベンチプレス

こちらも非常にシンプルなメニューで、ビッグ3にミリタリープレスを加えただけ。週に4日も時間を取らないのであれば、

- **1日目**：[スタンディング・ミリタリー・プレス](https://www.youtube.com/watch?v=2yjwXTZQDDI&feature=emb_title)＋スクワット
- **2日目**：デッドリフト＋ベンチプレス

ってやり方でも構いません。まぁ個人的には1日あたりに必要な時間が短い方が好きなんで、週4を採用してます。例えば、

- 月/火/木/金
- 日/月/水/金
- 日/月/水/木

といった感じでメニューをこなす感じになりますね。

### 「5/3/1」の負荷

筋トレでは負荷設定がかなり重要ですが、「5/3/1」では、週ごとに以下のように負荷を変えていきます。

<table><tbody><tr><th>週</th><th>セット1</th><th>セット2</th><th>セット3</th></tr><tr><td>1</td><td>65% x 5</td><td>75% x 5</td><td>85% x 5+</td></tr><tr><td>2</td><td>70% x 3</td><td>80% x 3</td><td>90% x 3+</td></tr><tr><td>3</td><td>75% x 5</td><td>85% x 3</td><td>95% x 1+</td></tr><tr><td>4</td><td>40% x 5</td><td>50% x 5</td><td>60% x 5</td></tr></tbody></table>

ここで「○○％」と指定してあるのは、**1RMの90％に対するパーセント**のことなんでご注意ください。例えば、あなたがいま「ベンチプレスを100kgあげられる！」って状態で「5/3/1」を行うのであれば、以下のような計算になるわけです。

<table><tbody><tr><th>週</th><th>セット1</th><th>セット2</th><th>セット3</th></tr><tr><td>1</td><td>100kg x .9 x .65 = 58.5kg </td><td>100kg x .9 x .75 = 67.5kg </td><td>100kg x .9 x .85 = 76.5kg </td></tr><tr><td>2</td><td>100kg x .9 x .7 = 63kg<strong><br></strong></td><td>100kg x .9 x .8 = 72kg </td><td>100kg x .9 x .9 = 81kg </td></tr><tr><td>3</td><td>100kg x .9 x .75 = 67.5kg</td><td>100kg x .9 x .85 = 76.5kg </td><td>100kg x .9 x .95 = 85.5kg </td></tr><tr><td>4</td><td>100kg x .9 x .4 = 36kg</td><td>100kg x .9 x .5 = 45kg </td><td>100kg x .9 x .6 = 54kg </td></tr></tbody></table>

これだけ見るとめんどうな印象かもしれませんが、いったん自分の計算しちゃえばあとは面倒な計算が不要になりますんで、ぜひお試しください。

でもって、いったん毎週の負荷を決めたら、「5/3/1」では4週間の1サイクルが終わるごとに少しずつ重量を変えていきます。具体的には、

- ベンチプレスとミリタリープレスは2.5kgずつ上げていく

- デッドリフトとスクワットは5kgずつ上げていく

みたいになってまして、これまた非常にシンプルですね。ちなみに、自分の1RMがわからない！という方は、[こちらの計算機](http://www.amy.hi-ho.ne.jp/mizore/1rm.html)や[RM換算表](https://fwj.jp/magazine/rm/)をお使いくださいませー。

## **なぜ「5/3/1」は優秀なのか？**

さて、「5/3/1」の実践法は以上ですが、「なんでこの手法が良いの？」ってとこが気になる方もいるでしょう。たんにやり方だけ知っててもモチベーションが上がりにくいので、「5/3/1」が優良プログラムである理由も押さえておくことにします。

### **1.多関節のトレーニングだけに絞っている**

多関節運動ってのは、[レッグエクステンション](https://b-fit.jp/gym-life/legextention/)みたいにひとつの関節を使う運動ではなく、一気に複数の筋肉を使って行う運動のことです。例えば、スクワット、デッドリフト、ベンチプレス、パワークリーンなどっすね。一度に多くの筋肉を鍛えることができるんで、筋肉量と筋力の増強に最も効果的だと考えられてるんですな。これらのメニューに絞ることで、トレーニングに必要な時間を短縮してるわけです。

### 2.めちゃくちゃ軽いところから始められる

「5/3/1」では、1RMの90％のさらに40〜95％ぐらいの負荷でやるんで、非常に気楽に取り組めるのがポイント。筋トレを始めると、誰でもすぐに高負荷にしたくなっちゃうもんですが、例え数ヶ月間は順調に進んだとしても、その後はどんどん停滞するのが一般的なんですよね。

この問題を解決するには、ゴールまでの時間をできるだけゆるやかにして、少しずつ前進していくのがベスト。あまり複雑なことを考えずに、シンプルなルールにしたがってジワジワと負荷を上げていくことで、気がつけば誰よりも遠い位置にたどりつくのを目指すのが「5/3/1」のキモですね。

### 3.ケガが少ない＆停滞期を突破しやすい

「5/3/1」では、定期的に思いっきり負荷を下げる週を組み込んでいるのも大きなポイント。いわゆるデロードって考え方ですけど、これを組み込むことで身体が適切に休憩が取れるし、ケガも少なくなるし、筋トレの停滞期も突破して再び筋肉を育てやすくなるしで、長期的な筋肉の発達には非常にいいんですよね。
