# いま来まくってるスパイス・サフラン：最新研究で明らかになった健康効果とおすすめサプリ3選

![記事内画像](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F20241003post-287%2F48a1a35d-ef73-466a-9acb-620c5f670181.jpg?alt=media&token=48a1a35d-ef73-466a-9acb-620c5f670181)

[２年ぶりにサフラン](https://daigovideolab.jp/blog/2098219)の話でーす。

「パレオな男」をお読みの方ならご存じのとおり、近年は[サフランの効果を示したデータ](https://yuchrszk.blogspot.com/2024/09/2024.html)がめっちゃ増えてまして、抗酸化と抗炎症の働きについては疑う余地なし。似たような働きを持ったスパイスにターメリックがありますが、「体内の利用効率を考えたらサフランのほうが優秀なのでは？」などと、近ごろは思い始めております。もちろん最近は自分でもサプリを使っていて、前回プッシュした「[ライフエクステンション・オプティマイズドサフラン](https://jp.iherb.com/pr/life-extension-optimized-saffron-60-vegetarian-capsules/23953?rcode=IRO489)」を愛用してたりするんですな。

いちおうおさらいしておくと、サフランは料理に使うと最高のスパイスですが、鮮やかなオレンジ色が示すとおりカロテノイドを豊富に含んでいるのがポイント([R](https://www.sciencedirect.com/science/article/abs/pii/S0304419X13000565?via%3Dihub))。カロテノイドは抗酸化作用を持つ色素の一種で、炎症を抑え、目の健康を改善し、人によってはうつ症状を緩和することさえあるとされております([R](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10045512/))。ただし、サフランはスパイスとして使うと高価なので、サプリメントとして摂取する方がずっとコストを抑えられて良い感じなんですな。

ってことで、私もサフランには注目してまして、これまでだいたい80以上の科学的研究と学術誌を調査しております。サフランには健康効果をもたらす化合物が何十種類も含まれていますが、特に重要なのは次の4つです。

- クロシン
- クロセチン
- ピクロクローシン
- サフラナール

クロシンはサフランの赤橙色をもたらす成分で、サフラナールは香りを決定づける成分です。ピクロクロシンは、サフランの風味に最も影響を与える化合物で、サフランの花にのみ含まれております。さらに、クロセチンは、抗腫瘍作用や癌予防効果があると考えられ、いっそうの研究が進み始めたカロテノイドです。

これらの化合物の働きにより、最近は以下のようなメリットが確認されてたりします。

- **代謝の調整メリット**：2019年のレビュー([R](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6535192/))では、サフランには免疫系に対する有益な効果があり、そのメリットのほとんどはクロシンとクロセチンによるものであると指摘しておられます(ただし、レビューされた研究のほとんどは動物または細胞を用いたものなので注意)。ヒトを対象とした研究では、代謝に問題がある男女44名に12週間、1日あたり100mgのサフランを投与したところ、総コレステロール値、空腹時血糖値、hsCRP(炎症の血液マーカー)が低下したとのこと。

- **神経保護メリット**：2015年のサフランの神経系への影響に関するレビュー([R](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4599112/))では、人間とラットの研究を混合して調査。すると、ヒトを対象とした研究でも、サフランには抗アルツハイマー特性がある可能性が示されたんだそうな。軽度から中程度のアルツハイマー病を持つ高齢者(55歳以上)の場合、1日あたり30mgのサフランにより、処方薬のドネペジルと同等の効果があることが分かったそうな。

- **うつ病の改善メリット**：サフランは軽度のうつ病の緩和に明確な利点があることが示されております。ほとんどの研究では、サフランはフルオキセチン(プロザック)と同等の効果があり、副作用も少ないと報告されていて、かなり良い感じなんですよね。ただし、あるメタ分析([R](https://academic.oup.com/nutritionreviews/article/77/8/557/5499264))では、このサフランに関する研究には、出版バイアスの存在も指摘されてまして、まだそこまで明確な知見でもない点は注意したいところです。ちなみに、サフランは睡眠の質も改善するようですが、その効果は抗うつ作用によるものかどうかはまだわかっておりません([R](https://pubmed.ncbi.nlm.nih.gov/33925432/))。

- **月経前症候群および月経前不快気分障害の改善メリット**：月経前症候群に悩む人々にとっても、サフランは有望なサプリメントかもしれません。ある研究([R](https://medicopublication.com/index.php/ijfmt/article/view/3191/2985))によると、1日30mgのサフランを摂取することで、PMSの重症度が著しく軽減されたんだとか。これは、PMSやPMDDの治療によく使われるプロザックの効果と同じぐらいかも？って感じですね。特に、サフランは他の代替療法よりも胸や腹部の痛みや不快感を和らげる効果が高いと考えられております。

- **炎症と酸化ストレス**：サフランは抗酸化性能が高いため、主に脳内でフリーラジカルによる酸化ストレスを減少させる能力があったりします([R](https://onlinelibrary.wiley.com/doi/abs/10.1002/ptr.6748))。まぁこの効果によって炎症が収まるかどうかについては、どのバイオマーカーを調べるかによって結果はバラバラでして、一般的に炎症性サイトカイン(炎症反応を調節する小さなタンパク質）へのメリットはそこまで大きくないかもしれません。一方で、酸化ストレスの主要なマーカーであるマロンジアルデヒド(MDA)への影響は大きいみたいなので([R](https://onlinelibrary.wiley.com/doi/full/10.1002/fsn3.2463))、やはり飲む価値はありそうっすね。
