# 筋トレでもっとも大事な「ボリューム」を完全に使いこなすためのガイドライン

![記事内画像](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F1852111%2F798415dc-617d-450b-a95b-6f984d1ad7f9.jpg?alt=media&token=798415dc-617d-450b-a95b-6f984d1ad7f9)

「**筋トレはボリュームが大事！**」なんて話を「パレオな男」ではよく書いております。たとえば、

- [筋肉を増やすための最適な筋トレボリュームはこれだ！というバスク大学のメタ分析](https://yuchrszk.blogspot.com/2018/09/blog-post_11.html)
- [ガッツリと「筋力」をアップさせるためにもボリュームは超大事なんだよ！というメタ分析の話](https://yuchrszk.blogspot.com/2018/09/blog-post_88.html)
- [筋トレで頭を良くしたいなら「ボリューム」に注意したほうがいいのかも](https://yuchrszk.blogspot.com/2017/04/blog-post_19.html)

といったあたりが代表的なところです。もちろん、筋トレの効果を左右する変数はいろいろありまして、

- どんなトレーニングを選ぶか？
- どれぐらい負荷をかけていくか？
- ちゃんと休息しているか？

みたいなポイントも大事なんですけど、**おそらくボリュームよりも最終的な成果に影響する要素はない**はず。これは多くのデータで示されていて、多分今後もくつがえることはないんじゃないかなぁ……と思っております。

---

が、あらためて考えてみたら、「**そもそもボリュームってどう言うことなの？**」ってポイントを書いたことがなかったことに最近気づきまして。読者さんからも「ボリュームって何？」や「具体的にどう考えればいいの？」みたいなご質問をチラホラと受け取ってたりするんですよね。

ってことで今回は、筋トレにおける最重要ポイントである「ボリューム」について、もっとも大事なところをまとめていきましょう。

## **そもそもボリュームとは？**

まずは定義からまいりましょう。筋トレにおけるボリュームってのは、

- 1回の筋トレでどれぐらいエクササイズをしたか？

を表す言葉でして、以下の式で簡単に出すことができます。

- ****ボリューム＝重量 x 回数 （レップ数） x セット数****

たとえば、現時点で自分が1セット10回のスクワットを100kgのウェイトを使って3セットやってるなら、

- 100kg**x**10回**x**3セット＝ 3,000kg

って計算になるわけっすね。基本的には、この数値を増やせば増やすほど筋肉も発達していく傾向がありまして、

- 100kg x 10回 x 3セット＝ 3,000kg
- 50kg x 20回 x 3セット＝ 3,000kg
- 100kg x 5回 x 6セット＝ 3,000kg

のように各変数を変えても最終的なボリュームが同じであれば、筋肉の成長は変わらないとお考えいただいて構いません（もちろん各自のスキルや神経系の発達レベルなんかもあるんで、あくまで”基本的には"ですが）。

つまり、大前提としては、

- いままでの筋トレよりもボリューム数が増えていれば筋肉は増えていく
- いままでの筋トレよりもボリューム数が減っていれば筋肉の発達は停滞する

といった感じになります。つねに自分のボリューム数を把握しつつ、無理のない範囲でジワジワとボリュームを上げていくのが肝要なわけっすね。

## **最適なボリュームをどう決める？**

ボリュームの基本を押さえたところで、続いて「自分にとって最適なボリュームを決めるにはどうすりゃいいの？」ってのを見てみましょう。いくら**ボリュームの各変数が自由に決められる**と言っても、最大で上げられる重量が100kgの人が「100kg x 1回 x 3セット」みたいなメニューを組むのはさすがに無理ですし、やはり現実的な”**落としどころ**”があるわけです。

### 最適なトレーニングの回数

この問題についてはすでに複数のメタ分析([R](https://www.ncbi.nlm.nih.gov/pubmed/20300012),[R](https://www.ncbi.nlm.nih.gov/pubmed/19661829))が存在してまして、これらの知見をえいやでまとめてしまうと以下のようになります。まずはトレーニングの最適な回数からいくと、

- **1週間のあいだに、それぞれの筋肉を120〜210回の範囲で鍛える（初心者は120回、上級者は210回を目指す）**

あたりが現実的なラインになります。たとえば、

- いま週3回で筋トレをしてる場合＝1回のエクササイズで40〜70回を目指す
- いま週2回で筋トレをしてる場合＝1回のエクササイズで60〜105回を目指す

みたいになりましょう。もちろん、これはあくまでただの参照点なんで、つねに調整していく必要はありますが。

### 最適なトレーニングのセット数

続いて、最適なセット数を見ていきましょう。こちらも万人に当てはまる法則を出すのは難しいんですけど、ボリューム研究の権威であるマイク・イスラエテル博士([R](https://renaissanceperiodization.com/))によりますと、

- **1週間のあいだに、それぞれの筋肉を5〜23セットの範囲で鍛える**

ぐらいの感じで決めていただくのが現実的でしょう。一例としては、週3回のトレーニングで週120レップスを目指す場合は、1日40レップスが必要なので、

- ひとつのエクササイズあたり8回 x 5セットを目指す
- ひとつのエクササイズあたり10回 x 4セットを目指す

あたりが一般的な落としどころになるんじゃないでしょうか。もっとも、この考え方はイスラエテル博士の理論をかなり簡略化したものなんで、より本格的な議論をお望みの方は[2月に出る新刊](https://amzn.to/2QpVZX2)をチェックされたし。

### 最適なトレーニングの重量

最後に最適な重量を見ていきましょう。といっても、ここまでくれば難しいことは何もありませんで、ほぼ自動的に重量は決まっちゃうはずであります。

具体的には、上で説明した「最適なセット数」で決めたレップ数に1〜4を足した回数ができる重量を使ってください。たとえば、

- ひとつのエクササイズあたり8回 x 5セットを目指すなら、10レップスぐらいで「もうこれ以上は体が動かない！」レベルの重量を使う

- ひとつのエクササイズあたり10回 x 4セットを目指すなら、12レップスぐらいで「もうこれ以上は体が動かない！」レベルの重量を使う

みたいな感じですね。「あと2〜3回はできるかなー」ぐらいの余力を残した重量を設定するのがコツであります。

もちろん、「これ以上は体が動かない！」ってとこまで追い込むやり方もあるんですが（いわゆるオールアウト）、近ごろは「[そんなに意味がないんじゃない？](https://yuchrszk.blogspot.com/2020/01/2.html)」って考え方もありますし、なによりもセットごとに筋肉が疲れさせると、次のセットで回数か重量を減らさざるを得なくなるんで、全体的なボリュームも低下しちゃうんですよねぇ。

特にベンチプレスやスクワットみたいに高重量を使いがちなメニューは筋肉が疲れやすいので、最終的なボリュームが減らないようにご注意ください。結局のところ、ボリュームを優先で考えていただくのがベストなんで。

ただ、ここにはひとつだけ注意点がありまして、

- 筋力を増やしたい場合（＝もっと高重量を挙げたい場合）は、意識して重い重量を挙げたほうが良い

ってのは言えます。筋肉量を増やしたいだけであれば、そこまで重量にこだわらなくてもOKですが、筋力については神経系の慣れが必要なんで、どうしても高負荷は必要になってくるんですよ。

こちらの目安としては、

- だいたい6RM以上の高負荷を使う

ぐらいに覚えておけば良いかと思います。まぁ筋力が増えれば長期的なボリュームも増やしやすくなるので、私も意識して高負荷トレーニングは取り入れてます。

## まとめ

以上の話をまとめると、

- 筋トレのボリュームは「重量 x 回数 （レップ数） x セット数」で決まる
- 1週間のあいだに、それぞれの筋肉を120〜210回の範囲で鍛えるのが現実的
- セット数は1週間のあいだに、それぞれの筋肉を5〜23セットの範囲で行うのが現実的
- 重量については、「あと2〜3回はできるかなー」ぐらいの余力を残した負荷を選び、先に決めたレップ数とセット数で決める

みたいになります。世にはいろんな筋トレアドバイスがありますが、最終的にもっとも大事なのはボリュームなので、筋トレ好きな方はぜひ覚えておいていただければと。
