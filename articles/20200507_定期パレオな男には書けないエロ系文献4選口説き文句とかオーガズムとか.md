# 【定期】パレオな男には書けないエロ系文献4選（口説き文句とかオーガズムとか）

というわけで、毎度おなじみエロ文献のコーナーです。アドセンスの関係で「パレオな男」では下ネタがNGなもので、ここで定期的に放出しておこうという試み。

## **初対面の異性に放つべきベストなフレーズとは？**

まずは「**ベストな声かけのフレーズはこれだ！**」みたいな研究([R](https://link.springer.com/article/10.1007/BF00288216))の話です。飲み会とかで初めて会った異性に声をかける時に、どんなフレーズを使うのがベストなのか？という問題ですな。

これはアラスカ大学の古典的なリサーチで、まずは300人の男女に「普段はどんな誘い文句を使ってます？」と質問。そこで浮かび上がったいくつかの口説きフレーズを、3つのカテゴリーに分けております。

- **無害系**＝ 自然な会話を装うパターン。「お勧めのお酒？」とか「ここで働いているの？」 とか「こんにちは」とか

- **直接系**＝ストレートに好意を示すパターン。「一緒に飲まない？」とか「きれいな目をしてるね」とか「電話番号を教えて」とか

- **ふざけ系**＝ ギャグで持ち込もうとそるパターン。「お互いひとりなら、一緒に飲むのが自然じゃない？」とか「え？25歳？24歳ぐらいかと思った！」とか

でもって、続いて431人の男女に「どの誘い文句がいいですか？もっとも惹かれるのはどれですか？」と尋ねたところ、それぞれの誘い文句のランキングはこんな感じになりました。

### 女性が好んだ誘い文句トップ5

1. 躍りませんか？（63.6％）
2. こんにちは（60％）
3. （レストランなどで）この店は初めてなんですよ。お勧めのメニューとかあります？（58.2%）
4. ちょっと恥ずかしいんですが、どうしてもあなたとお話ししたくて（56.4％）
5. あなたの○○○は本当に素敵です（髪とか目とか）（50.4％）

### 男性が好んだ誘い文句トップ5

1. お互いひとりみたいですね。ご一緒しませんか？（71.6％）
2. こんにちは（58.9％）
3. 車がうまく動かないんです。手伝ってもらえませんか？（57.1％）
4. （パーティの席などで）他の誰にも興味がないけど、あなたには私を知ってもらいたくて（54.6％）
5. ○○○への行き方を教えてくれませんか？（47.8％）

### 女性が好まなかった誘い文句トップ5

1. 俺は酒が強いんだよね（89.3％）
2. その髪って地毛？（89％）
3. 俺がサッカーボールを投げてるのに気づいた？良い腕じゃない？（58.2%）
4. 君は昔付き合ってた子に似てるんだよね（86.8％）
5. いままでいろんな女性と付き合ってきたけど、君は大当たりだ（84.7％）

### 男性が好まなかった誘い文句トップ5

1. 最後の彼氏と別れてだいぶ時間が経っちゃって（81.6％）
2. 前にどこかで会わなかったっけ？（81.3％）
3. いい体してるね。その体を調べてみてもいい？（79.5％）
4. 私、軽いタイプなんだけど、あなたは？（79.2％）
5. あなたの星座は何?（78.8％）

まぁアメリカとは文化が違うんで、日本に当てはまらないものも多そうですが（例えば「あなたの星座は何?」はアメリカでは一般的な会話スターターだったりする）、だいたいのところ以下のようなことはいえそうであります。

- 全体的には、男女ともに「ふざけ系」のセリフよりも無害か直接系を好む傾向がある

- 女性の場合は特に「ふざけ系」を嫌う傾向があるので、男は使わない方が無難

- うまく最初の言葉が家なさそうなら、男女ともに普通に「こんにちは」と話しかけるのがベスト

このあたりの傾向は、文化とは関係なく日本でも通じそうではあります。結局のところ、男女ともに普通の声かけからスタートした方が下手に失敗しなくていい感じはしますね（もちろん「踊りませんか？」みたいなフレーズを自然にさらっと言える人であれば、そちらを使ってもいいですが）。

## **女性が男性に使うと効果的な口説き文句とは？**

上の研究に続き、近年も似たような調査([R](https://www.sciencedirect.com/science/article/abs/pii/S0191886919305963))が行われております。こちらはセント・メアリーズ大学などの調査で、「**女性が男性に使うと効果的な口説き文句とは？**」ってポイントをチェックしてます。

こちらは130人の男を対象にした研究で、チームが用意した口説き文句のなかから「これはいい！」と思うものを採点してもらったそうな。ここでも上記の研究と同じく口説き文句を「無害系」「直接系」「ふざけ系」の3つのカテゴリーに分けてまして、それぞれを採点させたところ、

- やっぱり直接系のフレーズがもっとも評価が高かった

- ふざけ系と無害系の点数は同じぐらいだった

- ただし、ルックスの魅力が低い人（または露出度が低い人）が「直接系」を使うと効果がなかった

って傾向が確認されたそうな。女性の場合もやはり直接系の効果がデカいようですが、それは見た目の魅力（または衣服の露出度に左右されてしまうんだ、と）。うーん、男の反応はわかりやすい。

そんなわけで、ここまでの話をまとめて考えると、

- 自分のルックスに自信がなければ男女ともに初手から「直接系」を使った方が良さげ

- とりあえず失敗を防ぐ方向で行くなら、まずは「無害系」から入って、警戒心がなくなったところで「直接系」に移るのが良さげ

みたいな感じになりましょうかねー。

## **エロ動画は問題行動を引き起こすのか？問題**

「**エロ動画は悪影響なのか？**」って問題を調べた観察研究([R](https://www.sciencedirect.com/science/article/pii/S1743609520300321))が出ておりました。エロ動画を頻繁に見ることでなんらかの依存症や抑うつ症状が起きたりしないのか？って話ですな。

これは3つの独立したサンプルを使った調査で、合計15,000人以上の男女（18〜76歳）を対象に匿名のオンライン調査に答えてもらったとのこと。分析にあたっては、エロ動画ユーザーを3つのグループに分けてます。

1. エロ動画をあまり見ず、なおかつ問題行動がないユーザー（全体の68～73％）
2. エロ動画をたくさん見て、なおかつ問題行動がないユーザー（全体の19～29％）
3. エロ動画をたくさん見て、なおかつ問題行動があるユーザー（全体の3～8％）

というわけで、確かにエロ動画の視聴と問題が相関してるケースもあるものの、その量はかなり少ない感じっすね。それでは、エロ動画と問題行動がつながってる人は何が違うのか？ってことで、さらに以上のグループを40以上の心理学的な特徴にそって比べたところ、こんな結果になりました。

- 「エロ動画が好きで問題行動があるユーザー」は、抑うつ症状と退屈感の増加を経験し、逆に自尊心レベルが低い傾向があった

- しかし「エロ動画好きで問題行動があるユーザー」と「エロ動画をほとんど見ず問題行動がないユーザー」を比べても、**性格的特徴やその他の特性に大きな違いは見られなかった**

だったそうです。エロ動画に初めて接した年齢とか全員のビッグファイブとかをチェックしても、目立った理由は見つからなかったそうで、ここらへんは謎としか言いようがないっすね。

とりあえず、本研究から得られる知見としては、

- エロ動画を見る頻度は問題行動の指標にはならない
- 確かにエロ動画が問題行動につながる可能性は否定できないが、現時点ではどんな原因が絡み合ってるのかは全くわからない

ぐらいのもんでしょうか。エロ動画の謎はまだまだ深いですなぁ‥…。

## **良いオーガズムと悪いオーガズム**

オーガズムといえば**「快楽」と同義語**のようなイメージがあるわけですが、「**実際には”悪い”オーガズムも存在するのだ！**」って研究([R](https://www.ncbi.nlm.nih.gov/pubmed/31512005))が公開されておりました。

これはオンラインで募集した726人の参加者を対象にしたもので、セックスとオーガズムに関する過去の経験についてアンケートに答えてもらったんだそうな。参加者の平均年齢は28歳で、ほとんどが恋愛関係にあったとのこと。

具体的に参加者たちに何を聞いたかと言いますと、

- 合意のセックスのなかでオーガズムへのプレッシャーを感じたことがあるか？
- 望まないセックスに同意したことがあるか？（本当は疲れているのにOKしたりとか）

といった感じです。このように「なんとなくネガティブな状況」で感じたオーガズムは、必ずしも良いものにはならないのではないか？ってポイントをチェックしたわけですね。

そこでどんな傾向が浮かび上がったかと言いますと、

- 参加者のほぼ半数（48.1％）がプレッシャーの強いセックス（口頭で圧力を感じたセックス）、望まないセックスでオーガズムを経験したていた

- ただし、これらの状況で起きたオーガズムについて、3分の2（66.1％）の参加者は「質が低い」と評価。感覚が身体的な反応だけで構成され、感情的な快感が得られず、痛みさえ感じると回答した

- 悪いオーガズムを感じた後は、セックスへの欲求が失われるケースが多く、さらに将来の性的パフォーマンスが低下し、相手への嫌悪感すら生まれた

だったそうな。まぁ「感情的なつながりがないとセックスは意味がない」などとはよく聞くとこですけど、実際にストレスやプレッシャーはオーガズム体験をネガティブなものに変えちゃうわけっすね。これは心がけておきたいところです。
