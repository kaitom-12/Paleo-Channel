# 「その化粧品、老化を早めてませんか？」──肌を傷める“隠れリスク成分”リスト

![803e723793e7f1895000f571b2c1d456503e9404.png](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2216805%2F1_803e723793e7f1895000f571b2c1d456503e9404.png.png?alt=media&token=0bd1f9f7-4d7e-4d1b-a9cf-aa1ad60d6373)

「肌に優しい」とか「無添加」とか、そんなワードが化粧品のラベルにずらずらと並んでるのを見かけますが、「**本当にそれ、肌に優しいの？**」と思ったことはありませんでしょうか？

私も「シンプル処方」「オーガニック配合」みたいな表示を見て、「いや、逆に怪しくない？」と疑ってしまうようなタイプなんですが、近ごろ行われた系統的レビューを見てみると、どうやら多くの化粧品は“思ったよりリスキー”みたいなんですな。

---

ということで、近ごろ「**肌トラブルを起こしやすい成分とその理由**」について掘り下げた信頼性の高い系統的レビュー([R](https://pubmed.ncbi.nlm.nih.gov/40330400/))が出ましたんで、これをもとに「ヤバい可能性が高いから避けたほうが良い成分」をまとめておきましょう。

## **3人に1人が化粧品で肌トラブルを経験している**

このレビューでは、世界中の女性を対象とした9つの研究（合計4,569人分のデータ）を分析したもので、「**スキンケア系の商品を使ったあとでどんなトラブルが起きたか？**」って問題について、精度が高めな結論を出したものです。すべてが横断研究なので、因果関係を証明するには限界があるあたりはご理解ください。つまり、「この成分が肌荒れの原因である」と断定はできないわけっすね。

ただ、手法の厳密さや透明性の高さから、「全体として信頼できるレビュー」であると評価できるんで、私たちこれからスキンケアグッズを選ぶ際にはかなり役立つはずであります。

で、まずは大きな結論から言いますと、全体としては以下のような割合で副作用が報告されたそうな。

- ニキビ：36%
- 赤み：27%
- かゆみ：19%
- 刺激感：18%

つまり、全体の3人に1人以上は「化粧品やスキンケアアイテムで何かしらの肌トラブルを経験している」わけですな。特に副作用が出やすい人の特徴も判明してまして、

- 18〜26歳の若い女性
- 化粧品の使用頻度が高い
- 複数の製品を併用している

って感じになります。まあ、これはすべて同じこと言ってまして、若い女性ほど化粧品とスキンケアアイテムを使う種類と数が多いので、気をつけてねーってことですな。この結果を見るにつけ、スキンケアに使う商品は、必要なものを最低限まで絞り込むのが正しいことがわかるわけです。スキンケアは少数精鋭！

## **「スキンケアによる肌トラブルの原因は何か？」を突き詰めると、主に3つの成分カテゴリにたどり着く**

では、具体的に化粧品やスキンケアアイテムの何が悪さをしているのかってことですが、このレビューを通して浮かび上がった「とくに注意すべき成分」は以下の3つになります。

1. 香料
2. 防腐剤
3. 着色料

いずれも「パレオな男」で昔から「気をつけてねー」と言ってきたものばかりですけど、それぞれについて、具体的な成分名と問題点を見ていきましょう。

### **2. 防腐剤：菌は防ぐけど、肌には刺激的？**

防腐剤は、製品がカビたり腐敗したりしないようにするための成分ですが、これもまた皮膚トラブルの大きな原因となることがあります。代表的な問題児たちは以下のとおりです。

- ****イソチアゾリノン類（Isothiazolinones）****

-
  - **メチルイソチアゾリノン（Methylisothiazolinone / MIT）およびメチルクロロイソチアゾリノン（Methylchloroisothiazolinone / MCI）**：米アレルギー研究グループの調査では、最も頻度の高い防腐剤アレルゲンのひとつ EUでは2013年に「接触アレルゲン・オブ・ザ・イヤー」に選出され、その後、リンスオフ製品への使用濃度制限が導入されたぐらい。
  - **ベンジスチアゾリノン（Benzisothiazolinone / BIT）**：MIT/MCIと同系で、皮膚アレルゲンの報告多数。一部国では化粧品使用が制限または禁止されている 。

- **フォルムアルデヒド放出防腐剤（Formaldehyde releasers）**
  - **ホルムアルデヒド自体、およびクエータニウム-15、DMDMヒダントイン、イミダゾリジニル尿素、ジアゾリジリジニル尿素**：一部はEUで使用禁止。消毒剤としても使われるが、接触性皮膚炎や発がん性リスクがあるとして規制対象。アメリカでも発がん性に関する懸念が提起されている。

- **パラベン類（Parabens）**
  - **メチルパラベン、プロピルパラベン、ブチルパラベンなど**：内分泌撹乱などの疑いはあるものの、接触性皮膚炎発症率は比較的低い。ただし、敏感肌やアトピー体質の場合は症状悪化のおそれあり。

- **フェノキシエタノール（Phenoxyethanol）：**多くのスキンケア・ヘアケア製品に配合され、スキンアレルゲンとして上位にランクしている。パッチテスト陽性率は低くても、使用頻度が高い製品に注意が必要。

- **トリクロサン（Triclosan）ほか**：抗菌作用目的で広く使われてきたが、ホルモン撹乱や耐性菌発生のリスクから、現在では規制の対象 。他にもベンザルコニウムクロリド（Benzalkonium chloride）などがアレルギー源として報告されている。

この中だと、特にメチルイソチアゾリノンは過去にアレルギー報告が激増したことでEUで使用制限されたし、パラベンについてもエストロゲン様作用の懸念があり、敏感肌や妊婦では避けたほうが無難とされております。MIT/MCIのように、すすいでも残留の危険がある成分もありますんで、ぜひご注意ください。

### **3. 着色料：見た目は美しいが、肌には優しくない**

「赤いリップ」「カラフルなアイシャドウ」など、視覚的な印象を左右するのが着色料ですが、これもまた皮膚に悪さをしがちであります。多くの研究で問題にされがちなものは、だいたい以下のようになります。

- **タール系合成染料（Coal-tar dyes）**
  - **Red 40（Allura Red AC、CI 16035）**：蕁麻疹や腫れなどのアレルギー反応が報告されており、コスメや食料品にも広く使用されてたりする。
  - **Yellow 5（タートラジン、CI 19140）**：かゆみ、蕁麻疹、注意力低下の可能性あり 。
  - **Yellow 6（サンセットイエロー、CI 15985）**：発がん性やアレルギー症状が懸念され、コスメや医薬品にも使用されたりする。

- **カーマイン（Carmine、コチニール）：**天然由来の赤系着色料だが、喘息やアナフィラキシーを引き起こすリスクがある。米FDAは明示的な表示を義務付けています。

- **Disperse Blue 染料（布用染料）**：特にDisperse Blue 106／124は、合成繊維（ポリエステルなど）と接触した際に皮膚炎やアレルギー反応を引き起こしやすいことで知られる。

- **FD&C Blue 1（Brilliant Blue FCF、CI 42090）**：一般には安全とされているものの、低頻度ながら呼吸器症状を引き起こす例がある。

- **アゾ染料（Azo dyes）**：CI 15880 / CI 14700 / CI 16035 等は、香料や髪染めにも使われ、芳香族アミンを放出する可能性があり、刺激性や発がん性懸念がある。

ということで、ラベルを見てFD&C / D&C の数字・名称があれば要注意。過去に化粧品で炎症やアレルギーがあったような方は、ぜひこちらもご注意ください。

## **「誰でも起こりうる」けど「個人差は大きい」**

肌によろしくない（かもしれない）成分は以上ですが、研究によると、特に以下のような条件の人には副作用が出やすいらしいので注意が必要であります。

1. **もともとアトピー性皮膚炎や敏感肌を持っている**：アトピー性皮膚炎、花粉症、喘息などがある人は感作しやすい皮膚バリア構造を持っていることが多い。そのため、肌の角質構造が不安定で、外部刺激に過敏に反応しやすかったりする。特に香料や着色料は「分子量が小さく、皮膚に浸透しやすい物質」なので、アトピー肌では通常よりも2〜3倍の感作リスクがあるというデータもあったりする。
2. **同じ製品を毎日使い続けている**：同じものを使っているほうが肌にはやさしそうに思えますが、“経皮感作”のリスクが高まるという点で注意が必要だったりする。経皮感作とは、「皮膚から繰り返し入った物質に対して、免疫が過剰反応を起こすようになること」で、要するに長期的な“蓄積アレルギー”みたいなもの。最初は問題なく使えていても、ある日突然アレルギー症状が出るというのはこのパターンで、とくに香料や保存料に多く、使用年数が長くなるほどリスクが上がるという報告もある。
3. **複数の製品を重ねて使用している**：これも副作用リスクを押し上げる代表的なパターンで、 化粧水→美容液→乳液→化粧下地→ファンデーション→日焼け止め……といった“レイヤリング（重ね塗り）”が当たり前になっている方は、割と要注意だったりする。これは、それぞれの製品に、香料や保存料が個別に入っているため、成分が相互作用して、皮膚への刺激が強くなる可能性があるからである。特に長時間肌に残る製品（ナイトクリームやファンデなど）は経皮吸収されやすい これらの要因が重なることで、副作用が出る閾値を超えやすくなるわけです。
4. **家族や友人とコスメを共用している**：こちらは言わずもがな、細菌・ウイルスの感染経路になるという問題がある。調査によると、約7割の女性がコスメを共有していたという報告もあり、特に「リップ系」「チークブラシ」「アイライナー」など、粘膜や皮脂腺に接触するタイプの製品はリスクが高め。具体的なリスクとしては、「黄色ブドウ球菌や大腸菌の繁殖 → にきび、膿疱の原因」「ヘルペスウイルスの感染 → 口唇ヘルペスなど」「真菌の拡散 → マラセチアによる脂漏性皮膚炎の誘発」などがある。
5. **製品に水や唾液を加えるなどの誤使用をしている**：一部地域では「ドライになったリキッドファンデやアイシャドウに水を加えて復活させる」「口紅に唾をつけてなじませる」といった習慣があるようですが、これらは防腐効果を完全にぶっ壊す行為となる。これをやると、 製品中の保存料の濃度が下がるし、水道水や唾液に含まれる雑菌が混入しやすくなるしで、その結果として腐敗・カビ・異臭が発生したりしちゃう。

このように、「化粧品の副作用リスク」は誰にでも起こりうるんだけど、使い方や体質によって大きく変わるというのがポイント。要するに、化粧品は「合う・合わない」がかなり明確に出る領域なので、「万人に安全なもの」はほぼ存在しないとお考えください。だからこそ、自分の肌の特性や習慣を把握して、ミニマルかつ慎重なアプローチを取ることが大事なんですな。

## **副作用を防ぐために、今日からできる5つのこと**

では、こうしたリスクを減らすにはどうしたらいいか？研究で推奨されていたのは以下のようなポイントであります。

### **1．成分表示を必ずチェックする**

最近の化粧品は、成分表示が義務づけられており、パッケージ裏や公式サイトに全成分が記載されております。ここで必ず香料、パラベン、防腐剤などが含まれていないかを確認しましょう。この時は、「フリー表示」だけに頼らない（例：「パラベンフリー」でも他の防腐剤が入っていることがある）ように心がけ、成分数が少ない製品を選ぶようにしてください。配合成分が少ないほどリスクも減る傾向がありますんで。

### **2. 新しい製品は必ずパッチテストをする**

パッチテストってのは、製品を少量だけ肌に塗り、24〜48時間様子を見るテストです。やり方はとても簡単で、

1. 腕の内側や耳の後ろなど、皮膚が薄くて普段露出しない場所を選ぶ
2. 化粧品を綿棒などで1cm四方に塗布
3. 洗い流さずそのまま放置（ラップで覆ってもOK）
4. 24〜48時間後に赤み、かゆみ、腫れが出ていないか確認

って感じになります。反応が出なくても、本使用時には慎重にしてください（広範囲・長時間になると反応が変わることがあるんで）。また、敏感肌の人は72時間見るのがベターであります。

### **3. 複数の製品を一度に使わない**

スキンケアやメイクアップでありがちなのが、「化粧水→乳液→美容液→下地→ファンデ→ハイライト→チーク」と、何層にも製品を重ねてしまうこと。これが肌にとっては大きな負担になる理由ってのは、

- 各製品の刺激成分が“足し算”ではなく“掛け算”的に効いてしまうことがある

- 皮膚のバリア機能を一時的に壊す可能性がある

- 化学反応で新たなアレルゲンが生まれることも（ごく稀ですが）

ってのがあるからです。これに対策するためには、肌に必要な最小限のステップに絞って「シンプルケア」に切り替えるのがベストでしょう。長時間残る製品（クリーム、ファンデーション）は特に慎重に選んでくださいませ。

### **4. 信頼できるブランド・店舗から購入する**

インターネットの普及により、化粧品をいろんなとこで買えるようになりましたが、その分リスクも増えているとのこと。ここらへんは言わずもがなかもですが、

- 海外通販サイトの非正規ルート品やフリマアプリ、個人売買で出回る開封済み・期限切れ品、露店やディスカウントストアで売られている安価なノーブランドを買ったらあかん！

- 公式オンラインストア、認定販売店で買おうぜ！

ってのをお守りください。くれぐれも成分や製造国が不明な製品は避けるようにお願いいたします。

### **5. コスメの共用はしない**

これも当たり前なんだけど、意外と守ってる人がいないポイントかもですね。「ちょっとチーク貸して」「そのリップ可愛い、使ってみてもいい？」というシーンは、わりと日常的にあるかもですが、これが非常に危険であります。

特に口紅やアイメイク用品は、ウイルスや菌の温床になりやすく、アレルゲンの“他人由来”感作（＝自分では問題なかった成分に急に反応）が起きる可能性もあるんでご注意を。とくにリスクが高いアイテムは、リップ、マスカラ、アイライナー、ファンデのパフ・ブラシ、チューブ型の化粧品（直接肌に触れる設計）になります。どうしても共有したいなら、必ずスパチュラやコットンで取り分けるようにしましょう（それでも推奨はしないですが）。

## **まとめ**

ということで、今回のレビューを見てあらためて感じたのは、化粧品も慎重さが必要だなぁってことですな。特に私のようにアレルギー持ちは、できるだけ少数精鋭のアイテムを使い、できるだけ成分量が少ないものを選ぶのがよさそうであります。

もちろんすべての人に副作用が出るわけではありませんし、成分のリスクも「量と使い方次第」なんですが、肌トラブルが続いている方は、まず一度「今使っている製品の成分表をざっとチェック」してみることをおすすめします。たったこれだけでも、何が自分に合っていないのかのヒントが見えてくるかもしれませんので。ではまた！
