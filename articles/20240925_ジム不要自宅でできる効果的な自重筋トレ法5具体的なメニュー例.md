このシリーズでは、効率の良い自重の筋トレメニューを紹介していきます。というのも、読者さんのなかには「そんなにジムに行けません！」みたいな方も多くいるため、マシンや器具を使った筋トレメニューだと、実践できない人も少なくないんですよね。

前回にで自重トレーニングの推奨エクササイズは紹介し終わったので、今回はここまでの話をふまえた上で、具体的な毎日のトレーニングメニューを紹介します。自重トレーニングだけで体を鍛えたい方は、ぜひ参考にしてください。

## **マクロ・サイクルとマイクロ・サイクルってなんだ？**

具体的なトレーニングメニューを紹介する前に、筋トレのスケジュールを組む上で欠かせない「マクロ・サイクル」と「マイクロ・サイクル」の話をしておきましょう。

マクロ・サイクルとマイクロ・サイクルは、筋トレのスケジュールを作る時に使われる時間の単位です。ざっくりどんな意味かと言いますと、

1. **マクロサイクル**＝長期的な視野でエクササイズのプランを考えていく。通常は**6週間を1単位**として考える。
2. **マイクロサイクル**＝1日／1週間の単位でエクササイズのプランを考えていく。

って感じになります。自重トレーニングで筋肉を増やしたい場合は、6週間ごとにエクササイズの内容を変えていくことが多く、これはだいたい6週間ごとに停滞期が起こる人が多いからであります。たいていの人は6週間で筋肉が変化しづらくなるので、進歩し続けるためには、6週間を過ぎたら変化を起こす必要が出てくるんですよ。

エクササイズを変化させたい時に最もよく使われるのは「トレーニングボリュームの変更」で、1つの運動ごとにトレーニングセットを増やしたり、1つの動作パターンにつきエクササイズを1つ増やしていくのが定番です。

もうひとつは、前回お伝えした「SSTs」を追加して強度を上げる方法で、この場合は、毎日ワークアウトを変えるのではなくて、週のうち1つか2つのワークアウトを変えることから始めるとよい。例えば、週に4日ストレートセットでトレーニングしている場合、そのうちの2日をスーパーセットに置き換えるといった具合ですね。

## **おすすめの具体的な自重トレーニングプラン**

それでは、ここまでの話を押さえたところで、具体的なワークアウトのプランを考えてみましょう。プランの概要は以下の通りです。

- フェーズ1（初級）、マクロサイクルA（6週間）
- フェーズ2（中級）、マクロサイクルA（6週間）
- フェーズ2（中級）、マクロサイクルB（6週間）
- フェーズ3（上級）、マクロサイクルA（6週間）
- フェーズ3（上級）、マクロサイクルB（3週間）

### フェーズ1（初級）

体重、身長、体型は人それぞれ違うので、特定のエクササイズが、他の人より難しく感じられるのはよくあること。初心者が苦手とする一般的なエクササイズは、懸垂とディップスの2つで、特に体重が平均より少し重い人や、手足が長い人は、懸垂をマスターするのに時間がかかるはずであります。

そのため、以下に取り上げるフェーズ1のエクササイズを数レップこなすのに苦労した場合は、もっと簡単なエクササイズを見つける必要があるでしょう。懸垂ができないときはアシスト・バンド懸垂に取り組んだり、足を伸ばしたインバーテッドロウができないときは膝を曲げた状態から始めましょう。

フェーズ1（初級）の1〜2週目は、以下のようなエクササイズを行います。

- １週目＝ワークアウトA：（月、水、金）を行う。
- ２週目＝ワークアウトA：（月、水、金）を行う。

- **ワークアウトA：（月、水、金）**

1. 懸垂： 1セット4～12回を3セット
2. 腕立て伏せ ：1セット4～12回を3セット
3. ランジ ：1セット8～30回（片足4～15回）を3セット
4. プランク：1セット15～60秒を2セット
5. プローン・コブラ：1セット15～60秒を2セット

マイクロサイクル1と2は、自重エクササイズに適応し、一貫性と規律を身につけるために行います。この2週間は入門編なのでで、週3回のトレーニングによって筋肉の成長を促しつつ、体をエクササイズに徐々に適応させていきましょう。

続いて、3週目からは、1つの運動パターンにつき1つの新しいエクササイズを追加します。具体的には、プライオバーピー（下半身）、ディップス（プッシュ）、インバーテッドロウ（プル）の3つです。

新しく増えたトレーニング量を効率よくこなすために、ここからは週4日のトレーニング頻度に切り替え、毎回のトレーニングでプル、プッシュ、下半身、体幹のエクササイズを1つずつ集中的に行いましょう。

- ３週目 ＝ワークアウトA（月曜日、木曜日）とワークアウトB（火曜日、金曜日）を行う。
- ４週目 マイクロサイクル4：3週目を繰り返す
- ５週目 マイクロサイクル5：3週目を繰り返す

- **ワークアウトA（月曜日、木曜日）**

1. 懸垂： 1セット4～12回を3セット
2. 腕立て伏せ：1セット4～12回を3セット
3. ジャンピング・ランジ：1セット10～30回（片足5～15回）を3セット
4. プランク：1セット15～60秒を2セット

- **ワークアウトB（火曜日、金曜日）**

1. ディップス：1セット4～12回を3セット
2. インバーテッド・ロウ：1セット4～12回を3セット
3. プライオバーピー：1セット5～30回を3セット
4. プローン・コブラ：1セット15～60秒を2セット

最後の６週目はデロード・ウィークに使い、トレーニング日数は2日のみに減らします。もっとトレーニングしたいと感じても、次の週に十分なトレーニングをできるように、無理をしないほうがよいでしょう。

- ６周目：デロード・ウィーク

- **ワークアウトA（火曜日）**

1. ディップス： 1セット4～12回を2セット
2. インバーテッド・ロウ：1セット4～12回を2セット
3. プライオ・バーピー：1セット5～30回を2セット

- **ワークアウトB（木曜日）**

1. 懸垂：1セット4～12回を2セット
2. 腕立て伏せ：1セット4～12回を2セット
3. プライオバーピー：1セット10～30回（片足5～15回）を2セット

- **注意事項**：デロード・ウィークの翌週は、最初の2日間のパフォーマンスが少し落ちることがあります。これは、体がワークアウトの量や強度に再調整しているだけなので、デロード前のパフォーマンスを再現しようとして、無理をしないようにしてください。

### フェーズ2（中級）マクロサイクルA

このフェーズは、2つのマクロサイクルで構成されています。このマクロサイクルでは、トレーニング量を増やし（セット数を増やし、新しいエクササイズをいくつか行う）、強度を上げることで、神経筋システムにさらなる負荷をかけていきます。スーパーセットや上り坂スプリントなどのトレーニングテクニックも、ここから加えていくことになります。

フェーズ２（中級）の1〜2週目は、以下のようなエクササイズを行います。

- １週目＝ワークアウトA1、B1、A2、B2を行う。
- ２週目＝ワークアウトA1、B1、A2、B2を行う。

- **ワークアウトA1（月曜日）**

1. 懸垂： 1セット4～12回を3セット
2. 腕立て伏せ：1セット4～20回を3セット
3. プライオバーピー：1セット8～30回を3セット
4. ホロー・ボディ：1セット15～60秒を2セット

- **ワークアウトB1（火曜日）**

1. チェスト・ディップス：1セット4～12回を3セット
2. インバーテッド・ロウ：1セット4～20回を 3セット
3. プライオバーピー： 1セット5～30回を3セット
4. エンジェル・オブ・デス：1セット8～20回を2セット

- **ワークアウトA2（木曜日）**

1. 上り坂または階段スプリント： 1セット30秒を3セット（各スプリント間に2～3分憩）
2. 懸垂： 1セット4～12回を3セット
3. 腕立て伏せ：1セット4～20回を3セット
4. ホロー・ボディ：1セット15～60秒を2セット

- **ワークアウトB2（金曜日）**

1. 上り坂または階段スプリント： 1セット30秒を3セット（各スプリント間に2～3分休憩）
2. ディップス：1セット4～12回を3セット
3. インバーテッド・ロウ：1セット4～20回を3セット
4. エンジェル・オブ・デス：1セット8～20回を2セット

- **注意点１**
  トレーニングに高強度のランニングを取り入れることができない場合は、フェーズ１のやり方に基づいて下半身のトレーニングを続け、プライオバーピーとジャンピングランジを交互に行いましょう。
  つまり、ワークアウトA2とB2を高強度のランニングで始める代わりに、それをスキップして、体幹エクササイズの前に、3番目のエクササイズとしてジャンピング・ランジかプライオ・バーピーを加えます。

- **注意点２**
  肩のトレーニングを優先させたいのであれば、通常の腕立て伏せをパイク腕立て伏せに変えてもOK（その後、逆立ち腕立て伏せに発展させていく）。チェスト・ディップスは、プッシュ系エクササイズで鍛えられる筋肉をかなりカバーしているので、さらにボリュームを増やしても良いでしょう。

続いて、3週目からはスーパーセットを追加し、ランニング量を増やしていきましょう。これらの週では、ほとんどのエクササイズにスーパーセットを追加し、強度と代謝ストレスを高めて体に負荷をかけます。

- ３週目 ＝以下のワークアウトA1、B1、A2、B2を行う。
- ４週目 ＝3週目を繰り返す
- ５週目 ＝3週目を繰り返す

- **ワークアウトA1（月曜日）**
- 1. 懸垂と腕立てのスーパーセット（3セット）
  - a) 懸垂 4～12回
  - b) 腕立て伏せ 4～20回
- 2. プライオ・バーピーとホロー・ボディのスーパーセット（3セット）
  - a) プライオ・バーピー： 8～30回
  - b) ホロー・ボディ：15～60秒

- **ワークアウトB1（火曜日）**
- 1. チェスト・ディップスとインバーテッド・ロウのスーパーセット（3セット）
  - a) チェスト・ディップス：4～15回
  - b) インバーテッド・ロウ：4～20回
- 2. プライオ・バーピーとエンジェル・オブ・デスのスーパーセット（3セット）
  - a) プライオ・バーピー： 5～30回
  - b) エンジェル・オブ・デス：8～20回

- **ワークアウトA2（木曜日）**
- 1. 上り坂または階段スプリント：1セット30秒を4セット（各スプリント間に2～3分休憩）
- 2. 懸垂と腕立てのスーパーセット（3セット）
  - a) 懸垂： 4～12回
  - b) 腕立て伏せ：4～12回
- 3. ホロー・ボディ：1セット15～60秒を3セット

- **ワークアウトB2（金曜日）**
- 1. 上り坂または階段スプリント：1セット30秒を4セット（各スプリント2～3分休憩）
- 2. チェスト・ディップスとインバーテッド・ロウのスーパーセット（3セット）
  - a) ディップス：4～15回
  - b) インバーテッド・ロウ： 4～12回
- 3. エンジェル・オブ・デス：1セット8～20回を3セット

最後の６週目はデロード・ウィークに使い、高強度のランニングから体を完全に休ませ、筋力の維持に集中しましょう。レップ数を20％ほど減らし（懸垂10回を8回にするなど）、走りに行きたくなったら15～20分のジョギングをします。心拍数は140回/分以下に抑え、平らな柔らかい地面（土や芝生など）で行いましょう。

- ６周目：デロード・ウィーク

- **ワークアウトA（火曜日）**
  - 1. チェスト・ディップス：1セット4～12回を3セット
  - 2. インバーテッド・ロウ：1セット4～12回を3セット
  - 3. プライオ・バーピー：1セット5～30回を2セット
  - 4. エンジェル・オブ・デス：1セット8～20回を3セット

- **ワークアウトB（木曜日）**
  - 1. 懸垂： 1セット4～12回を3セット
  - 2. 腕立て伏せ：1セット4～12回を3セット
  - 3. プライオ・バーピー：1セット10～30回（片足5～15回）を2セット
  - 4. プランク：1セット15～60秒を2セット

### フェーズ３（上級）マクロサイクルA

フェーズ３（上級）マクロサイクルAの1〜2週目は、以下のようなエクササイズを行います。

- ２週目＝フェーズ２マクロサイクルBのワークアウトを行う。

- ３週目 ＝以下のワークアウトA1、B1、A2、B2を行う
- ４週目 ＝3週目を繰り返す
