# 「強み」活用大全＃3「強みってそもそもどういうことなの？」

このシリーズは、**あなたが持つ「強み」を活かす方法を掘り下げる内容**になっております。「強みを活かそう」とはよく言うものの、類書などを読んでみると、**意外と「そもそも強みとはなんぞや？」ってとこを掘り下げたものが少ない**ので、ここらへんを押さえておくと「ストレングスファインダー」などの効果も出やすくなるはずであります。

## **帆船のメタファーで問題解決力が上がる理由**

で、[前回](https://daigovideolab.jp/blog/2081965)はマストリヒト大学などの先生方が考案した「**帆船のメタファー**」の全要素を見てみました。このメタファーは**人間の複雑な心理の構成要素**をまとめて表現してまして、自分の人生にトラブルが起きたときに「どこをどうすれば問題が解決するのか？」を判断するのに役立つんですよ。

たとえば、ヨットのメタファーがどのように問題点の整理に役立つかと言いますと、

- 弱点（04.水漏れ）を無視して強み（05.帆）を強調すると、ヨットに勢いがつくが徐々に沈んでしまう。つまり、強みを活かしつつも弱点に対処していく必要もある

- 個人的な価値がある方向に航海しているヨット（03.舵輪）は、価値がない方向に航海しているヨットに比べて、荒天（06）でも軌道を維持できる可能性が高くなる。

- コンフォートゾーンを離れることへの恐れ（02.方位磁石）から、別の方向（03.舵輪）を選ぼうとしないヨットは、新しい海（01.海）を航行することができない。これは、心理学の世界でよく言われる「ネガティブな感情を回避しても変化が出ない」という現象を表している。

- 海の状態（穏やかだったり荒波だったり）は、天気（06）のようにコントロールできない状況だけでなく、別の方向に向かうヨット（03.舵輪）によっても影響を受ける。他の船の動きによって、ヨットは一時的な乱流や、岩場、危険地帯などに入るかもしれない。
  同様に、他のボート（07）がこちらの航行ルートをさえぎり、自分が向かいたい方向に行けなくなることもある。これらの例は、内的および外的な要因によって、現実が影響を受けることを示している。

- 新しい航行ルートの中で「自分でコントロールできないのはどこだろう？」と考えてみると、人生のトラブル回避に役立つことがある。例えば、「お酒をやめるぞ！」と決めた人は、同僚（07.他の船）に「そんなの意味ないから飲もうぜ！」と言われるかもしれない。そんな時は、他の船に「同じ方向に進もうぜ！」と説得しても意味がないので、「水漏れや帆のように自分がコントロール可能な要素は何か？」と考えた方が良い解決策を思いつきやすくなる。

といった感じになります。このように、メタファーを使いながら自分の人生に起きたことを考えていくと、**問題から感情的な距離を置くことができる**ので、[脱フュージョン](https://yuchrszk.blogspot.com/2016/10/2016.html)に近い効果を得られるんですよ。感情との距離は分析の基本ですからね。

もし何らかのトラブルが起きたら、以下のような感じで、自分が置かれた現状をメタファーで表現してみるのがおすすめです。

- なんか最近ボートが動いている気がしないんだよなぁ……。海の一点に浮かんでいて、波に揺られてるだけというか（人生の意味や自律性の欠如を経験していると思われる）

- 他の船員が指示している方向に航海しているだけのような気がするなぁ……（高い社会的圧力と自律性の欠如を経験していると考えられる）

- 自分の船って水漏ればっかり起きてる気がするなぁ……（自分の問題に過度に集中しているのかもしれない）

- 自分の船が、これからやってくる荒天に耐えられるか心配……（自己効力感が低く、自分の対処能力に疑問を持っている状態だと考えられる）

実は、こんな感じでメタファーの使用に慣れていくと、**少しずつ問題解決の能力が鍛えられていく**ことがわかってたりします([R](https://link.springer.com/chapter/10.1007/978-94-015-9307-6_11?noAccess=true))。というのも、メタファーを使っていると、**私たちは自分自身についてのメタ視点を作れるようになり**、問題をより大きくて異なる視点から捉えることができるようになるんですよ。「あー、いま自分は特定の問題（船の水漏れとか）に集中しすぎて、価値に向かう作業を犠牲にしているんだなぁ」みたいな感じですね。

## **帆船のメタファーを実際に使う前に「強み」を深堀りしておこう**

ってことで、メタファーの重要性を理解できたところで、いよいよ実践編です。帆船のメタファーを使って、あなたの「強み」を存分に発揮する方法を具体的に見ていくわけですが、その前に、もうひとつ重要な論点である「**強みってそもそもどういうことなの？**」ってところを深堀りしておきましょう。自己啓発書とかだと「皆さまご存じ！」みたいなノリで「強み」って言葉が使われますけど、

- そもそも「強み」って学問的にどういう定義をされているの？

- 「強み」の研究ってどこまで進んでいるの？

ってあたりは意外と明確じゃなかったりしますからね。そもそもの「強み」がどういった特性なのかを知らないと、いくらテクニックを身に着けてもしょうがないですから。

### **「強み」の定義とは？**

「「強み」ってなに？」って問題については、実は現状で「これで決まり！」みたいな定義があるわけではなく、**複数の解釈が乱立している状態**だったりします。例えば、

- ストレングスファインダーの創始者([R](https://amzn.to/3KtmtQS))は、人の強みを「**才能、知識、実行力の組み合わせ**」と定義している。ここで言う才能とは、自然に繰り返される思考、感情、行動のパターンのことで、知識とは学んだ事実や教訓を意味し、実行力はある活動を行う能力のことである。

- ポジティブ心理学の父であるセリグマン([R](https://www.viacharacter.org/research/findings/character-strengths-and--well-being-happiness))は、「性格的な強みとは、**思考、感情、行動に反映されるポジティブな特性**だと定義できる。それらは個人差として測定することができる」と定義している。

- ポジティブ心理学応用研究所のアレックス・リンリーは、「強みとは、**特定の行動様式、思考様式、感情様式のための既存の能力**であり、使用者にとっては真正で活力に満ちたものであり、最適な機能、発達、パフォーマンスを可能にするものである」と定義している([R](https://amzn.to/3pMLMp0))

みたいな感じですね。専門家によっても割と定義が違っているのがおわかりいただけると思います。

まぁ「強みとは、最適なパフォーマンスを可能にする個人の特性である」という考え方は全体的に共通してるので、ここでは、アレックス・リンリー先生の強みの定義を採用しようかと思います。強みを構成する重要な要素が一番明確に示されてますからね。

### **「強み」が眠ったままの人はとても多い**

リンリー先生による「強み」の定義をもう少し細かく言うと、こうなります。

- 「強み」は外から獲得するものではないため、**多くの人の「強み」は幼少期から確認される**ことが多い

- ただし、みなが自分の強みを適切に使ったり、伸ばしたりしているわけではなく、自分の強みを毎日使っている人がいる一方で、**相対的に強みが眠ったままの人**もいる

- 「強み」は「本物感」をともなうことが多い。これは、自分の強みを使ったときに感じられる「**なんか本当の自分のような感じがする！**」って感覚のを意味する。言い換えれば、「強み」を使っているときの自分は自然体な存在であり、人によっては「これが天命だ」と感じることもある

- 「強み」を使う行為は、一般にエネルギーをもたらしてくれる。これは「強さ」の最も重要な特徴のひとつでであり、「弱み」が自分を消耗させるのに対して、「強み」は自分にエネルギーを与えてくれる

- 「強み」を使うことは、最適な発達とパフォーマンスを促進する傾向がある。「強み」を発揮すると、自分がやっていることを楽しめるケースが多く、そのため「活動の結果」とりも「プロセス」に集中できるようになる。このような「内発的な動機」がブーストする結果、高いレベルのパフォーマンスを達成することができる。

というわけで、「強み」は生まれ持ったポジティブな特性のことで、使えば使うほどパフォーマンスを最適にしてくれる特性があるのだ、と。にも関わらず、「強み」を意識して使っていない人は意外なほど多いそうで、これはいかにももったいない話ですなぁ。

帆船のメタファーに例えれば、「強みを活かす」ってのは帆が風を受けて進む状態に似ております。船の帆を効果的に使うことができる船長は、船をフルスピードで航行させることができますからね。風の力（06.出来事）を利用して目的地へ高速で移動しているのが、強みを生かしている状態と言えましょう。

逆に、船の帆がなかったら、船はどこにも行けずに水に浮かんだままになっちゃうのは間違いないところ。帆があるからこそ船は良い方向に進めるように、「強み」があるからこそ人生が豊かにできるわけですね。

### **「強み」ではないものも押さえておこう！**

ちなみに、ここでよくある間違いが、「強み」を、才能、スキル、価値観、興味などと混同してしまうパターンです。まぁ学術的に明確な「強み」の区別があるわけじゃないので、まだ議論の余地はかなりあるんですけど、たとえば「創造性」とか「感謝」みたいな「強み」と、「IQ」や「絶対音感」みたいな才能とはちゃんと区別しておいたほうがいいでしょう。

具体的には、こんな感じです。

- **才能**：生物学的な基盤がしっかりし存在しており、かなりのところまで遺伝に左右されるもの（例：知能、絶対音感、運動能力など）。
- **スキル**：訓練によって培われた特定の能力のこと（例：商売を学ぶこと、コンピュータスキル、リサーチスキルなど）
- **興味**：個人が情熱を持って追求したいと思う分野やテーマのこと（例：スポーツをする、特定の趣味に没頭する、芸術にいそしむなど）
- **価値観**：とは、その人にとって最も重要な永続的な信念、原則、または理想のこと

以上の要素に対して「強み」ってのは、「こういう行動をしているとなんだか気分がいいなぁ」とか「こういう考え方をするとやる気が出るなぁ」といった感じで、「内発的な動機」の向上につながっていくのがポイントであります。ここらへんを区別しておかないと、あとで自分の強みを探す際にとまどっちゃうだろうからご注意ください。
