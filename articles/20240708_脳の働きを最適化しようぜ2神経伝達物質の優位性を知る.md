# 脳の働きを最適化しようぜ！#2「神経伝達物質の優位性を知る」

![記事内画像](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F20240708post-127%2Fbd1f0c0f-50a1-4d21-8b78-9cd9b930573d.jpg?alt=media&token=bd1f0c0f-50a1-4d21-8b78-9cd9b930573d)

「**脳の最適化**」シリーズの続きです！([#1](https://daigovideolab.jp/blog/20240706post-113))

脳の最適化ってのは、文字通り自分の脳が万全に働いている状態のこと。脳の神経系と身体の間のコミュニケーションがスムーズに行われ、「なんか元気！」や「なんか生き生きしてる！」みたいな感覚が強い状態を目指そうって話であります。

このようなテーマは今までもしてきましたが、「**体に良いことをたくさん****やってるのに成果が出ない！**」という方は、「**脳と身体の連携**」がうまく取れていないケースが多いんですよ。

そこで、このシリーズでは、あなたの脳のポテンシャルを発揮させるために、いろんなフィックスを取り上げていきます。前回からは“脳の中枢神経系の疲労”をやわらげる方法を考えてまして、その第一歩として「**神経伝達物質の優位性を判断しよう！**」って話をしております。

## **脳の配線を変える方法１. 神経伝達物質の優位性を判断する（続き）**

前回お伝えしたとおり、人間の脳のなかでは、いくつかの神経伝達物質が常に飛び交い、あなたの行動や健康状態を決めております。なかでも重要なのは、**ドーパミン、****アセチルコリン、****GABA、****セロトニン**の4つで、どの神経伝達物質が優位になるかは、生まれつきの性質やライフスタイルで決まります。

**ほとんどの人は、特定の神経伝達物質の濃度が高くなる傾向**があり、その違いによって気分や行動を左右されるようになったりするんですよ([R](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9987524/))。

それでは、前回に行ったテストの結果をもとに、あなたが持つ「**神経伝達物質の優位性**」について考えて行きましょう。

## **優位性１．ドーパミン優位**

ドーパミン優位は、人口の17％が当てはまると考えられております。ドーパミンが適切に出ている人は、自分の欲求をちゃんと理解し、意志の強い人である可能性が高め。

その他、ドーパミン優位な人の特徴としては、

- 自信に満ちて理性的
- 感情や感覚よりもファクトや数字を扱うのが得意
- 自分のことを批判的に見るのもうまい
- 他人の批判にはあまり反応しない
- 目の前の仕事に集中するのがうまい
- 戦略的思考と問題解決がうまい
- ストレス下でもうまく機能する
- 多動すぎて、ひとつの目標を達成できないこともある
- 有酸素運動に飽きやすく、HIITみたいに高負荷な運動や筋トレを好む

そのため、ドーパミン優位の人には、医師、研究者、発明家、技術者、建築家などが多め。なかなか素晴らしい特性ですね。

ただし、これがうまく行ってるときはナイスなんだけど、ここでドーパミンが過剰になりすぎると、以下のような問題が起きやすくなります

- 衝動的な行動に走り、自分の限界を超えてしまう
- 肉体的にも精神的にも燃え尽きてしまう
- ドーパミンの効きが悪くなるため、疲労感、だるさ、記憶力の低下、抑うつ状態が起きる
- 過剰にリスクを取ろうとする
- 暴力や他者を支配する気持ちが増える

- 性行為に依存しやすくなる

そのため、ドーパミン優位な人は、常に適度なバランスを保つよう心がけてください。具体的には、以下のポイントを守ると良いでしょう。

- ****ドーパミンが過剰な場合****
  - **カフェイン制限:**カフェインはドーパミンの放出を促進するため、摂取量を減らす。
  - **アルコール制限:**アルコールもドーパミンのレベルを影響するため、節度を持って飲む。
  - **リラクゼーション技術の徹底**: 深呼吸、瞑想、アロマセラピーなどを活用してストレスを軽減。 リラックスできる趣味や活動を見つける。
  - **有酸素運動**: ジョギングやウォーキングなどの有酸素運動はストレスを軽減し、脳のバランスを保つのに役立つ。
  - **乳製品を減らす**：ドーパミンの原料となるのは「チロシン」というアミノ酸は、乳製品に多くふくまれるので。

- **ドーパミンが少ない場合**
  - ビタミンB複合体、ロディオラ、イチョウ葉などのサプリを飲む
  - 鶏肉、カッテージチーズ、卵、豚肉、七面鳥、ナッツ類、小麦胚芽、オート麦、牛乳、ヨーグルトなどを食べる
  - カフェインを摂取する

## **２．アセチルコリン優位**

アセチルコリン優位の人は、五感が敏感で、創造性に富み、新しいアイデアを受け入れられるケースが多め。だいたい以下のようなメリットがあると考えられております。

- どんな状況でも最善を尽くすことができる

- 考え方が柔軟で創造的、自発的でもある

- 高強度な高ボリュームな運動に対応できる

- 世界を感覚的にとらえるのがうまい

- 頭の回転が速く、常に他人を気遣うことができる

- 言葉やアイデア、コミュニケーションに関わることに喜びを感じる（アセチルコリンは、言語、知性、理解力をつかさどる脳の頭頂葉で多く生成される）
- 楽観主義者で、人の中に可能性を見出す

- 利他的で博愛的
- 新しいことにオープンで失敗を恐れない

ということで、このタイプは、カウンセラー、シンクタンクのメンバー、ヨガや瞑想のインストラクターなどの職業についているケースが多め。また、アセチルコリンのレベルが高いと、脳のスピードが上がって創造性がブーストされるので、芸術家、作家、広告の専門家などもアセチルコリン優位であることが多かったりします。

ただし、これがうまく行ってるときはナイスなんだけど、ここでアセチルコリンが過剰になりすぎると、以下のような問題が起きやすくなります

- 自分の欲求を顧みずに脳そうする

- ひとつの物事に対してのめり込みすぎて消耗する

- 世界が自分を利用していると感じたり、被害妄想のような状態に陥ったりする

- 妄想が高じて社会的に孤立する

- パニック障害、躁病、不安神経症のリスクが上がる

そのため、アセチルコリンが優位な人は、この物質が増えすぎないように心がけてください。具体的には、以下のポイントを守ると良いでしょう。

- ****アセチルコリンが過剰な場合****
  - コリンを多く含む食品（例：卵、レバー、大豆製品など）の摂取を控える
  - カフェインは神経系に刺激を与えるため、摂取量を減らすことでアセチルコリンの過剰を抑える助けになる
  - 瞑想、ヨガ、深呼吸などのリラクゼーション技術は、ストレスを軽減し、アセチルコリンのリバランスにも役立つ
  - カフェインを高用量で摂取し、ロディオラ・ロゼアやバコパ・モニエリと組み合わせることでアセチルコリンの過剰が抑えられる可能性がある

- ****アセチルコリンが少ない場合****
  - コリン、ホスファチジルコリン、アセチル-L-カルニチン、高麗人参などのサプリを飲む
  - 卵、ナッツ類、コールドプレスオイル、アボカドなど、健康的でコリンが豊富な脂肪源を多く含む食事を摂る
  - 1日4g以上のフィッシュオイルを飲む

## **３．GABA優位**

GABAは抑制性の神経伝達物質なので、こいつが優位の人は、ストレスの多い状況でも平静を保ち、自信に満ちた状態で行動できるケースが多め。不確実が少ない組織や厳格なスケジュールを好み、制度や伝統に惹かれる人も多いでしょう。

GABAが優位な人には、だいたい以下のようなメリットがあると考えられております。

- 情緒が安定している
- 他人や自分の怒りに動じない
- 平和を好む
- 人を育てるのが得意
- 思いやりがある
- 時間をちゃんと守る
- 整理整頓がうまい
- 周囲の人間関係に安定をもたらすことに喜びを感じる
- のんびりとしたアウトドア活動やスポーツを楽しめる

GABA優位な人の数は、全人口の半分を占めると考えられてまして、会計士、警備員、医療技術者、報道記者などの職業につくケースが多め。

さらに、GABA優位な人は、どんな仕事においても、グループをまとめ、チームプレーヤーとして働くのが上手。常識的で落ち着きがあり、感情の起伏が激しかったり、怒りを爆発させたりすることもないタイプであります。

ただし、これがうまく行ってるときはナイスなんだけど、ここでGABAが過剰になりすぎると、以下のような問題が起きやすくなります

- 自分のニーズを無視して他人のために尽くす

- 集団のために身を捧げすぎて傷ついてしまう

- 愛情を求めることにエネルギーを使いすぎ、相手に頼りすぎる

- 権威的な人物にアドバイスを求めすぎて、搾取されてしまう

- 他人の助言を求めすぎて、自分の意見がなくなってしまう
- ハードな運動をするモチベーションがなくなる

そのため、GABAが優位な人は、この物質が増えすぎないように心がけてください。具体的には、以下のポイントを守ると良いでしょう。

- ****GABAが過剰な場合****
  - GABAを多く含む食品（例えば、発酵食品やトマト缶詰、野菜ジュース）の摂取を控える
  - タウリン、L-テアニン、ビタミンB6、マグネシウムなどのサプリを飲む
  - プチ断食は、体内の自律神経のバランスを整える効果があり、GABAの過剰な活動を抑える可能性がある
  - 温冷交代浴（サウナと冷水浴の交互利用）は、自律神経の調整に効果があり、GABAのバランスを整えるのに役立つ……かも

- ****GABAが少ない場合****
  - メラトニン、フェニバット（夜用）、バレリアンルート、パッションフラワーなどのサプリを飲む
  - サケ、鶏肉、豆腐、ジャガイモ、バナナ、アボカド、ほうれん草、ブロッコリーなどを食べる
  - キムチ、ザワークラウト、味噌、テンペ、ヨーグルトなどの発酵食品を食べる
  - 緑茶、白茶、ウーロン茶を飲む

## **４．セロトニン優位**

セロトニン優位の人は、感覚への刺激に敏感で、やや衝動的で、変化や目新しさを好む人が多め。映画、パーティー、ゲームなどに惹かれる傾向があり、ギャンブル、山登り、狩猟、スカイダイビングなどのエクストリームなスポーツも好きな人が多いですね。

セロトニンが優位な人には、だいたい以下のようなメリットがあると考えられております。

- 休息を取るのがうまい
- マインドフルに生きるのがうまい
- くり返しの仕事に新しい方法を見つけたりするのがうまい
- 心身ともに調和を取るのがうまい
- 挫折にめげない人が多い
- 人間関係に情熱的
- 明るく、楽観的で、気さく

- 同僚、友人、家族に対して優しい

- 広い人間関係を持っている

このような特性があるため、セロトニン優位な人は、建設作業員、石油採掘作業員、バーテンダー、パイロット、コンピュータープログラマーなど、専門のツールを使って働く職業で能力を発揮するケースが多いと考えられております。

ただし、これがうまく行ってるときはナイスなんだけど、ここでセロトニンが過剰になりすぎると、以下のような問題が起きやすくなります

- 衝動的で新しい経験への欲求が強いので、ものごとを深く知る前に次に行ってしまう

- 秩序やルーティンを軽んじる傾向があるため、他人に迷惑をかける

- 自立を愛するがゆえに、親密な人間関係に負担をかけることがある

- 神経質で注意散漫になる

- 極端な感情に陥りやすくなる

- 対人関係で自暴自棄になることがある

- 批判に弱くなり、嫌われることを病的に恐れるようになる

- 痛々しいほど内気で、自分を不十分で劣った存在とみなすことがある

そのため、セロトニンが優位な人は、この物質が増えすぎないように心がけてください。具体的には、以下のポイントを守ると良いでしょう。

- ****セロトニンが過剰な場合****
  - チキン、ターキー、サーモン、卵、乳製品、ナッツ、種子、豆類などを控える
  - ホットヨガやサウナに入ることで、体内のセロトニンレベルが調整されることがある。
  - コメディ映画を見たり、友人と笑い話をしたりすることで、セロトニン過剰の症状がやわらぐ可能性がある
  - 絵を描いたり、クラフトを作ったりするアートセラピーもセロトニンのバランスを改善するのに効果的だと考えられる。

- ****セロトニンが少ない場合****
  - フィッシュオイル、5-HTP、マグネシウム、セイヨウオトギリソウ、トリプトファンなどのサプリを飲む
  - チキン、ターキー、サーモン、卵、乳製品、ナッツ、種子、豆類などを食べる
  - ブロッコリー、バナナ、オレンジ、トマトなどを食べる
  - 毎日15分程度の日光浴をする
  - 有酸素運動をする
