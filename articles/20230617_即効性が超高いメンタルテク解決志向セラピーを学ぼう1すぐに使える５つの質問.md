# 即効性が超高いメンタルテク「解決志向セラピー」を学ぼう！#1「すぐに使える５つの質問」

## **即効性が超高いメンタルテク「解決志向セラピー」とは？**

これは1980年代に家族療法の分野から生まれた心理療法で、スティーブ・デ・シェイザー博士などが開発したもの。名前のとおり「**問題よりも解決策を話し合おうぜ！**」って考え方をベースに置いたセラピーです

この考え方を理解するために、「会社の製造マシンが壊れた！」という状況を考えてみましょう。マシンがないと仕事が進まないので、周囲の同僚に相談してみたところ、みんなは以下のような答えを返してきたとします。

- 同僚A「具体的に、機械のどの部分が壊れたのかを考えようぜ！」
- 同僚B「まずはマシンの仕組みを詳しく理解しないとなぁ……」
- 同僚C「その機械は、どこのメーカーが作ったんだっけ？」
- 同僚D「そんな壊れやすい機会を導入したのは誰だ？」

これらの返答を前に、あなたは「どいつもこいつも解決策を出さないな！」とイライラしはじめました。「この状況では、問題をこねくりまわすよりも、新しい機械を買っちゃえば問題は一気に解決するのに！その予算の話をしようぜ！」みたいな感じですね。この事例では、機械が壊れた理由を理解することよりも、新しいマシンを購入することの方がはるかに重要なはずであります。

この事例の同僚のようぬ、何らかのトラブルに出くわしたときに、「この問題にはどんな由来があるのか？」「この問題の細部はどうなっている？」といったポイントにこだわってしまう人は多め。しかし、私たちが実際に求めているのは「解決」なんで、トラブルがどのように起きたかを知っても意味がなかったりするんですよ。

ってことで、「解決志向セラピー」は、「問題がなぜどのように生じたか？」ではなく、とにかく目の前の問題を解決しようぜ！ってところに注力する心理療法になります。従来のセラピーとは違って「私の問題はどこから始まって、その問題が私の人生にどのような影響を及ぼしているのか？」ってあたりにはこだわらないので、「統合失調症や大うつ病性障害といった大きな問題には向いてない」って問題はあるんですが、その代わりに、「**メンタルの問題を解決するスピードが速い**」って特徴を持っております。

そのため、あまりに大きなメンタルの問題には適さないものの、以下のような問題に取り組むには、非常に有効であることがわかってたりします([R](https://www.tandfonline.com/doi/full/10.1080/01926187.2022.2069175))。

- 気分の落ち込み
- 感情のマネージメント
- 人間関係の問題
- コミュニケーションの障害
- SNS、薬物、アルコールなどへの依存
- 摂食障害

「コミュニケーションがうまくいかないなぁ」「ダメとわかっててもつい怒っちゃうなぁ」「なんかいつも気分がヘコんでるなぁ」ぐらいの問題にお悩みの方は、「解決志向セラピー」に取り組んでみるのもいいんじゃないでしょうか。

## **「解決志向セラピー」では何を目指すのか？**

そこで、「とにかくスピーディに問題を解決する！」って目標を達成するために、「解決志向セラピー」では、以下のような前提をベースに置いております。

1. すべてのことは常に変化する
2. 私たちは「変えられるもの」だけに重点を置くべきである
3. 問題に苦しむ人は、みんな自分で問題を解決する能力を持っている
4. 問題の解決は、未来に焦点を当てなければならない（問題の歴史にはこだわらない）

これらの前提に基づき、「解決志向セラピー」では、以下のような方向性で問題の解決に取り組んでいきます。

1. 「質問」を駆使することで、自分なりの解決策を探る。
2. 自分の肯定的な資質、強み、リソースに気づき、それを強化する。
3. できないことに目を向けるのではなく、できることに目を向ける。
4. 自分がすでに取り組んでいる解決策のなかで、どこが本当に有用なのかを特定し、さらに効果的な解決策に発展させる。
5. 問題ではなく、解決策の詳細に焦点を当てる。
6. 具体的なアクションプランにまで落とし込む。

あくまでゼロから新しい対策を構築しようとするのではなく、**私たちがすでに持っているスキル、強み、能力を引き出していく**のが「解決志向セラピー」の大きな目標のひとつ。あくまで自分がすでに持っている能力を使いこなすのがポイントなので、それゆえに短時間で効果が出やすいわけですね。

## **「解決志向セラピー」で使われる５つの質問**

以上をふまえたうえで、ここから「解決志向セラピー」でよく使われるテクニックをまとめていきます。いずれも、手軽に使えて効果が高いものが多いので、気になったものがあれば試してみてくださいませ。

### ****解決志向セラピーのテクニック１．**ミラクルクエスチョン**

これは、以前にブロマガでも紹介した技法ですが、「解決志向セラピー」のド定番なので、あらためて取り上げておきましょう。心理療法士のスティーブ・デ・シェイザー博士が開発したもので、なにか問題が起きたら、以下の質問について考えてみるだけでOKです。

> 今晩あなたが眠っている間に、奇跡が起こったと想像してください。奇跡とはあなたが抱えている問題がすべて解決してしまうというものです。ただ、あなたは、眠っていたので問題が解決していることに気が付きません。明日の朝、どのような違いがあることで、奇跡が起こって問題が解決したことが分かるでしょうか？

って、これだけ読むとバカみたいな質問のようですが、ここで最も大事なのは、いつもの生活や目の前の問題をいったん棚上げしておいて、「自分の理想となる人生は？」「自分が希望する目標とは？」ってあたりを掘り下げるところです。奇跡を仮定することにより、日常生活では気づきづらい自分の欲求に気づき、本当にやりたい事を探していくわけですな。これにより人生の方向が定まり、よりよい解決策の発見につながるわけです。

ちなみに、この質問について考えた後は、でてきた答えを文章かイラストで書き残しておくのがおすすめです。これによって、自分の人生の欲求や方向性が脳にすりこまれますんで。

### ****解決志向セラピーのテクニック２．****変化を前提とした質問

「変化を前提とした質問」も解決志向セラピーでは定番のテクニック([R](https://link.springer.com/book/9781403945136))。名前のとおり、「すでにその問題が解決／改善していたら？」という前提をベースにした質問で、ミラクルクエスチョンと同じように、自分の本当の欲求や自分が持つ人生の方向性を掘り下げることができるんですな。

こちらも実践は簡単で、なにか問題が起きたら、以下の質問について考えてみるだけでOKです。

- いまの問題が、もっとひどいことになっていないのはなぜだろう？

- 完全な大失敗が起きるのを防いだ要素は何だろうか？

- どうやってメンタルがどん底に落ちるのを避けられたのだろう？

- 自分を完全な失敗から遠ざけたものはなんだろう？ 誰のおかげだろう？

- いまの問題が起きたときよりも、良くなったことはなんだろう？

って感じで考えてみて、なにかよい答えが見つかったら、その答えを「いまの問題の解決策として使えないか？」と思案していくわけです。こちらも定番の手法なので、ぜひお試しください。

### ****解決志向セラピーのテクニック３．****例外の質問

こちらも解決志向セラピーでは定番のテクニックで、なにか問題が起きたら、以下の質問について考えてみるだけでOKです。

1. 似たような問題に遭遇したときに、私が怒らないのは、どのようなときだろうか？
2. 私が最も幸せを感じるのは、どのようなときだろうか？
3. 最近、「良い一日を過ごせた」と感じたのはどのようなときだろうか？
4. 人間関係で、最も幸せを感じたのはどのようなときだろうか？
5. 問題が起きた日に、なにかよいところはなかっただろうか？
6. 自分の人生に「まったく問題がない」と感じられたのは、どのようなときだろうか？

### ****解決志向セラピーのテクニック４．**スケーリングの質問**

これは、自分の経験を評価したり、自分の経験を変えたい動機を評価したりするために使う質問です。なにか問題が起きたら、以下の質問について考えてみてください。

1. 10点が最高、1点が最低だと考えたときに、今日の自分は何点だろうか？
2. （もし４点だと考えたら）なぜ私は5点ではなく、4点だと判断したのだろうか？

このように考えていくことで、たいていの人は、いまの問題にふくまれるポジティブな部分と、どのような変化を起こすべきかを探ることができるわけです。こちらも、シンプルな問題にはかなり使える手法なので、お試しくださいませ。

### ******解決志向セラピーのテクニック５．****コーピングクエスチョン**

こちらは、自分がどれぐらいの回復力を持っているのかを掘り下げる質問です。これによって、「あ、意外と自分は対処力を持っているんだな」ってとこに気づき、より良い問題解決を生み出せるわけであります。

1. 私は、これまでどのように人生を管理してきたのだろうか？
2. 私は、これまでの人生をどうにか成り立たせるために、なにをしてきたのだろう？
3. 私の人生で、うまくいっていることはなんだろうか？

というわけで、今回は「即効性が高い心理療法」として知られる「解決志向セラピー」の基本を見てみました。このシリーズはまだ続きまして、次回は、さらに「解決志向セラピー」の重要テクを見てみましょうー。ではまた！
