# 未来を生き抜く最強のソフトスキル「好奇心」を爆上げしようぜ！#11「クイックサンディング」

「好奇心を爆上げしようぜ！」シリーズの続きでーす([#1](https://daigovideolab.jp/blog/20240623post-61),[#2](https://daigovideolab.jp/blog/20240623post-65),[#3](https://daigovideolab.jp/blog/20240624post-71),[#4](https://daigovideolab.jp/blog/20240626post-86),[#5](https://daigovideolab.jp/blog/20240626post-90),[#6](https://daigovideolab.jp/blog/20240628post-101),[#7](https://daigovideolab.jp/blog/20240630post-104),[#8](https://daigovideolab.jp/blog/20240704post-110),[#9](https://daigovideolab.jp/blog/20240712post-139),[#10](https://daigovideolab.jp/blog/20240714post-143))。

このシリーズでは、スコット・シゲオカ先生の知見をベースに、私が「現代における最重要ソフトスキル」である“**好奇心**”を鍛える方法を考えております。

で、前回は、好奇心に必要な「DIVEモデル」の３つめの要素である「Value（価値観）」の解説が終わりまして、今回はその続きとして４つめの要素である「**Embrace（受け入れる）**」を掘り下げていくことにします。

## **E：受け入れる（Embrace）**

「受け入れる」ってのは、人生の困難にじっくりと向き合い、見つめる訓練をすることです。加齢や病気、失業や収入の減少、家族、友人、同僚との別れ、愛する人やペットの死など、どれだけ頑張っても避けられない人生のトラブルを受け入れて、回復力を取り戻す作業っすね。

なんでこの作業が欠かせないのかと言うと、人生の困難に巻き込まれたままだと、私たちは自らを深い好奇心から閉ざしてしまいがちだからです。その理由はいくつかありまして、

- **心理的防御メカニズム**：深刻なストレスや困難に直面すると、人間の防御メカニズムが起動。否認、回避、抑圧といった行動で感情的な痛みや不安から自分を守ろうとするが、そのせいで同時に新しい情報や経験に挑むモチベーションが下がる。

- **認知的負荷の増加**：困難な状況では、問題解決や生存に直結することに集中するため、脳の機能を他に回すことができなくなっちゃう。そのせいで好奇心を持って新しいことを探求する余裕がなくなり、既知の情報や過去の経験に頼る傾向が強くなる。

- **安全欲求の優先**：困難な状況では「基本的な安全を守りたい！」って欲求がブーストするので、自己実現や探索といった高次の欲求は後回しになり、好奇心や新しい挑戦に対する意欲が低下する。

- **自己効力感の低下**：人生のトラブルで失敗や挫折を経験すると、自分の能力や価値に対する自信（自己効力感）が低下。これにより、新しいことに挑戦する意欲が減少し、好奇心が抑制される。

といった心理が働くからです。深く考えずとも、ネガティブな感情にとらわれた人ほど、前向きに新しいことに取り組む意欲がなくなっちゃうのはわかりやすいんじゃないでしょうか。だからこそ、このような人生の困難を受け入れることは、私たちが意識して鍛えるべき重要な筋肉のひとつだと言えるわけです。

この筋肉が備わっていれば、たとえば以下のような問題を乗り越えて、逆に好奇心をブーストすることができるはずであります。

- **健康問題を受け入れる**：深刻な健康問題に直面した時、その現実を否定したり無視したりすることは簡単。しかし、その健康問題を受け入れることができれば、適切な治療を受けることができ、生活習慣の改善に取り組むきっかけになるはず。その結果として、より健康的でバランスの取れた生活に取り組む好奇心が増し、全体的な生活の質が向上する可能性がある。

- **親子関係の困難を受け入れる**：親子の関係において、意見の違いや摩擦が生じることはよくあるもの。これを避けようとするのは簡単だけど、その問題を受け入れて向き合うことができれば、親子関係をより深く理解し合うための好奇心が爆誕。お互いの気持ちや意見を尊重し合うことで、関係が改善されることが期待できる。

- **経済的困難を受け入れる**：お金の問題に直面した時に、その現実を否定することは簡単なんだけど、その困難を受け入れられれば、適切な計画を立てて財政状況を改善するための具体的なステップを踏むことができるはず。これにより、お金と人生に関する好奇心がアップし、長期的にはより安定した経済的な基盤を築くことができる。

- **仕事を失うことを受け入れる**：仕事を失った時に、怒りや悲しみを感じるのは自然なこと。しかし、その状況を受け入れないと、ネガティブな感情に囚われ続け、新しい機会を見つけることが難しくなっちゃう。ところが、この瞬間を受け入れることができれば、解雇がキャリアや人生を再構築するチャンスであることに気づくかもしれない。これにより、前の仕事よりも自分に合った職への好奇心が上がり、より良い人生を追求するチャンスが生まれやすくなる。

って感じで、困難を受け入れられば、人生への好奇心が復活することがおわかりいただけたのではないかと。

もちろん、人生の困難を受け入れる作業は簡単じゃないものの、シゲオカ先生は、私たちは誰でも2つの大事なスキルを鍛えられることを指摘しております。

- **地に足をつけるスキル**： 意識して行動のペースを下げることで、安定感、安らぎ、現在を感じることを学ぶスキル。

- **勇気を養うスキル**： 自分が恐れていることに対して、あえて進んで向かっていくスキル。

これらのスキルが身につけば、人生の困難を乗り越えやすくなるのは間違いなし。このスキルを伸ばすために、ここからは3つの具体的な練習を紹介していきましょう。

## **受け入れトレーニング１：クイックサンディング**

クイックサンディングは、直訳すると「流砂」って意味です。たいていの人は、流砂に飲み込まれるとパニックを起こし、砂の中でもが来まくってしまい、逆に手足を取られてさらに早く沈んでしまうもの。流砂に飲まれたときの正しい方法ってのは、

1. 砂の流れに逆らってもがくと体が沈んじゃうので、まずは落ち着く。
2. 流砂に浮くためにゆっくりと動く。流砂の粘土、塩、水の密度は人体の密度を超えている野で、どんなに流砂が深くても体が沈むことはない。
3. 流砂の中で深呼吸をし、胸の上下を観察する。頭ではなく体に集中することで、感情をうまく調整して脱出することができる。
4. 頭を砂の表面から浮かせたまま、ゆっくりと足を前後に蹴る。これによって砂が揺さぶられ、足が自由に動くポケットができる。これをくり返すと、やがて浮力のおかげで足が砂の表面まで浮き上がってくる。
5. いったんこうなれれば、しっかりとした地面に向かって安全に浮くことができる。

みたいになります。こんな感じで、あえて砂に逆らわずに身をゆだねることで、逆に流砂から抜け出しやすくなるわけです。

もちろん流砂に飲まれる事態に遭遇する人は少ないでしょうが、流砂から抜け出すための考え方は、 私たちが危機に直面したときに脱出する方法へのヒントを与えてくれるんですな。

たとえば、仕事の激務にプレッシャーを感じたり、子供や老親の介護の責任からストレスを感じたりしたとき、私たちは激しくネガティブな感情を抱き、恐れてあきらめてしまうか、あるいは衝動的な決断を下し、目の前の状況を乗り切ろうとして空回りしがち。このような反応を続けると、流砂からの脱出と同じように事態が悪化し、ストレスや麻痺、恐怖がさらに増しちゃうだけに終わるんですね。

とはいえ、人生がハードモードになった瞬間に、私たちの身体は闘争、逃走、凍結のどれかに切り替わるもの。そこでクイックサンディングでは、人生の困難で激しいストレスを感じたときに、がっつりと落ち着いて、現在に留まり続け、意図的に動く能力を養っていきます。

では、具体的なトレーニング法を見ていきましょうー。

### **クイックサンディングの実践法**

クイックサンディングは、「呼吸の意識」「ゆっくりとした動きの練習」「マインドフルネス活動」「反省とジャーナリング」という４つの要素で構成されております。普段からこれらの要素を鍛えておくことで、いざ困ったことが起きたときにも、落ち着いて、現在に留まり、意図的に動く能力を養っていくんですな。

ちなみに、クイックサンディングで行うことは、いずれも瞑想のトレーニングに近いのところがあります。なので普段から瞑想を行っている方は、その代わりにクイックサンディングを組み込んでみるのも良いでしょう。

1. **呼吸の意識を鍛えるトレーニング**
  1. 静かな場所で快適な姿勢で座るか横たわる。
  2. 目を閉じて、鼻から4カウントで深く息を吸う。
  3. その息を4カウントで止める。
  4. 口から6カウントでゆっくり息を吐く。
  5. 胸の上がり下がりに集中しながら、このサイクルを5〜10分繰り返す。
2. **ゆっくりとした動きの意識を鍛えるエクササイズ**
  1. **ゆっくり歩く瞑想**
  2. 室内外の静かな場所を見つける。
  3. 一歩一歩に注意を払いながらゆっくり歩く。
  4. 足が地面に触れる感覚や体の動きを感じる。
  5. 10〜15分間歩き、周囲を観察しながら現在に留まる。
  6. **スローダンスのエクササイズ**
  7. ゆったりとした音楽を選ぶ。
  8. 音楽のリズムに合わせてゆっくりと体を動かす。
  9. 動きの感覚や音楽に集中する。
  10. 自然に、急がずに5〜10分間踊る。
3. **マインドフルネを鍛えるストレーニング**
  1. **ボディスキャン瞑想**
  2. 快適な姿勢で横になる。
  3. 目を閉じて数回深呼吸をする。
  4. つま先から頭まで、身体の各部位にゆっくりと注意を向ける。
  5. 感覚や緊張、違和感を判断せずに感じる。
  6. 15〜20分間この練習を行う。
  7. **自然観察散歩エクササイズ:**
  8. 自然の中を散歩する。
  9. 周囲の詳細に注意を払い、色、形、音、匂いに集中する。
  10. ゆっくりと15〜20分間歩き、現在に留まる。
4. **自己の経験を振り返る能力を鍛えるトレーニング**
  1. 毎日終わりに5〜10分間、自分の「クイックサンディング」の経験について書く。
  2. ストレスや圧倒された瞬間に、どのようにこの実践を適用したかを振り返る。
  3. 感情の変化、頭の明晰さ、身体の感覚について記録する。
  4. 何がうまくいったか、改善できる点を考察する。

ってことで、これらのトレーニングを定期的にやっていただくことで、少しずつクイックサンディングの感覚が身につくはずであります。ただ、これだと具体的に困ったときにどうすればいいのかがわかりづらいので、クイックサンディングの使用例を挙げておきます。

### **クイックサンディングの使用例**

- **日付**: 2024年7月24日
- **状況**: 今日、仕事で急なプロジェクトの締め切りが課され、圧倒される気持ちになりました。複数のタスクが重なり、どれから手をつければよいのか分からず、心臓が早くなり、呼吸も浅くなっているのを感じました。
- **呼吸の意識の実践**:
  - まず、デスクから離れて静かな場所に移動。目を閉じて、4カウントで息を吸い、4カウントで止め、6カウントでゆっくり息を吐きました。この呼吸を5分間続けることで、心拍数が落ち着き、頭が少しクリアになりました。

- **ゆっくりとした動きの実践**:
  - オフィスの周りをゆっくりと歩きながら、足の感覚や周囲の景色に意識を向けました。10分間の歩行瞑想を行うことで、心の中の混乱が少しずつ収まりました。

- **マインドフルネス活動の実践**:
  - オフィスの窓から外を見ながら、自然観察をしました。木々の揺れや空の色に集中しました。これにより、プレッシャーから一時的に解放され、リラックスすることができました。

- **改善点**: 次回は、プレッシャーに飲み込まれる前に早めに「クイックサンディング」を実践することで、よりスムーズに対応できるようにしたい。また、日常的に短時間の瞑想や深呼吸を取り入れることで、ストレス耐性を高めたい。

こんな感じで、なんか困ったことがあったら、呼吸→動き→マインドフルネスの順に、脳の働きをスローに変えていくわけですね。プレッシャーに飲まれそうになったときには、非常に役立つ方法なので、ぜひお試しください。

これらのトレーニングは好きなペースで行っていただいて構いませんが、ざっくりスケジュールのサンプルを提案してみると、以下のようになります。

- ****クイックサンディングの週間スケジュール例****
  - 1〜2日目: 呼吸の意識とボディスキャン瞑想
  - 3〜4日目: ゆっくり歩く瞑想と自然観察散歩
  - 5日目: スローダンスと毎日の反省ジャーナル
  - 6〜7日目: いずれかの練習の組み合わせとジャーナリング

ってことで、今回はこのへんで。これらのエクササイズを定期的に実践することで、ストレスの多い状況でも冷静さを保ち、現在に留まり、意図的に動く能力を養うことができますんで、ぜひお試しくださいー。
