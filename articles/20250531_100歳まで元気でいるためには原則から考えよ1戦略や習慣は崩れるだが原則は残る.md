# 100歳まで元気でいるためには“原則”から考えよ！#1「戦略や習慣は崩れる。だが、“原則”は残る」

![21145acb237ba223ab15ce13bda36be62be49973.png](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2215819%2F1_21145acb237ba223ab15ce13bda36be62be49973.png.png?alt=media&token=97a659e0-06a0-4c03-af8c-592cbf958b7d)

私たちは、健康のために日々数百の選択をして生きております。

朝、何時に起きるか。

食事は自炊か外食か。

今日は運動するか、しないか。

こうした一つひとつの選択が、やがて年を取った時の健康に、ものすごく大きな影響を与えるわけです。実際、100歳を超えて元気に生きている人たちを調べてみると、「50歳からめっちゃ健康になった！」って人は一人もいなくて、実際には50代や60代の頃からすでに驚くほど元気だったって傾向が見られるんですよ。つまり、100歳でも元気な人ってのは「80歳の時点で50代レベルの体力があった」人たちが、そのまま長生きしているわけです。

---

でもって、100歳でも元気な人たちが何をしていたかと言えば、

- 体をよく動かしていた
- 食べすぎなかった
- 睡眠が安定していた
- 社会的つながりを持っていた
- ストレスをうまく処理していた

というめっちゃ地味なラインナップでして、奇抜な健康法はゼロ。100まで元気な人たちは、地味だけど基本的なライフスタイルを60年くらい続けてきたってことですな。非常につまらない結論でありますが、これがアンチエイジングにおける最大の真実ではあります。

が、これらの基本的な対策は、わかっていても、なかなか続かないものでございます。たとえば、「運動が大事とわかっていても、仕事や家事が忙しいとつい後回しになってしまう！」みたいな問題に悩む人は多いはずであります。では、なぜこのような問題が起きるんでしょうか？

## **戦略や習慣は崩れる。だが、“原則”は残る**

ここまで述べてきたような問題について、アンチエイジング研究の第一人者であるピーター・アティア博士は、以下のような原因を指摘しておられます([R](https://amzn.to/3Hd8Atv))。

- **「あなたが健康に関する“原則”を持っていないからだ！」**

「原則がない」とはどういう意味かといいますと、たとえば多くの人ってのは、「健康になろう」として、以下のようなことに挑戦するじゃないですか。

- 糖質制限
- ジム通い
- 断食
- 早起き
- マインドフルネス

でも、時間が経つと、何かしらの事情で中断されたり、迷ったり、継続できなくなったりしちゃう。このような現象が起きるのは、「**ほとんどの人が“戦術”から入って、“戦略”を知らず、“原則”が抜けている**」からなんですよ。これら3つの違いを簡単に説明しておくと、

- 戦術＝「糖質制限ダイエットを始めた」みたいな具体的行動。
- 戦略＝「腹筋が割れた状態を目指す」という中期的ゴール。
- 原則＝「私は30年後の体調を最重視する」みたいな軸となる考え方。

といった感じになります。ご覧の通り、戦略と戦術のどちらも原則から生まれているので、たとえ戦術や戦略が崩れても、「原則」が残っていれば再構築することができるわけです。例えば、「今月は忙しくてジムに行けなかった」としても、「私は“未来の体調と自由”を重視する」という原則さえ残っていれば、また運動習慣を立て直せるじゃないですか。こんな感じで、原則は「失敗しても戻れる場所」を作ってくれるわけです。

逆に言えば、「原則なき努力」は、何か問題が起きたときに全部パーになるのが怖いところ。これが、普段、健康習慣が身に付かずに失敗している人に起きがちな問題なわけです。

それでは、“原則”を持っている人には、どのような特徴があるのかを見てみましょう。たとえば以下のような考え方で、一時的に運動をストップさせた人がいたとしましょう。

1. 「私は“未来の自分”を守ることを最優先にする」
2. 「健康のために毎週3回運動する」
3. 「今週は忙しいからジムはやめておこう」

この思考の流れだけを見ると、「運動を続けるのに失敗してるじゃん」と思っちゃうかもしれません。が、実際にはちょっと違うんですな。というのも、この人の「原則」は“未来の自分”の利益なので、たとえ「今週ジムに行かない！」という選択をしたとしても、「疲労がたまっているときは無理しない方が、中長期的に体調を守れるはずだ」という判断が背景にあれば、むしろ原則に忠実だと言えるんですよ。

この考え方を、アティア博士はこう表現します。

> 原則があれば、瞬間的な判断に迷わない。時間軸を越えた自分の味方になってくれる。「原則とは、どこに戻るかを決めておく“帰還地点”である」

つまり、原則ってのは、たとえ調子が崩れても、立て直すための“地図”になってくれるわけですね。というわけで、100歳になっても元気な体でいたいなら、まずは自分なりの原則を考えるのがファーストステップになるんですよ。万人に通用する汎用的な健康法（例：糖質制限・断食・有酸素運動）はないので、自分自身の目標・状況・反応に合わせて、柔軟にカスタマイズされた意思決定システムをつくるべきなんですな。

ちなみに、アティア博士が使っている原則は、以下の3つだそうです。

1. 「予防は、治療よりも効率がいい」→ がんも心疾患も、出てから対処するのでは遅すぎる。出る前に叩く。
2. 「過去より“今と未来”の習慣が重要」→ これまで失敗していても関係ない。今から修正できるかに全力を注ぐ。
3. 「エラーを責めず、リセットを重視する」→ トラッキングの数字が悪くても落ち込まない。リカバリー能力を優先。

このような“自分なりの原則”を決めておけば、「例外的な事態」にも柔軟になれるわけっすね。などと書いておきながら、私自身が別に原則を考えたことがなかったので、博士の考え方には納得させられました。ちょっと自分にとっても健康の原則を考えてみるか……。

## **原則の作り方：フレームワーク思考を導入せよ**

となりますと、「じゃあ、自分の“原則”ってどうやって見つければいいの？」って話になりますが、ここでアティア博士は、「フレームワーク作成の3原則」を提唱しておられます。これがかなり使える原則なので、押さえておくと便利でしょう。

### **原則① 科学と実践の“中間”をとる**

まずは、「科学的エビデンスは参考にすべきだが、絶対視してはいけない」ってが大原則になります。というのも、長寿や慢性疾患に関する研究は、「100年後にどうなるか」という超長期の視点が必要なんですが、そんな長期スパンのRCT（ランダム化比較試験）は現実的に存在しないもんですから。なので「あと何十年生きられるか」といった長期のアウトカムについて、エビデンスをもとに考えるのは不可能なんですよね。

加えて、研究というものは統計的に「平均的な人間」を対象にしているので、「自分にとって正しいかどうか」は結局のところ試してみないとわからないところがあります。だからこそ、アティア博士は「エビデンスベースド（根拠に基づいた）」ではなく「**エビデンスインフォームド（根拠にヒントを得た）**」という立場を強調しておられます。つまり、科学的知見はあくまで“方向を示すコンパス”であり、実際にどう進むかは、自分の体調・経験・反応という“リアルなデータ”と照らし合わせながら調整していくしかないわけっすね。エビデンスはあくまで地図でして、その地面を歩く方法を考えるのは、自分自身ってことですな。

アティア博士いわく、

> 私たちに必要なのは、科学の力を“方向指示器”として使いながら、自分自身の経験や反応を組み合わせて判断していく“アートとサイエンスの融合”だ。

とのことで、知識だけでなく現実と折り合う柔軟さを身につけ、自分に合った健康戦略を見つけられるようにしましょう。

### **原則② 特定の流派にこだわらない**

２つめの原則は、簡単に言うと「“糖質制限派”とか“断食信者”とか、レッテルに縛られるな！」みたいな話です。

なにせ人間の体はめちゃくちゃ複雑なので、今日うまくいったことでも、来月には逆効果になってるなんてザラにあるんですよ。そんな中で「これが正解！」と決め打ちするのは、ほとんど思考停止に近い行為になっちゃうんですよね。

そもそも、あらゆる健康法にはメリットとデメリットがありまして、それを自分の目的や体調、ライフステージに応じて“その都度”調整する力のほうが大事だったりします。アティア博士自身、かつては「断食最強！」って説を推していた時期があったんだけど、後になって「筋肉が落ちる」「ホルモンバランスが崩れる」などの副作用に気づき、方針を大きく変えたんだそうな。

つまり、「原則は変えないけど、やり方（戦術）はいつでも変えていい」が博士のスタンスなわけでして、これは私も大賛成ですね。大切なのは“何をするか”ではなく、“なぜそれをするのか”なので、その理由がしっかりしていれば、糖質制限でも、地中海食でも、パレオダイエットでも、断食でも、全部アリ。逆に理由が曖昧なら、どんなに有名な健康法でも、それは単なる“思考停止エクササイズ”に過ぎなくなっちゃうのでご注意ください。

アティア博士いわく、

> 方法ではなく、“原則”を持て。方法は時に変わるが、原則は状況に柔軟に適応できる知性である。

とのことで、ぜひ“柔軟性”を原則の1つとして捉えていただければと思う次第です。

### **原則③ データと自己観察を土台にする**

最後の原則は、「主観だけで判断せず、身体の“客観的変化”を見ながら調整せよ」と言うものです。

人間の体ってのは、思っている以上に気まぐれなもの。昨日の自分と今日の自分が、まるで別人のように感じることもあるし、同じ習慣を続けているはずなのに、なぜか調子が良かったり悪かったりするのが普通であります。

なので、こういう“ゆらぎ”に振り回されないために必要なのが、「**ちゃんと観察して、ちゃんと測る**」というスタンスです。つまり、自分の体に起きている変化を主観で決めつけるのではなく、睡眠の質はどうか、体重や筋肉量はどうか、血糖値はどう推移しているか、といった客観的データを使って、日々の行動を微調整していくことが重要だって話ですね。

これってのは要するに、「仮説を立てて、検証して、改善する」という科学の基本そのものでして、自分の健康を最適化するためには、ちょっとした“科学者モード”を日常に持ち込むのがいちばん手っ取り早いって話でもあります。気合いや根性に頼らず、体の反応を見ながらゆるやかに調整していくって視点があるだけで、「続かない習慣」から「進化する習慣」へと、うまくギアチェンジできるようになるはずであります。人間の体は日々変わっていくので、最適な健康習慣は“定数”ではなく“変数”として扱うべきだってことですな。

## **OSTモデルで「フレームワーク」を作ってみよう！**

それでは、上記の3原則に基づいて、自分にとっての健康原則を作ってみましょう。ここでアティア博士は、「OSTモデル」という質問フレームを使うように推奨しておられます。これは「Objective → Strategy → Tactics」という3段階の構造を使って、自分に合った戦術を導き出すためのツールです。なかなか使い勝手が良いので、まずはこれを使って自分のなりのフレームワークを作ってみましょう。

### **① Objective（目的）：最終的にどうなりたいのか？**

まず「Objective（目的）」では、「人生の大目標」を明確にします。ただし、“体重を減らす”のような短期的な目標ではなく、もっと人生全体を通じたゴールを設定するのがポイントになります。

この段階では、以下のような問いの答えを考えてみてください。

- **Objective（目的）の問い：**
  - 「私が本当に目指しているのは何か？」
  - 「私の最終的なゴールは何か？」
  - 「死ぬ直前のあなたにとって、“健康だった”とはどういう意味を持つか？」
  - 「80歳や90歳になったとき、どんなふうに動ける自分でありたいか？」
  - 「私は何を解決しようとしているのか？」

- **Objective（目的）の例：**
  - 「私は、90歳になっても孫と一緒にスキーができるような身体能力を維持したい」
  - 「100歳で自力歩行と読書ができる状態をキープしたい」

これらの問いは、その人が人生において達成したい健康目標や、そもそもなぜそれを望むのかを明らかにするために行います。

### **② Strategy（戦略）：その目的のために、どんな分野に取り組むべきか？**

続いて、「目的」を達成するにはどんな要素が必要かを考え、優先順位を決めていきましょう。ここでは“原則”に基づいた大まかな「分野」を特定していきます。

この段階では、以下のような問いの答えを考えてみてください。

- **Strategy（戦略）の問い：**
  - 「私の目的を支えるために、最も重要な身体機能は何か？」
  - 「その目的のために、食事・運動・睡眠・感情のどこを重点的に改善すべきか？」
  - 「最もボトルネックになっているのはどこか？」
  - 「私は過栄養か？それとも栄養不足か？」
  - 「筋肉量は不十分か？十分にあるか？」
  - 「私は代謝的に健康か？それともそうではないか？」

- **Strategy（戦略）例：**
  - 「自力で動き続けたい → 筋力とバランスがカギ → 筋トレと安定性トレーニングを優先」
  - 「認知症を防ぎたい → 睡眠の質とインスリン感受性の改善が必要 → 夜型生活の是正と食生活の見直し」

これらの質問は、現状の身体状態を評価し、どの分野を優先的に改善するかを判断するために使います。食事、筋肉、代謝といった複数の健康軸のうち、どこに最も戦略的な介入を行うべきかを見極めましょう。

### **③ Tactics（戦術）：具体的に何をどう行うか？**

このフェーズでは、戦略で決めた分野を、日々の具体的な行動に落とし込みます。このとき重要なのは、“自分が実行できる形に分解すること”でして、この段階では、以下のような問いの答えを考えてみてください。

- **Tactics（戦術）の問い：**
  - 「その状態を改善するために、明日から始められることは何か？」
  - 「この戦略を具体的な日常行動に落とし込むなら、どうするか？」
  - 「この習慣は、現実的に自分の生活にフィットしているか？」
  - 「途中で中断した場合、どうやって再スタートするつもりか？」

- **Tactics（戦術）の例：**
  - 「毎朝10分だけ、自重スクワットを行う」
  - 「睡眠を改善するため、23時以降のスマホ使用をやめる」
  - 「炭水化物の摂取は、運動直後と朝食に集中させる」

ということで、まずはOSTに従って考えを深めていくとやりやすいと思います。多くの人は、健康のために「運動しなきゃ」「食べすぎ注意」といった戦術レベルの思いつきで行動を始めるんだけど、これらの質問を考えておくと、「何のためにやっているのか？」「そのために何が本当に重要なのか？」という“上流”の設計ができて、思いついた戦術が続きやすくなるはずであります。何か行動起こす時は、このOSTモデルを使って「常に上流から考えるクセ」をつけるようにするといいっすね。

ちなみに、OSTモデルを使ってもなかなか自分なりの原則が思いつかない方は、以下のような方法も取り入れてみてください。

### **オプション①：「なぜそれをしたいのか？」を3回問う**

具体的な戦術から考えて、「なぜ？」を掘り下げていく方法です。例えば、「筋トレをする」って戦術を思いついたとしたら、

1. なぜ筋トレしたい？ → 健康になりたいから
2. なぜ健康になりたい？ → 60代でも自由に動けるようにしたいから
3. なぜ自由に動きたい？ → 子どもや孫と旅行したいから
4. → 原則：「家族との自由な時間を失いたくない」

みたいな感じで、先術を掘り下げていくわけですね。

### **オプション②：「やりたくないこと」を言語化する**

自分がどうしてもやりたくないことを言葉にしてみるのも、原則を探すための良い方法です。例えば、

- 病気で寝たきりになるのはイヤ！
- 頭がぼんやりして、決断力を失うのはイヤ！
- 痩せたくて我慢する人生はイヤ！

みたいに、将来の自分がこうなりたくないと思うようなものをいくつかピックアップしてみて、その共通点を探してみてください。この事例であれば、おそらく「自己決定権を失いたくない」が原則なのだと思われます。「やりたいこと」ではなく「やりたくないこと」から、原則は意外と見えてくるものなんで、ぜひこちらもお試しを。

ということで今回は、100歳まで元気に生きるためには「自分なりの原則を作ろうぜ！」と言うお話でした。原則ってのは、私たちが日々の選択を行う際の“帰還地点”なので、これが決まっていれば環境が変わったり、人間関係が変わったりしても大丈夫であります。

そこで次回は、今回探し当てた原則をもとに、自分なりの運動スタイルをどうやって見つけていくかについて考えてみます。ではまた！
