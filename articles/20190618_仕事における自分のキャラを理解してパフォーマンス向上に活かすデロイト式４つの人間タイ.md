# 仕事における自分のキャラを理解してパフォーマンス向上に活かす！デロイト式「４つの人間タイプ」#1

![記事内画像](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F1772707%2F01760786-0d1e-43fc-8bb1-3a3d44cadf01.jpg?alt=media&token=01760786-0d1e-43fc-8bb1-3a3d44cadf01)

世界最大の会計事務所こと「デロイト」が、「**ビジネス向けの性格テストを考案したよー**」って言うおもしろいデータを公開しておりました。

これは、「[人はなぜ恋に落ちるのか?](https://amzn.to/2WViOGa)」で有名なヘレン・フィッシャー博士とデロイトの共同研究で、まずは先行研究からビジネスマンを中心に行動と思考様式をリストアップ。そこから性格テストを作り、３つの独立標本（それぞれ1000人ぐらい）を対象に正確性を確認した内容になっております。

この性格テストが何を目的にしてるかと言いますと、

- **仕事における自分のキャラを理解してビジネスに活かそうぜ！**

みたいなことです。性格テストといえばご存じビッグファイブが有名ですけど、あれはかなり包括的なタイプ分類なので、

- その人が集団内でどのようにふるまうのか？
- 組織のなかでどのように問題に取り組むのか？
- チーム内でどのような意思決定をするのか？

といったポイントを予測するにはちょい不向きだったりするんですよ（別のデータをかませばビッグファイブでもいけるんだけど少しめんどい）。

ってことで、このテストの内容を知っておくと、**どんなとこを意識して働くと能力を発揮しやすくなるの？**みたいなとこがわかりやすくなってよろしいかと思います。

## **あなたの仕事におけるキャラを判断する24問**

では、さっそくデロイト流の性格テストを見てみましょう([R](https://amzn.to/2K3yW2j))。採点方法は簡単で、以下の文章をみて「**仕事をしてる時の自分はこんな感じだなー**」と思えるものにチェックをつけててください。特に点数をつける必要はありません。

1. 社交的だ
2. 他人の気分は傷つけない
3. データを重視する
4. 几帳面だ
5. 大きな視点から見る
6. 他人に共感する
7. 論理的に考える
8. あまりしゃべらない
9. 自発的に動く
10. 伝統を重んじる
11. 目標に突き進む
12. ディテールを重視する
13. リスクを取る
14. 他人との和を重視する
15. 競争するのが好き
16. 実利的だ
17. 変化に強い
18. 内的モチベーションが高い
19. いろいろと試す
20. 計画性がある
21. 想像力を駆使する
22. 対立を嫌う
23. 好奇心が強い
24. 忠誠心が強い

でもって、判断方法は以下のようになります。

- 1、5、9、13、17、21番のチェック数が多い人＝パイオニア
- 2、6、10、14、18、22番のチェック数が多い人＝インテグレーター
- 3、7、11、15、19、23番のチェック数が多い人＝ドライバー
- 4、8、12、16、20、24番のチェック数が多い人＝ガーディアン

人によっては「パイオニアとドライバーの数が同じなんだけど……」みたいなケースもありましょうが、それはそれで問題ありません。ひとつのキャラだけがズバ抜けて強いなんて人は少数派で、誰しもがこれら4タイプの要素を合わせもってますんで。

## ４つのキャラはどんなタイプの人なの？

では、それぞれのタイプがどのようなキャラなのかと言いますと、以下のようになっております。

### **パイオニア**

リスクを取るのが好きで、集団にエネルギーを与えるタイプ。直感に頼って行動するのをよしとするので、下手をすると大けがすることも少なくない。その代わり、大胆で斬新なアイデアが好きなので、大ホームランを飛ばすことも。

- テンションが上がるポイント
  - アイデア出し
  - 新しいチャレンジ
  - 自発的な行動

- テンションが下がるポイント
  - 厳格なルールやシステム
  - 他人からの否定
  - プロセスの重視

### インテグレーター

他人との仲を重視して、集団をひとつにまとめるのが得意。人間関係を重視して、ものごとを白黒では考えない。人当たりが良い人が多い。

- テンションが上がるポイント
  - コラボレーション
  - 対人コミュニケーション
  - 他人からの信頼と尊敬

- テンションが下がるポイント
  - 社内政治
  - 他人との対立
  - 柔軟性のなさ

### ドライバー

チャレンジが好きで、ひたすらゴール達成に努力を注ぐ。論理的に考えるのが好きだが、ものごとを白黒で判断しすぎて嫌われることも多い。

- テンションが上がるポイント
  - 問題が解決にいたること
  - 率直なコミュニケーション
  - なにかに勝利すること

- テンションが下がるポイント
  - 優柔不断な人やプロジェクト
  - 効率が悪い仕事
  - ポイントがわからないプロジェクト

### ガーディアン

安定が大好きでリスクを嫌う。データとディテールを重視し、過去から学ぶことに強い意義を見出す。

- テンションが上がるポイント
  - 一貫した組織やルール
  - 将来が予測できるプロジェクト
  - 細かなところまで定まったプラン

- テンションが下がるポイント
  - 何も決まっていないプロジェクト
  - 締め切りのプレッシャー
  - 不確実性

## とりあえずのまとめ

ってことで、デロイトによる仕事に特化した４つの性格タイプでした。これを押さえとくと、「自分はガーディアンだから、とにかくプロジェクトの細部を詰めることに力を注ごう……」とか「あの人はドライバーだから、率直な物言いを心がけよう……」などなど、自身のパフォーマンス向上から社内コミュニケーションまで幅広く適用できるんじゃないかと思われます。

で、次回はもうちょい深掘りして、いかに組織の中でこの4分類を活用していくかを見ていきたいと思います。どうぞよしなに。
