# 30日であらゆる謎の不調を解決するマインドボディワーク入門「第3週目」

マインドボディワーク入門の続きです！([#1](https://daigovideolab.jp/blog/2179044),[#2](https://daigovideolab.jp/blog/2179377))

このシリーズでは、メンタルの問題によって、腰痛、頭痛、肩や首の痛み、お腹の不調、アレルギーといった謎の不調が悪くなってしまう現象に 立ち向かうためのワークを紹介しています。体の不調の多くはメンタルと密接に結びついているため、 薬物治療などで効果が出ない方はこちらもぜひお試しください。

ちなみに、あらためて説明しておくと、このシリーズで問題にしているのは、「**緊張型筋炎症候群(TMS)**」って症状です。腰痛治療の先駆者として知られるジョン・サーノ博士が提唱した概念で、

- **緊張**＝「感情的な緊張」と「身体の筋緊張」の両方を意味する。
- **筋炎**＝シンプルに筋肉に圧痛や痛みがあること。
- **症候群**＝この問題の症状にはいろいろあって一言でまとめられないよーぐらいの意味。なので、TMSにおけるが起きた人は、背部痛、頚部痛、しびれ頚部痛、しびれなどなど、いろんな症状に悩むことになる。

みたいな定義になります。簡単にまとめると、いろんな緊張によって筋肉の痛みがブーストして、いろんな問題が起きちゃう現象って感じでして、なんとも困ったもんであります。

TMSについては、問題が起きやすい人がいることが分かってまして、

- メンタルが緊張しやすい人は、自律神経にアンバランスが起きるので、腰や首や肩に痛みが生じる。

- 他の心身症を持っている人（胃潰瘍、喘息、アトピーやじんましん、円形脱毛症、高血圧、頭痛やリウマチなど）も、TMSにかかりやすい。

- 完璧主義者、自己批判が多い人、責任感が強い人も、大きな身体的圧力や緊張を生み出すため、しばしば身体的症状として表れる。

みたいな感じになります。そのため、これらの症状が出ちゃうと、たいていは背中の捻挫や椎間板の手術といった物理的な治療を受けることになるものの、一時的に症状がやわらぐぐらいで、すぐに再発してしまったり、症状が体の他の部位や左右に移動することも珍しくなかったりします。心身症にくわしいお医者さんって少ないので、なかなか対策が難しいんですよね。

まー、以上の話ってのは、言い換えれば「腰痛、頭痛、肩の痛み、首の痛みは、『お前、もっと自分を大事にしろよ！』と身体が言ってきてるサインかも？」ってわけですな。もし自分を悩ませる痛みの原因が検査でも分からず、痛みを感じる時と感じない時があったりする場合は、自分自身の心と体の休息を優先してみると良いかもしれません。

では、あらためて基本を押さえたところで、具体的なワークに進みましょう。前回はワークの第2週目までを見てきましたので、今回はその続きです。

## **マインドボディワーク第3週目**

この週は、感情的な問題や、人生の妨げとなっている人生の障害を探っていきます。人生をよりアクティブに生きることを探求し始め、肉体的なコンディションを整えていくことにしましょう。楽しいアクティビティの量を増やし、あなたが陥っている痛みのパターンや習慣を断ち切ることを探求し始めましょう。さらには、毎日の症状の改善も含めて、あなたの人生における良いことに感謝するい作業もはじめていきます。

### **15日目のワーク**

日付 \_\_\_/\_\_\_\_/\_\_\_\_

1. 先週のワークで書いたことを読み返してください。あなたが書いた文章の中に繰り返し出てくる問題は何ですか？（特定のネガティブな感情、ネガティブな思考など、何度も出てくるようなものをピックアップしましょう）。
2. あなたが書いた文章の中に繰り返し出てくる問題について考え、この問題を克服し、より効果的に対処するには何が必要かを考えてください。（その問題を解決するために、どのようなステップを踏みますか？ そのプロセスには、いつどのように着手できますか？）
3. これから数カ月のあいだ、体調が良くなるにつれて、どのような活動を増やしてみたいと思っていますか？ その計画によって、どのような感情を感じますか？ 新しいことをはじめる場合に、心配したり、興奮したり、恐れたりといった感情がわくのは自然なことなので、少しでも自分がわくわくする活動であれば、ネガティブな感情が起きても心配はありません。
4. このワークを続けている数週間の間に、心と体のつながりについての理解を深めるような、あるいは心と体のつながりに懐疑的な気持ちを持たせるようなニュースが取り上げられたことはありましたか？ もしそのニュースのせいで心身のつながりに対して懐疑的になった場合は、あなたがどのような懸念や感情を持ったのかを書き出してください。

### **16日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_

1. ここ最近の人生で、あなたが最も多く抱いている感情はなんですか？このワークをはじめたときと比べて、感情になんらかの変化はありましたか？
2. 4日目のワークで行った「あなたがコントロールできたこと／できなかったこと」のリストを振り返ってください。このリストを見て、他にあなたが対処すべき問題はありますか？ その問題に直面する上で、最もあなたの行動をジャマするような感情的な要因は何ですか？
3. この問題（またはリストにある他の問題）に直面するのが難しい理由はありますか？ あなたにとって、この問題(あるいはリストの他の問題)に直面することが困難であった理由はありますか? もし理由があるなら、それを詳しく説明してください。
4. 最近、あなたが「正しいことをした」と感じたのはいつ、どのような内容ですか？ そのことで自分を褒めるならどうなりますか？

### **17日目のワーク**

日付 \_\_\_\_/\_\_\_\_\_/\_\_\_\_\_

1. 今日はどのような感情を最も多く抱きましたか？ それは、具体的にどのような事態に対する感情ですか？ その感情を抱いたのはなぜですか？
2. あなたは、誰に対して最も罪悪感を感じやすいですか？ その罪悪感に対して、どのように対処していますか？
3. あなたの両親や上司、友人の中で、あなたを動かすために罪悪感を使ってくる人はいませんか？ もし思い当たることがあるなら、その人がどのような手段で罪悪感を使ってくるのかを書き出してください。
4. あなたが 罪悪感を感じることで、悲しみや怒りなど、他の感情を感じますか？ それはどのようなものですか？ 具体的な例を挙げてください。

### **18日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_

1. 今日の気分や感情はどうですか？ 後ろめたい気持ちはありませんか？
2. 最近の身体の症状はどうですか？ 痛みと感情の結びつきが理解できてきましたか？ 痛みと感情の間に、どのように関係があることに気付きましたか？
3. あなたに「不安」や「身動きが取れないような感覚」を感じさせる出来事はなんですか？
4. 自分の人生を振り返ってみて、
5. 「不安」や「身動きが取れないような感覚」は以前にもあったものですか？ 以前にも対処したことがありますか？ もしあるなら、具体的な出来事の例を挙げてください。あなたにとって、その感覚はどのようなもので、今はどのように対処していますか？

### **19日目のワーク**

日付 \_\_\_/\_\_\_\_/\_\_\_\_\_

1. 最近、あなの人生で特筆すべき変化は起こっていますか？
2. 最近、自分自身についてどう感じていますか？ いつもと違うような感覚や感情はありますか？
3. 自分のことを過剰に批判をするとき、それはどのような内容ですか？ 具体的な問題、特徴、出来事を書いてください。
4. また、この自己批判を、どのようにやわらげることができるでしょうか？ もっと自分に優しくなれる方法はないだろうか？
5. 自分を批判する時に、あなたは誰かを思い浮かべていますか？ もし誰かを思い浮かべるなら、それはなぜですか？

### **20日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_\_

1. 最近、あなの人生で特筆すべき変化は起こっていますか？
2. あなたにとっての最大の恐怖は何ですか？ 時間をかけて考えてみてください。
3. 毎日、どれぐらいその恐怖に意識を向けていますか？ なぜそのことに意識が向くのだと思いますか？
4. その恐れは、あなたの行動を妨げますか？ その恐れは、具体的に、どのようにあなたの人生をジャマしていますか？

### **21日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_

1. 今日（または今週）、あなたに最もストレスを与えたことは何ですか？ その出来事と、あなたの反応を説明してください。
2. ストレスを最もよく感じるのはどんなときですか？ それはどのように起こりますか？
3. あなたがストレスを感じて「怒り」「恐れ」「不安」などを感じたときに、それらは本当にあなたの感情を言い表しているでしょうか？ あなたの感情を、もっと的確に表現できる感情はないでしょうか？
4. あなたは、子供の頃にも同じような感情を体験したことがありましたか？ もし心当たりがあるなら、それはどのような体験でしたか？
