# 努力してるのに成長しない人の共通点、それは「コーチャビリティ」の無さ#7「最終回：フィードバック実行」

![6d87e9ed20f2ea3b5a1fd05fd7b04e1bacc84409.png](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2231416%2F1_6d87e9ed20f2ea3b5a1fd05fd7b04e1bacc84409.png.png?alt=media&token=d28e33d5-d268-4ac7-8c09-e0f8f839fa21)

『**努力してるのに成長しない人の共通点、それは「コーチャビリティ」の無さ**』の続きです！([#1](https://daigovideolab.jp/blog/2229785),[#2](https://daigovideolab.jp/blog/2230614),[#3](https://daigovideolab.jp/blog/2230680),[#4](https://daigovideolab.jp/blog/2230929),[#5](https://daigovideolab.jp/blog/2231104),[#6](https://daigovideolab.jp/blog/2231364))

このシリーズでは、「なぜ同じ努力をしても結果に差が出るのか？」という問題を、科学的な視点からチェックしております。コーチをつけても伸びる人と伸びない人の違いは何か？みたいなポイントですね。

そこで、前回は成長が早い人の第五の特徴である「フィードバック受容」を深掘りしたんで、今回はその第六の特徴である「**フィードバック実行**」をチェックしてみましょう。

簡単におさらいすると、「フィードバック実行」ってのは、受け取ったアドバイスや改善点を、実際の行動に落とし込み、継続的に試しながら自分のパフォーマンスに反映していく能力のことです。これがコーチャビリティに欠かせないのは当然で、どれだけ正しい知識や優れたアドバイスを持っていたとしても、それを実際の行動に移さなければパフォーマンスは1ミリも変わりませんからね。“理解しているだけの人”と“何も知らない人”のあいだに差はほとんど生まれませんから。

ということで、ここでは「フィードバック実行」の改善に効く手法を、いくつか取り上げておきましょう。

---

で、まず前提として、この「フィードバック実行」を実践するにおいては、何をおいても「実行意図」が重要だってのは覚えておきましょう。これは「いつ・どこで・何をやるか」を事前に決める手法のことで、パレオチャンネルでは「イフゼンプランニング」の名前でも有名でしょう。たとえば、「明日から運動する」って目標があったとしたら、「明日の朝7時に、家の前で10分走る」みたいに行動の条件を細かく具体化するってやり方で、もはや詳しく説明するまでもないでしょう。

この手法は、メタ分析でもかなり効果が確認されていて、実行率が2〜3倍になるなんて報告もあったりします。人間ってのは、少しでも判断しなきゃいけない場面があると動けなくなっちゃうんで、細かいところまで事前に決めておくと反射で行動しやすくなるんですよ。

なので、「フィードバック実行」を行うなら、まずは「実行意図」に習熟するのが基本中の基本。日常のあらゆる行動に「イフゼンプランニング」を組み込んでみてくださいませ。

が、このポイントについては、他にもいろいろと効く手法がありますんで、そこらへんを見ておきましょう。

## **フィードバック実行トレーニング１：罰則システム**

「罰則システム」は、やらなかったら罰を受ける仕組みを作るという方法で、とにかく**「やると得」ではなく「やらないと損」に設計する**のがポイント。シンプルながら行動科学の世界ではかなり再現性が高い手法として知られてまして、人間は基本的に同じ金額でも「得をする喜び」より「損をする痛み」のほうを2倍以上強く感じるものなので、この性質をうまく使うと意志力に頼らず行動を引き出せるわけです。

その一方で、多くの人は「実行したらご褒美」みたいな設定をしがちでして、

- 運動したらご褒美
- 勉強したらご褒美
- 続いたら自分を褒める

みたいな感じにすることが多いんですよね。もちろん、これは一定の効果があるんだけど、同時に失敗する人も多いことがわかってたりするんですよ。それというのも、ご褒美は報酬が後にやってくるのに対して、目の前のタスクをサボるってのはすぐに報酬を得られるからです。すると、脳はほぼ確実に「今ラクなほう」を選んじゃうんですよ。なので、この問題を解決するためには「サボった瞬間に損が発生する仕組み」を作る必要があるんですな。

これは経済学者の[イアン・エアーズ](https://amzn.to/4mUvw1n)がよく提唱する方法で、禁煙・運動・ダイエットなどでかなり再現性が高いことは折り紙付き。実践にはいろんな手法がありますが、特に取り組みやすいのは以下のようなパターンが使いやすいでしょう。

---

### **実践法1：デポジット方式（王道）**

エアーズ博士が最もオススメするのがこの方法で、やり方は簡単。

1. 最初にお金を預ける（例：1万円）
2. ルールを決める（例：毎日30分作業をする）
3. 守れなかったら没収する

みたいな感じで、「やらなかったら確実に損をする状況」をあらかじめ作ってしまうだけです。このとき重要なのは、

- 「預けたお金を取り戻す」って仕組みにすること
- 罰を第三者に委ねること

の2つでして、信頼できる友人やパートナーにお金を預けておくと、効果が跳ね上がります。まぁ、最悪自分でやってもいいんだけど、自分で管理するとどうしても甘くなりますからね。

### **実践法２：公開コミット**

こちらもエアーズ博士がよく使う手法で、サボったら人にバレて恥をかく環境を作るって考え方です。こちらもやり方は簡単で、

1. SNSやコミュニティで目標を宣言
2. 毎日結果を報告
3. 未達の場合は理由も公開

みたいになります。ここでのポイントは「見られている状態」を作ることでして、そもそも人間ってのは、お金よりも「評判」や「恥」に強く反応することがわかってるんで、この反応を利用して行動を強制的に引き出すわけです。

そのため、この手法は特に、

- 継続系（ブログ、筋トレ）
- 成果が見えるもの

との相性がいいんで、そこらへんに取り組んでいる方はお試しください。

### **実践法３：逆インセンティブ**

こちらはちょっと応用編で、「やらない行動にコストを乗せる」ってやり方も効果的です。たとえば、

- スマホ使用 → 1分ごとに罰金カウント
- サボり時間 → 可視化して減点
- 無駄時間 → 強制ログ

みたいに、サボり行動そのものにコストを発生させるわけっすね。こうすると、「何もしない」が一番損になる状態が作れますんで、コミットメントが高まりやすいんですよ。これもぜひお試しください。

ということで、エアーズ博士が提唱する手法は以上のとおりですが、ここで設計をミスると普通に効果がなくなるかもなので注意してください。罰則システムを上手く働かせるためには、特に以下の3つをお守りいただければと。

- **注意点１ 罰は「痛いけど現実的」にする**：ここで使う罰は、強すぎると実行しなくなるし、弱すぎると効かなくなっちゃうので、「ちょっと嫌だな」ぐらいのレベルを維持するようにしてください。
- **注意点２ ルールは具体的に**：「頑張る」じゃなくて「毎日20分」って感じで具体的に。曖昧さは逃げ道になりますんで。
- **注意点３ 即時性を重視**：実行に失敗して、しばらくしてから罰を与えると弱いので、失敗してすぐに罰が発生するようにしてください。脳は未来の損を軽視するんで、即時性がめっちゃ大事であります。

いずれにせよ、人間は本質的にラクなほうに流れる生き物なので、そこに逆らうよりも「サボると損する！」「やると現状維持だ！」と痛感させる仕組みに変えたほうが圧倒的にうまくいきますんで。ちょっと乱暴に聞こえるかもしれませんが、実際のところ「やらない自由」を減らすほど、人生はラクになるってのが真実なんで、最初は小さくでいいので、ぜひ取り組んでみてください。

## **フィードバック実行トレーニング２：他人の脳を借りる**

「他人の脳を借りる」ってのは、脳科学で言う「**観察学習**」の発想を使った手法です。これは、めっちゃざっくり言うと、

- 他人の行動を見るだけで、自分の行動パターンが変わる！

という現象のことでして、実際のところ、スポーツやリハビリの分野でも、「上手い人の動きを見るだけでパフォーマンスが改善する」って現象が確認されております。これにはご存じミラーニューロン（他人の行動を自分のことのように処理する神経回路）が関係してまして、意志力がゼロの人でも、環境さえ整えれば「勝手にやるモード」に入れるわけっすね。

では、この「観察学習」をどう実践に落とすかってことですが、ポイントは3つあります。

### **他人の脳を借りる際のポイント１：作業している人を常に視界に入れる**

一番シンプルなのは、YouTubeなどで「study with me」や「作業用動画」を流しっぱなしにする方法です。ただし重要なのは、「自分とレベルが近い人」を選ぶこと。あまりに優秀すぎる人だと逆に比較ストレスが働いて逆効果になるケースがあるので、「ちょっと頑張れば届きそう」ぐらいの相手がベストです。ここでは音声もオンにするのがポイントで、キーボード音やページをめくる音など、細かい行動の手がかりが増えることで、脳がより“同期”しやすくなります。

というと、「動画など流したらマルチタスクになって気が散るんじゃない？」と思うかもですが、それはあくまで関係ない情報を同時に処理しようとする時の話。周囲に自分と同じような作業をしている人がいる場合は、その人の行動を視界に入れることで集中力が高まるケースが多く報告されておりまして、適切に使えばマルチタスクどころか“集中ブースター”として機能するんですよ。

### **他人の脳を借りる際のポイント２：リアルタイムの相互監視環境を作る**

こちらは、いわゆる「もくもく会」や「オンライン自習室」みたいなもので、ZoomやDiscordでカメラをつけて互いに無言で作業すればOK。会話はほぼ不要で、「見られている状態」を維持するのが目的であります。

この手法のキモは、単なる観察学習に「社会的プレッシャー」が乗る点にあります。人間は一人だとすぐにサボっちゃうんだけど、誰かが見ているとやりたくなるものでして、研究でも他者が近くにいるだけで作業時間や集中力が上がる「社会的促進」って現象が確認されてたりします。特に単純作業や慣れた作業ではパフォーマンスが上がりやすいとされてますね。

### **他人の脳を借りる際のポイント３：観察→即実行の距離を極限まで縮める**

意外と見落とされがちなポイントとして、観察学習は「見たあとすぐやる」と効果が最大化するってのがあります。見てから実行までの時間が空くと、せっかく活性化した行動回路がリセットされちゃうんですよ。具体的には、

- 動画を見る → 同時に手を動かす
- 誰かが書く → 自分も書く
- 誰かが集中する → 自分もそのまま作業に入る

といった具合に、“同時実行”を徹底するようにしてくださいませ。

ってことで、まとめるとこのトレーニングの本質はシンプルで、「やる気を出す」のではなく、「やっている環境に自分を置く」ことにあります。人間は思っている以上に環境依存の生き物なので、「頑張ろう」とするよりも、「頑張っている人の中に入る」ほうが圧倒的にラクに動けるんですよね。逆に言えば、一人で気合いでなんとかしようとするほうが非効率なんですよ。もし実行力を上げたいなら、まずは1日30分でもいいので「誰かが作業している環境」に自分を放り込んでみてください。おそらく想像以上に、スルッと作業が始まるはずであります。

## **フィードバック実行トレーニング３：雑にやる**

「雑にやる」ってのは、みんな大好きスモールステップの発展版です。いちおうスモールステップを説明しとくと、行動を小さく分解して、無理なく実行できる単位に落とし込むテクニックですね。

「雑にやる」戦略では、この考え方をかなり極端なところまで引き伸ばしまして、

- **「これなら絶対にサボれない」レベルまで行動のハードルを下げる！**

ってとこまで徹底して細分化していきます。多くの人は「続かない理由＝意志が弱い」と考えがちなんだけど、実際のところはそうではなく、

- 始めるのが面倒
- ちゃんとやらなきゃと思っている
- 失敗したくない

といった“心理的コスト”の高さが原因で止まっているケースがほとんどなんですよ。たとえば「1時間勉強する」と決めると、

- 時間を確保しなきゃ
- 集中できる環境を整えなきゃ
- ちゃんと理解しなきゃ

といった複数のハードルが一気に立ち上がりまして、この時点で脳は「めんどい」と判断して回避に入るわけですな。行動科学の研究でも、習慣形成の最大のボトルネックは「開始コスト（スタートの面倒くささ）」だとされていますんで、ここを無視して「よしやるぞ」と気合で押し切ろうとしてもまず続かないので、どうにかしておきたいところです。

「雑にやる」を実践する際は、以下のようなやり方を取り入れてみてください。

### **雑にやる１：タスクの“バカレベル”分解**

まずやるべきはこれで、普通にスモールステップに分解するんじゃなくて、「こんなの意味ある？」と思うレベルまで細かくするってやり方です。たとえば、ブログを書くなら、

1. PCを開く
2. ファイルを開く
3. タイトルを書く
4. 1行だけ書く

みたいに分けてくださいませ。重要なのは「完了の定義」を極端に低く設定することで、“1行書いたら勝ち”ぐらいに設定してくださいませ。私も最近はダラブッカを練習する際に、この考え方を取り入れております。

その他の例としては、

- 本を読む → 1ページだけ開く
- 筋トレ → 1回だけ腕立てする
- 英語 → 単語を1つだけ見る
- 日記 → 1行だけ書く
- 片付け → 机の上の1つだけ動かす
- メール → 件名だけ書く

ぐらいまで細かくすることが考えられますね。これをやると始めるハードルが消えるし、始めた勢いで続くし……って流れが自然に発生。そのおかげで、“気づいたらやってた”状態に入りやすくなりますんで、困ったら「バカ分解だ！」と考えて、徹底的にブレイクダウンしてみてください。

### **雑にやる２：「やめてもOK」を前提にする**

これも重要なことで、多くの人は「一度始めたらちゃんとやらなきゃ」という前提を持ってるもんですが、これはプレッシャーの増大につながっちゃうんで逆効果。なので、「雑にやる」を実践する際は、「1分やったら、やめてもOK」ってルールを作り、作業を行う前に自分にそう言い聞かせてみてください。

このような条件をつけると、心理的な負担が激減して、とりあえず始めやすくなるってメリットが得られたりします。実際には、始めたらそのまま続けるケースが多いんですが、それは“副産物”であって、あくまで「１分でやめてOK」と考えながらやるのがポイントになります。

### **雑にやる３：「雑にやる」をあえてルール化する**

ここもポイントでして、「雑にやる」戦略においては、「“ちゃんとやる”を禁止する！」ぐらいでちょうどいい感じに落ち着きます。たとえば、

- 文章は推敲しない
- とりあえず思いついたまま書く
- 完成度は気にしない
- 筋トレはフォームを気にせず1回だけやる
- 英語は発音を気にせず読むだけ
- 楽器は1フレーズだけ雑に弾く

といった、ゆるめのルールを事前に決めておけばOKであります。これは心理学でいう「完璧主義の抑制」にあたりまして、「クオリティを下げても構わない！」と思って取り組むことで、一気に作業のハードルが下がり、タスクの実行率が上がるって現象があるんですよね。特にマジメな人や完璧主義傾向が強い人ほど、ここを緩めるだけで一気に動けるようになったりします。

ってことで、「雑にやる」のガイドラインを見てみましたが、この方法を一言でまとめると「やる気を出すのではなく、やらざるを得ないレベルまで簡単にする！」って感じになります。多くの人は「どうすれば頑張れるか？」を考えますが、実際には「頑張らなくてもできるようにしとく」ほうが成功率が高くなったりするものなんですな。

さらに面白いことに、多くのデータでは、雑に始めたほうが結果的に量が増え、最終的な質も上がるって報告も出てるんですよ。これは多くの創作研究でも示されている通りで、最初の質より“総量”のほうが成果を決める傾向が強いってのは、アダム・グラントの「[オリジナルズ](https://amzn.to/4cOb3Xy)」でも示されていたことですな。

なので、「ちゃんとやらなきゃ」という感覚が出てきたら、それはむしろ危険信号だと考えて、「雑でOK！むしろ雑にやる！」ぐらいのスタンスでちょうどいいと思います。

そんなわけで、長らく続いてきた「コーチャビリティ」の話はこれにて終了。結局のところ、「知っているかどうか」ではなく「どれだけ実際に試したか」で成長の差は決まるってことで、ぜひ紹介した手法を1つでもいいので日常に取り入れてくださいませ。ではまた！
