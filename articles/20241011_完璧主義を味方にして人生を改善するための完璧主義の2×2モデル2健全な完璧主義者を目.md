# 完璧主義を味方にして人生を改善するための「完璧主義の2×2モデル」#2「健全な完璧主義者を目指そう」

「完璧主義の2×2モデル」の続きでーす([#1](https://daigovideolab.jp/blog/2204531))。

このシリーズでは、人生を破壊しかねない完璧主義に立ち向かうべく、「完璧主義の2×2モデル」ってのを使いつつ、「**健康的な完璧主義**」を目指す方法を紹介しております。完璧主義の良い面をうまく活かして、人生の改善に役立てようねーみたいな話ですね。

それでは、前回で理論の説明は終わったので、今回は具体的なトレーニング法をチェックしていきましょうー。

## **ステップ１．自分の完璧主義を特定して、監視する**

ってことで、「健全な完璧主義者」になるために使うべきは、毎度おなじみ「認知行動療法」です([R](https://amzn.to/4dyoyJ5))。完璧主義は歪んだ信念によって発生する現象なので、当然ながら認知行動療法のテクニックが使えるわけです。

健全な完璧主義者を生み出すための認知行動療法は、以下のように運用していきます。

1. 完璧主義がいつ起こるかを特定し、監視する
2. 個人の思考を疑い、何が現実かを知る
3. ECPの完璧主義的思考パターンに挑戦し、克服する
4. 挫折や失敗に対処する

このステップを踏むことで、あなたの脳内に自動的に生まれる特定の状況、思考、行動に対する意識が向上。悪い完璧主義が発生する主要な原因である「周囲の評価への不安」に対処できるようになりますんで。かく言う私も、完璧主義には長らく悩まされてますんで、地道に作業を続けているところです。

では、健全な完璧主義を目指すための介入をチェックしてみましょう。まず最初のステップでは、下のリストを使って、自分の人生を完璧主義がジャマしちゃう例を考えてみてください。

1. **完璧主義の状況**：完璧主義的な懸念を感じた特定の状況を記録してください（例：試合に負けたときなど）。
2. **完璧主義的な思考**：この懸念を抱いたときに頭に浮かんだ考えを記録し、その考えをどれぐらい信じているかを「0～100%」で評価してください（例：自分は完全な失敗者だ。信じてる度は60％ぐらい）。
3. **完璧主義的な行動**：その気持ちに応じてあなたが取った行動を記録してください（例：試合後、疲れ果てるまで練習をした）。
4. **自分の気持ち**：あなたの感情を記録し、その感情を「0～100%」で評価してください（例：怒り、不安、恥ずかしいなど。「怒り50％」とか）。

この作業は、できるだけ完璧主義で問題が起きた直後に行うのがベスト。このようなモニタリングを習慣づけるには、常にバッグの中などにメモ帳やログブックを置いておくと良いでしょう。

## **ステップ2．個人の予測を試す**

続いて、自分の考えや行動のどれが真実なのかを掘り下げてみましょう。ここで大事なのは「行動実験」の考え方で、自分の脳内に浮かんだ思考や行動が、果たしてどれぐらい現実になるのかを試してくやり方です。

例えば、あなたがアスリートで「自分がチームメイトの前でミスをしたら、彼らは自分を軽蔑するだろう」と思っているとしましょう。その場合は、あえて「試合中にミスをしても、落ち着いて状況を受け入れ、他のチームメイトとのコミュニケーションを意識的に増やしてみる」って実験を行うことで、果たして自分の予測が正しいかどうかをチェックするわけですな。

もうひとつ例を挙げると、あなたがビジネスマンで「重要なプレゼンの前に徹夜で準備をしないと、必ず失敗してしまう」と考えていたとしましょう。この場合は、あえて徹夜せずに、計画的に数日間に分けて準備し、睡眠を十分に確保する。プレゼン当日は普段どおりの生活を心がける」って実験を行い、果たして自分の予測が正しいものなのかどうかを調べていくわけです。

もちろん、その結果として、自分の予測が現実になる可能性もあるわけですが、それはそれで「自分の思考がどれだけ正しいのか？」をジャッジするための指標になりますからね。特定の思考に悩まされたら、まずは行動実験に取り組んでみましょう。

行動実験を行うには、以下の手順をふんでみてください。

1. **完璧主義的な懸念/信念を書き出す**：「自分が完璧だと感じるまで、集中的にトレーニングしなければならない」「重要なプレゼンの前に徹夜で準備をしないと、必ず失敗してしまう」「自分の考えや意見を人前で話すと、必ず批判される」みたいに、自分の人生に問題を起こしていそうな心配や懸念を書き出します。
2. **信念/懸念に基づく予測を行う**：上で書き出した心配が現実になったらどんなことが起きるのかを考えます。例えば、「もし試合中にミスをしたら、チームメイトは冷たい態度を取り、信頼を失うだろう」「徹夜しないと内容が不十分になり、プレゼン中に焦り、失敗するだろう」「会議で発言すると、他のメンバーは自分の意見を否定し、批判してくるだろう」みたいな感じです。
3. **予測を具体化する**：ステップ２で考えた予測を、さらに細かく掘り下げていきます。「試合中にパスミスやシュートミスをしたら、チームメイトは私を無視したり、プレー中に私をサポートしなくなるだろう」「プレゼンを途中でつっかえたり、資料をうまく説明できなかったら、上司は私に重要な仕事を任せなくなり、評価が大きく下がるだろう」みたいな感じです。
4. **行動実験**：自分の不安とは異なる行動を考え、それを実際に行っていきます。「試合中にミスをしても、落ち着いて状況を受け入れ、他のチームメイトとのコミュニケーションを意識的に増やしてみる」「徹夜せずに、計画的に数日間に分けて準備し、睡眠を十分に確保する。プレゼン当日は普段どおりの生活を心がける」「会議で自分の意見を積極的に述べ、周りの反応を観察する。意見に対して賛成・反対の意見が出ることをあらかじめ受け入れておく」みたいな感じです。
5. **結果をチェックする**：行動実験を行った後で、「自分がどのように感じたか？」「これによってパフォーマンスに違いが生じたか？」などをチェックしていきます。「ミスの後、チームメイトは逆に励ましてくれたり、ミスをカバーしてくれた。コミュニケーションの回数も減らず、冷たい態度は見られなかった」「プレゼンの前日も十分に睡眠をとり、当日は落ち着いてプレゼンを行えた。焦ることもなく、予想よりも高評価を得ることができた」「自分の意見に対して、批判的な意見はほとんどなく、むしろ建設的な意見や追加の提案が多かった」みたいな感じですね。
6. **振り返り**：行動実験の結果をふまえて、何に気づいたのか、何を理解したのかを書き出してみましょう。「 自分がミスをしても、チームメイトはそれを受け入れており、自分を軽蔑するようなことはなかった。むしろ、彼らとの関係をより強化できた」「徹夜せずとも、十分なパフォーマンスを発揮できることに気づいた。逆に、睡眠をとることでプレゼンに集中できた」「他者が批判的に感じるのは、自分の思い込みだったことに気づいた。他者の意見を受け入れることが、会議をより生産的にした」って感じです。
7. **修正された信念**：最後に、ここまでの作業をふまえて、どのような考え方や心配がより現実的なのかを考えて書き出してみましょう。「自分がミスをしても、チームメイトは受け入れてくれるし、パフォーマンスがすべての評価を決めるわけではない」「徹夜をしないことが、失敗につながるわけではない。計画的な準備と休養が成功につながる」「自分の意見を述べることは批判を受ける原因ではなく、他者とより深い議論を生むきっかけとなる」みたいな感じです。

以上の作業は、1週間に1回または2回のペースで行ってください。このような検証と振り返りを定期的に行っておくと、少しずつ正確な情報が蓄積されて、より客観的な視点が身につくようになりますんで。

## **ステップ3．悪い完璧主義の思考パターンに挑む**

ステップ２の行動実験を行って、より現実的な思考をゲットできたら、これをベースに「**ちょうどよいガイドライン**」を考えていきましょう。

基本的に、悪い完璧主義ってのは「これをしなければならない！」って厳しいルール設定を伴いまして、このような独自のルールは「オール・オア・ナッシング」思考に起因することが多いんですよ。いわゆる「1回負けたらすべて失敗だ！」みたいな思考のことですな。この思考が強いと、あらゆる物事を「完全な失敗」か「完全な成功」かで判断するため、平均的なパフォーマンスを発揮する余地がなくなっちゃうんですよ。

したがって、このようなルールが自尊心に与えるダメージを減らすために、自己を評価する新しい方法を開発しなけりゃいけません。自分だけの厳格なルールを柔軟なガイドラインに置き換え、それを新たな基準として使って行くわけですね。

そのためには、以下のような手順を踏んでみてください。

1. **特定する（Identify）**： 硬直したルールを特定します。（例：次の試合で10回中9回勝たない限り、努力を続ける価値はない。）
2. **具体化する（Specify）**： 硬直したルールが、どのような「オール・オア・ナッシング」思考で構成されているかを考えます（例：勝つか、諦めるか。）
3. **ガイドラインを作る（Create）**： 極端なルールの真ん中ぐらいにあるガイドラインを作成します。（例：強い相手に負けたが、全力を尽くして新しい学びを得た。または、10回中4回負けたが、これはただ調子が悪い日があっただけだと受け入れる。）
4. **振り返る（Reflect）**： 完璧ではないパフォーマンスを特定することで学んだことを振り返る。（例：10回中9回勝てなかったとしても、自分の価値が下がるわけではない。）
5. **テストする（Test）**： 新しいガイドラインをテストするために、行動実験を行います（ステップ２の手順を使用）。（例：次の試合で10回中6回勝ったとしても、それは素晴らしい成果だとする。）

このようなオール・オア・ナッシングの思考を練習すればするほど、自分の成功をゼロかイチかで考えなくなり、より柔軟で現実的な対応ができるようになるわけです。 ちなみに、このトレーニングを行う際は、自分が自分に課した目標が達成可能かどうかを判断するために、友人やチームメイトに、目標を達成できなかったときにどう対処しているかを聞いてみるのも良いでしょう。

といっても、これだけだとイマイチわかりづらいでしょうから、いくつかの事例を挙げてみましょう。

- **事例 1: スポーツ選手のパフォーマンス評価**
  - **硬直したルール**：「次の試合でミスを一度でもしたら、自分は無価値だ。勝利以外はすべて失敗だ。」
  - **極端な基準を具体化**：「完璧にミスなしで試合に勝つか、もしくは少しでもミスをして試合に負けるか。中間はない。」
  - **柔軟なガイドラインを作成**：「試合中にミスをしても、それを迅速に修正し、全力でプレーすることが重要。また、勝つことよりも自分の成長を感じられたら成功とみなす。ミスをしても落ち込むのではなく、その原因を考え次の機会に活かすことを目標にする。」
  - **振り返る**：「ミスをしても、それが必ずしも敗北を意味するわけではなく、ミスから学ぶことで自分を成長させられる。また、勝利しなくても、ベストを尽くすことに価値があると感じられるようになった。」
  - **テストする**：「次の試合では、ミスをしてもそれを受け入れ、落ち着いてプレーを続ける。試合後には、『ミスがパフォーマンス全体にどれほど影響を与えたか』を振り返る。また、試合中にどの程度冷静でいられたかを自己評価する。たとえば、試合後に、チームメイトやコーチに「ミスをどう感じたか」「全体のパフォーマンスはどうだったか」についてフィードバックを求めたりとか」

- **事例 2: 学業の成績に対する考え方**
  - **硬直したルール**：「テストで100点を取れなければ、自分は失敗だ。90点以下はすべて無意味だ。」
  - **極端な基準を具体化**：「100点以外は全て不合格。90点でも満足してはいけない。」
  - **柔軟なガイドラインを作成**：「90点を超えたら、理解度が十分であるとみなす。100点を取ることを目指しつつも、重要なのはどれだけ学んだかであり、点数だけにとらわれないようにする。80点以上であれば、テスト後に解答を確認し、間違えた箇所を復習して次に活かすことを目標とする。」
  - **振り返り**：「90点を超えても達成感を感じなかったのは、点数にこだわりすぎていたからだと気づいた。100点を取れなかったとしても、努力した過程や学んだ内容を評価することが重要だと分かった。」
  - **テストする**：「次のテストでは、90点以上を目指しながらも、勉強中やテスト中に学ぶ楽しさを見つけることを意識する。テスト結果が返ってきたら、100点でなくても「自分がどこで理解が足りなかったのか」を分析し、それを改善する方法を考える。」

- **事例 3: 仕事の完璧主義**
  - **硬直したルール**：「プロジェクトを完璧に仕上げなければ、上司に評価されないし、自分には価値がない。」
  - **極端な基準を具体化**：「完璧に仕上げるか、ミスをして評価が大きく下がるか。中間の評価は存在しない。」
  - **柔軟なガイドラインを作成**：「プロジェクトの成功はミスの有無だけでなく、どれだけクリエイティブなアイデアを提案できたか、期限内に仕上げたか、チームワークを発揮できたかも評価基準とする。プロジェクトが完全に完璧でなくても、どのように問題を解決したか、またチーム内でどのように協力したかを振り返る。」
  - **振り返り**：「プロジェクトが完全に完璧ではなかったが、チーム全員が満足する成果を得られた。上司も結果よりもプロセスを評価してくれたので、必ずしも完璧が必要ではないと気づいた。」
  - **テストする**：「次のプロジェクトでは、完璧を目指すのではなく、タイムマネジメントとチームワークを優先し、柔軟に対応することを心がける。プロジェクト終了後には、自分とチームが学んだことを記録し、今後に役立てるようにする。上司にプロジェクトの進捗や改善点を率直に相談し、完璧主義のプレッシャーを減らす努力をする。」

ってことで、健全な完璧主義をめざすためのステップは以上です。この作業で最も大事なのは、「何が自分の行動を駆り立てているのか？」を意識することで、あなたが「これはなんか強制されている気がする」と思ったり、「自分で決めた基準ではないなぁ」と感じてしまうような目標を目指すと、自己批判が起きやすくなり、あなたが本来持つパフォーマンスを低下させたりしますんで。

この問題を解決するためには、否定的な考えを認識し、目の前の状況をより健全にとらえる方法を見つける訓練をするのが一番。脳に根づいた完璧主義を修正するのは大変なんですけど、小さな変化にも確実に意味がありますんで、私と同じタイプの人は一緒に頑張っていきましょう。ではまた！
