このエントリの目標ってのは、

- **見た目が良い肉体を作りたいと思ったときに、どうやって毎日の食事を決めていくか？**

になります。筋肉が多くて体脂肪が少ない体を作る際に、いかに食事の量を決めていくか？みたいなポイントですね。この点において、過去のエントリはちょっと複雑すぎて使いづらいとこがあるんで、今回は「シンプルに使いやすい！」ってとこを目指してみました。

## **1日のカロリー摂取量をどう決めるか？のガイドライン**

さて、これからあなたが「**見た目の良い肉体を作りたい！**」と決めた場合は、当然ながら、まずはカロリーの摂取量を決めなきゃいけないわけです。世の中には「カロリー神話は崩れた！」や「糖質を減らせばよい！」という極論もありますけど、**なんだかんだでカロリーを調整するしかよい肉体を作る道はない！**って結論には変わりがないもんですから。

でもって、カロリー摂取量を設定する方法としては、一般的に3つの方法があります。

1. 仮定
2. 推定
3. 観察

では、さっそくそれぞれのやり方をみていきましょう。

### **1.仮定**

まず最初の「仮定」ってのは、**あらかじめ1日の摂取カロリーの目標をおおまかに設定**して、これの数値を目標に食事をしていくやりかたです。もちろん日々のカロリー計算には違いが出てしまうんだけど、もっとも手軽なんで、めんどうなことを考えたくない人はこのやり方を使うのが一番ラクでしょう。

ってことで、体型の目標によってどのように摂取カロリーを設定するかの目安を見てみましょうー。

1. **積極的に体脂肪を減らしたい場合**＝1日の食事を体重1キログラムあたり24キロカロリーにする
2. **ゆるめに体脂肪を減らしたい場合**＝1日の食事を体重1キログラムあたり29キロカロリーにする
3. **いまの体型を維持したい場合**＝1日の食事を体重1キログラムあたり33キロカロリーにする
4. **ゆるめに筋肉を増やしたい場合**＝1日の食事を体重1キログラムあたり37キロカロリーにする
5. **積極的に筋肉を増やしたい場合**＝1日の食事を体重1キログラムあたり42キロカロリーにする

もちろん、これらは非常に大まかな目安でしかないので、「この数値をガチガチに守らなきゃダメなんだ！」ってわけじゃないです。あくまで自分の目標に沿って、これぐらいのカロリーを目指して長期的にがんばるとうまくいきやすいよーって話ですんで。

### **2.推定**

次の「推定」は、多くの人に当てはまるカロリー計算式を利用して、だいたいの基礎代謝の推定値を算出する方法です。人気のある方程式には、次のようなものがあります。

- **日本版ハリスベネディクト**
  - **男性**：66+ 13.7×体重 + 5.0×身長 – 6.8×年齢
  - **女性**：665.1 + 9.6×体重 + 1.7×身長- 7.0×年齢

- **ミフリンセントジョー式**
  - 9.99 x 体重(kg) + 6.25 x 身長(cm) - 4.92 x 年齢 + 166 x 性別 (男性＝1、女性＝ 0) ー161

- **国立健康・栄養研究所式**
  - **男性**：（0.0481×体重＋0.0234×身長－0.0138×年齢－0.4235）×1000/4.186
  - **女性**：（0.0481×体重＋0.0234×身長－0.0138×年齢－0.9708）×1000/4.186

- **カニンガム式**
  - 370+21.6×除脂肪体重
  - 除脂肪体重は「体重×(100-体脂肪率)/100)」で計算

これのどれが正解ってことはないんですけど、一般論としては、

- かなりの筋肉量がある人にはカニンガム式を使う（除脂肪体重を組み込んでるので正確な数値が出やすい）
- そこまで筋肉がついてない場合は、日本版のハリス・ベネディクト式か国立健康・栄養研究所式を使う（どっちも日本人の平均的な体型を組み込んでるので）

みたいになるでしょう。まぁ、個人的な経験から言えば、どの方程式を使っても自分の基礎代謝や安静時の代謝をそこそこ把握できるなーって印象ではあります。必要であれば、4つの式をすべて実行して、その平均値を取ってみてもいいんじゃないでしょうか。

でもって、安静時の代謝量の推定値を出したら、ここに「活動係数」をかけましょう。要するに、自分がいつもどれぐらい体を動かしているかを考えて、そのぶんを安静時の代謝に組み込んでいくわけですね。

もっとも**定番の活動係数**は以下のようになります。

- 座り仕事がメインで、ほとんど運動をしない場合＝1.2
- 週に1〜3日のウォーキングやジョギングをしている場合＝1.375
- 週に3〜5日のランニングや筋トレをしている場合＝1.55

- 週に6〜4日のハードな有酸素運動や筋トレをしている場合＝1.725

- ほぼ毎日のようにハードな有酸素運動や筋トレをしている場合＝1.9

まぁこれも細かく考えていくと「毎日運動はしてるけど日中はほとんど座り仕事なんだよなぁ」みたいな問題にぶちあたりがちなんですが、ここはあんま詰めてもしかたないので、おおまかに自分がどのような運動をしているかを基準に考えてください。

ここまでの話をまとめると、たとえば体重60kgで週に1〜3日のウォーキングをしている40歳で170センチの男性が、国立健康・栄養研究所式で計算をしてみたとしたら、

- （0.0481×60＋0.0234×170－0.0138×40－0.4235）×1000/4.186 × 1.375＝**2179.6キロカロリー**

みたいな感じになるわけっすね。これが、この人の1日の消費カロリーになります。

以上の消費カロリーを出したうえで、最後は自分の目的に合わせてさらに数字をいじっていきましょう。具体的な計算法は、以下のようになります。

- **体重や筋肉を増やしたい場合**：1日の総消費カロリー量に1.1または1.2をかける。これによって推定の維持カロリーよりも10～20％多く食べることになり、体重増加はかなりスピーディに進んでいくはずであります。ここで、もし体脂肪の増加を最小限に抑えたい場合は、1日の総消費カロリー量に1.05をかけるぐらいからスタートするとよいでしょう。
  逆に「積極的に体重を増やしたい！多少の脂肪増加は気にしない！」って場合は、1日の総消費カロリー量に1.15〜1.25ぐらいをかけた数値を設定してくださいませ。
  しかし、もっと単純に計算したいのであれば、「維持カロリー＋125キロカロリー」ぐらいに設定しておくと「**体脂肪の増加をギリまで押さえた増量**」になり、「維持カロリー＋500キロカロリー」に設定しておくと「体脂肪は増えるが積極的な増量」になりますんで。

- **体重や体脂肪を減らしたい場合**：この場合は上と逆のアプローチをとりまして、「とりあえずゆっくり減量したい！」って場合は、1日の総消費カロリー量に0.8〜0.9をかけて目標の摂取カロリーを設定しましょう。これで10～20％のエネルギー不足が発生しますんで、筋肉の減少を押さえつつゆるやかに体脂肪を減らしていけるはずであります。
  一方で、もっと積極的に減量していきたいときは、1日の総消費カロリー量に0.6〜0.7をかけて、30～40％のエネルギー不足を作り出してくださいませ。ただし、これぐらい積極的に減量を始めると、目標をより早く達成できるものの、空腹感や無気力感が増して、筋肉が減る可能性も高くなりますんでご注意ください。個人的な経験では、30～40％のエネルギー不足はやっぱどうにも辛くて、仕事にも差しつかえが出ちゃったんで、減量したいときはゆるやかな方式に切り替えました。
  また、もうちょい簡単に計算したいときは、「**ゆっくり減量したいとき＝1日の総消費カロリー量から250〜500キロカロリーを引く**」を使い、「**普通に減量したいとき＝1日の総消費カロリー量から500〜750キロカロリーを引く**」を使い、「**積極的に減量したいとき＝1日の総消費カロリー量から750〜1000キロカロリーを引く**」ぐらいの計算を使ってくださいませ。

### **3.観察**

最後に３つめの手法が「観察」です。これは自分の体重の変化を目安に摂取カロリーをコントロールしていく方法でして、「上記のような一般的な式を使うのは誤差が大きいから嫌だ！」みたいな人に向いてます（観察法も結構な誤差は出ますけども）。

観察法のやり方は簡単で、

1. 毎朝の体重を記録する
2. 1日のトータルのカロリー摂取量を記録する
3. 1週間後の体重を1週間前の体重とくらべる
4. 体重の変化に応じてカロリー摂取量を増減させる

みたいになります。あくまでも1週間ごとの体重を基準にしつつ、日々の摂取カロリーを決めていくわけっすな。

では、どのような感じで体重の変化を見ればいいかと言うと、以下のようになります。

- **ガッツリ減らす**：週に＞1.0％ずつ体重を減らす
- **ゆったり減らす**：週に0.25〜1.0％ずつ体重を減らす

- **いまの体重を保つ**：現在の体重をキープする

- **ゆったり増やす**：週に0.25〜1.0％ずつ体重を増やす

- **ガッツリ増やす**：週に＞0.25％ずつ体重を増やす

たとえば、もしあなたが「ガッツリ減らすぞ！」ってのを目標にして、1週間後の体重が１％も減ってなかったから、そこから１日の摂取カロリーをさらに減らしていけばいいわけっすね。記録の手間はあるもののの、たいして量があるわけじゃないですし、日常のルーチンに組み込むといいんじゃないでしょうか。定期的にコツコツ調整していけるので、「仮定」や「推定」よりも長期的には精度が高まりますしね。

おそらく、このアプローチの最大の課題は、「**一時的な体重の変動に一喜一憂しない！**」ってとこでしょうね。人間の体重は、ナトリウムの摂取量、糖質の摂取量、水分レベルによって日々変動しまくるんで、「昨日より500グラムも増えてる！」とかいちいち考え出すと、メンタルがやられちゃいますんで。

## **次回予告**

ってことで今回は、「**見た目が良い体を作るために1日のカロリー摂取量をどう決めるか？**」ってポイントを見てみました。これらの戦略は相互に排他的なものではなくて、タイミングを見ていろんな方法を使うといいでしょう。一般的には、

1. 最初は「仮定」と「推定」を使って、おおまかな摂取カロリーを決める
2. 何週間か使ってみたら「観察」に移動して、体重の変動を基準にする

みたいに切り替えるのが普通でしょう。どんな手法を使っても、長い目で見て進歩を続けるためには、肉体の変化を観察する必要が出てきますからねぇ。

そんなわけで、今回で摂取カロリーの決め方は終了で、次回はタンパク質や糖質量の決め方をまとめていきます。ではまた！
