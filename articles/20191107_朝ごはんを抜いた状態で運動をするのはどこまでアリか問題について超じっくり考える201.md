# 「朝ごはんを抜いた状態で運動をするのはどこまでアリか？」問題について超じっくり考える：2019年版

![記事内画像](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F1829411%2F4b5d19a3-6ce5-4834-a7cc-02b16f49ca54.jpg?alt=media&token=4b5d19a3-6ce5-4834-a7cc-02b16f49ca54)

「運動で体をしぼるのは結構ムズかしいよ！」とは「[パレオダイエットの教科書](https://amzn.to/34on2WV)」にも書いてることで、どれだけ走ろうが筋トレをしようが、どうしてもカロリー削減には勝てないんですよね([R](https://www.ncbi.nlm.nih.gov/pubmed/20826629))。

その理由についてはいろいろありますけど、

- そもそも運動で削れるカロリーは小さい

- 運動をすると、そのあとで大食いをしちゃうケースも多い([R](https://www.ncbi.nlm.nih.gov/pubmed/17848941))

- 運動をすると[NEAT](https://yuchrszk.blogspot.com/2015/05/neat_29.html)が減っちゃう（運動したせいで日中に体を動かさなくなる）([R](https://www.ncbi.nlm.nih.gov/pubmed/23470300))

みたいなところが代表的なところ。運動でせっかくカロリーを削ったのに、それが帳消しになるような行動を取ってしまうのが人間であります。

## **運動後にハイカロリーなものを食べたくなっちゃう問題**

特に大きいのは「運動後の大食い」問題で、その流れをざっくり説明すると、

1. 運動のおかげで体内の糖質が燃えて、肝臓内のグリコーゲンが少なくなる
2. 肝臓内のグリコーゲンが少なくなったのを、人体が「エネルギー不足になった！」と解釈する
3. 運動後の食事量が増える！

みたいになってます。そもそも肝臓内のグリコーゲンってのは、体のエネルギー調整の指標になってたりしまして([R](https://www.ncbi.nlm.nih.gov/pubmed/21615191))、ここの容量が減るとどうしても食欲は暴走しがちなんですよね。実際、「**運動をすると体に悪いものを食べたくなってしまう……（ポテチとかファストフードとか）**」みたいな人も多いんじゃないんでしょうか。

で、この「**運動後にドカ食いしたくなる問題**」に使えそうなのが「**空腹状態のエクササイズ**」であります。お腹になにも入ってない状態で行う運動のことですね。

どういう理屈なのかを簡単に説明しますと、

1. 空きっ腹で運動をするとグルコースは消費されるが、同時に脂肪も燃焼する
2. 脂肪が燃えたおかげで肝臓内のグリコーゲン量が増える（体内における糖の貯蔵量よりも脂肪の貯蔵量が多いので）
3. そのせいで不要に食欲が暴走せずにすむ

みたいになります([R](https://www.ncbi.nlm.nih.gov/pubmed/15498802))。空きっ腹のまま運動をすると、グルコースと同時に脂肪を燃やして糖に変えてくれるんで、その分だけ肝臓内のセンサーを刺激せずにすみ、**その後も健康的な食事に意識が向きやすくなるのではなろうか**、と。

## **「朝メシ抜きの運動」が使えそうなケース**

が、残念ながらこの仮説についてはほとんど検証が進んでなかったんですが、近ごろいい感じのデータ([R](https://eprint.ncl.ac.uk/254915))が出てましたんで、「運動後についハイカロリーなものを食べちゃう！」って問題にお悩みの方には参考になるんじゃないかと。

これは12人の若い男性を対象にしたランダム化のクロスオーバー試験で、被験者の年齢は23祭でBMIは23.6ぐらい。全員に対して３つのトライアルを行なっております。

1. 8:00AMに朝食を食べる → 3時間の休憩 → 好きなだけランチを食べる
2. 8:00AMに朝食を食べる → 2時間の休憩 → ピークパワーの50％で1時間のサイクリング → 好きなだけランチを食べる
3. 朝食を食べない → 2時間の休憩 → ピークパワーの50％で1時間のサイクリング → 好きなだけランチを食べる

というわけで、朝食アリとナシでその後の食欲にどれぐらいの変化が出るのかをチェックしたわけですね。ここで使われた朝食は普通のオートミールなどで、430kcalぐらいになってます。

そこで、どんな結果が出たのかと言いますと、

- 普通に朝食を食べてから運動をせず、好きに昼食を食べた場合の1日のカロリーバランス＝+492 kcal

- 普通に朝食を食べてから運動をして、好きに昼食を食べた場合の1日のカロリーバランス＝+7 kcal

- 朝食を抜いてから運動をして、好きに昼食を食べた場合の1日のカロリーバランス＝**-400 kcal**

- 肝臓内のグルコースレベルは、昼食の摂取量と正の相関を示した（r=0.62）

みたいになってます。運動をせず普通に食事したグループがカロリーオーバーになってるのは当然ですが、朝食を抜いてから運動したグループはその後の昼食でのドカ食いが減り、結果として1日のカロリーバランスがマイナスになったみたい。結構、仮説どおりの結果が出てますね。

というわけで話をまとめると、

- あくまで**短期間**に限ってだが、朝食を抜いたあとで運動をすると過食が起きにくく、1日のカロリーバランスがマイナスになる（可能性がある）

みたいな感じです。もちろんこれは少人数の実験だし、過去には「[空腹時に運動をしてもダイエットに影響がない](https://yuchrszk.blogspot.com/2017/12/blog-post_86.html)」というより精度が高いデータも出てますんで、おそらく**長期的な減量には使えない**可能性が大であります。そこら辺はくれぐれもご注意ください。

ただし、一方では「**空腹時に運動をすると体脂肪が燃えやすいよ**！」というメタ分析([R](https://www.ncbi.nlm.nih.gov/pubmed/27609363))があるのも確かなんで、要するにすべてをひっくるめれば、「**朝メシ抜きの運動**」が有効な人というのは、

- 運動すると食欲が増しちゃうせいでエクササイズが帳消しになりがちな人には効く

- 「夏までに痩せたい！」みたいな人が短期決戦で体脂肪を削るためには効く

ということは言えそうに思います。私の場合は、すでに数年にわたって朝メシ抜きでウォーキングを続けてるので、もはや運動後の食欲の変化は感じてないのですが、もしエクササイズによる食欲の暴走にお悩みの方は、

1. 朝メシを抜いて、最低でも12〜14時間の空腹期を作る
2. ウォーキングか軽いサイクリングぐらいのゆるい運動を1時間ぐらい行う

みたいな流れでやってみるといいと思います。ただし、ここでHIITみたいなハード運動をすると、おそらく人体への負担が大きくなりすぎる気もしますので、あくまで軽めのエクササイズでお願いします。
