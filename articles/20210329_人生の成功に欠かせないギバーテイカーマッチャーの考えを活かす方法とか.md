# 人生の成功に欠かせない「ギバー」「テイカー」「マッチャー」の考えを活かす方法とか

![a48317b6b359d604bdf52059739ac3283faac8a5](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2006292%2Fa48317b6b359d604bdf52059739ac3283faac8a5.jpg?alt=media&token=affff766-5141-4c22-ae78-1df7b8ad6a16)

みんな大好きアダム・グラント先生([R](https://hbr.org/2013/04/in-the-company-of-givers-and-takers))は、人生における成功は以下の4要素で決まると考えておられます。

1. モチベーション
2. 能力
3. 機会／運
4. 他人との関わり

いずれもめちゃくちゃ重要な要素なのは言うまでもないでしょう。このなかでも**グラント先生が重視してる****のは「他人との関わり」**で、周囲の人間とどうコミュニケーションを取るかで、人生の運やモチベーションが大きく左右されてしまうのは非常にわかりやすい話でしょう。俗に「**互恵スタイル**」などと言われる観点ですな。

---

でもって、このブロマガをお読みの方であれば、アダム・グラントさんが「ギバー」「テイカー」「マッチャー」という3つのコミュニケーションスタイルを提唱してるのはご存じなはず。いちおうおさらいしておくと、

1. **ギバー**：主に他者の利益のために行動し、自分自身の個人的なコストはほとんど考慮しない。テイカーやマッチャーに比べて成功する可能性もあるが、人を助けすぎて失敗することも多いので、行動する前に費用対効果の分析を行わないと死ぬ
2. **テイカー**：自分の利益を他者の利益よりも優先させる自己中心的な傾向がある。他人を助けることがあっても、その貢献が他の人の目に触れたり、自分の評判を高めたり、その他の見返りが約束されている場合に限られる
3. **マッチャー**：上記2つのスタイルの中間に位置する。他人を助けるときには、あくまで向こうのお返しを期待し、バランスを保とうとする。誰かが自分に支援や援助をしてくれれば、それに合わせて恩返しをする。他者への支援を検討する際に、見返りがあると確信できるまで時間と労力を費やすことをためらう。

みたいになります([R](https://www.researchgate.net/publication/313788094_Givers_takers_and_matchers_-_Reciprocity_styles_and_their_contribution_to_organizational_behaviour))。人間を分類する方法はいろいろありますけど、かなり使い勝手が良い分け方っすね。

というわけで、以上をふまえた上で、人生でうまくやっていくためには「**自分の周囲には**ギバー・テイカー・マッチャーの誰が多いのか？****」を明確にしておくのが超大事。グラント先生の本では「自分がいかにギバーになるか？」といったポイントが強調されてますが、厳しい世の中をわたっていくためには、**周囲の人たちの互恵スタイルを知っておく方が大事だったりする**んですよ。いかに自分がギバーになったとしても、**まわりがテイカーばかりだったら搾取されて終わり**ですからね。

というわけで今回は、自分の社会的ネットワークの中で「ギバー」「テイカー」「マッチャー」のどれが多いかを特定する手法を見てみましょう。このやり方を知っておくと、

- テイカーの悪影響を避けることができる
- 自分のエネルギーやリソースを削る人と過ごす時間を減らせる
- 残ったエネルギーを大事なことに振り分けられるようになる

ってメリットがありますんで、「なんか日常のエネルギーがない……」とか「いつも時間に追われている気がする……」みたいな方にはおすすめです。要するに、****自分の人生の防御力を上げることができるようになる****わけですな。

では、具体的な方法を見てみましょうー。

### ステップ1：ネットワーク分析

まずは、あなたの社会ネットワークの中で、「ギバー」「テイカー」「マッチャー」を特定してみましょう。以下の詳しい説明を読みつつ、あなたの周りに「**このような行動をとる人いないか？**」と考えてみて、思い当たる人の名前をリストアップしてみてください。友人、家族、職場の同僚など誰でも構いません。

**a. ギバーの特徴**

- 困っている人に手を貸す
- 頼まれなくても小さな親切をする
- 自ら助けを必要としている人を探す
- 人に利用されやすい
- 成功するための最良の方法は、他の人の成功を助けることだと考えている
- 自分を犠牲にしても、時間やエネルギーを惜しみなく提供する
- 自分の時間を犠牲にしすぎることがある
- 他の人が助けを必要としていることに気づき、喜んでサポートを提供する
- 他の人が目標を達成できるように自分の時間やリソースを提供し、他の人に助けを求めることがほとんどない
- 他者のニーズに応えることに時間をかけすぎて、燃え尽き症候群になることがある
- アドバイスや知識の共有により、無条件に他の人をサポートする
- 周りの人たちと強い関係を持っている
- 与えることが自分の人生に与える影響をほとんど考慮しない

上記のリストに目を通したら、自分の周囲で当てはまる人を思いつくだけ書きましょう。

**b. テイカーの特徴**

- 自分のことに集中し、自分の利益を最優先する
- 自分のことを考え、他の人にも同じことを期待する
- 他の人が自分に何を提供してくれるかを評価し、自分が与える以上の利益を得る
- 富、権力、成功を重んじる
- 利己的だが、魅力的でカリスマ的に見える
- 人前で魅力的に振る舞うのがうまい
- 何かをしたくないときに「ノー」と言うことに抵抗がない
- 競争心が強く、周りの人よりも優れていたり、成功していたりすることにこだわる
- 自分のミスを他人のせいにする
- 個人的な利益（自分の評判を上げるなど）が個人的なコストを上回る場合にのみ、援助を提供する
- 他人に助けを求めたり便宜を図ってもらうことはあっても、最終的に何らかの利益にならない限り、お返しをすることはない
- 自慢が多い
- 自分の目標達成に役立つ人には優しいが、何のメリットもないような人には悪く接する
- 周りの人のやる気やエネルギーを奪い、敵対的な環境を作り出す可能性がある

上記のリストに目を通したら、自分の周囲で当てはまる人を思いつくだけ書きましょう。

**c. マッチャーの特徴**

- 与えることと奪うことを同じ割合にしようとする
- 他の人を助けるときは、同じレベルのお返しを期待する
- 見返りがあると確信するまで、時間や努力を費やすことをためらう
- ギバーの成功を応援する傾向がある
- 助けることが社会的規範の一部であると考えており、他人を支援することが好き
- 人の努力は公平であるべきだと考えている
- 互恵的なスタイルに合わせる傾向がある。例えば、テイカーと接すると同じように振る舞う。誰かが自分を助けてくれれば、その人にお返しをするような行動をとる
- 人から何かを受け取ると、そのお返しをしたくなる
- 「あなたがあれを買ってくれたから、これを買ってあげる」というようなことを言いがち

上記のリストに目を通したら、自分の周囲で当てはまる人を思いつくだけ書きましょう。

### ステップ2：人的投資の再検討

いまの対人ネットワークを把握できたら、続いては、「自分はテイカーにどれだけの時間と労力を費やしているか？」や「テイカーと過剰に関わってないか？」を確かめるステップです。

もちろんテイカーが必ずしも悪いわけじゃないものの、ほとんどの場合は一方通行のコミュニケーションになりがちなので、やる気やエネルギーが失われるケースが多め。逆に、「ギバー」と「マッチャー」は自分に活力を与えてくれるケースが多いんで、増やしていきたいところです。

ってことで、具体的には以下の質問について考えてみるといい感じです。

- テイカーとしてリストアップした人のそばにいるとき、あなたはどのように感じますか？

- あなたがマッチャーとギバーとして挙げた人たちと一緒に過ごすとき、あなたはどのように感じますか？

- テイカーといる時に抱く感覚は、ギバーやマッチャーと比べて、どのような違いがありますか？

- あなたの人生では、テイカーと過ごす時間が多すぎると思いますか？ もしそうだとしたら、このような人たちに、どれぐらい時間とエネルギーを注ぎ続ける必要がありますか？

- テイカーに多くの時間と労力を割くのをやめて、マッチャーやギバーにもっと投資することは可能でしょうか？ もし可能であれば、テイカーと過ごす時間を減らすために、どのようなステップを取ることができますか？

- マッチャーやギバーとの時間を増やすためには、どのようなステップを踏めばよいでしょうか？

- 人生においては、すべてのテイカーのと時間を減らすわけにもいきません。この事実を念頭に置いて、彼らmの悪影響から自分を守るために、どのような境界線を設定できますか？

- テイカーには複数の側面があり、例えば職場ではテイカーの特徴を示していても、家族にはギバーな人もいます。あなたが挙げたテイカーのリストを見たときに、その人たちが、ギバーな一面を見せたシチュエーションに心当たりはありませんか？ そのようなシチュエーションをもっと利用できないでしょうか？

## **まとめ**

ってことで、今回は「**自分の社会資本**」を考える上で超大事な「ギバー」「テイカー」「マッチャー」のお話でした。繰り返しになりますが、テイカーとの付き合いが必ずしも悪いわけではなくて、

- テイカーは一時的に大成功を収めることも多い
- こちらを「役に立つ」と思った時のテイカーの働きはすごい

といったあたりは重要なポイントなんで、押さえておいてください。あくまで適度な距離感を見定めるのが重要って話ですんでー。
