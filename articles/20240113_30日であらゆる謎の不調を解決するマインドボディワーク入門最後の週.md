# 30日であらゆる謎の不調を解決するマインドボディワーク入門「最後の週」

![920114b36351fc2abb293aaa06b9387d816b967a](https://firebasestorage.googleapis.com/v0/b/daigovideoapp-d658e.appspot.com/o/blogs%2Fpaleo%2F2181036%2F1_920114b36351fc2abb293aaa06b9387d816b967a.jpg?alt=media&token=50b6a8fa-77c3-446d-a5f1-768b74008e8a)

マインドボディワーク入門の続きです！([#1](https://daigovideolab.jp/blog/2179044),[#2](https://daigovideolab.jp/blog/2179377),[#3](https://daigovideolab.jp/blog/2180772))

---

このシリーズでは、メンタルの問題によって、腰痛、頭痛、肩や首の痛み、お腹の不調、アレルギーといった謎の不調が悪くなってしまう現象に 立ち向かうためのワークを紹介しています。体の不調の多くはメンタルと密接に結びついているため、 薬物治療などで効果が出ない方はこちらもぜひお試しください。

でもって、このシリーズは今回が最後です。もしあなたの痛みが本当にメンタルから来るものだった場合は、4週目＋2日のワークを終えた時点で、すでに症状がだいぶやわらいだ人もいるでしょう。もちろん、脳の思い込みってのはかなり強固なんで、30日のワークでは修正されないケースもありますが、メンタルと痛みの相関はかなり立証されてますんで、ここでくじけずにがんばっていただきたいところです。

## **マインドボディワーク第4週目**

最後の週では、これまでやってきたワークのまとめに取りかかります。まずは先週やったワークをもう一度読み直しながら、最後のワークに取り組みましょう。

### **22日目のワーク**

日付 \_\_\_\_/\_\_\_/\_\_\_\_\_

1. いままで書いてきたことを読み直して、どの質問と答えがあなたの心に最も強く響きましたか？ 最も強く心に響いた質問と答えをピックアップし、なぜそれらが心に響いたのかを考えてみましょう。
2. 今日あなたが体験したことで、上の質問で「心に響いた質問と答え」で味わった感情と、似たような感情を味わった事例はなかったでしょうか？ なかった場合は、過去に類似の感情を経験したことがなかったかを思い浮かべてください。その時の感情はどのようなもので、あなたはどのような反応をしたでしょうか？
3. 上の質問で書き出した感情と、あなたの痛みとの関連について考えてください。あなたが、その感情について考えたり書いたりしている間に、痛みが治まったり、悪化したりといったことはありませんでしたか？
4. もっと運動の量を増やすことについて考えるときに、どのように感じますか？ 運動してもまったく痛みとは関係ないと感じますか？ それとも、運動をしたら痛みが悪化すると感じますか？
5. 今週はどのような楽しい活動を予定していますか？ このようなアクティビティについて考えるのはどんな気分ですか？

### **23日目**のワーク****

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_\_

1. ここ最近の人生で、あなたが最も多く抱いている感情はなんですか？このワークをはじめたときと比べて、感情になんらかの変化はありましたか？
2. 身体に痛みを感じた場合、最近のあなたはどう対処していますか？ そこで自分が抱く感情や、そこで自分が使う対処法、そこで自分が使うテクニックなどを考えて書き出してください。もし痛みがない場合は、「もし痛みが再発したらどうするか？」を考えてみてください。
3. 身体の痛みについて考えると、どのような感じがわきますか？ その感じは数週間前と変わっていますか？もし変わったらなら、どのように変わりましたか？
4. あなたが痛みに関して一番恐れていることは何ですか？ 例：日常が楽しくなくなる、痛み止めの濫用が続く、仕事を失うかもしれないなど
5. 今の痛みが完全に消えたところを想像してください。痛みがなくても、上の質問で出てきた恐怖は、やはりあなたを悩ませますか？ その事態が怖い理由はなぜですか？

### **24日目のワーク**

日付 \_\_\_/\_\_\_\_/\_\_\_\_

1. あなたが人生で最も楽しみにしていることは何ですか？
2. 自分がなにかを達成したときに、ちゃんと自分をほめられていますか？ もしほめていないと思うなら、それはなぜですか？ 自分をもっとほめるにはどうすればいいですか？
3. 自分をほめるときに、あなたがいつも自分のどこをほめますか？（例：性格、知性、おもしろさ、ルックスなど）。自分をほめることについて、なんらかのパターンはあります？
4. 最近、両親や友人にほめられたことはありますか？ もしほめられたなら、その時にどう感じましたか？
5. 自分自身をほめるべきことを、最低でも１０個挙げてください。そして、それらの点を実際にほめる方法を考えてください。

### **25日目のワーク**

日付 \_\_\_/\_\_\_\_/\_\_\_\_\_

1. ここ最近の人生で、あなたが最も多く抱いている感情はなんですか？このワークをはじめたときと比べて、感情になんらかの変化はありましたか？
2. どのような活動をしているときに、自分が完全に没頭しており、過不足がない状態だと感じますか？ そのような活動の例をいくつか挙げてください。
3. 上で挙げた活動を、もっと頻繁にやらない理由はなんですか？
4. 1日15分間の実践で、もっと自分の気持ちを落ち着かせるようなアクティビティはありませんか？ あなたにとって「人生に過不足がない」という感覚はどのようなものですか？
5. 今日は、どのような運動をしましたか？ それに対してどんな感情を抱きましたか？

### **26日目のワーク**

日付 \_\_\_\_/\_\_\_\_\_/\_\_\_\_\_

1. ここ最近の人生で、何が特筆すべき変化はありましたか？
2. 最近、本当に怒りを感じことはありましたか？ もしあったなら、その理由を思い出せる限り鮮明に描写してください。
3. いま振り返ってみて、その怒りはあなたの中のどこから来たのでしょうか？ 以前にもそのように感じたことがありますか？ それについても思い出せる限り鮮明に描写してください。
4. 怒りが起きたときに、自分でそれを認めて受け入れられていますか？ 怒りが増すのはどのような状況ですか？

### **27日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_\_

1. 最近、あなたにとって最も重要な人間関係について、どのような感想や感情を持っていますか？
2. 最近、その人との接し方で何か変わったことはありますか？ もし合ったなら、それはどのような感覚ですかか？ そう感じたのはなぜですか？
3. その人と分かち合うのが最も難しい感情は何でしょうか？ その理由はなんですか？ それは、あなたが抱く認めがたい感情と同じものですか？
4. 最近の痛みには何か変化がありましたか？ （自分の感情と痛みとの関連について、何か気付いたことがあれば書き出してください）。

### **28日目のワーク**

日付 \_\_\_\_/\_\_\_\_\_/\_\_\_\_\_

1. あなたの仕事（オフィスや家庭）に、何か変化はありましたか？ 最近の自分の仕事について、どのような感情を抱くことが多いですか？
2. いまの仕事で一番大変なことは何ですか？ それについてどのように感じていますか？
3. 自分の仕事をどのように変えたいですか？ どのように変わってほしいですか？
4. 自分の仕事のなかで楽しさを感じるところは何でしょう？ 仕事がうまくいっているときはどんな気分でしょうか？

## **最終２日**

30日間サイクルの最後の2日間は、ここまでの総括と反省を行いすつ、そして今後の計画を立てていきましょう。少し時間を取って、今日までの全ワークに目を通しながら、ここまでの作業を振り返ってみます。

### **29日目のワーク**

日付 \_\_\_\_/\_\_\_\_/\_\_\_\_\_

1. このワークで書いてきた中で、あなたにとって最も重要だと思われるものはどれですか？ そして、それを重要だと思うのはなぜですか？
2. いまあなたが感じる痛みは、あなたの状態について何を教えてくれますか？ それは、自分の感情とどうつながっていますか？
3. 今後、自分の感情とうまく付き合っていくためには、どうすればよいと思いますか？ ワークを続けなくても、感情とのつながりを保つには、今後どのようなことが必要ですか？ どんな考えや感情でも構いません。
4. 感情との付き合い方の改善を維持するために、取り組むべきことは何でしょうか？ さらに感情との付き合い方がうまくなるために取り組むべきことは何でしょうか？

### **30日目のワーク**

日付 \_\_\_\_/\_\_\_\_\_/\_\_\_\_\_

1. ここ最近の人生で、何が特筆すべき変化はありましたか？
2. 自分の痛みとメンタルのつながりについて考えると、どんな感情が浮かびますか？ 不安や心配はありますか？
3. このワークを続けた1ヶ月間で、自分自身について学んだ最大のことは何ですか？
4. 今後、どのようなことをしたいと思いますか？ 好きなアクティビティ、気持ちの整理、就職活動、人間関係の改善など、何でも構いません。

## **30日後**

すべてのワークを終えたあなた。おめでとうございます。

ワークが終わったら、まずはあなたの健康状態を評価してみてください。ここまでのワークで進歩を遂げているのなら、これからのあなたの進歩は積み重なっていき、成長し続けるはずであります。困った時は、いつでもこのワークに戻ってください。

逆に身体の問題がほとんど改善していない場合は、状況を見直すことを考えてみてください。具体的には、

1. 再び医師の診察を受ける。
2. 心身症にくわしい心理療法家を探して相談する。
3. ここまでの30日間ワークを再び繰り返す。

といった感じになります。自分の症状を心身症として受け入れることがまだ難しい、あるいは心身のつながりを信じるのがまだ難しいと感じるなら、[シリーズの初回](https://daigovideolab.jp/blog/2179044)で取り上げた本を再読してみるのもいいでしょう。

いずれにしても、痛みと脳のサイクルが断ち切れるまでには、短期間で終わる人もいれば、多少時間がかかる人もいます。もしあなたが後者であったとしても、絶望せずに取り組んでいただければと思います。ではまた！
