「人生の停滞を乗り越える10のルール」の続きです！(#1,#2,#3,#4,#5,#6)

 

このシリーズでは、ニューヨーク大学の心理学者、アダム・オルター博士の文献をもとに、「人生が行き詰まっている！」「仕事がうまく進まない！」といった問題に悩む方へ、こいつを突破するための10のルールをチェックしております。私のように「いまやってる仕事で何も面白いことができていない気がする……」みたいな感覚にさいなまれがちな人は、ぜひお試しあれ。

 

停滞突破ルール7. 異端者を使う

というわけで、停滞を突破するための７つめのルールは「異端者を使う」です。その名のとおり、自分が停滞感を覚えたら、あえて“異端”の考え方を導入してみるって考え方です。

 

というのも、近年のイノベーション研究などを見ていると、「異端者」や「異分野出身者」をあえて混ぜたチームのほうが、はるかにブレイクスルーを起こしやすいって報告がやたらと増えてきたんですよ。その理由はシンプルで、「みんなが同じ方向だけ見ていると、そもそも新しい道が見えない」からであります。

 

たとえば、アダム・オルター博士が海外ドラマ『Doctor Who』の制作チームを分析し、評価が高いエピソードを担当したスタッフを調べてみると、

 

  • メンバーの経歴がバラバラ
  • 初めて一緒に働く人がいる
  • 他分野・異文化からの新参者がいる

 

という“カオス状態”なメンバーで作っていることが多かったんだそうな。逆に、「気心知れた仲良しメンバー」だけで固めると、何とも平凡で記憶に残らない話ばかりになってしまったんだそうで、これはなかなか面白い話ですな。

 

似た話はいろいろありまして、天才と呼ばれるピクサーのブラッド・バード監督（『Mr.インクレディブル』『レミーのおいしいレストラン』）も、

 

「わざと空気を読まない“ブラックシープ（変わり者）”をチームに入れろ！」

 

と推奨しておられます。彼いわく、「異端者が放つ予測不能なアイデアや意見」が組織の“惰性”を打ち破る最大のカギになるんだそうな。実際、バード監督のプロジェクトは、ブラックシープを積極的に起用した時期ほどイノベーションが爆発したんだそうで、これもナイスな実例っすね。

 

 

 

実践編：どうやって“異端”の思考を使う？

じゃあ、どんなふうに自分の停滞に「異端者の視点」を取り入れれば良いのか？ってことですが、基本的な考え方はこんな感じです。

 

  1.  異分野・異文化・他社から“全く違う人”を1人以上入れる：　いつもの「気の合うメンバー」＋「初めまして」の人を必ず組み合わせてみる。

  2.  ブラックシープ（異端者）役を毎回つくる：　「今日はAさんが“あえて反対意見を出す係”ね」と役割を交代制にする。

  3.  会議ルールに“否定しないタイム”を設ける：　出てきたアイデアや異論反論を、その場で否定しない。全員が「とりあえず聞く」時間を必ず作る。

  4.  AIやくじ引きを使って、強制的に“無意味な提案”をさせるワークを挟む：予想外の発想が飛び出す→そこから本命の突破口が見つかることも多い。

 

ただし、これはあくまで“集団”の中での考え方なんで、個人の人生が停滞した時に使うのは難しいかもしれません。ということで、いかに異端者の発想を「自分に取り込む」方法を見てみることにします。自分の仕事や人生が停滞していると感じたら、以下のようなワークを導入してみてください。

 

 

異端ワーク1．「逆張り」ワーク

これは、自分の「常識」や「当たり前」に、いったんNOを突きつけてみるワークです。一見バカバカしいアプローチなんですが、アダム・オルター博士によれば、停滞を抜け出すためのカギになることが意外と多いんだそうな。具体的には、こんなことをやってみてください。

 

 

ステップ1：前提・常識を書き出す

今、自分が「当たり前」「正しい」と信じていることや、行動の前提になっている“ルール”を紙やノートにリストアップします。

 

  • 例：
    • 「仕事は早く終わらせるべき」
    • 「会議は静かに話すもの」
    • 「毎日運動しないと健康になれない」
    • 「上司の意見は絶対」
    • 「新規事業は失敗しやすい」

 

大きなテーマでも、小さな“思い込み”でもOKなんで、いまの停滞を起こしていると思われるものを中心に書き出してください。

 

 

ステップ2：真逆・逆張りの仮説を立てる

書き出したそれぞれの前提に対して、「もしこの逆が正しかったら？」という仮説を立てて、こちらも書き出してみましょう。

 

  • 例：
    • 「仕事は“遅く”やった方がいい場合もあるのでは？」
    • 「会議は“雑談が多いほうが”良いのでは？」
    • 「運動を“休む日が多い”方が健康になるのでは？」
    • 「上司の意見は“疑った方が”成果が出るかもしれない」
    • 「新規事業は“失敗しやすいからこそ成功しやすい”のでは？」

 

 

ステップ3：逆張り視点で「メリット・可能性」を探す

ステップ2で考えた「逆張りが正しい」と仮定したときに、どんなメリットや新しい可能性が生まれるか？を考えてみます。

 

  • 例：
    • 「仕事をあえて“ゆっくり”やることでミスが減り、質が上がる」
    • 「会議で雑談が増えることで、アイデアが出やすくなる」
    • 「休養日を増やすと、身体の回復力やモチベが高まる」
    • 「上司の意見を疑うことで、より良い案が生まれる」
    • 「失敗の多い新規事業の中に、実は大ヒットの種がある」

 

 

ステップ4：現実の課題や悩みに「逆張り案」を当てはめる

今の自分の停滞や課題（仕事の進め方、人間関係、健康習慣など）に「逆張り案」を1つ試してみましょう。

 

  • 例：
    • いつも早く仕上げている仕事を、あえて余裕をもって「じっくり考える日」をつくる
    • 「これはムダ」と思っていた雑談の時間を、会議で5分だけ設けてみる
    • 「やらないと落ち着かない運動」を、あえて1日サボってみる

 

 

ステップ5：結果を観察＆気づきを記録する

逆張り行動をやってみて、「何が起きたか？」を振り返り、気づきを記録します。実際に「予想外によかったこと」「困ったこと」「気づいた新しい視点」など、なんでも書き出してくださいませ。

 

  • 例1：仕事のやり方を「遅くする」に逆張り
    • やってみたこと：　普段よりもタスクを“あえてじっくり進める”ようにした。
    • 結果・気づき：最初は「効率悪いな」と不安だったが、細かいミスに気づけて、仕上がりの質がかなり上がった。　余裕ができたせいか、新しいアイデアも浮かびやすかった。

 

  • 例2：会議で雑談タイムを取り入れてみた
    • やってみたこと：　いつもはすぐ本題に入る会議を、開始5分だけ雑談に使ってみた。
    • 結果・気づき：メンバー同士の緊張がほぐれて、会議中も発言が増えた。思わぬところで共通の悩みが出てきて、課題解決のヒントが生まれた。

 

ということで、ワークの全行程は以上です。これを見ればおわかりのように、「逆張り」ってのは“反対の視点”から自分を見直すセルフツールでして、停滞しているときほど、思い込みや慣習をひっくり返すことで突破口が見つかるものなんですよ。ということで、まずは“安全な範囲”から、小さな逆張りチャレンジをしてみてくださいませ。

 

 

 

異端ワーク2．AI異端ワーク

停滞を打破したいなら、AIに“現実離れしたとんでもないアイデア”を出してもらうってのもおすすめです。これもアダム・オルター博士が実際にやっている方法で、突拍子もない案から、本当に使えるヒントが見つかることは少なくないんだそうな。たしかに、悩みが堂々巡りしているときってのは、“自分では絶対に思いつかないバカなアイデア”こそが役立ったりするんですよね。ってことで、AIの力を借りて、非常識な発想から突破口をつかむ方法を見てみましょう。

 

 

ステップ1：テーマを一言で書き出す

まず、「何について停滞しているのか？」を考えて、一文で整理しましょう。

 

  • 例：
    • 仕事の新サービス企画が思いつかない
    • ブログのネタが毎回ワンパターンになる
    • 転職後のキャリアが迷子

 

ここでは具体的に書けなくてもOKなんで、自分の“もやもや”をなるべくシンプルな言葉にするのがコツであります。

 

 

ステップ2：AIに「変なアイデア」をリクエストする

ChatGPTなどのAIに、“常識外れ”や“ありえない”アイデアをお願いしましょう。

 

  • 使えるプロンプト例：
    • 「この悩みについて、絶対現実では無理そうな解決策を10個ください」
    • 「逆転の発想や、笑い話レベルの解決策をリストアップして」
    • 「この問題について、“絶対にふざけてるだろ”と思うような突飛なアイデアを10個ください」
    • 「物理法則や社会常識が一切無視できるとしたら、どんな方法で解決できますか？」
    • 「3歳児が考えたような解決策を10個ください」
    • 「宇宙人が地球人を驚かせるために編み出す解決策をリストアップしてください」
    • 「未来人が100年後からアドバイスするとしたら、どんな突破案を教えてくれますか？」
    • 「“全部失敗しても構わない”前提で、失敗前提のバカバカしい作戦を考えてください」

 

私の体験では、キャラクターや“視点”を変えるプロンプトは特に効果的でして、さらには「常識破り」「現実無視」「ふざけてOK」など、条件を盛り込むとAIがブレーキを外しやすくなりますんで。もちろん使い回しもOKで、毎回少しずつお題や人数・視点を変えても新しい気付きが得られるはずであります。

 

 

ステップ3：AIから出てきた“変な案”をリストアップ

AIが出してくれたアイデアを、そのまま並べて書き出しましょう。くだらないとか思わず、必ずすべてリストアップします。その上で、「もしかして、これヒントになるかも？」という部分を探してください。

 

  • 例：
    • 「AIが直接脳にサービス内容をテレパシーで送信」→現実のヒント：「お知らせや通知の“手間ゼロ化”」「ユーザーが意識しなくても勝手に情報が届くUX」→ 例：ロック画面に自動表示されるヒント集／SlackやLINEのボット通知機能
    • 「サービス利用者全員がタイムトラベルできる」→現実のヒント：「過去の自分・未来の自分にアドバイスを送る機能」「失敗したときに“巻き戻し”ができる設計」→ 例：やり直しボタン付きのアプリ／目標達成アプリの「過去の自分からメッセージ」通知
    • 「ブログを読むだけで筋肉が増える」→現実のヒント：「学びと運動を同時進行する仕掛け」「読みながら筋トレできるサービス」　→ 例：音声記事＋ストレッチガイド／記事の合間に「運動タイム」ボタンが表示されるウェブサービス
    • 「社内全員がコスプレで会議する」→現実のヒント：「日常の仕事に遊び・非日常感を導入」「会議の“服装ルール”で心理的ハードルを下げる」　→ 例：月1回“ドレスコード・デー”を導入／「推しキャラ・Tシャツ」推奨日
    • 「上司が透明人間になって見守る」→現実のヒント：「見えないけど“適度な監視感”がある仕組み」「匿名フィードバック」　→ 例：アンケートを完全匿名で回収／チャットの“見守りモード”を設置
    • 「社内の全員が1日1回クイズに答えないと退社できない」→現実のヒント：「強制的な振り返り・知識共有の導入」「小テスト感覚で楽しく学ぶ習慣」　→ 例：業務終了時に「今日の気づきクイズ」／朝礼で“知識シャッフル”ゲーム
    • 「サービスの説明がすべて短歌や俳句」→現実のヒント：「あえて制約のある伝え方」「クリエイティブな自己紹介や商品説明」　→ 例：SNS投稿に“5・7・5縛り”の日／エレベーターピッチを30秒ポエム化

 

 

ステップ４：「変なアイデア」から“派生案”を10個出す

拾ったヒントを現実に落とし込めるよう、さらに10個のアイデアに広げます。

 

  • 例：
    • 音声記事を聞きながらストレッチする“ながら運動”アプリ→ 記事を聞きながら自動でストレッチ音声が流れるサービス。
    • ブログ記事の途中に“筋トレチャレンジ”ボタン設置→ 途中で“腕立て5回”のミッションが出現。達成すると限定記事が読める。
    • 記事の内容に合わせた「ポーズ」イラストが随所に出る→ 読みながら自然と身体を動かす仕掛け。
    • 読み進めると画面に“カウントダウン体操動画”が埋め込まれる→ 読了ごとに30秒スクワットチャレンジ。
    • 「運動した人だけコメントできる」認証付きブログ→ スマホの加速度センサーで腕立てやスクワット回数を計測し、達成した人だけコメント欄が解放される。
    • 「運動後の読書に効果あり」医学コラムの連載→ “運動×学び”の相乗効果をエビデンスで伝える特集記事。
    • 記事の最後に「今日の筋トレ小話」コーナーを毎回入れる “読むだけ健康法”の実践コーナー。
    • 「著者と一緒に筋トレライブ配信」付き記事→ 記事公開時にライブ運動イベントも同時開催。

 

 

ステップ5：1つだけ現実に試す

ってことで、最後に一番気軽に実行できそうなアイデアを1つだけ選び、実際に行動に移してみましょう。1日だけ、1回だけ、10分だけ、など「実験」レベルでOKだし、失敗しても全然問題ないので、成功や失敗にこだわらずやってみてくださいませ。「小さな実験」を続けることが、停滞突破の王道ですんで。

 

 

 

異端ワーク3．セルフ・デビルズアドボケイト

停滞から抜け出したいのに、どこかモヤモヤして前に進めない時は「デビルズアドボケイト（反対役）」として、自分自身を徹底的に批判してみるのも効果的であります。本気で自分のアイデアや計画に“ツッコミ”を入れてみることで、盲点や本当の課題がハッキリ見えてきますんで、こちらもお試しいただければと。

 

 

ステップ1：書き出し

まずは現状と「進めたいこと」を紙に書き出しましょう。

 

  • 例：
    • 「今の仕事にやりがいを感じない」
    • 「新しいプロジェクトがなかなか進まない」

 

こんな感じで、自分の停滞ポイントを素直に言語化してみてください。進めたいプランや理想像も併記すると、なおよしであります（例：「副業を始めたい」「新商品を提案したい」など）。

 

 

ステップ2：最大の敵になる

「あなたの最大の敵」になったつもりで、徹底的に反論・否定してみましょう。あえて意地悪で、嫌な上司や批判的な友人、SNSの炎上コメント主になりきってみてくださいませ。

 

  • 書き方例：
    • 「どうせまた三日坊主でしょ？」
    • 「そんなプラン、前にも失敗したじゃないか」
    • 「そもそも本当にそれ必要？」
    • 「他の人に勝てる理由ある？」
    • 「やらないほうが安全じゃない？」

 

もしここでうまく反論と否定が出てこない時は、以下の質問の答えを考えてみてくださいませ。

 

  • 「これまで見落としていたリスクや課題は？」
  • 「周囲から否定されるとしたら、どんな理由が多い？」
  • 「全然うまくいかなかった場合、なぜだと思う？」
  • 「自分でも信じ切れていない点はどこ？」
  • 「時間・お金・体力のどこが足りない？」
  • 「本当に今やる価値がある？優先順位は？」

 

 

ステップ3：“反論リスト”を冷静に読み返す

続いて、上で書き出した反論や突っ込みを、いったん「他人事」として冷静に眺めましょう。「ムカつく…」と感じても、感情ではなく“ファクト”としてチェックするのがポイントであります。でもって、そこから「具体的な対策案」「新しい視点」を抽出してみてください。その際は、「自分をいじめる」だけで終わらず、必ず“反転案”を設けましょう。もし「反論できない」と感じたら、「一度保留」「小さく分解」「他人に相談」など、すぐに動ける小さな一歩を決めてください。

 

  • 例：
    • 「三日坊主になる」→“あえて3日間だけ全力でやってみる”や“周囲に宣言して監視役をつける”
    • 「リスクが多すぎる」→“小さくテストできる形で始める”
    • 「優先順位が低いかも」→“やらない場合のデメリット”も紙に書いて比較する

 

 

ってことで、今回は「違いこそ最強の突破口だ！」みたいな話でした。同じ考え方の人と付き合うのも大事ですが、時に“よそ者”や“変わり者”の力を借りないと限界突破は難しいのでご注意ください。そのためには、反対意見や無茶振りも歓迎し、異質な発言が出る場を“仕組み”として用意する姿勢が大事になりますんで。
