「AI時代に必要なのは『ケンタウロス思考』だ！」の続きです！(#1,#2,#3,#4,#5,#6,#7,#8)

 

このシリーズでは、みんな大好きサイエンス誌に掲載された最新のレビュー論文をもとに、AIを単なる便利ツールとして使うのではなく、人間の思考を拡張する「チームメンバー」として扱うための実践法を考えていきます。AI時代に私たちが鍛えるべきなのは「AIに正解を出させる力」ではなく、「AIと一緒に考える力」なのではないか？というのが、このシリーズの大きなテーマであります。

 

さて、ここまでのシリーズでは、AIを単なる便利ツールではなく、役割を持ったチームメンバーとして扱おう！という「ケンタウロス思考」を見てきました。簡単におさらいすると、

 

  • AIに仕事を丸投げしない
  • 役割を分ける
  • ときには意見を戦わせる
  • 出てきた答えを疑い、最後は自分で統合して決める

 

みたいな感じっすね。要するに、これから大事なのは「自分の仕事や生活のなかに、どんなAIチームを作るか？」みたいな話であります。人間とAIは得意とする欠点の種類がズレているので、うまく役割を分ければ、単独では出せない答えに近づける可能性があるわけですね。

 

といっても、もちろんいきなり6人のAIエージェントを連携させる必要はなく、最初は「発散係」「ツッコミ係」「編集係」ぐらいでも十分。大事なのは、AIを使うたびにゼロから「何を頼もう？」と考える状態を抜け出し、自分なりの思考の流れを持つことであります。

 

ということで、今回はシリーズ最終回。実際に、自分だけのAI思考チームを組み上げるための手順を見てみましょうー。

 

 

 

まず、あなたが強化したい仕事を1つだけ選ぶ

さて、AIのチームを組もうとするときにありがちな問題が、「用途がぼんやりしている！」ってパターンです。たとえば、「AIを使って仕事を効率化したい！」とか「もっと人生をよくしたい！」みたいな目標だけを立てて、肝心の作業内容を決めないまま始めちゃうようなケースですな。

 

こんなふうに「人生をよくするAIチーム！」みたいに考えると、だいたい途中で何をさせればいいのかわからなくなるんで注意したいところです。結果として、チームの役割分担もプロンプトも曖昧になっちゃうんですよね。

 

この問題を解決するためには、まずは「繰り返し発生する具体的な仕事」をひとつだけ選んでください。いくつか例を挙げると、

 

  • 文章を書く
  • 調べものをする
  • 企画を考える
  • 仕事の意思決定をする
  • 勉強・学習を進める
  • 創作アイデアを出す
  • 人間関係や人生の悩みを整理する

 

といった感じっすね。なにかひとつ決めたら、以下のフォーマットでメモに残しておいてくださいませ。

 

私がAIチームで強化したい作業は、＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿です。

 

この作業で、いちばん詰まりやすい場所は、＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿です。

 

本当はAIに手伝ってほしいのに、うまく任せられていないことは、＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿です。

 

ここでのポイントは、「AIに何をしてほしいか？」よりも、自分はどこで止まりがちか？を見つけることであります。たとえば、文章を書く場合でも、人によって詰まる場所は大きく異なりまして、

 

  • ネタが出ない
  • 調べものに時間がかかりすぎる
  • 構成が決まらない
  • 書き出しが重い
  • 文章は書けるけど、論理が甘くなる
  • 書いたあとに直しすぎて終わらない

 

みたいな感じで、原因は千差万別じゃないですか。この違いを無視して「ブログ作成AI」を作っても、やたらアイデアが多すぎたり、こちらの目的を取り違えたりして、あまり役に立たないんですよね。AIチームってのは、あくまで自分の弱点を補うための編成として組むのが鉄則であります。

 

ということで、この「AIチームを何に使うのか？」問題に取り組むためのワークをやってみましょうー。

 

 

 

ワーク1：作業を「工程」に分ける

何も考えずにAIを使うと、私たちはつい「記事を書いて」とか「企画を考えて」とか「この問題を解決して」みたいな指示をしがちであります。まぁ、こういう頼み方が必ずしも悪いわけではないんですが（私もしますし）、ケンタウロス思考では、ここで一段階止まるのが大事。なぜなら、完成品だけをそのまま投げると、AIはあなたの代わりに考えるしかなくなるからであります。

 

ということで、まずは以下のワークを埋めてみてくださいませ。

 

 

ワーク：作業を分解する

私が選んだ作業：

 

この作業が完成するまでの工程：

  1.  
  2.  
  3.  
  4.  
  5.  
  6.  

 

 

いくつか例を挙げましょう。もしあなたが「ブログを書く」なら、こんな感じです。

 

 

  1. 読者が抱えている悩みを見つける
  2. ネタや論点を広げる
  3. 必要な情報を集める
  4. 構成を組む
  5. 原稿を書く
  6. 論理の穴を探す
  7. 読みやすく整える
  8. タイトルを考える

 

 

あるいは、あなたが新規事業の企画を考える人なら、こんな感じです。

 

 

  1. 解決したい問題を言語化する
  2. 想定する顧客を分ける
  3. 既存の代替手段を調べる
  4. 仮説を作り、小さな実験に落とし込む

 

 

ちなみに、この段階では、「どのAIを使うか？」はまだ考えなくてOK。まず先に必要なのは、自分の仕事が、どんなプロセスでできているかを見える化することなんで。

 

 

ワーク2：AIに任せる工程、人間が行う工程を分ける

工程が見えたら、次にやるのは分担であります。ここでありがちな失敗は「面倒な部分は全部AIにやってもらおう！」と考えることでして、たとえば検索結果をそのまままとめさせたり、文章を最初から最後まで書かせたり、意思決定まで任せたりするような使い方ですな。

 

もちろん、調査や要約、初稿づくりなどはAIにかなり任せられるし、そうしたほうが絶対にいいんですけども、これだとどうしても人間側が何を担当すべきかがあいまいになってしまうんすよ。なので、ここでは人間が担当すべき仕事をはっきりさせる必要があるわけです。

 

特に、人間側に残したいのは以下の4つであります。

 

  • 目的を決める
  • 何を重要とみなすか決める
  • リスクをどこまで受け入れるか決める
  • 最終的な責任を負って選ぶ

 

ということで、ここでは「AIに渡す仕事」と「自分で持つ仕事」を分けるワークをやってみましょうー。

 

ワーク：分担を決める

B：AIと人間が一緒にやる
C：人間が中心でやる

工程2：　→　A / B / C

工程3：　→　A / B / C

工程4：　→　A / B / C

工程5：　→　A / B / C

工程6：　→　A / B / C

 

その工程で必要なもの主役にしやすい側
大量の情報整理AI

比較表や選択肢の整理AI
文脈の理解人間
読者や相手への配慮人間
長期的な価値判断人間
何を捨て、何を残すか人間
反対意見を出すことAI＋人間

 

ここでAIに任せるべきなのは、「自分が苦手な工程」だけじゃないのでご注意ください。むしろ、量が必要な工程、視点を増やしたい工程、単調な検査が必要な工程ほど、AIに任せたほうがチーム全体が強くなりますんで。

 

 

ワーク3：AIチームを「4つのタイプ」にわける

最初からAIチームのメンバーを増やしすぎると、だいたい使いこなすのが面倒になって終わっちゃうんですよ。なので、まずは以下の4タイプのメンバーだけに絞りましょう。

 

  1. 発散係
  2. 調査・整理係
  3. 批判係
  4. 統合を補助する係

 

とりあえず、この4タイプがあれば、最低限の思考チームは組めます。でもって、最後にあなた自身が「編集長」または「指揮者」として全体を統括していくわけです。では、それぞれのタイプをチェックしていきましょう。

 

 

タイプ1：発散係AI

発散係ってのは、アイデアを広げるための係です。その仕事は正解を出すことではなく、あなたが見落としている選択肢を増やすことなんで、そのつもりで指示を行いましょう。というわけで、以下のワークをどうぞ。

 

ワーク：発散係を決める

発散係AIに任せたいこと： ＿＿＿＿＿＿＿＿＿＿＿＿

 

このAIに、絶対にしてほしくないこと： ＿＿＿＿＿＿＿＿＿＿＿＿

以下のテーマについて、無難な案ではなく、 異なる切り口・見落とされがちな視点・逆張りの仮説を できるだけ幅広く出してください。

この段階では結論を出さず、アイデアの量と多様性を優先してください。

当たり前ですが、発散係に「一番いい案を出して」と頼む必要はありません。この役の仕事は、あくまで選択肢の地図を広げることなので、最初から完成度を求めすぎないようにしてください。

 

 

タイプ2：調査・整理係AI

次は、情報を持ち帰ってくる係です。この役に任せるのは、判断ではなく判断材料の整備ですね。というわけで、以下のワークをどうぞ。

 

ワーク：調査・整理係を決める

調査・整理係AIに集めてほしい情報：＿＿＿＿＿＿＿＿＿＿＿＿

C： ＿＿＿＿＿＿＿＿＿＿＿＿

 
あなたは調査・整理担当です。

以下の問いについて、結論を急がず、 論点を「事実」「解釈」「不明点」に分けて整理してください。

タイプ3：批判係AI

チームに必ず入れときたいのが、この批判係です。AIを使っていると、こちらが欲しかった答えが出た瞬間に、「よし、採用！」みたいになりがちですが、ここで安心するのは時期尚早であります。AIは、こちらの期待に沿った文章を作るのがうまいので、だからこそ別のAIには、あえて嫌な役をさせたほうがいいんですよ。というわけで、以下のワークをどうぞ。

 

ワーク：批判係を決める

これまた言わずもがなですが、ここで出てくる反論は、あなたのアイデアを潰すためのものじゃないので、「ムキー！　なんでそんなこと言うんだ！」とかならないでくださいませ。このタイプは、案を現実に耐えられる形にするための負荷テストを行ってくれているとお考えいただくといいでしょう。

 

 

タイプ4：統合補助係AI

最後は、バラバラになった情報と意見を整頓する係です。情報を分類したり、意見の一致・不一致を整理したりと、判断の前段階を整える仕事を行うわけっすね。

 

ここで注意したいのは、「統合係AIに結論を決めさせない」ことで、このタイプがすべきなのは、結論を作ることではなく、あなたが結論を出しやすい形に並べ直すことですんで。というわけで、以下のワークをどうぞ。

 

ワーク：統合補助係を決める

統合係AIに整理してほしい材料： ＿＿＿＿＿＿＿＿＿＿＿＿

 

最終的に自分が決めたいこと： ＿＿＿＿＿＿＿＿＿＿＿＿

 
あなたは統合の補助担当です。

以下の複数の意見を、 「共通している点」 「意見が割れている点」 「判断に必要な追加情報」 「それぞれの案を採用した場合のトレードオフ」 に分けて整理してください。

最終判断はしないでください。 私が判断しやすくなるように、論点を可視化してください。

この役割を置いておくと、AIを複数使ったときにありがちな、「たくさん聞いたけど、結局どうすればいいのかわからない……」を避けやすくなりますんで、ぜひ合わせてお試しあれ。

 

 

 

ワーク4：あなた自身の「指揮者ルール」を作る

さて、ここまでで、AIチームのメンバーはそろいまして、ひとまず最低限のチームは完成したと言えるでしょう。

 

しかし、残念ながら、AIチームはメンバーを増やしただけでは機能しませんで、最後に必要なのは、あなた自身が「どう決める人間なのか」を決めることであります。ここをAIに任せると、せっかく作ったチームが「それっぽい答えを大量生産する装置」になっちゃうんで、肝に銘じておきましょう。というわけで、以下のワークをどうぞ。

そのために、AIの提案でも採用しないものは、＿＿＿＿＿＿＿＿＿＿＿＿。

最終的に「今回はこれでいく」と決めるのは、＿＿＿＿＿＿＿＿＿＿＿＿という条件を満たしたときです。

 

もちろん、このワークに正解はありませんで、仕事なら「再現性」と「損失の小ささ」を優先するかもしれないし、創作なら「既存の正しさ」より「自分にしか作れない感じ」を優先するかもしれないし、健康の話なら「効果の大きさ」より「安全性と続けやすさ」を重く見たほうがいいかもしれません。AIは、その優先順位を自動では決められないので、ここは人間が優先順位をつける必要があるわけです。そのために、「自分は何を大事にし、どのリスクを引き受け、何を捨てるのか？」ってのをハッキリさせておくわけですね。

このワークについては、すべての項目を完璧に埋められなくても大丈夫です。むしろ、最初は1つか2人のAIだけで回してみて、以下のポイントを振り返りながら、少しずつチームを調整していくのがよいでしょう。

 

  • 発散係は役に立ったか？
  • 批判係は厳しすぎなかったか？

  • 自分は最後にちゃんと判断できたか？

 

 

 

大まとめ

というわけで、ながらく続いてまいりまして「ケンタウロス思考」シリーズも、これにて終了。最初に言ったとおり、この考え方は、AIにすべての仕事を任せるためのものではなくて、むしろ逆のスタンスを取ってまして、

 

  • AIに発散させる
  • AIに調べさせる
  • AIに反論させる
  • AIに整理させる
  • そのうえで、自分が何を採用し、何を捨て、どこへ進むかを決める

 

みたいな流れができると、AIはあなたの代わりに考える存在ではなく、あなたの思考を広く深く変えてくれるチームメイトになるはずであります。これぞ次世代の知性！

 

ということで、これを読み終わったら、まずは今日作った小さなチームを、ひとつの仕事に使ってみてくださいませ。その上で、AIを含めた自分のチームが、どれだけ良い問いを立て、どれだけ良い対立を作り、どれだけ納得できる判断にたどり着けるか？ってのをチェックしてみましょう。その繰り返しが、これからの仕事や創作の成果を高めてくれるはずであります。これぞ次世代の知性！（二回目）
