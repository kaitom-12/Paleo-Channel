10位　ソーシャルメディアのコントロール

  • 実用性　65.2
  • 難易度　3
  • 効能　　集中力改善

10位はSNSのコントロールです。仕事中にツイッターやFacebookを見ちゃうのは誰でもあることですけど、実際のダメージの深さには意外なほどみんな気づいてなかったりしますね。

 

ちなみに、filterdの調査データは、だいたいSNSで写真を1回クリックするごとに、他の投稿もクリックしてしまう回数が平均で20回までエスカレートするそうな。こりゃ確かにヤバすぎますね。

 

対策としては、前回取り上げたフィルタリングソフトを使ってもいいですが、この調査では「SNSを使うのは1日2回！1回5分まで！」と決めておいて、実際にSNSをチェックする時間をカレンダーに入れておくテクニックが推奨されておりました。確かにSNSは無駄にドーパミンしか生み出さないシステムなんで、遠ざけるに越したことはないっすね。

 

 

 

09位　2分ルール

  • 実用性　69.6
  • 難易度　2
  • 効能　　時間管理

GTDなどで提唱されるルールで、「2分以内に完了できるタスクは、何も考えずにすぐやる！」って考え方です。メール返信やスケジューリングのように2分でこなせそうなものは、その場でメモしたり考えたりするのではなく、瞬時に手をつけていくわけですね。


「ヤバい集中力」にも書いたとおり、1日の初めに小さなタスクをガンガンにこなすと、そこからモチベーションに勢いがつきまして、より大きな仕事に取り組みやすくなる効果もあったりします。

 

ちなみに、この調査では「2分で終わるタスク」を15個ぐらい集めておいて、大きな仕事の前に30分をかけて小さなタスクを全てを終わらせてしまうやり方を推奨しておられます。私はまだ試したことがないですが、確かに弾みはつきそうっすね。

 

 

 

08位　健康的な食事

  • 実用性　69.6
  • 難易度　3
  • 効能　　ウェルビーイング改善

あまりに基本的すぎて「生産性アップ系の本」ではあまり取り上げられませんけど、お菓子やスナックばっか食べてたら脳が必要な栄養を補給できなくなり、何時間ものハードワークに耐えられなくなっちゃうのは間違いないところ。パレオダイエットでも地中海式でもなんでもいいので、健康的な食事を心がけることで、長期的なパフォーマンスが上がることがわかっております。

  • 効能　　ゴール達成率改善

こちらも基本中の基本ですけど、実用性としては7位ぐらいなんですね。個人的には「やるべきことはカレンダーに組み込んじゃう」って方法のほうが好きなんでTo-doリストは使ってませんが、「タスクをすべて書き出す」って考え方の大事さに異論がある人はいないでしょうね。

 

 

 

06位　短い休憩を取る

  • 実用性　78.2
  • 難易度　2
  • 効能　　ウェルビーイング向上

定期的な短い休憩を取ることで生産性が向上するのは、何度も研究で実証されております。ポモドーロ・テクニックみたいに「25分の作業→5分程度の小休憩」ってパターンでもいいんですけど、できるだけ自分の作業に適したタイミングを探し当てないと、あんまり効果が出なかったりしますのでご注意ください。

 

私の場合は、何度か検証をくり返すうちに「一般的なテキストだと15分で1,500文字」「書籍のような難しい文章は15分で600文字」がだいたいの限界だとわかってきたので、1セットを15分に設定して、1〜2分ほどの休憩を取るようなサイクルに落ち着きました。休憩時間が短くないか？と思われそうですが、個人的には5分も休むと文章の勢いが削がれる感じがあったんで、だいたい1〜2分ほどAppleWatchの「呼吸」アプリで深呼吸してます。

 

 

 

05位　デバイスをコントロール

  • 実用性　82.6
  • 難易度　3
  • 効能　　地域

デジタルデバイスが注意を逸らす！と言われ始めて久しいですけど、この調査では、スマホのコントロールは5位に入るぐらいの効果があるんだそうな。いくつかの研究によれば、

 

  • 私たちは1日に150～221回は携帯電話をチェックしている
  • 携帯電話を目の前に置いているだけでも、脳のパフォーマンスは低下する

 

って事実がわかってますので、気が散りそうなデバイスは作業環境から完全に取り除いてしまうのが吉であります。私の場合は、進行管理のためにどうしてもiPadは必要なので、この端末にはカレンダーと表計算アプリぐらいしか入れないようにしてます。
 

 

 

04位　 運動

  • 実用性　82.6
  • 難易度　3
  • 効能　　ウェルビーイング向上

運動が脳の働きを改善するのは、みなさますでにご存じでしょう。個人的には食事の改善よりも上位にランクインしてるのが意外でしたけども、考えてみれば、即効性については運動が一番実感しやすいかもしれないですね。

 

この調査が主張する運動のメリットとしては、

 

  • マインドワンダリングから抜け出しやすくなる
  • 創造的な思考をかき立てるのに役立つ

 

といったところが挙げられておりました。基本的には時速5〜6キロぐらいの速歩を10分やるぐらいでも十分な効果が出ますんで、ぜひお試しください。

 

 

 

03位　ノーと言う

  • 実用性　91.3
  • 難易度　2
  • 効能　　ウェルビーイング向上

基本的に人間は他人の頼みを断るのが苦手な生き物なので、何も対策を立てていないと、ついついみんなを喜ばせようとして大量の仕事を抱え込みがち。これが3位にランクインしたってのは、世の中やっぱ断るのが苦手な人が多いんでしょうね。

 

かくいう私もお断りが苦手なタイプですが、アメリカのメイヨークリニックなんかは、「ノーと言う」ためのポイントを以下のようにまとめてますんでご参照ください。

 

  • プライオリティの確認：何かを頼まれたら、返答する前に「この頼まれごとは自分にとってどれぐらい重要だろうか？」と自分に質問。その答えによって、イエスと言うかノーと言うかを考える。
  • イエス／ストレス比チェック：「その頼みごとにイエスと答えたら、そこから得られるメリットとストレスの比率はどのような割合になるか？」を考えてみる。
  • 罪悪感・義務感チェック：返事をする前に、「自分は相手への罪悪感か義務感で返答しようとしていないか？」と自分に質問してみる。罪悪感か義務感で返事をすると、長期的にストレスが増大することがわかっている。
  • 時間をおく：相手の頼みに答えを出す前に、できれば1日は考える時間を作る。そこまで時間をおけない場合も、出来るだけ回答までの時間を伸ばした方が良い。
  • ノーを言う際は確実にノーと言う：ノーと言えない人の多くは、反射的に「ちょっとよくわからない」や「できるかわからない」といった表現を使おうとする。これは相手に悪い印象を与えるだけなので、まずは確実にノーと言うことを心がける。
  • 端的に言う：頼みを断らねばならない理由を話すのは重要だが、長く説明をすればするほど言い訳だと解釈されやすくなる。

 

 

02位　優先順位をつける

  • 実用性　97.5
  • 難易度　3
  • 効能　　時間管理

第2位で「実用性97.5ポイント」という高得点を叩き出したのは「優先順位」でした。これまたすげー当たり前のメソッドですけど、だいたいの人は「タスクの優先順位はわかってる」と考えちゃって、紙に書き出すまでは意外としないんですよね。

 

ってことで、いまあるタスクをリストアップしたら、10点満点でも色分けでもなんでもいいんで、優先順位をつけるといい感じです。

 

 

 

01位　タイムボクシング

  • 実用性　100
  • 難易度　3
  • 効能　　時間管理

ってことで、はえある第1位は「タイムボクシング」でした。もちろんスポーツのボクシングではなく、直訳すると「時間のボックス化」みたいな意味になります。

 

実用性100点のわりに意外と知られてない方法ですけど、たとえば「大事なことに集中する」とか「デジタル・ミニマリスト」で有名なカル・ニューポート先生も、「なんだかんだでタイムボクシングがベストだよねー」みたいな発言をしてまして、かなり有用性は高い手法だと思われます（もちろん私も愛用してます）。

 

そのやり方はとてもシンプルなんですが、ここで説明するにはやや分量が必要ですんで、次回はこのシリーズの番外編として「実用性100のライフハック『タイムボクシング』を極める！」と題して、正しい手法についてまとめていこうかと思います。では、また次回！
