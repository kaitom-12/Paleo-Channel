このシリーズでは、「やるのは大変だけど実践すれば効果は抜群」でおなじみの心理セラピーである「スキーマ療法」の基本を述べてまして、現在は「解決編」に入っております。スキーマ対策については、「自分でできるスキーマ療法ワークブック」という名著が存在しますが、これはガッツリスキーマを正す趣旨で書かれていまして、実践が大変なところもあったりします。

 

そこでこのシリーズでは、スキーマ療法の研究で有名なマシュー・マッケイ先生らの調査をベースに、もうちょい手軽だけど、十分な効果を見込めるエクササイズをご紹介します。まぁトラウマレベルのスキーマであれば、「自分でできるスキーマ療法ワークブック」に取り組むべきでしょうが、中程度の対人トラブルや社交不安の方であれば、いい具合に使っていただけるのではないかと。

 

さて、前回のステップから、「デフュージョン」のトレーニングに進んでまして、その中から「思考の観察」「思考のラベリング」という2種類の手法を見てみました。いずれも、自分のスキーマから距離を置くために欠かせない能力なので、新しい行動を取りたいのにスキーマがジャマするような状況で、めっちゃ役に立つはずであります。

 

ということで、今回もまた、スキーマへの対処能力をアップさせるトレーニングを見ていきましょうー。

 

 

ステップ15. デフュージョン（続き）

さて、前回に続いてデフュージョンの手法をいくつか見てみます。ここまでで「思考の観察」と「思考のラベリング」は押さえたので、残りは「思考の手放し」に特化した手法をチェックしましょう。

 

以下に挙げるのは、思考を解放するために設計された、イメージやメタファー を使ったビジュアライゼーション練習です。これらは、「頭にこびりついて離れない！」みたいな思考を、心の中から追い出す方法を学ぶのに最適です。人によって適したビジュアライゼーションは異なるので、それぞれを試してみて、どれが一番自分の感覚に合うか試してみてくだ さい。

 

 

トレーニング15.5 流れの中の木の葉

  1. 5〜10分間、邪魔されない静かな場所を見つけ、手足を組まずに横になるか座る。

  2. 目を閉じて、深く、ゆっくりした呼吸を数回する。

  3. 自分が秋の小川のほとりにいるところを想像してください。思考が心に浮かぶたびに、その思考を、流れの速い小川に落ちていく紅葉に見立ててください。そして、紅葉が水にぶつかり、流れの中で渦を巻き、下流に流され、そのまま視界から消えていくのを見てください。新しい思考が現れるたびに、その思考を葉っぱに変えて、 小川に流してみましょう。

  4. 5分から10分ほど続けたら目を開けて、「このトレーニングで考えるペースは変わったか?」「手放すのが難しい葉があったか?」などを少し考えてみて終了です。

 

トレーニング15.6  看板

  1. 5〜10分間、邪魔されない静かな場所を見つけ、手足を組まずに横になるか座る。

  2. 目を閉じて、深く、ゆっくりした呼吸を数回する。

  3. 自分が車に乗っていて、高速道路を運転しているところを想像してく ださい。その最中に思考が現れたら、それがあたかも道ばたに立つ看板に描かれているかのようにイメー ジしましょう。

  4. 看板は、あなたが近づくにつれて徐々に大きくなり、やがて後ろに消えていきます。新しい思考がそれぞれ新しい看板になり、あなたの意識の中に押し寄 せては、一瞬にして消えていく様子をイメージしましょう。

  5. 5分から10分ほど続けたら目を開けて、「車のスピードが速くなったり遅くなった りしたか?」「なかなか無視できない看板や、重複した看板が現れなかったか？」などを少し考えてみて終了です。

 

 

トレーニング15.7  風船と雲

  1. 5〜10分間、邪魔されない静かな場所を見つけ、手足を組まずに横になるか座る。

  2. 目を閉じて、深く、ゆっくりした呼吸を数回する。

  3. ヒモがついたヘリウム入りの風船の束を持っているところを想像してください。もしくは、そのような風船の束を持っているピエロを、あなたが見ているところを想像してください。

  4. 思考が頭に浮かぶたびに、その思考を風船に乗せてヒモを手放しましょう。そして、風船が空に舞い上が り、小さな点になって消えていくのを見守ってください。

  5. 別の方法として、空に浮かぶ雲に思考を置き、水平線の彼方へ流れていくのを見守っても構いません。

  6. 5分から10分ほど続けたら目を開けて、「思考のペースは変わったか?」「その場にとどまろうとする風船や雲はなかったか?」などを少し考えてみて終了です。 

 

 

トレーニング15.8  コンピュータのポップアップ

  1. 5〜10分間、邪魔されない静かな場所を見つけ、手足を組まずに横になるか座る。

  2. 目を閉じて、深く、ゆっくりした呼吸を数回する。

  3. コンピューターの前に座って、のどかな自然の風景の写真を見ているところを想像して ください。すると、あなたの思考が、突然スクリーン上にポップアップ広告 のように現れました。そこで、あなたがそれぞれのポップアップの隅にある「X」ボタンをクリックすると、そのポップアップは消えてしまいます。

  4. 5分から10分ほど続けたら目を開けて、「ポップアップのペースは速くなったり遅くなったりしたか?」「何度も現れるポップアップはないか？」などを少し考えてみて終了です。 

 

 

トレーニング15.9 電車とボート

  1. 5〜10分間、邪魔されない静かな場所を見つけ、手足を組まずに横になるか座る。

  2. 目を閉じて、深く、ゆっくりした呼吸を数回する。

  3. ドライブの途中中で踏切の前に停車したところ、その前を、長い貨物列車が通り過ぎはじめたところを想像してみましょう。レールの継ぎ目を車輪が過ぎるたびリズミカルな音が鳴ります。

  4. 思考が頭に浮かぶたびに、それを貨物の上に置き、それが通り過ぎて去 っていくのを見送ってください。列車のイメージが苦手なら、船が行き交う川を思い浮かべてみても構いません。

  5. 5分から10分ほど続けたら目を開けて、「列車のスピードは速くなったり遅くなったりしたか?」「何度も現れる貨物はないか？」などを少し考えてみて終了です。 

 

 

トレーニング15.10 物理的に手放す

  1. 目を開けたまま背筋を伸ばして座り、手のひらを上に向けて、利き手を楽な高さで前に出します。

  2. 何らかの思考が浮かんだら、それが利き手のひらの中にあると想像しましょう。思考がしっかりと手の中に収まったら、手のひらをくるっと回して下に向け、思考が地の底へ落ちていくのを想像してください。

  3. 思考を手放したら、再び手のひらを上に向け、次の思考を待ちます。思考が現れるたびに、手から思考を「落とす」あるいは「手放す」作業を続けましょう。手放すという物理的な動きをすることで、思考を手放す経験を、よりリアルで具体的なものに感じることができます。

 

この練習はいつでもでき、厄介な考えを打ち消す能力の強化に有効です。人前でこのようなジェスチャーをすることに抵抗がある場合は、手を回す代わりに、手首を微妙に動かしたり、指を少し広げたりしてもいいでしょう。

ちなみに、ここで取り扱う思考は、ネガティブなスキーマ思考だけを使わなくても構いません。「夕食に何を食べようか」とか「新しい猫にどんな名前をつけようか」といった中立的な思考や楽しい思考でも、がんがん観察やラベリングの素材に使って構いませんので。

 

最後に、デフュージョンを使ってみた人の具体例も紹介しておきます。

 

 

29歳女性のデフュージョン例：

私はレストラン設備会社でカスタマーサービスをしています。去年、新しい恋人を見つけるためにマッチングアプリに登録しましたが、オンラインデートをすると、古いスキーマ思考が出てくるので、感情をコントロールするために、観察、ラベリング、思考を手放す方法を組み合わせました。

 

ソファに横になり、目を閉じて白い部屋のイメージを思い浮かべながら、最初は「ホワイトルーム瞑想」を試しました。デートに関する否定的な考えが浮かんだら、違うタイプの男性が一つの扉から入ってきて、もう一つの扉から去る様子をイメージしました。「イケメンは私を選ばない」「ブサイクな男性だけにしか人気がない」「変な男が現れるかもしれない」という考えを無視するのは難しく、「白い部屋」から追い出すのは大変でした。

 

次に、 始めたのがラベリングのテクニックです。イケメンは私を選ばないと思ったとき、私は自分の考えを変えてみました。「今、私の心は『自己評価が低い』と考えている。「ブサイクな男性にしかモテない」と思ったら、「今、私は『かわいそうな私』と考えている」と変換してみました。こうやって、自分の考え方に別の解釈を加えることで、それがただの「考え」でしかないことが理解できました。自分の考えから距離を置くことで、まだ何も起こっていないことにも気付きました。

 

その後、ネットで知り合った工事の業者とカフェでデートをしましたが、その前に、手放しのエクササイズを試してみました。「思考が手の中にあるのを想像する」というエクササイズです。たとえば、デート中に、相手のことを写真より10歳は老けて見えたと感じたら、テーブルの下で手を握りしめ、その不安な感情を静めるジェスチャーをしました。

 

時には困難なこともありましたが、デフュージョンから多くを学びました。ネガティブな考えから十分な距離を保つことができれば、相手の見た目はそんなに悪くなく、相手が純粋にいい人だと気付くことができました。

 

 

ってことで、今回はこれで終了。デフュージョンの話はもうちょい続きまして、次回は思考と距離を取る方法を深掘りしてみましょうー。
