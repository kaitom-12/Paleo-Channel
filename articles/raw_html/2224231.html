「『自分はまだダメだ…』を武器にする技術」の続きです！(#1,#2,#3,#4,#5,#6,#7)

 

このシリーズでは、私たちの人生の満足度を下げちゃうインポスター症候群について触れております。ざっくり言うと「自分の成功を実力と認められず、偶然や運の結果だと思い込んでしまう心理現象」のことで、こいつをこじらせると、いつまでも達成感を得ることができず、人生の満足度がダダ下がりしちゃう可能性が高まるんで、心当たりのある方はぜひ注意しておきたいところです。

 

ということで、今回はその第8弾。インポスター症候群の対策として、ステップ８「インポスター“症候群”という言葉を捨てる」とステップ９「全員を救えないと知る」の２つを見てみましょう。

 

 

 

インポスター症候群改善ステップ8.「インポスター“症候群”」という言葉を捨てる

さて、ここまでさんざん「インポスター症候群」って言葉を使ってきたのに恐縮ですが、このステップでは、インポスター症候群って言葉を忘れる作業をしていただきます。というのも、人間ってのは、何かに名前がついた瞬間、それを“固定された属性”のように扱い始めるからです。

 

たとえば、「燃え尽き症候群」「学習性無力感」「愛着障害」みたいな名称は、確かにある種の傾向を把握する役には立つんだけど、一方でその言葉がラベルとなり、自己定義になっちゃうリスクもあるんですよね。たとえば、

 

  • 「HSPだから、人付き合いが苦手で当然」と思い込んでしまう
  • 「私はADHDだから、先延ばしを直せない」と行動改善を諦めてしまう
  • 「発達障害の傾向があるから、チームでの作業には向いていない」と役割を避けてしまう

 

といった問題がありまして、特定の名前が「呪い」になっちゃう例はよく見かけるところです。「インポスター症候群」もその一つで、この言葉を初めて聞いたとき、「ああ！自分には問題があるのだ！」と感じちゃう人は多いんじゃないでしょうか。この他にも、

 

  • 「インポスター症候群ってことは、自分はずっとこのままなんだ」と思い込んでしまう
  • 「インポスター症候群なんだから、成功体験を受け入れられないのは当たり前」と思ってしまう
  • 「インポスター症候群のせいで、自信がないんだ」とすべてを病名のせいにしてしまう

 

みたいなパターンが考えられますね。こうした感覚は、自分の感情や行動を“変えられるもの”ではなく“仕方のないもの”と見なす態度につながってしまうことが多いんですよ。

 

事実「症候群」って言葉は、割りと昔から心理学の世界でも問題視される傾向がありまして、以下のような心理的な影響があるとされております(R)。

 

  • 不治感の喚起：症候群って言葉を、病名や障害名と並んで使われることで、「長く付き合わなければならない状態」「治りにくいもの」みたいな印象を与えちゃう。

  • 自己同一化：「私はインポスター症候群だから」と言ってしまうと、それが自分のアイデンティティの一部のように扱われ、「症状」ではなく「属性」として固定されちゃう。

  • 行動の抑制：「これは“症候群”だから仕方ない」と思うと、それを乗り越える行動を起こしにくくなっちゃう。まあ、このようなラベリングには「納得感が生まれる」ってメリットはあるんだけど、その一方で「自分で自分の限界を決めてしまう」ってリスクも持ってたりします。

 

いずれもなかなか手ごわい問題でして、「今の自分」を受け入れることと、「これからの自分」を縛ってしまうことは紙一重なのだと申せましょう。人間の心理ってめんどうですね。

 

 

 

「症候群」を「ギャップ」として再定義してみよう！

では、この問題をどうすりゃいいのかってことですが、多くの研究者は、「インポスター症候群を、“病”ではなく“ギャップ”だと定義せよ！」と言っておられます。どういうことかと言いますと、そもそもインポスター症候群ってのは、「自分が達成したこと」と「自分が感じている自己評価」のあいだにあるズレ（＝認知ギャップ）のことを指すのであって、それは不治の病ではなく、行動と経験によって埋めていける“差分”にすぎない……みたいな考え方です。

 

こんな感じで、「インポスター症候群」をギャップとして捉えることにより、こいつをただの「一時的な成長課題」へと変換していくわけです。なぜこれが効くのかと言いますと、「ギャップ」って考え方には以下の働きがあるからです。

 

  • 「ギャップ」は動詞で埋められる：ギャップってのは、「今の地点と理想の地点の間の距離」を意味しております。なので、これは学習、経験、練習によって埋めることができるわけです。たとえば、「専門家のように話せない」なら「説明トレーニングを週に2回」すればいいだろうし、「質問に即答できない」なら「想定質問を10個書き出して模擬練習」すればいいだろうしって感じで、「症候群」ではなく「ギャップ」と考えれば、「これをどう乗り越えるか？」に意識がシフトして、いらぬ罪悪感に悩まされなくなるわけっすね。

 

  • 「ギャップ」は一時的である：「ギャップ」は成長とともに変化するのが前提なので、固定されないのがよいところ。これは常に「いまここ」の課題であり、「永遠の属性」じゃないんですよ。なので、インポスター症候群をギャップだと思うことで、「これは今の自分の課題なだけで、未来の自分はちゃんと成長していく存在なんだ」と思えるようになるわけです。

 

  • 「ギャップ」による不安は「成長すべきポイントがある」というサインである：インポスター感情とは、「私はもっと上手くなりたい」「もっと価値を届けたい」という思いの裏返しで発生することが多め。もし何も成長を望まなければ、そもそも「バレるかも」なんて恐怖は起きないですから、これは向上心がある人だけに現れる副作用なのだと言えるでしょう。その点で、「この不安はギャップによるものだ」と思うことができれば、「インポスター感は病気ではなくポテンシャルの裏返しなのだ！」って発想になるんじゃないかと。

 

ここらへんのメカニズムが働くと症候群が一気にギャップに変わりますんで、ぜひとも心がけておきたいところです。

 

が、そうは言っても、なかなか気持ちを切り替えるのも難しいと思いますんで、ここではいくつかの対策をまとめておきましょう。

 

対策①：不安を「質問」に変換する

インポスター感情を「質問」に変換してみる手法です。たとえば、

 

  •  「自分はあの人ほど知識がない…」→「あの人が持っている知識で、今の自分に必要なものは何か？」

  •  「自分は全然できていない」→「どの場面で、何ができれば『できた』と判断できるだろうか？」

  •  「このレベルで発表していいのだろうか…」→「どの点を明確に伝えられれば、自分として『よし』と言えるか？」

  •  「評価されたけど実力じゃない気がする…」→「この評価に自分のどんな行動が貢献していたと思えるか？」

  •  「まだまだ未熟だ…」→「どの分野に、どれくらい時間をかければ『納得ライン』に届くのか？」

 

みたいな感じっすね。こんな風に不安を「問い」に置き換えると、感情が行動タスクに変換されやすくなって良い感じです。

 

 

対策②：ギャップジャーナルを書く

続いて、自分の感じたギャップを記録してみるのも良い方法です。フォーマット例としては、

 

  1. 今週「足りない」と感じたことは？
  2. それはK（知識）/S（技能）/E（経験）のどれか？
  3. 何をすれば1ミリでも埋められそうか？

 

みたいになります。たとえば、

 

  • 質問への即答がうまくできなかった
    • → S（技能）
    • → 想定質問を10個書き出して、10分間スピーキング練習

 

  • 専門用語の定義をうまく説明できなかった
    • → K（知識）
    • → 毎日1ワードの定義を書き起こして、声に出して説明

 

  • クライアントとの会話で緊張しすぎた
    • → E（経験）
    • → 毎週1回、架空クライアントとのロールプレイを練習

 

みたいな感じで1行ずつ書けばOK。書くことで「不安の出どころ」と「埋めるルート」が可視化されるんで、週1ぐらいのペースでお試しいただくと良いでしょう。

 

 

対策③：感情→行動の変換テンプレートを使う

このテンプレートは、自分のインポスター感情について、以下の順序で考えていく方法です。

 

 

  1. 「◯◯が不安」
  2. 「その背景にはどんなギャップがある？」
  3. 「埋めるには、何を学び／練習すればよいか？」
  4. 「30分でできる具体的行動は何か？」
  5. 「完了基準はどう設定する？」

 

 

いくつか例を挙げてみると、

 

  • 「講座での発言が不安」 
    • → 「知識の整理不足」 
    • → 「講座内容の要点を毎回5行でまとめる練習」 
    • → 「過去の講座ノートから要点5行を書く」 
    • → 「3講座分書いたら完了」

 

  • 「他人の期待に応えられていない気がする」 
    • → 「自分の強みの言語化不足」 
    • → 「他者評価と自分の実績を見直して言語化」 
    • → 「1日15分、自分の過去の仕事レビューを書く」 
    • → 「3案件分レビューできたら完了」

 

みたいになります。ということで、これらの対策ってのは、いずれも感情をコントロールしようとするのではなく、ギャップを受け止めて可視化するための技術になっております。「症候群」ってラベルを自分に貼ってしまうと問題が起きやすくなるんだけど、これを「ギャップ」というラベルに貼り替えれば私たちは学習者に戻ることができるわけです。

 

 

たとえ、あなたが今「インポスター症候群」に悩んでいるなら、それは「能力の欠如」ではなく「改善の余白」と捉えてくださいませ。それは病気ではなく、次に学ぶべき場所を教えてくれるガイドですんで。

 

 

 

インポスター症候群改善ステップ9.「全員を救えない」と知る

インポスター症候群の方は、一般的に次のような問題に悩むケースが多めであります。

 

「なんであの人は変われなかったんだろう」 
「もっとうまくやれていれば…」 
「自分の指導力が足りなかったのかも…」

 

このような想いは、誰かをサポートする立場の人なら、一度は抱いたことがあるでしょう。コーチ、医療者、管理栄養士、カウンセラー、教師みたいな「人と関わる職業」についている人にとっては、宿命ともいえる感情でしょう。

 

が、この感情が慢性化して「すべては自分の責任だ」と信じ込むようになると、インポスター症候群の温床になってしまうのが難しいところ。この罠を回避するためのひとつの鍵として大事なのが、「私にできるのは、クライアントが自分で変わるための環境を整えることだけだ！」って考え方であります。これは「支援者の役割は変化の責任を引き受けることではなく、変化の余白を一緒に探すことなのだ」という前提に立脚した、とても大事な心の姿勢なわけですな。

 

この考え方を深めるために重要なのは、心理学の世界でよく使われる「TTMモデル（多理論統合モデル）」であります。これは、人が行動を変えるプロセスは段階的に進むって理論でして、ここでは人が変化に至るまでにたどるステップを以下のように考えます。

 

  1. 無関心期：変わるつもりすらない 
  2. 関心期：変わらなければとは思っているが、行動には移さない 
  3. 準備期：変化に向けて小さな行動を始めている 
  4. 実行期：実際に行動変化を行っている 
  5. 維持期：変化した行動を継続している

 

つまり、あなたがどれだけ素晴らしい知識と熱意と技術を持っていても、相手が「無関心期」や「関心期」にいたなら、どんなアドバイスやロジックをしても届かないわけです。成果が出ないのは、決してあなたのせいじゃないってことですな。特に高いプロ意識を持つ人ほど「クライアントが変わらないのは自分の責任だ」と思いがちでして、これによってインポスター症候群が進んでしまうわけです。

 

これは、「成果で測られる職業」が抱える構造的な問題とも言えまして、

 

  • 成果が出た → 自分の手柄
  • 成果が出ない → 自分の失敗

 

という二項対立がある限り、自己評価は常に「結果」に振り回されてしまうんですね。そこに「人を助けたい」という善意が加わると、「変わらない人がいる現実」が受け入れづらくなり、強い罪悪感と無力感が生まれちゃうわけです。いったんこうなると、インポスター症候群をこじらせるための燃料を毎日投下しているようなものっすね。

 

ここで思い出したいのが、心理学の最も有名な概念のひとつである「内的統制感」と「外的統制感」です。簡単におさらいすると、

 

  • 内的統制感：自分の努力で結果を変えられるという感覚 

  • 外的統制感：結果は運や環境によるという感覚

 

みたいになります。たしかに、内的統制感は成長に欠かせない資質なんだけど、すべてをコントロールできると思い込むと、逆に自分を追い詰めることになるんですよ。

 

この理屈に照らせば、あなたが本当にコントロールできるのは、以下の3つしかないでしょう。

 

  1. 相手との関係構築（信頼・共感・傾聴） 
  2. 情報の提供と提案（わかりやすさ・根拠・適切さ） 
  3. 伴走する姿勢（忍耐・柔軟さ・フィードバック）

 

これをすべてやった上で、その後で相手が行動を起こすかどうかは、相手の“準備”と“タイミング”に委ねるしかないんですよ。基本的に人を変えることはできないので、自分にできるのは「人が自分を変えたくなったときに備え、その場を整えること」だけだとお考えください。

 

でもって、この視点に立つと、「相手が変化しない＝自分の失敗」って考え方ではなく、「変化しない＝その人の準備がまだ整っていないだけ」って考え方にシフトできるはず。その上で、「その人が変化に向かう日」に備えて関係性や記憶を温めておくのが、プロとしての長期的な視座になります。

 

ということで、もし他人を変えられない罪悪感に飲まれそうになったときは、次の3つの視点で振り返ることをおすすめします。

 

  1. この人は、いま行動変容のどのステージにいるだろうか？（TTMの5段階でチェック） 
  2. 自分が提供できるものは全て提供できただろうか？ 
  3. 次にまたチャンスが来たとき、自分は同じことを繰り返すだろうか？

 

このチェックを使って「自分の責任はここまで」と線引きできれば、自分の罪悪感も一気に減っていくのではないか、と。あなたが一生懸命向き合った結果、それでも誰かが変わらなかったとしても、それはあなたが尽くさなかったからではなく、「今はその人の時期ではなかった」だけと思えるようになるはずであります。これは、相手をひとりの自律した人間としてリスペクトする姿勢につながりまして、この姿勢こそがプロとしての自信へとつながるんですな。

 

このシリーズの10ステップの中で、この「全員を救えないと知る」は、おそらく最も深い意味を持つパートのひとつ。「全員は救えない」と想うことは決して努力の放棄ではなく、「努力の方向の再定義」なので、そこだけ押さえておいてくださいませ。ではまた！
