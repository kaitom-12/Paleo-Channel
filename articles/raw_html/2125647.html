「ダブルアップ・トレーニング」の続きです！(#1,#2,#3,#4,#5)

 

 

このシリーズでは、筋肉量と心肺機能の両方を、できるだけ効率よく成長させるための運動プログラムを紹介しております。とにかく体力をつけたい人や、アンチエイジングを狙いたい人は、ぜひ参考にしてくださいませ。

 

 

で、前回は「ダブルアップ・トレーニング」で使う「筋トレの注意点」をチェックしましたんで、今回からは総まとめとして、「ダブルアップ・トレーニングの具体的な実践例」を見ていきましょう。

 

 

 

ダブルアップ・トレーニングの概要

オプション 1：標準版

ダブルアップ・トレーニングの標準版では週5日のトレーニングを行い、以下のような形になります。

 

  • 月曜日 下半身筋トレ＋SIT
  • 火曜日 上半身筋トレ
  • 水曜日 HIIT
  • 木曜日 オフ
  • 金曜日 全身筋トレ
  • 土曜日 ゆっくり長い有酸素運動
  • 日曜日 オフ

 

 

オプション2：週4日版

週に4日しかトレーニングする時間がない場合、HIITワークアウトを半分にし、片方を上半身筋トレのトレーニングの後に、もう片方を全身筋トレのワークアウトの後に行うことができます。

 

  • 月曜日 下半身筋トレ＋SIT
  • 火曜日 上半身筋トレ＋ハーフHIIT
  • 水曜日 オフ
  • 木曜日 全身筋トレ＋ハーフHIIT
  • 金曜日 オフ
  • 土曜日 ゆっくり長い有酸素運動
  • 日曜日 オフ

 

 

オプション3：ゆっくり長い有酸素運動削除板

ゆっくりした有酸素運動をする時間がない場合は、水曜日のワークアウトを繰り返すだけでも構いません。

 

  • 月曜日 下半身筋トレ＋SIT
  • 火曜日 上半身筋トレ
  • 水曜日 HIIT
  • 木曜日 オフ
  • 金曜日 全身筋トレ
  • 土曜日 HIIT
  • 日曜日 オフ

 

 

 

曜日ごとのさらに細かい説明

ダブルアップ・トレーニングでは、１つのブロックが合計で4週間続きます。トレーニングセッションの強度と時間は、時間の経過とともに徐々に増加しますんで、初週のブロックが簡単すぎるようであれば、いきなり2週目のトレーニングからはじめても構いません。では、トレーニングの各日ごとの実践を見ていきましょうー。

 

 

ブロック1：1週目

1日目 下半身筋トレ＋SIT

  • 下半身筋トレ
    • スクワット、レッグプレス、ブルガリアン・スプリット・スクワットのいずれかを3～5セット×8～12レップス行う
    • レッグカール（スライディング、マシン、グルートハムローラーのいずれか）、またはルーマニアン・デッドリフトを3～5セット x 8～12レップス行う

 

  • 筋トレの諸注意
    • スクワットを初めて行う場合は、ハムストリングスを鍛えるために、ルーマニアンデッドリフトではなく、レッグカールのバリエーションを使用するのがベストです。

    • 最低でも8レップ、最高でも12レップできる重量を選びます。

    • 各セットの最後のレップは、めちゃハードに自分を追い込めるように負荷を調整しましょう。ここで言う「追い込める負荷」ってのは、頭に銃をつきつけられながら「あと2回できなきゃ殺す」と言われた場合に、どうにかギリギリできるぐらいのレベルです（つまり、あとギリギリ2回できる手前で止める）。

    • 毎回のトレーニングでは、前のトレーニングよりも多くのレップ数をこなすようにしてください。

    • 各セットの間は2分間の休息を取ってください。

 

 

  • SIT
    • ウォームアップ 3～5分
    • 20秒の全力有酸素運動　RPE8-9
    • 1.5分スロー
    • 20秒の全力有酸素運動　RPE8-9
    • 1.5分スロー
    • 20秒の全力有酸素運動　RPE8-9
    • クールダウン 3〜5分

 

  • 有酸素運動の諸注意
    • インドアバイクで行うのがベストです。

    • RPEとは、Rating of perceived exertionの略です。これは、あなたが感じる運動のハードさを主観的に評価した数字で、RPEが10であれば、全力で最大限の努力をしていることになり、RPEが1であれば、全く努力をしていないことを表します。

    • RPE8～9は全力疾走とまではいかないが、それに近いレベルを意味します。このペースは、同じレベルの運動を45秒以上維持することができないぐらいのハードさです。

    • 運動ペースは、インターバル中、一定に保つようにしてください。

    • スローフェーズでは、息を整えるために楽な負荷でサイクリングしましょう。

 

 

 

2日目：上半身筋トレ

  • A1 インクライン（30°）ダンベルプレスを 3～4セット x 8～12レップス行う。

  • A2 フロントラットプルダウン または バンドプルダウン または アシストプルアップ を3-4 セット x 8-12 レップス行う。

  • B1 ベンチプレス または ダンベルベンチプレスを 3-4 セット x 5-8 レップス行う。

  • B2 シーテッド・ケーブル・ロー または ダンベル・ローを 3～4セット x 8～12レップス行う。ラテラル・レイズを 2-3 セット x 12-15 レップス行う。

  • C1 インクライン・ダンベル・カールを 2～3セット x 12～15レップス行う。

  • C2 オーバーヘッド・トライセップス・エクステンションを 2-3セット x 12-15レップス行う。

 

 

  • 筋トレの諸注意
    • 各セットの最後のレップは、めちゃハードに自分を追い込めるように負荷を調整しましょう。ここで言う「追い込める負荷」ってのは、頭に銃をつきつけられながら「あと2回できなきゃ殺す」と言われた場合に、どうにかギリギリできるぐらいのレベルです（つまり、あとギリギリ2回できる手前で止める）。

    • 毎回のトレーニングでは、前のトレーニングよりも多くのレップ数をこなすようにしましょう。

    • 時間を節約するために、エクササイズA1とA2のスーパーセットを行うことができます（例：インクラインダンベルプレスのセットを行い、30～60秒休み、プルダウン/プルアップのセットを行い、30～60秒休み、再びインクラインプレスに戻す、など）。B1とB2、C1とC2も同じです。

    • スーパーセットを使用しない場合は、各セットの間に少なくとも2分間の休息を取るようにしてください。

    • アシストプルアップは、エクササイズバンドかサスペンショントレーナーで行うこともできます。通常のアシストなしの懸垂を3セット、5レップ以上できるようになったら、通常の懸垂を行いましょう。

 

 

3日目：ゆっくり長い有酸素運動

  • 最大心拍数70～75%で30分

 

  • 有酸素運動の諸注意
    • ウォーキング、リュックサックを背負ってのウォーキング、サイクリング、ボート漕ぎなど、どんな運動でもかまいません。

    • 心拍数は最大心拍数の65～75%になるようにします。

    • 心拍計を使用していない場合は、トークテストを使って強度をモニターすることもできます。足が熱くなったり、会話が続かなくなったりする場合は、無理をしている証拠です。その時は、もっと低めの負荷を心がけましょう。

    • 心拍数が65～75％ゾーンから外れてしまうこともあるでしょう。例えば、自転車に乗っていて坂道に差し掛かったとき、頂上まで到達するために数分間高い強度で運動することがあります。しかし、トレーニングセッション全体の平均として、心拍数は最大値の65～75％の間に落ち着くようにしましょう。

 

4日目: 休息

 

 

5日目: 全身筋トレ

  • 全身筋トレ
    • スクワット または レッグプレス または ブルガリアンスプリットスクワットのいずれかを、 2～3セット x 12～15レップス行う。

    • レッグカール（スライディング、マシン、グルートハムローラー）またはルーマニアン・デッドリフトを2-3セット x 12-15レップス行う。

    • A1 腕立て伏せを3〜4セット x 自分ができる限界までレップ数を増やす。

    • A2 クローズグリッププルダウン または バンドプルダウン または アシストプルアップを 3-4セット x 8-12レップス行う。

    • フェイスプル（ケーブルまたはバンド）を2〜3セット x 12〜15レップス行う。

    • B1 ダンベル・カール を2～3セット x 12～15レップス行う。

    • B2 ライイング・トライセップス・エクステンションを 2～3セット x 12～15レップス行う。

 

  • 筋トレの諸注意
    • 可能であれば、週の初めに使用したものと異なる脚のエクササイズを使用してください。例えば、月曜日にスクワットをしたなら、金曜日はブルガリアン・スプリット・スクワットをしましょう。

    • 腕立て伏せの「自分ができる限界までレップ数を増やす」とは、「あともう1回は確実にできるが、2回は無理だ！」ぐらいのレベルを意味します。

    • アシストプルアップは、エクササイズバンドかサスペンショントレーナーで行うこともできます。通常のアシストなしの懸垂を3セット、5レップ以上できるようになったら、通常の懸垂を行いましょう。

    • A1とA2、B1とB2のスーパーセットも可能です。スーパーセットを行わない場合は、各セットの間に少なくとも2分の休息を取るようにしてください。

 

 

6日目：ゆっくり長い有酸素運動

  • ゆっくり長い有酸素運動60分（最大心拍数の65～75％）。

 

 

7日目：休息
