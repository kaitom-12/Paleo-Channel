「時短で体をデカくする『レストポーズ法』の実践法」シリーズの続きでーす(#1,#2)。

 

 

このシリーズでは、以下のような方に向けた筋トレメソッドを紹介しております。

 

  • 高負荷トレーニングで関節を痛めがち（私の場合は肩が弱い傾向があります）
  • 筋力アップよりは体をデカくしたい
  • 高負荷は気分的につらいので筋トレが続かない……
  • あんま時間がないからなるたけ時間を削りたい

 

ってことで、ハードなトレーニングは嫌だけど地味に体をデカくしたいような方にはよろしいのではないか、と。

 

 

で、今回は「基礎原理編2」として、レストポーズ法の重要なポイントをさらに深掘りしていきます。その後、具体的なメニューの紹介に入っていく感じで。

 

 

基礎原理3：レスト＆ポーズの基礎

筋トレの効果を左右する「エフェクティブ・レップス」とは？

まずは「レストポーズ法」の中核とも言える、セット間の休憩法から見ていきましょう。

 

 

ご存じのとおり、筋トレってのはセット数を増やしたほうが筋肉は増えやすいわけですが、そのぶん必要な時間も多くなっちゃうわけです。なので、ジムに費やす時間を短くできて、なおかつ同じぐらい筋肉が刺激できれば最高なわけですな。

 

 

なんとも都合がいい話ですが、この問題をどうにか解決できそうなのが「レストポーズ法」であります。

 

 

たとえば「力こぶを鍛えてたくましい腕にしたい！」って場合、普通ならば、

 

  1. 1セット40秒ぐらいのダンベルカールをする
  2. 2分の休憩をいれる
  3. 再び40秒のダンベルカール
  4. 以上を3セット分くり返す

 

みたいなやり方がド定番でしょう。だいたい1メニューにつき6分ほどかかる計算でして、何種目もやってたら結構な時間になるわけですね。

 

 

ただ、ここでぜひ押さえておきたいポイントは、

 

  • 筋肉が本当に刺激されるのは最後の2〜3回！

 

ってところです。つまり、ダンベルカールを1セット10回やるときは、1〜7回目までの動きでは筋肉はさほど刺激されず、腕がプルプルし始めた8〜10回目こそが本当に重要なんですな。筋トレの世界では「エフェクティブ・レップス」と呼ばれる考え方であります。

 

 

「エフェクティブ・レップス」をくり返すのが「レストポーズ法」のキモ

ならば、「エフェクティブ・レップスだけをくり返せばいいんじゃない？」と思った研究者がおりまして、実際にいくつかの実験を行なったんですな。具体的にどのようなテクニックかと言いますと、

 

  1. 最初のセットで限界までダンベルカールをして筋肉を追い込む
  2. 20秒だけ休憩
  3. 再びウェイトを取り上げ、さらに3〜4回ほどダンベルカールをする
  4. また20秒だけ休憩してから追加で3〜4回のダンベルカール
  5. 以上を3セット分くり返す

 

のようになります。休憩時間をギリギリまで減らしつつ、小分けにしたミニセットをくり返していくわけですね。

 

 

このやり方だと、ひとつのメニューをこなすのに必要な時間は約3分。普通の筋トレより時間が半分になったのに、エフェクティブ・レップスの総量は変わらないことになるんですな。すばらしいですねぇ。

 

 

普通の筋トレとレストポーズをくらべてみたら……

というと、「本当にそれで普通の筋トレと同じ効果が出るの？」と思われた方も多いでしょうが、いくつかの研究で良い成績が出てたりします。

 

 

たとえば2017年にブラジルで行われた実験(R)では、被験者を2つのグループに分けたんですよ。

 

  1. 普通の筋トレ：セットごとに2分の休憩をはさんで筋トレ（6回を3セットずつで）
  2. レストポーズ法：1セット後は20秒の休憩をはさみ、3〜4回の筋トレをくり返す

 

どちらのグループも1RMの80％ぐらいの負荷で行い、筋トレのメニューもすべて同じにそろえてあります。

 

 

そして、6週間後に全員の筋肉量や体脂肪の変化をくらべてみたところ、

 

  • 両グループにはなんの差もなし！

 

って結果が出まして、どちらも同じように筋肉が増え、同じように体脂肪が減ったんだそうな。普通の筋トレの半分しか時間を使ってないのに、なんともすばらしい話じゃないでしょうか。

 

 

 

まとめ

そんなわけで今回は、レストポーズ法の中核をなす「エフェクティブ・レップス」についてまとめてみました。とにかく時短をしたい方には有用な手法なんで、この基本はぜひ押さえていただきたいところです。
