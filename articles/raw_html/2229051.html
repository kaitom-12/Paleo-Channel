「その悪癖、もしかしたら自然に治るかもよ？」の続きです！(#1,#2,#3,#4,#5,#6)

 

このシリーズでは、依存症の世界でよく見かける「自然回復」って現象をもとに、「悪癖が自然に改善しちゃう人は何が違うのか？」ってのを深掘りしております。「なんとなく酒がやめられたなー」とか「気づいたらタバコを吸う量が減ったなー」みたいな体験をした人たちのデータを参考にしながら、私たちの悪癖を改善するヒントを得ようってことですな。

 

前回から、「自然回復」を起こすための手法として「アイデンティティが変わる」ってポイントをお伝えしてまして、今回もその続きを見てみましょう。

 

 

アイデア３　悪癖を「研究対象」にする

悪癖を減らす方法として意外に効くのが、自分の悪癖を研究対象にするってやり方であります。

 

私たちが悪癖に取り組む時ってのは、普通、

 

  • スマホを減らすぞ！
  • 間食をやめるぞ！
  • 夜更かしを直すぞ！

 

みたいに「改善モード」で向き合うわけですが、このやり方はだいたい長続きしないわけです。その理由は単純で、人間は自分を管理し続けるのが苦手だからです。人間の脳はそもそも「管理者」よりも「オートパイロット装置」に近い構造をしているんですよ。

 

そこで、ここでは発想を変えて、自分を管理するのではなく観察するって手法を取るわけです。これは、自分の悪癖を研究サンプルとして扱うってことでして、たとえば、

 

  • どんな時間帯に悪癖が起きやすいのかを見る

  • どんな気分のときに行動が起きるのかをチェックする

  • どんな場所にいるときに発生しやすいのかを記録する

  • その行動の直前に何をしていたのかを観察する

 

みたいなことを意味します。「悪癖をやめようとする人」ではなく 「悪癖を観察する人」になるみたいな考え方ですな。

 

一見すると回り道のように思えるかもですが、行動科学の世界ではかなり有名なテクニックでして「セルフモニタリング」と呼ばれております。セルフモニタリングの研究はかなり多くて、たとえば健康行動のメタ分析(R)を見ても、

 

  • 食事記録
  • 運動ログ
  • 習慣トラッキング

 

などをつけるだけで、行動が変わるケースが頻繁に報告されてるんですよ。どうやら私たちの行動ってのは観察されると変化するって性質があるみたいなんですな。実際、いくつかのダイエット研究でも、

 

  • 食事内容を記録した人
  • 記録しなかった人

 

を比較すると、記録を取ったグループのほうが体重が落ちやすいことが何度も確認されてたりしますからね。ここで重要なのは、研究チームは参加者に食事を制限する指示を出していないってところです。参加者はただ「記録した」だけで、それでも行動が変わったわけですな。

 

なぜ「観察」によって習慣が変わるのかと言いますと、主に次の3つが考えられております

 

理由１ 行動のトリガーが見える

悪癖の多くは、ストレス、退屈、疲労みたいな特定のトリガーによって発生します。ところが、私たちはそれに気づいていないことのほうが多いんですよね。たとえば、

 

  • 退屈 → SNS
  • 疲労 → 間食
  • ストレス → アルコール

 

みたいなパターンがあるにも関わらず、私たちはそれを「自分の意志の問題」だと誤解してしまうわけです。

 

しかし、ここで観察を始めると、「あ、いつもこの時間にスマホ触ってるな」みたいなことに気づけるじゃないですか。この気づきにより、習慣は少しずつ弱まっていくんですな。

 

 

理由２ 行動の自動化が崩れる

習慣というのは基本的にオートパイロットで起きてまして、つい考えずにやってしまうことのほうが普通なわけです。ところが、ここで「いま自分は何をしているのか？」と観察するだけで、自動化が崩れるんですよ。心理学ではこれをメタ認知と呼んでまして、こいつが起動すると、

 

  • 行動する自分
  • 行動を見ている自分

 

の二層構造になるんですね。この瞬間、習慣は少しだけコントロール可能な行動に変わるんですな。

 

 

理由３ アイデンティティが変わる

ここが一番重要なポイントで、悪癖を実行しているとき、私たちは「自分＝悪癖をする人」というアイデンティティに近づきます。「私はSNSに弱い人間なのだ！」みたいなセルフイメージが強化されちゃうわけっすね。

 

しかし、ここで観察を始めると、セルフイメージが「自分＝行動を観察する人」に変わるんですよ。これはかなり大きな変化でして、

 

  • 行動の主体
  • 行動の観察者

 

が分かれることで、習慣の力は一気に弱くなるものなんですね。これは瞑想やマインドフルネスが効くメカニズムに近いところがありますね。

 

では、「悪癖の研究者」になるには、具体的になにをすればいいのか。ここでのポイントは、悪癖を改善しようとしないことでして、あくまで研究者として観察に徹するのがコツであります。おすすめのやり方をいくつか見てみましょう。

 

 

実践法１ 行動ログを取る

 

悪癖の研究を始めるうえで、まず一番シンプルで効果が高い方法が 「行動ログを取る」 ってやり方であります。これは上記のとおり行動変容の研究では定番の方法で、やり方は非常にシンプルで、

 

  • 悪癖が起きたタイミングで「時間」「何をしたか」「そのときの気分」の3つを軽くメモするだけ。

 

 

であります。たとえば、

 

  • 「22:30 スマホでSNS 退屈」
  • 「15:10 間食 疲れ」
  • 「23:40 YouTube ストレス」

 

みたいな感じっすね。ここで重要なのは改善しようとしないことでして、多くの人はログを見て「またやってしまった…」と反省を始めますが、それは研究者の態度ではないのでご注意ください。あくまで「データが取れたな」ぐらいの感覚でOKですんで。

 

この方法の面白いところは、ただ記録するだけなのに行動が変わり始めるところです。さらに、ここでログを1週間ほど取ると、「疲れて帰宅すると甘い物を食べる」「夜の退屈でSNSを見る」など、自分の行動パターンが見えて来まして、これまで無意識だった習慣が観察可能なデータに変わるんですよ。ここまで来ると、悪癖は単なる失敗ではなく研究対象になりまして、習慣の自動性が少しずつ崩れるはずであります。

 

なので、まずは完璧を目指さず、1日数行のログから始めてみてください。研究者の気分で記録するだけでも、行動は意外と変わり始めますんで。

 

 

実践法２ トリガーを探す

「悪癖の研究者」モードに慣れたら、次にやるべきはトリガー探しであります。トリガーってのは「その行動が起きるきっかけ」のことで、行動科学の世界では、習慣はだいたい「きっかけ → 行動 → 報酬」というループで回ると考えられてまして、この最初の“きっかけ”を特定するのがかなり重要なんですね。

 

たとえば「スマホをだらだら見てしまう」という悪癖があったとして、多くの人は「自分は意志が弱いからだ」と思いがちだけど、実際にはもう少し単純なパターンで動いているケースが多かったりします。たとえば、

 

  • 仕事が終わった直後 → SNS

  • 夜の23時以降 → YouTube

  • 昼食後 → 甘いもの

 

みたいに、時間帯や感情、環境によってかなり決まった動き方をしているんですね。これを心理学では「トリガー」と呼んでるわけです。

 

なので、研究者モードに慣れてきたら、次はまずは1週間ぐらい「いつ・どこで・どんな気分で」悪癖が起きたのかを記録してみてください。たとえば、

 

  • 「帰宅してソファに座るとSNSを開く」
  • 「仕事で疲れた日に甘い物を食べている」
  • 「夜23時を過ぎるとYouTubeを見始める」
  • 「退屈になるとスマホを触っている」

 

みたいな感じですね。これをやっていると、高い確率で「だいたい同じタイミングで起きてるな……」というパターンが見えてくるはずです。ここまで来るとしめたもので、悪癖の正体は「意志の弱さ」ではなく、「単なる条件反射だったんだなぁ……」って思考が身に染み始めるんじゃないかと。

 

実際、過去に行われた習慣の研究では「行動の原因の半分以上は環境と状況によって説明できる」というデータもありまして、人間は思った以上に自動的に動いている生き物なんですね。なのでまずは、自分の悪癖を「性格の問題」と決めつけるのではなく、「どんな条件で発動する行動なのか？」という視点で観察してみてくださいませ。これだけで、習慣の見え方がかなり変わってくるはずであります。

 

 

実践法３　 行動を評価しない

 

悪癖の観察を始めると、多くの人がすぐにハマる落とし穴が「評価してしまうこと」であります。ログを取っていると、「またスマホ触ってしまった……」「今日も間食してしまった……」みたいに、自分をジャッジしたくなるんですよね。

 

しかし、この反応は研究者の態度としてはNGでして、行動科学の世界では、セルフモニタリングの効果を最大化するためには「評価をしない観察」が大事だと言われてるんですな。これは、瞑想の分野でもよく出てくる「ノンジャッジメンタル」って考え方に近いものです。

 

理由はシンプルで、人間は自分を評価し始めると「防衛反応」が起きるからです。たとえば、「またやってしまった」と思った瞬間、脳は不快感を避けようとして「今日は疲れてたから仕方ない」とか「これぐらい普通だろう」といった言い訳を作り始めます。すると観察が止まり、行動のパターンも見えなくなるわけですね。

 

そこでおすすめなのが、研究者の視点です。研究者は実験データを見ても、「これはダメなデータだ」とは言わず、ただ「こういう結果が出た」と記録するだけじゃないですか。これと同じで、自分の行動ログも「良い」「悪い」ではなく「データ」として扱うのがポイントです。たとえば、

 

  • 22:30　SNS　退屈
  • 15:10　間食　疲れ

 

といった具合に、淡々と記録するだけでOK。これをやってると、不思議なことに行動のパターンが徐々に見えてきますし、習慣も少しずつ弱まっていくものなんですよ。人間の行動ってのは、「見られているだけで変わる」って性質がありまして、なので悪癖を直そうとする前に、まずはデータを集める気持ちで観察してみてくださいませ。行動科学の世界では「観察は介入である」って格言もありますんで、このメンタリティでやってみると上手くいくんじゃないでしょうか。

 

 

 

アイデア４　悪癖をダサくする

行動科学では、人の行動を決める要素として主に次の3つが挙げられます。

 

  • 快（気持ちいい）
  • 不快（嫌だ）
  • 意味（自分らしい）

 

いずれも納得の原因ですけども、ここで意外と見落とされがちなのが、この「意味」の部分であります。心理学ではこれを「アイデンティティ・シグナリング」と呼びまして、簡単に言うと、

 

  • 人は「自分らしさ」を表現する行動を選ぶ

 

という現象であります。たとえば、

 

  • 健康を大事にする人は、自然と運動を選びやすい
  • ミニマリストの人は、無駄な買い物を嫌う
  • 知的な生活を好む人は、読書を選びやすい

 

みたいな感じですね。でもって、この原理を逆に使ったのが、悪癖を「ダサい行動」にしてしまうって作戦なんですな。

 

なぜ「ダサい」と感じると行動が変わるのか？と言いますと、これは社会心理学の研究でもよく知られている現象でして、私たちは、

 

  • 自分の価値観
  • 自分のイメージ

 

に反する行動をすると、かなり強い違和感を覚えるからです。これが、皆さまご存じ「認知的不協和」ってやつであります。要するに、「自分はこういう人間だ」というイメージと、「自分がやっている行動」がズレると、脳はそれを不快に思うって考え方ですな。

 

たとえば、

 

  • 「健康志向の人」が毎晩ジャンクフードを食べる
  • 「合理的な人」が無意味にSNSをスクロールする

 

みたいな状態になると、「あれ？これ自分らしくないな」という感覚が生まれて、この違和感が強くなるほど行動は自然に減っていくものなんですね。つまり、悪癖を「ダサい」と感じるようになると、意志力を使わなくても減るという仕組みです。

 

では、具体的にどうやって悪癖をダサく感じるようにすればいいのか。代表的な実践法を見ていきましょう。

 

 

実践法１　「映画のワンシーン」として想像する

 

まずは、自分の悪癖を「映画のワンシーン」として想像する方法を試してみましょう。さんざん書いてきたように、私たちは自分の行動を第三者の視点で眺めると評価が変わりまして、これを「セルフ・ディスタンシング」なんて呼んだりします。要するに、自分を一歩引いた位置から見ることで、行動の意味づけが変わるわけですね。

 

この手法を実践するには、たとえば深夜にスマホを触りそうになったら、こんな感じで想像してみてください。

 

深夜1時。薄暗い部屋の中で、猫背の人物がソファに沈み込みながらスマホをスクロールしている。目は半分閉じていて、特に面白くもない投稿を延々と眺めている。気づけば1時間が経過。部屋には静かなブルーライトだけが漂っている……。

 

こうして映画のワンシーンとして見ると、当事者のときには気づかなかったことが見えてくるはず。「あれ、この行動ってあんまりカッコよくないな」とか、「この主人公、だいぶ時間を無駄にしてるな」みたいな感覚が出てくるんですよ。これは、自分の行動を客観視できたおかげで、評価の基準が変わったのが原因であります。

 

この方法のいいところは、意志力をほとんど使わないとこでしょう。単に「この行動、映画にしたらどう見えるかな？」と想像するだけで、行動の意味づけが変わる可能性がありますんで、悪癖に困ったらいちど頭の中でカメラを回してみてくださいませ。

 

 

 

実践法２　「憧れの人はそれをやるか？」と考える

 

多くの悪癖は、「やめよう」と思うほど強くなってしまうもの。そこで役に立つのが、行動の基準を「自分」ではなく「他人」に移す方法であります。その一つが、「憧れの人はそれをやるか？」と考えるというテクニックです。

 

心理学には「アイデンティティ・シグナリング」という考え方がありまして、人は自分の価値観や理想像に近い行動を選びやすいことが知られています。つまり、「自分がどんな人間でありたいか」というイメージが行動を決めるわけでして、この原理を使うと悪癖を抑えるのが少し楽になるはずであります。

 

こちらも実践する方法は簡単で、たとえばスマホの無限スクロールや夜更かしなどの誘惑が出てきたときに、

 

  • 「自分が尊敬している人なら、この行動をするだろうか？」

 

と考えてみるだけです。自分の好きな作家や研究者、クリエイターなどを思い浮かべて、「この人が深夜にダラダラSNSを見続けるだろうか？」と想像してみるって事ですな。そう考えてみると、たいていの場合は「いや、たぶんやらないな」と思うんじゃないかと。

 

すると面白いもんで、その瞬間に行動の意味づけが変化。さっきまで「ちょっとした気分転換」だった行動が、「自分の目指すスタイルには合わない行動」に見えてくるんですね。これもまた認知的不協和が働いたおかげであります。

 

これは要するに、「自分がどうしたいか」よりも、「自分がなりたい人はどう振る舞うか」を基準にすると、自然と選択が変わってくるって話ですな。意志力に頼るよりも、行動の基準を少し外側に置くほうが、習慣はずっと変えやすかったりしますんで、こちらもお試しあれ。

 

 

 

実践法３　「その行動を言語化する」

もう一つ最後におすすめなのが、「言葉を変える」というテクニックです。これは心理学ではフレーミング効果と呼ばれるもので、同じ出来事でも、名前や説明の仕方が変わるだけで、人間の感じ方や判断が大きく変わる現象を指しております。

 

たとえば、夜中についついお菓子を食べてしまう習慣があったとしましょう。この行動を

 

  • 「ちょっとした夜のおやつ」

 

と呼ぶのと、

 

  • 「睡眠ぶっこわれスナック」

 

と呼ぶのでは、印象がかなり違うはずであります。前者だと『ささやかな楽しみ』に見えるんですけど、後者だと一気に『健康を壊す行動』に見えてくるんじゃないでしょうか。

 

実際、行動科学の研究でも、行動のラベルを変えるだけで選択が変わるケースはよく確認されております。これは、人間の脳が、行動そのものよりも「その行動がどんな意味を持つか」に強く影響されるからです。悪癖が続いてしまうのは、その行動が、無意識のうちに「ご褒美」や「息抜き」といったポジティブな言葉でラベリングされている可能性が高いからだったりするんですよ。

 

そこでおすすめなのが、悪癖に少し辛辣な名前をつけてしまうことです。たとえば、

 

  • 「無意味にSNSを見続ける」って悪癖に困っているなら、「ドーパミン強制スクロール」
  • 深夜のネット徘徊に困ってるなら「睡眠ぶっこわしタイム」
  • ストレス食いなら「クソ食わせスナック」

 

といった具合です。こうした言葉を自分の中で使い始めると、その行動の意味づけが変わり、「あ、またドーパミン強制スクロールをやってるな……」と客観的に見られるようになり、面白いことに、その行動が少しずつ自分のスタイルに合わないものに感じられてくるはず。つまり、「やめなきゃ」と頑張らなくても、「なんかダサいな」と感じるようになり、自然と頻度が下がっていくわけですな。

 

 

 

ってことで、悪癖をダサくする方法は以上です。いずれのテクニックもポイントはシンプルで、「行動の意味づけを変える」ことがメインになっております。人間の行動は、快、不快、意味のいずれかで決まるんですが、このうち「意味」を変えると、意志力を使わなくても行動が変わる ことがあるんですな。悪癖をやめようとして疲れている人は、いったん「それってかっこいい行動か？」と考えてみるだけでも効果があるかもしれません。

ってことで、長らく続いた悪癖シリーズは今回で最終回。ありがとうございましたー。
