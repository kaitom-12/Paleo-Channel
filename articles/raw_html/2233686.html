「AI時代に必要なのは『ケンタウロス思考』だ！」の続きです！(#1,#2,#3,#4,#5,#6,#7)

 

このシリーズでは、みんな大好きサイエンス誌に掲載された最新のレビュー論文をもとに、AIを単なる便利ツールとして使うのではなく、人間の思考を拡張する「チームメンバー」として扱うための実践法を考えていきます。AI時代に私たちが鍛えるべきなのは「AIに正解を出させる力」ではなく、「AIと一緒に考える力」なのではないか？というのが、このシリーズの大きなテーマであります。

 

そのために、このシリーズでは、実際にAIとどう向き合えばいいのかを、単なるプロンプト術ではなく、手を動かしながら考えていくことにしております。ということで今回は、さらに「AIの意見を価値判断する」ワークをやってみましょう！

 

 

 

AIは「正解らしきもの」を出せるが、「あなたにとっての正解」は決められない問題

さて、AIを使っていると、たまに妙な感覚になることはないでしょうか。たとえば、仕事の企画を相談したら、AIが市場データを整理して、メリットとデメリットを比較して、リスクまで列挙してくれて便利なんだけど、ただその一方で、AIの回答を眺めながら、

 

「で、結局どうすればいいんだ？」

 

と思ってしまうような、そんな感覚であります。

 

これは「AI使ってると感じることあるある」のひとつなんですが、もちろんこいつはAIの性能が足りないからではありません。むしろ、AIがどれだけ賢くなっても、最後まで埋められない穴がありまして、それが今回のテーマである「価値判断」であります。

 

これがどういうことかと言うと、AIは「成功確率が高そうな案」や「過去のデータから見て無難な案」を出すのは得意なんだけど、

 

  • 自分は何を大事にしたいのか
  • 何を失っても守りたいのか
  • どのリスクなら引き受けられるのか
  • 誰に、どんな影響を与えたいのか

 

といったことまでは、代わりに決めてくれないんですよ。AIは地図を描けるんだけど、どこへ行きたいかは、こちらが決めるしかないんで。これぞ今回のテーマである、「価値判断力」で、AI時代にますます重要になる能力だと言われてるんですな。

 

この事実を考えるために、まずは簡単な例を考えてみましょう。あなたがAIに、こう相談したとします。

 

今の仕事を続けるべきか、独立すべきか迷っています。
年収、安定性、成長性をふまえて判断してください。

 

するとAIは、おそらく以下のような整理をしてくれるでしょう。

 

選択肢メリットデメリット
今の仕事を続ける収入が安定する、社会保障がある、失敗リスクが低い裁量が少ない、成長が頭打ちになる可能性
独立する自由度が高い、収入の上限が上がる、仕事を選べる収入が不安定、孤独、営業や事務も必要

 

確かに、この整理は役に立つんですが、この表をいくら眺めても最終回答は出ないんじゃないでしょうか。なぜなら、答えは「どちらが客観的に優れているか」ではなく、

 

あなたは、安定と自由のどちらを、どの程度まで優先したいのか？

 

で決まるからです。たとえ同じような条件だったとしても、

 

  • 子どもとの時間を最優先したい人
  • 収入の変動に耐えられない人
  • いまは挑戦して失敗してもいいと思う人
  • 多少つらくても、自分の仕事を作りたい人

 

では、選ぶべき答えが変わるじゃないですか。つまり、AIが扱うのは主に「事実」と「予測」なんで、人間が引き受けるのは「意味」と「優先順位」なんですよ。この分業を見失っちゃうと、AIのもっともらしい答えに引きずられて終わるんで注意してくださいませ。

 

ということで、「価値判断力」を鍛えるために、以下のワークに取り組んでみてくださいませ。

 

 

 

ワーク1：いま、AIに決めてもらいそうになっていることを書き出す

まずは、あなたが現在抱えている迷いを1つ選んでください。これは、仕事でも、創作でも、人間関係でも、買い物でも構いません。

 

いま迷っていること：

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

例：
・新しい仕事を引き受けるべきか
・ブログの方向性を変えるべきか
・子どもの習い事を増やすべきか
・高額な買い物をするべきか
・ある人との関係を続けるべきか

 

次に、その問題をAIに相談したと仮定してみてください。AIは、どんな「合理的な答え」を出しそうでしょうか。

 

AIがすすめそうな答え：

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

AIが重視しそうな基準：

□ お金
□ 時間
□ 成功確率
□ 安定性
□ 効率
□ 将来性
□ 他人からの評価
□ リスクの低さ
□ その他：＿＿＿＿＿＿＿＿＿＿＿＿

 

このワークで重要なのが、AIが重視しそうな基準ってのは、たしかに役には立つものの、それがあなたの人生で最優先すべき基準とは限らないってところですね。

 

私たちは、迷っているときほどつい「正しい答え」を探しちゃうものですが、現実における人生の重要な選択の多くには、数学の問題のような正解がないじゃないですか。たとえば、

 

  • 安定した仕事を辞めて挑戦する
  • 収入は下がるが、時間に余裕がある働き方を選ぶ
  • 売れそうな企画より、自分が本当に書きたいテーマを選ぶ
  • 効率は悪いが、誰かとの関係を優先する

 

こうした判断は、外から見れば「非合理」に見えることがあるんだけど、その選択が自分の価値観に合っているなら、長い目で見て後悔が少なくなることのほうが多かったりしますからねぇ。

 

なので、ここでくれぐれも意識しておきたいのは、

 

AIが出す「最適解」と、自分が引き受けたい「納得解」は別物である。

 

という点です。ケンタウロス思考における人間の役割は、AIを上回る答えを考えることではなく、むしろ「AIが出した選択肢の中から、自分の人生にとって意味のあるものを選ぶこと」なんですよ。

 

 

 

ワーク2：あなたの「判断のものさし」を取り戻す

続きまして、さっき書いた迷いについて、次の4つに答えてみてください。答えは、別にきれいなものでなくても構わなくて、矛盾していても大丈夫であります。むしろ、矛盾が出てくるなら、それは判断が難しい理由をちゃんと捉えられている証拠ですんで。

 

1. この判断で、絶対に守りたいものは何ですか？

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

2. この判断で、多少なら失ってもいいものは何ですか？

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

3. 失敗したとしても、「やってよかった」と思える条件は何ですか？

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

4. 成功したとしても、「これは違った」と思いそうな条件は何ですか？

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

 

たとえば、独立するかどうかで迷っている人なら、こんな答えになるかもしれません。

 

1. 絶対に守りたいもの
→ 家族との生活を壊さないこと。自分で仕事を作る感覚。

2. 多少なら失ってもいいもの
→ 短期的な収入。肩書きの安定。

3. 失敗してもやってよかったと思える条件
→ 3年間、本気で自分の仕事を試せたこと。

4. 成功しても違ったと思いそうな条件
→ 収入は増えたが、家族との時間も健康も失った場合。

 

あるいは、ブログの方向性を変えるかどうかで迷っている人なら、こんな答えになるかもしれません。

 

1．絶対に守りたいもの
→ 自分が心から面白いと思えるテーマを書くこと。長く続けられること。
２．多少なら失ってもいいもの
→ 短期的なPVや、いまの読者の一部からの評価。
３．失敗したとしても、「やってよかった」と思える条件
→ 半年間は新しいテーマを本気で試し、自分なりの手応えを確かめられたこと。
４．成功したとしても、「これは違った」と思いそうな条件
→ 数字は伸びたが、自分が興味を持てないテーマばかり書くようになった場合。

 

 

ここまで書くと、AIに何を聞くべきかも変わりまして、もし最初の質問が「独立すべきですか？」だったとしたら、次はこう変わるはずです。

 

家族との生活を大きく崩さず、3年間だけ独立を試すとしたら、どんな資金計画・受注計画・撤退基準を作るべきですか？

 

この質問なら、AIはかなり役に立ってくれるはず。ここでは、ちゃんと目的と優先順位は人間が決め、実行の設計をAIに任せてますからね。

 

もちろん、AIに「どうすべきですか？」と丸ごと聞くのも会話の入り口としては悪くないものの、そこで返ってきた答えを採用するかどうかは別問題。価値判断が必要な局面では、AIへの質問を少し変えたほうがよくて、おすすめは、AIに「答え」を出させるより、以下を出させることです。

 

  • 見落としている選択肢
  • 各案の最悪の展開
  • 短期的なメリットと長期的なコスト
  • 反対する人なら何を言うか
  • 自分の価値観と衝突しそうな点
  • 撤退基準
  • 小さく試す方法

 

みたいな感じですね。あくまでAIは決定者ではなく、判断材料を増やす参謀として使うのがいいってことですね。

 

 

 

ワーク3：AIに「価値観との衝突」を見つけさせる

では、今度はさきほどの「迷い」について、以下のプロンプトを使ってみてください。

 

私は次の判断で迷っています。

【判断テーマ】
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

私が大事にしたいことは、以下です。

【大事にしたい価値】
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

この判断について、
1. 選択肢を3つ以上出す
2. それぞれの短期的メリットと長期的コストを整理する
3. 私が大事にしたい価値と衝突する点を指摘する
4. 「失敗しても納得しやすい選択」を考える
5. いきなり決めず、小さく試す方法を提案する

という順番で考えてください。

 

AIの回答を読んだら、次の欄を埋めてください。

 

AIに指摘されて、初めて気づいたこと：

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

AIの提案のうち、自分の価値観と合わないもの：

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

AIの提案のうち、試してみる価値がありそうなもの：

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

 

たとえば、記入例は以下のようになります。

 

 

AIに指摘されて、初めて気づいたこと：
→ 独立後の収入だけでなく、「営業や事務にどれだけ時間を取られ、それが自分に耐えられるか」まで考える必要がある。

AIの提案のうち、自分の価値観と合わないもの：
→ 収入を最優先にするため、家族との時間を大幅に削って営業量を増やす案。

AIの提案のうち、試してみる価値がありそうなもの：
→ いきなり会社を辞めず、週末だけ小さな案件を受けながら、半年間の収入・負荷・家族への影響を記録してみる。

 

 

AIに指摘されて、初めて気づいたこと：
→ 習い事を増やすことで得られる技能だけでなく、移動時間や親子ともに「何もしない時間」が減るコストまで考える必要がある。

AIの提案のうち、自分の価値観と合わないもの：
→ 将来の選択肢を広げるため、平日も週末も予定で埋め、複数の習い事を同時に始める案。

AIの提案のうち、試してみる価値がありそうなもの：
→ まず本人が興味を示している習い事を1つだけ、3か月の体験期間として始め、楽しそうか、疲れすぎていないか、家族の余白が保てているかを記録する。

 

このワークの目的は、AIに答えを決めてもらうことじゃなくて、AIの回答を材料にしながら、

 

  • 自分は何を嫌がるのか？
  • どこまでならリスクを取れるのか？
  • 何を選んだら、あとで自分を嫌いになりそうなのか？

 

を浮かび上がらせることであります。ここでひとつ注意したいのは、価値判断というと、

 

「自分の直感を信じよう！」
「自分らしさを大事にしよう！」

 

みたいなことを考えがちなことです。直感や好みは大事な要素ではあるんですけども、ケンタウロス思考における価値判断力ってのは、

 

  1. 自分が何を大事にしているかを把握する
  2. AIに、事実・選択肢・リスクを広げてもらう
  3. 自分の価値観と現実の制約がぶつかる場所を見る
  4. そのうえで、何を優先し、何を諦めるか決める

 

というプロセスを指してまして、決して「気分で決めること」ではないことを重々ご承知あれ。

 

 

 

ワーク4：最終判断を、自分の言葉で書く

最後に、いま考えていることを、AIの言葉ではなく、自分の言葉でまとめてみてください。

 

 

私が今回、最も大事にしたいものは、

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

そのために、引き受けてもいいリスクは、

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

逆に、これだけは避けたいことは、

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

AIの助言をふまえたうえで、私が今やることは、

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

その判断を、3か月後に見直すとしたら、確認したいことは、

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

 

たとえば、子どもの習い事を増やすかどうかで迷っている場合は、こんな感じになるでしょう。

 

 

私が今回、最も大事にしたいものは、
→ 子ども本人が楽しみながら、自分の興味を深められること。

そのために、引き受けてもいいリスクは、
→ 数か月試した結果、本人に合わず、月謝や時間が多少ムダになること。

逆に、これだけは避けたいことは、
→ 将来のためという名目で予定を詰め込みすぎ、子どもが疲れたり、親子でゆっくり過ごす時間がなくなったりすること。

AIの助言をふまえたうえで、私が今やることは、
→ 本人が関心を示している習い事を1つだけ選び、まず3か月間の体験として始める。

その判断を、3か月後に見直すとしたら、確認したいことは、
→ 子どもが自分から行きたがっているか。疲れすぎていないか。家族の生活に無理が出ていないか。

 

 

あるいは、高額な買い物をするかどうかで迷っている場合は、こんな感じになるでしょう。

 

 

私が今回、最も大事にしたいものは、
→ 一時的な満足ではなく、これから数年にわたって生活の質を本当に上げてくれるものを選ぶこと。

そのために、引き受けてもいいリスクは、
→ 買ったあとで多少の後悔が残ったり、予算に少し余裕がなくなったりすること。

逆に、これだけは避けたいことは、
→ 「みんなが持っているから」「今だけ安いから」という理由だけで買い、すぐ使わなくなること。

AIの助言をふまえたうえで、私が今やることは、
→ 購入を2週間だけ保留し、そのあいだに使用頻度・代替品・維持費をメモしてみる。

その判断を、3か月後に見直すとしたら、確認したいことは、
→ 実際にどれくらい使ったか。その買い物によって、生活の手間や満足度が本当に変わったか。

 

 

ここで書いた「今やること」は、大きな決断でなくて構いません。たとえば、

 

  • いきなり退職せず、週末だけ小さく仕事を受けてみる
  • 新企画を出す前に、読者5人に見せる
  • 高額な買い物は、2週間だけ保留する
  • 相手と一度だけ、率直な話をする
  • AIの提案を採用する前に、一次情報を確認する

 

のように、できるだけ小さく取り組めるようなアクションにしたほうが、判断の精度は上がりますんで、そこはご注意あれ。

 

 

 

まとめ

ってことで今回は、「価値判断力」のお話でした。たしかに、AIってのは、選択肢を増やし、情報を整理し、失敗パターンを予測してくれるんだけども、

 

  • 何を大事にするか
  • どのリスクを取るか
  • どんな後悔なら引き受けられるか

 

を決めるのは人間の仕事だよーって話ですね。ケンタウロス思考において、AIは優秀な参謀になってくれるものの、参謀が優秀であるほど、こちらが「何のために戦うのか」を決めておかないと、いくらでも間違った方向に向かっちゃいますからねぇ。ではまた！
