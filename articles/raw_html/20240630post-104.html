意図する能力を鍛えるトレーニング法３：好奇心旺盛な自分をイメージする

「好奇心旺盛な自分をイメージする」は、名前のとおり、好奇心に満ちまくっていて新しいものごとにガンガン挑んでいる自分を想像してみるトレーニングです。

 

これはスポーツ心理学の世界でよく使われる手法で、たとえばクロスカントリーの選手が、これから走る3マイルのコースを走っている自分を想像し、良いパフォーマンスをしている自分をイメージするようなことはよく行われます。上り坂の状態、下り坂のペース、曲がり角など、コースのすべてを細かくイメージしつつ、レース中ずっと長く力強歩幅をキープできている状態をイメージするわけです。

 

これは、スポーツ心理学で「メンタル・リハーサル」と呼ばれる手法で、実際に、試合前にうまくいっている自分をイメージすることでパフォーマンスが向上する現象は何度も確認されております。たとえば、心理学者のアラン・リチャードソンが行った実験では、実験に参加する学生を3つのグループに分けまして、

 

  1. 最初のグループは20日間連続でフリースローを打つ練習をする。
  2. ２番目のグループは、初日に1回、20日目に1回だけフリースローの練習をする。
  3. ３番目のグループは、2番目のグループと同じことをしたが、毎日20分間、フリースローを成功させる自分をイメージした。

 

ってデザインで「メンタル・リハーサル」の効果をチェックしたんですよ。すると、グループ1はフリースローの精度に24パーセントの改善が見られたのに対し、グループ2の上達率はほぼゼロでした（ほとんど練習していないのだから当たり前）。

 

ところが、第3のグループは、物理的にはグループ2より練習していなかったにも関わらず、フリースローの精度に23％もの向上が見られたんだそうな。つまり、実際に練習を積んだグループとほぼ同じレベルでフリースローが上達したわけですね。同じような結果は、野球や体操などさまざまなスポーツで再現されてまして、メンタル・リハーサルの効果は疑いようがないところです。

 

でもって、この手法は深い好奇心を発動したいときにも使えるのがミソ。たとえば、好奇心に満ちた出会いを頭の中で思い浮かべることで、人間関係、仕事、そして自分自身など、あらゆる方向にむけて好奇心を展開できる可能性が高まるんですよ。

 

というわけで、具体的に「好奇心のメンタル・リハーサル」を行うためのプロンプトを紹介しましょう。以下のプロンプトは、友人を対象にしたものですが、家族、同僚、大切な人など、深い好奇心を発動したい相手であれば、誰をイメージしても構いません。

 

大切なのは、その人物と会う10分前ぐらいに時間を取って「好奇心のメンタル・リハーサル」を行うことです。なので、10分ほど目を閉じていても問題がない環境で行うようにしてください。

 

 

「好奇心のメンタル・リハーサル」のプロンプト

  1. 座りやすい場所か横になれる場所を見つけ、目を閉じてください。自分の呼吸に集中し、少なくとも3回、自分が息を深く吸って吐くところを観察しましょう。それが終わったら、あなたにとって好奇心を発動する必要がある状況を思い浮かべます。このプロンプトでは、友人と一緒に過ごす場面を例にしてみます。 
  2. まず、友人と会う場所に到着した自分を想像します。自分がどこにいるかを詳しくイメージしてください。それは自宅か、それともレストランか？　自分は座っているか、立っているか、横になっているか？　周りに何が見えるか？　どのような匂いがするか？　どんな音が聞こえるか？　などをイメージしましょう。
  3. 続いて、あなたの友人と、好奇心をもって接している自分を思い浮かべてください。相手に純粋な関心を示すために、あなたは何をしていますか？　どんな質問をしていますか？　どんな声のトーンですか？　あなたのボディランゲージはどのような感じですか？
  4. さらに、友人があなたの好奇心をうまく受け止めているところを想像してください。相手はどのように反応していますか？　笑っている？　微笑んでいる？　言葉以外の表現をしている？　相手はあなたへの興味を示すために、どんなことをしたり、言ったりしていますか？
  5. 友人と好奇心を持ってコミュニケーションしている自分をイメージしながら、自分の中に湧き上がってくる感覚に集中してください。身体のどこでそれを感じていますか？　例えば、心臓から温かさを感じますか？　お腹にピリピリした感覚を感じますか？
  6. さらに、友人が好奇心をもって、あなたと一緒にいる時間をとってくれたことに感謝している自分をイメージしてください。
  7. 最後に、自分の呼吸に集中し直しましょう。少なくとも3回は深く息を吸い、また自分の呼吸を観察したら、そっと目を開け、周囲の環境に意識を戻します。

 

このようなメンタル・リハーサルを会話の前にしておくと、事前にスピーチの練習をしておくのと同じように、実際に深い好奇心を発揮すべきときに、より準備万端で自信を持って臨むことができるはずであります。非常に簡単にできて効果が高い方法なので、誰かと仲良くなりたいときはぜひお試しください。

 

ちなみに、なかには脳内でイメージを思い浮かべるのが苦手な人もいるかもしれませんが、その場合は、頭の中でシナリオを想像する代わりに、脚本家が2人の登場人物の対話を台本に書き出すように、紙に台本のように書き出しても同じような効果を得ることができます。紙に書こうが、脳内で会話を視覚化しようが、どちらにしても深い好奇心を持つための適切なマインドセットを養うのに役立ちますんで。

 

 

意図する能力を鍛えるトレーニング法４：好奇心のキャビネット

「好奇心のキャビネット」は、シゲオカ先生が、テキサス大学オースティン校の学生たちに教えているエクササイズです。その方法は非常にシンプルで、「物理的またはデジタルなオブジェクトを使って好奇心をかき立てる！」みたいな感じです。

 

これは16世紀に流行した「キャビネット・オブ・キュリオシティーズ」（珍品陳列棚）に由来するトレーニングで、自分自身や身近な人々の物語を探求するツールとして活用していきます。といっても、わかりづらいでしょうから、具体的なステップで実践法を見てみましょう。

 

ステップ1：テーマの設定

まず、興味を引くテーマやトピックを選びます。例えば、家族の歴史、自分の成長過程、特定の趣味や興味、文化や歴史などです。あなたの興味や関心に基づいてテーマを選んでください。

 

ステップ2：オブジェクトの選定

ステップ１で決めたテーマに関する、物理的またはデジタルなオブジェクトを集めましょう。これには以下のようなものが含まれます。

  • 家族の写真やアルバム
  • 昔の手紙やカード
  • 祖父母から譲り受けたアクセサリー
  • 特定の音楽やビデオ
  • 子供の頃に好きだったおもちゃやゲーム

ステップ3：オブジェクトの展示

選んだオブジェクトを見やすい場所に展示します。物理的なキャビネットを使用する場合は、実際に棚やボックスに配置し、デジタルの場合はフォルダーやアルバムを作成します。

 

ステップ4：リフレクションとジャーナリング

展示したオブジェクトを見ながら、それに関連する思い出や感情を振り返り、以下の質問を自分に問いかけ手見ます。

  • このオブジェクトはどのような記憶を呼び起こしますか？
  • その時の自分はどんな気持ちだったか？
  • オブジェクトに関連するエピソードや物語には、どのようなものがあるか？

ステップ５：新たなオブジェクトの追加

定期的に新しいオブジェクトを追加し、キャビネットを更新します。新しい体験や出来事に関連するオブジェクトを追加することで、常に好奇心を喚起し続けましょう。

 

トレーニングの実践例

  • 実践例1：職業の選択と成長の探求
    • テーマ：キャリアの選択と成長の過程
    • オブジェクト：
      • 初めての仕事の名刺
      • 職場での賞状や感謝状
      • キャリアに影響を与えた本や記事
      • 重要なプロジェクトの資料
    • 振り返りとジャーナリング：
      • 初めての仕事を始めたときの感情や期待を振り返る。
      • キャリアのターニングポイントとなった出来事を書き出す。
      • これからのキャリア目標や夢について考える。

 

  • 実践例2：旅行と冒険の記憶
    • テーマ：旅行や冒険の経験
    • オブジェクト：
      • 訪れた国や都市の写真
      • 旅行先で購入したお土産
      • 旅行中に書いた日記やメモ
      • 地図や観光ガイド
    • 振り返りとジャーナリング：
      • 最も思い出深い旅行先とその理由を記録する。
      • 旅行中に学んだことや発見したことを書き出す。
      • 次に行きたい場所や挑戦したい冒険について考える。

 

  • 実践例3：学びと教育の軌跡
    • テーマ：学びと教育の経験
    • オブジェクト：
      • 小学校から大学までの成績表や卒業証書
      • 影響を受けた教師やメンターの写真
      • 大学での研究論文やプロジェクト資料
      • 学校でのクラブ活動やスポーツの記念品
    • 振り返りとジャーナリング：
      • 学校生活での重要な出来事や学びを振り返る。
      • 影響を受けた教師やメンターとの思い出を書き出す。
      • これから学びたいことや挑戦したい分野について考えます。

 

  • 実践例4：文化や趣味の探求
    • テーマ：特定の文化や趣味に関する経験
    • オブジェクト：
      • 趣味に関連する道具やアイテム（例：楽器、カメラ、スポーツ用品）
      • 文化に関連するアートや工芸品
      • イベントやフェスティバルのチケットやパンフレット
      • その趣味や文化に関する書籍や雑誌
    • 振り返りとジャーナリング：
      • その文化や趣味に初めて触れたときの感情や経験を振り返る。
      • その趣味や文化を通じて得た知識やスキルを書き出す。
      • 将来的に取り組みたいプロジェクトや目標を考える。

 

  • 実践例5：人間関係と友情の探求
    • テーマ：大切な人間関係や友情の記憶
    • オブジェクト：
      • 友人や家族と撮った写真
      • 思い出の手紙やカード
      • 共同で行ったイベントや旅行の記念品
      • 友情を象徴するアイテム（例：友情ブレスレット、ペアグッズ）
    • 振り返りとジャーナリング：
      • 大切な友人や家族との思い出を振り返る。
      • その関係がどのように自分に影響を与えたかを書き出す。
      • 今後の人間関係で大切にしたいことや目標を考えます。

 

ってことで今回は、深い好奇心をさらに養うためのトレーニング法を、もう２つ紹介してみました。どちらも割とやってて楽しいトレーニングなので、「好奇心を発動したい！」と思ったらぜひお試しください。ではまた！
