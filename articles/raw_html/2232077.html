「パレオチャンネルは情報が多すぎて、どう使えばいいかわからない！」みたいなお悩みを、よくいただくわけです。食事、睡眠、運動、メンタル、時間術、サプリ、仕事術と、改善ポイントが多すぎて、結局どこから始めればいいのかわからないって問題ですな。

 

まぁ、そう言われると、私などは「好きなとこからやりなはれや」ぐらいにしか思わないんですけど、やっぱ大量の情報を前にすると、どこから手をつければいいのか迷ってしまうのが人情。自分にとって最初に直すべきポイントを見つけるための地図が欲しくなるのは当然でしょう。

 

ということで今回は、自分の人生における“最初に手をつけるべきポイント”を見つける方法を見てみましょう。

 

 

 

人生を「制約理論」で考えてみよう！

さて、「人生を良くしたい！」と思ったとき、多くの人はすぐに、

 

  • もっと努力する
  • もっと勉強する
  • もっと習慣を増やす
  • もっと時間を有効活用する

 

みたいな方向に走りがちでしょう。現状の問題に対して、新しい行動や知識をどんどん足していくことで対策を図ろうとするわけですね。

 

しかし、このような考え方は、悪いとは言わないものの、いまいち上手く働かないことが多かったりします。というのも、人生の問題は「努力が足りないから起きている」とは限らないからで、たとえば、睡眠不足で脳が回っていない人が、もっと勉強時間を増やしても効率は上がりませんし、ストレスで食欲が暴走している人が、厳しい食事制限だけを足しても長続きしませんからね。つまり、流れが詰まっている場所を見ないまま努力を足すと、がんばっているのに前に進まないという悲しい状態になりやすいわけです。

 

そこで、本項で提案したいのが「人生のボトルネックを探そう！」って考え方であります。 ボトルネックってのは、もともと製造業で使われる考え方で、「プロセスの流れを止めたり、遅らせたりする弱点」のことでして、たとえば、工場で部品の組み立ては速いのに、最後の検品だけが遅ければ、商品全体の出荷スピードは検品工程に引っぱられます。仕事でも、資料作成は終わっているのに、上司の承認が遅ければ、プロジェクト全体は前に進みません。これらの問題をクリアして全体の効率を上げるには、その流れを止めている一点を見つけて、対処する必要があるはずです。

 

これは私たちの暮らしでも同じことで、健康になりたい人が「筋トレを増やそう！」と思っても、実際のボトルネックが睡眠不足なら、 運動量を増やすほど疲れて悪化しちゃうでしょう。収入を増やしたい人が「スキルを学ぼう！」と思っても、実際のボトルネックが営業・発信・人脈なら、 勉強だけ増やしても結果は変わらないはずです。

 

似たような事例は山ほどありまして、

 

  • 痩せたい！と悩んでいたら、実際のボトルネックは、食欲ではなく睡眠不足だった
  • 勉強が進まない！と悩んでいたら、実際のボトルネックは、集中力ではなくスマホだった
  • 仕事で成果が出ない！と悩んでいたら、実際のボトルネックは、能力ではなく優先順位の曖昧さだった
  • 人間関係がしんどい！と悩んでいたら、実際のボトルネックは、上司ではなく自分の感情コントロール力のなさだった

 

などが代表例ですね。ここらへんは誰にでも心当たりがあるでしょう。

 

これは制約理論（Theory of Constraints）の考え方にもとづいてまして、この理論では、

 

  • システム全体の成果は「もっとも弱い制約」によって決まり、その制約を特定して改善することが重要だ！

 

とされております。制約理論はもともと工場や企業の生産性を改善するために生まれたマネジメント理論で、製造業、プロジェクト管理、サプライチェーン、医療現場の業務改善などでその正しさが確認されております。

 

一例を挙げると、医療現場を対象にした試験(R)では、手術室や救急外来、患者記録の管理プロセスなどで「どこが患者の流れを詰まらせているのか？」を調べ、特定の工程に患者や書類が滞留しているポイントを見つけることで、待ち時間や処理の遅れを激しく減らせたんだそうな。似たような事例は他にもありまして、プロジェクト管理の分野などでも、ボトルネックを見つけることで待ち時間や処理の遅れを減らしたケースが報告されております(R)。

 

そこで、この考え方を人生にも適用してみよう！ってのが、本稿の目的になります。つまり、本稿のポイントを簡単に言えば、

 

人生で大事なのは、「何を足すか？」ではなく、「どこで流れが詰まっているか？」を見ることだ！

 

って感じっすね。いたずらに努力の量を増やす前に、まずは自分の生活のどこでエネルギー、時間、注意力、感情が詰まっているのかを見つける。そこがわかれば、あとは最小の時間と労力で、人生を変えられる可能性が高まるわけです。

では、実際にあなたの人生のボトルネックを探すためのステップを見てみましょうー。

 

 

ステップ1. まず「人生」を1本の生産ラインとして見る

人生のボトルネックを探すときに、最初にやっておきたいのが「自分の人生を1本の生産ラインとして見る」という発想であります。

 

生産ラインってのは、工場でベルトコンベアに乗った商品が、材料の準備、加工、梱包、出荷へと進む一連の流れのことで、このときに大事なのが、どこか1カ所で作業が詰まると、全体の流れが悪くなってしまうという点です。材料は十分にあるのに加工が遅ければ在庫が積み上がりますし、加工は速いのに検品が遅ければ、結局商品は出荷されませんからね。

 

これは人生でもまったく同じで、たとえばあなたが「もっと仕事で成果を出したい」と思い、「もっと作業時間を増やそう」と考えたとしましょう。しかし、ちょっと考えてみれば、仕事の成果ってのは単純に努力量だけで決まるわけではなく、実際には、かなり多くの工程がつながっていることがわかるはず。ざっくり書けば、こんな感じです。

 

睡眠 → 体調 → 集中力 → 作業時間 → 優先順位 → 実行 → フィードバック → 改善 → 成果

 

この流れを見ると、「成果が出ない」という悩みの裏には、いろんな詰まり方があり得ることがわかるでしょう。当然ながら、睡眠が足りていなければ体調が落ち、体調が落ちれば集中力が落ち、集中力が落ちれば同じ1時間でも作業の密度が下がるはず。すると、いくら作業時間を増やしたところで、睡眠不足がさらに悪化して、ますます成果が出なくなるのは確実でしょう。

 

これは、いわば生産ラインの最初のほうで詰まっている状態だと言えます。にもかかわらず、最後の「作業量」だけを増やしてみても、全体の流れは良くなりません。

 

あるいは、これを読んでいる人の中には、体調も集中力も悪くないのに、優先順位で詰まっているケースもあるでしょう。毎日ちゃんと机に向かっているし、真面目に働いているにも関わらず、やっている作業が「成果につながる重要タスク」ではなく、「なんとなく処理した気分になる雑務」ばかりだったら、努力量のわりに結果が出ないのは当然であります。この場合のボトルネックは、やる気でも体力でもなく、何に集中するかを決める工程にあるわけです。

 

こういった事例のように、人生を生産ラインとして見ると、「私は根性がない」「才能がない」といった雑な自己評価を避けやすくなりまして、その代わりに、

 

  • どの工程で流れが止まっているのか？

 

って視点から問題を考えられるようになるわけです。

 

これはかなり大事なスキルで、なぜなら人生の問題ってのは、たんに特定のプロセスがうまく機能していないだけのことが多いからです。一例として、健康で言えば、

 

  • 食事 → 血糖 → 活動量 → 睡眠 → 回復 → 翌日の食欲

 

みたいなプロセスがあるじゃないですか。もしここで睡眠が崩れると、翌日の食欲が乱れる→甘いものを食べたくなる→血糖が乱れる→運動する気がなくなる→また睡眠が崩れる、みたいなプロセスが発生しやすくなるんですな。この時、本人は「自分は食欲を我慢できない人間だ」と思ってるかもですが、実際のボトルネックは「睡眠の乱れ」や「運動不足」なのかもしれないんですな。

 

もうひとつ、同じ考え方は人間関係にも当てはまりまして、コミュニケーションの不調に悩んでいる人には、

 

  • 疲労 → 余裕のなさ → 雑な反応 → 相手の不満 → 関係悪化 → ストレス増加 → さらに疲労

 

みたいな流れが起きていることがよくあります。このような流れにハマっている人は、必ずしもコミュ力がないとは限らず、そもそも「疲労」や「余裕のなさ」がボトルネックになっていないかを見る必要があるんですな。

 

このステップにおける最大のポイントは、人生を「才能」や「性格」ではなく、「流れ」と「工程」で見ることです。人生の問題を工程に分解すると、改善策がかなり具体的になりまして、「睡眠時間を30分増やす」とか「食後に10分歩く」みたいに、実際に変えられる行動へ落とし込みやすくなるんですよ。

 

逆に人生を生産ラインとして見ないと、私たちはすぐに「全部を直そう！」としちゃいまして、食事、睡眠、運動、人間関係をまとめて改善しようとして、結局どれも中途半端に終わりやすくなります。これは、マジメなＤラボ民ほど起きやすい現象かもですな。

 

しかし、実際に効果が出やすいのは、まずはじめに、

 

  • いま一番流れを止めている工程はどこか？

 

を考えることです。何か問題が起きているとき、成果が出ないとき、調子が悪いとき、習慣が続かないときには、はじめに人生の工程を考えてみて、その上で「この流れの中で、どこが詰まっているのか？」を探すほうが、よほど人生の改善はラクになるはずであります。

 

 

 

ステップ2. ボトルネックは「悩み」ではなく「成果を制限している一点」だと心得る

続いて、あなたの人生をよどませている“ボトルネック”を特定してみましょう。このステップでまず大事なのは、

 

  • 人生のボトルネックは、必ずしも「いま一番つらい悩み」とは限らない

 

というところであります。たとえば、あなたがいま「仕事がつらい！」と感じているとしましょう。すると、あなたの意識としては「仕事がつらいんだから、仕事そのものが悩みの中心だ！」と考えたくなるはず。その上で、上司がしんどい、タスクが多い、成果が出ない、評価されない……など、目の前に並ぶいろんな問題に対処しようとするんじゃないでしょうか。

 

しかし、ボトルネック分析の視点では、ここでまず見るべきなのは、

 

  • 私の成果や生活の流れを、実際に一番止めているものは何か？

 

という一点であります。この視点から問題を見直してみた場合、もしかすると仕事の悩みの根本は、実は「睡眠不足」だったりするかもしれません。睡眠が足りないせいで朝から集中力が低く、判断力も落ち、ミスが増え、上司への報告も遅れ、結果として仕事全体がしんどくなっている……みたいな流れですな。この場合、あなたの悩みは「仕事」なのに、実際のボトルネックは「睡眠」だと考えられるわけです。

 

あるいは、あなたが「あの同僚が苦手だ」「上司に振り回される」と思っていたとしても、本当のボトルネックは「境界線を引けないこと」にあることもよくあったりします。頼まれると断れないとか、自分の予定より他人の都合を優先してしまうとか、嫌なことを嫌だと言えないとか、そういった行動パターンが積み重なり、対人ストレスが積み上がっているわけですな。この場合も、目に見えている悩みは「会社の人間関係」ですが、実際のボトルネックは「境界線の弱さ」です。

 

ここを間違えると、本人はめちゃくちゃ頑張っているのに、「なぜか人生が変わらない！」みたいな状況が起きちゃうわけです。ボトルネック怖い！

 

だからこそ、ボトルネックを見つけるときは、悩みの大きさではなく、波及効果で考えるのがめっちゃ大事。「ここを改善したら、他の問題もまとめて軽くなりそうか？」って考えてみるのが、ボトルネック探しの最大のポイントになるわけです。

 

たとえば、睡眠を改善したら、食欲、集中力、メンタル、運動意欲、人間関係の余裕まで良くなりそうなら、睡眠はかなり有力なボトルネック候補だと言えましょう。逆に、ある悩みがいくら気になっていても、それを改善しても他の問題にあまり波及しないなら、最初に手をつけるべき場所ではないかもしれません。かように、人生のボトルネックとは、「一番うるさい悩み」ではないわけです。ここはめっちゃ大事なので、何度も復唱して肝に銘じておいてください。

 

 

 

ステップ3. 「COM-B」でボトルネックを探す

さて、ボトルネック探しの心構えがわかったところで、いよいよ実際に自分なりのボトルネックを探してみましょう。その方法はいろいろありますが、行動科学の世界で最もよく使われるのが、「COM-Bモデル」ってフレームワークであります。

 

COM-Bってのは、「私たちの行動を変えるには、どのような要素が必要なのか？」って問題を理論化したものです。簡単に言うと、COM-Bでは人間の行動を決めるものは、

 

  1. Capability：能力
  2. Opportunity：機会・環境
  3. Motivation：動機

 

の3つだと考えてまして、この枠組みを使うと、だいぶボトルネックの見通しがよくなるんですよ。

 

もう少し詳しく考えてみましょう。私たちが「これができない！」って考えるときには、だいたい以下のどれかがボトルネックになってるはずであります。

 

  1. やり方がわからない
  2. やれる環境がない
  3. やる気や感情が邪魔している

 

これはめちゃくちゃ大事な観点でして、この視点から見ると、自分の人生の問題をもっと冷静に分解できるようになるんですよ。

 

たとえば、あなたが「毎日運動できない！」という悩みを抱えていたとしましょう。このとき、COM-Bのフレームワークが頭にないと、「意志力を鍛える動画を見よう！」とか「習慣化の動画を見よう！」みたいに即断したくなっちゃうわけですが、ここでぐっとこらえて、問題をCOM-Bの3要素に分けて考えてみたらどうなるでしょうか？

 

  1. 能力の問題はないか？：運動メニューが難しすぎるのかもしれない。そもそも何をすればいいかわからないのかもしれない。あるいはスクワットのフォームに自信がないのかもしれないし、疲労管理の知識がないのかもしれず、はたまた体力が低すぎて普通のメニューがきついのかもしれない。この場合、ボトルネックは「誠実性」や「習慣化」ではなく、たんに「運動の知識不足」や「メニューの難しさ」なのかもしれません。それならば、運動メニューを笑えるぐらい簡単にすることやフォームを学ぶことなどの対策をして、能力のハードルを下げるのが大事になりましょう。

  2. 環境や機会の問題はないか？：朝に時間がない？ ジムが遠い? 運動着が出しにくい場所にある? 家族の予定に邪魔される? スマホが近くにあって、気づいたらSNSを見ている? など、環境にまつわるボトルネックも考えられるでしょう。この場合は、「運動をする環境」が設計できていないだけなので、環境を変えるのが適切な対策になります。たとえば、寝る前に運動着を出しておく、ヨガマットを敷きっぱなしにする、ジムをやめて家で3分だけやる、みたいな感じっすね。

  3. 動機や感情の問題はないか？：運動のメリットを感じていない、やったほうがいいのはわかるけど面倒くさい、完璧にできないならやりたくない、疲れているときに運動する意味がわからないみたいに、心理的な抵抗があるケースです。ここで大事なのは、モチベーションにも種類があるってことでして、「報酬が遠すぎる」「不安が強い」「失敗経験が多い」「完璧主義が邪魔している」「その行動が自分の価値観とつながっていない」みたいに、いろんなパターンがあるんですよ。これを見極めずに習慣化の動画を見ても、いまいち効果が出にくくなるので注意したいっすね。

 

このように、COM-Bを使うと、行動できない理由をかなり具体的にできまして、漠然と「意志力を鍛えないと……」とか「習慣化しないと……」とか悩むよりも解像度が高くなり、おかげで効果的な対策も立てやすくなるわけです。

 

他にもいくつか事例を挙げておきますと、たとえば「ブログが書けない」という問題が起きた場合は、

 

要素ボトルネック例対策
能力構成の作り方がわからないテンプレを使う
環境書く時間が固定されていない朝の30分を執筆枠にする
動機批判が怖い下書きとして公開範囲を狭くする

 

みたいに分けることができるかもしれません。

 

あるいは、「早寝できない」って問題があるなら、

  

要素ボトルネック例対策
能力睡眠改善の手順を知らない起床時刻固定から始める
環境ベッドでスマホを見てしまうスマホを寝室の外に置く
動機夜だけ自由を取り戻したい夜ではなく朝に自由時間を作る

 

という感じに分解してみたほうが、格段に対策を立てやすくなるでしょう。とにかく、なにか悩むことがあったら、その問題を「能力が足りないのか？」「環境が悪いのか？」「動機や感情が詰まっているのか？」と分けてみる。これが、パレオチャンネルの情報を上手く使うための第一歩になります。

 

ってことで、長くなったので今回はこのへんで終了。次回は、さらにCOM-Bを掘り下げて、さらに細かくあなただけのボトルネックをあぶり出す方法をチェックしていきましょう。とりあえず今回は、まずは「できない理由を能力・環境・動機に分けるのが大事！」ってところを覚えておいてくださいませ。ではまた！
