人生を変えたきゃ「自分自身を知れ！」はマスト


「自分自身を知れ！」ってのが人生をうまくやっていくためにメチャ大事なのはご存じのとおり。ブログで紹介したところだと「『汝自身を知れ！』は21世紀の成功に必要な人生スキルだ！という話」ってのがありましたし、このブロマガでも「微動だにしない自信を身につけるための「セルフコンセプト・クラリティ」入門」なんてエントリがありましたな。

 

 

いずれにせよ、自分がどんな価値観や思考のアルゴリズで動いているのかを知らないと、人生の行く末を見極めることもできないし、そもそも自分がどんな環境で楽しいのかを判断できないですからねぇ。いわば地図なしで見知らぬ土地を動き回るような状態になるので、そりゃあ道に迷うのが当たり前なわけです。

 

 

というと、「あれ？『無(最高の状態)』では自己を無くすのがいいって言ってなかった？」という疑問を持つ方もいるかもしれません。が、ここでいう「自分自身を知れ！」ってのは、言い換えれば「自分がどんな物語で構成されているのかを理解しようぜ！」って話でして、実際に目指すところはそんなに変わらなかったりします。

 

 

自分を構成する物語さえ理解できれば、悪いストーリーに無駄に振り回されやすくなるし、逆に良いストーリーを自由に選ぶこともできますからね。より人生の自由度を増すためにも、やはり「自分自身を知れ！」は重要なポイントだと申せましょう。

 

 

 

１日６問ずつで自分を徹底的に掘り下げる

といったところで、アーサイナス大学のブレント・マッティングリー先生などのチームが、近ごろ「自己認識を高めるために超役立つ36の質問を考えたよ！」って話(R)を公開してくれていて、これがかなり役に立ちそうでした。これは、自己認識にかんする過去の理論や研究、確立された心理学的尺度を参考に作られたもので、個人の内省をうながして、自己認識や自己理解を深めるようにデザインされております。

 

 

「36の質問」というと、「誰とでも最速で親密な関係になれる36の質問」を思い出した人もいるかもしれません。ニューヨーク州立大のアーサー・アーロン博士が考案した質問集で、いろんな人と親密な関係を築くために役立つナイスな質問リストですね。

 

 

で、今回の「自分自身を知るための36問」を考案したチームは、実はアーロン博士のお弟子さんだったりします。アーロン博士に影響されて、自分を掘り下げる質問を36まで絞り込んだんだそうで、弟子のレスペクトを感じますね（笑

 

 

なので、個人的には、今回の「自分自身を知るための36問」によって自分のことを知り、その知識をベースにしつつ、アーロン博士の36問を使って他人との仲を深めていくのがおすすめ。どちらも徹底的に使い込むことで、対人関係の悩みはかなり減るんじゃないでしょうか。

 

 

では、さっそく「自分自身を知るための36問」を見ていきましょう。この質問集は6つのパートに分かれており、それぞれに6つの質問が用意されております。それぞれの質問について深く考えたら、その答えを書き留めて振り返ってみてください。

 

 

研究チームは、「この質問集をしっかり使うためには、ひとつのセクションに15～20分程度かけるといいよー」と言っておられます。だいたい１問につき３〜４分を使って、きっちりと考えるのが望ましいわけっすね。

 

 

すべてのセクションをこなそうと思ったら、短くても１時間半は必要な計算ですが、１日でやるとぐったりしそうなので、１日に１セクションずつ終えていくのがいいかもしれません。私も１日に１セクションずつ試しました。

 

 

ちなみに、研究チーム曰く、「１回やって終わりじゃなくて、考える時間をより多く確保したほうが効果的だよー」とのこと。確かに、自分の掘り下げはできるだけやっといたほうがいいので、時間をかけるに越したことはないでしょうな。

 

 

 

 

自己認識を高めるために超役立つ36の質問

ってことで、「自分自身を知るための36問」は、以下のようになります。

 

 

セクション1.  あなたのコアを深掘りする６問

まずは、自分の”中核”を再認識するための質問集です。ここでは自分のコアになる部分について深く考える質問が並んでまして、「私はどんな人間か？」を深掘りしていきます。

 

  1. あなたを表す形容詞や特徴を5つ挙げたらどうなりますか？（「優しい」とか「背が高い」とか）★

  2. あなたが果たすべきだと思う役割を5つ挙げたらどうなりますか？（「父親」とか「知識を広める」とか）

  3. 自分が持っているスキルや能力を5つ挙げたらどうなりますか？

  4. あなたの持ち物のうち、あなたがどんな人であるかを知ることができるものを5つ挙げたらどうなりますか？

  5. 自分がどのような人間であるかを知るのに役立った人生経験を5つ挙げたらどうなりますか？★

  6. 親しい友人や家族があなたを表現するのに役立つと思う属性を5つ挙げたらどうなりますか？（「人見知り」とか「やり始めれば最後までやる」とか）

 

 

 

セクション2.  あなたが自分についてどう思っているのかを知る６問

続きまして、あなたの性格や価値観のなかで、「これがもっとも楽な自分だ！」とか「これが素の自分だ！」と感じられるポイントを掘り下げていきます。心理学でいう「本来感」を知るための質問で、「自分らしさ」にかかわる要素ですね。

 

  1. 「自分はどんな人間だろうか？」と考えたときに、自分の性格のなかでどの側面が最もはっきりと意識されますか？★

  2. あなたが世間に見せている「あなた」は、あなたが「これが本当の自分に近い」と感じるあなたと、どのような点が一致していますか？★

  3. 社会的または仲間からの圧力にもかかわらず、自分らしさに忠実であり続けた例を3つ考えてみてください。どのようにすれば、同じように自分らしさを維持することができますか？

  4. あなたの重要な価値観を３つ挙げたら何になりますか？ そして、自分の将来を改善するために、その価値観をうまく使う方法はありますか？

  5. あなたの人格のなかで、状況にかかわらず変わらないのは、どのような部分でしょうか？

  6. セクション1の質問1から6で作った「あなたのコアリスト」を見てください。これらのリストのうち、あなたが考える「素の自分」と相反するものはありますか？  もしあるのなら、どうすればもっと一貫性を保てるでしょうか？

 

 

 

セクション3. あなた美点を掘り下げる６問

このセクションでは、あなたの優れた点や誇りに思えることを深掘りします。悪いところにばかり目を向けてたら、自分の美点を忘れちゃいますからね。

 

  1. あなたの最高の資質は何だと思いますか？

  2. 自分を他の人と比べた場合、特に優れている点はどこだと思いますか？

  3. あなたの人生は、あなたの知人や友人の人生と比べて、どのような点で優れていると思いますか？★

  4. 自分自身について、誇りに思うことを3つ挙げたらどうなりますか？★

  5. あなたが人生で達成した最大の出来事を3つ書いてください。あなたの次の大きな目標は何ですか？

  6. あなたが苦労していることは何ですか？これらの苦悩を共有する人がいますか？

 

 

 

セクション4. あなたが置き去りにしてきた過去を掘り下げる６問

このセクションでは、いまの人生のルートに入る前の自分について思い出し、あなたが過去に置き去りにしてきたかもしれないことを掘り下げていきます。これも自分のメンタルを健やかに保つためには必須の作業ですね。

 

  1. あなたが心から楽しめるにもかかわらず、あまり行う機会がない活動を3つ挙げてください。これらのことをもっと頻繁に行うには、どのようなステップを踏むことができますか？★

  2. あなたという人間が、望むべき人生のルートから外れてしまった部分はあるでしょうか？ もしあるなら、それを望むルートに復帰させるために、あなたは何ができるでしょうか？★

  3. あなたは自分のことより他人のことを優先してたことがありましたか？ もしあるなら、どうすれば自分と他人のニーズのバランスを取り戻し、もっと自分のニーズに目を向けられるようになるでしょうか？

  4. 近ごろあまり時間を割いていなかった趣味がありますか？　もしあるなら、その趣味のための時間を、どのように増やすことができますか？

  5. 高校を卒業するとき、どんな人になりたかったか思い出してみてください。その時に、今の自分にはないと思うポジティブな要素は何ですか？ どのようにしたら、今の自分の中に、そのポジティブな要素を再発見できますか？

  6. 昔の写真を見たり、古い日記を読んだりして、何時間か過ごしてみてください。昔の自分に再会することで、どのようなメリットを感じられましたか？

 

 

  

セクション5. あなたの仕事人生を掘り下げる６問

このセクションでは、あなたの仕事人生にあらためて目を向けて、それを自分を向上させる機会としてとらえることができないかを考えていきます。

 

  1. あなたの仕事は、どのような点で人間的な向上に役立っていますか？ どうすれば、この状態を将来も継続させることができますか？★

  2. あなたの仕事で、どのような新しいことや面白いことを学ぶことができますか？ これらの経験は、あなたにどのようなメリットをもたらしていますか？★

  3. あなたが仕事で引き受けねばならない責任の中で、楽しいと思うものは何ですか？ また、それによって、あなたは仕事をよりうまく進められるようになりましたか？

  4. 平凡で退屈な仕事を、もっと面白く、楽しくするにはどうしたらよいでしょうか？

  5. 過去5年間で、あなたは仕事でどんな新しいスキルを身につけましたか？これらは、現在のあなたにどのようなメリットがあったでしょうか？

  6. 今後5年間で、さらにどのような専門性を身につけることができるでしょうか？

 

 

 

セクション6. あなたの未来を掘り下げる６問

最後の世界は、あなたの未来に目を向けるための質問です。自分のコンフォートゾーンを飛び出して、新しいことに挑戦し、いかに自分の新しい面を発見するか？ってポイントを掘り下げるわけですね。

 

  1. あなたが挑戦できる、新しくて面白い活動を3つ挙げてください。その中で、来週から始められるものはどれですか？

  2. あなたが学びたいと思うトピックを3つ挙げてください。そのうち、 少なくとも1つについて、もっと理解を深めるためには、どんな行動計画を立てればいいでしょうか？

  3. 今月、自分の向上につながることを3つ考えてください。それぞれを達成するために、あなたはどのようなステップを踏むことができるでしょうか？

  4. 今後行ってみたい場所を3つ挙げてください？ それぞれの場所を訪れることで、あなたは何を学ぶことができますか？

  5. 過去5年間で、あなたはどのような点で人間的に成長しましたか？ また、そのことが現在のあなたにどう影響していますか？★

  6. 今後5年間で、あなたが人として成長するための方法を考えてください。それを実現するには、どんな行動計画を立てればいいでしょうか？★

 

 

ということで、「自己認識を高めるために超役立つ36の質問」は以上です。質問のなかに「★」マークがついたことがありますが、これは「36問をすべてやるのが面倒なら、せめて★マークがついた質問だけは考えてみて！」ってことだそうです。これだと12問で済みますんで、確かにだいぶ楽ですね。

 

 

いずれにせよ、これらの質問にがっつり取り組むことで、自分自身をより深く理解し、自己認識力を高めることができ、人生の満足度、幸福度、気分の良さ、ストレスの軽減につながりますので、ぜひお試しください。「自分自身を知ることは、すべての知恵の始まりである」っていうアリストテレス先生のお言葉はまことに真実ですので。
