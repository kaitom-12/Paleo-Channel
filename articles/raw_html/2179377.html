マインドボディワーク入門の続きです！(#1)

 

 

このシリーズでは、メンタルの問題によって、腰痛、頭痛、肩や首の痛み、お腹の不調、アレルギーといった謎の不調が悪くなってしまう現象に 立ち向かうためのワークを紹介しています。体の不調の多くはメンタルと密接に結びついているため、 薬物治療などで効果が出ない方はこちらもぜひお試しください。

 

でもって、前回はワークの第1週目の1〜3日目までを見てきましたので、今回はその続きです。

 

 

マインドボディワーク第1週目（続き）

４日目のワーク

日付 ___/___/_____

  1. 今日は、 あなたにストレス やネガティブな感情をもたらす出来事がありましたか？


  2. 最近の生活で、あなたがストレスを感じることを、リストアップしましょう（あくまでただのリストなので、思いつくだけ片っ端からリストアップする）。リストアップが終わったら、「自分の力ではどうにも変えられない、または自分の力では改善ができないものはどれだ？」と考えて、当てはまるものに「x」をつけましょう 。


  3. 「x」をつけたストレス源を横線や黒塗りで消し、「これらは自分ではどうにもならないので手放そう」と自分に言い聞かせましょう。その上で、リストに残った「自分の力でどうにか改善できるストレス源」だけをピックアップして、あなたの人生に影響を与えているなものから順に並べてください。


  4. 「自分の力でどうにか改善できるストレス源」のなかで、今日あるいは明日から取り組める項目はどれですか？ 最も簡単に取り組めて、最も影響が大きい項目をひとつ選び、具体的にどのような行動をするのかを考えて、紙に書き出しましょう（他の項目については、後でまた取り組みます）。

 

 

 

５日目のワーク

日付 ___/___/_____

  1. 今日は、あなたにネガティブな感情を引き起こすような事態は起きましたか？　また、4日目のワークで決めた「ストレス対策」は実践しましたか？　もし実践できなかった場合は、その理由を書いてください。


  2. 今日の読書で、 自分の問題に関係していそうなところがありましたか？


  3. 今日のあなたの「セルフトーク」について考えてみましょう。 自分の痛みと緊張のサイクルを強めるようなメッセージを、 自分自身に与えていなかったでしょうか？（たとえば、「 この緊張で筋肉がこわばり、痛みが増すはずだ」「 背中が丸いから腰痛が悪化するかもしれない」 のような感じです）


  4. あなたが人生で最も恐れていることは何ですか？（この問題については、また後のワークで繰り返します）

 

 

 

６日目のワーク

日付 ___/___/_____

 

  1. 今日は、 あなたの人間関係で何が起きたかに焦点を当てます。今あなたは、誰に一番腹を立てていますか？ その人物のことを想像しながら、自分の感情を詳しく説明し、その人に怒りがわく理由を 書き出しましょう。それと同時に、怒りの感情と自分の不調が関係していないかどうかについても考えてみてください。


  2. 今日の読書で、 自分の問題に関係していそうなところがありましたか？


  3. あなたの不調について、友人や家族には 話をしていますか？　自分の不調が、 メンタルから来ている可能性について話をしましたか？　もし話をした場合は、友人や家族はどのような反応をしましたか？（心身症でよくある問題のひとつは、友人や家族からの無理解があります。「腰痛や頭痛の原因はメンタルにもある」 と言う考え方に対して、周囲が懐疑的だったり、嘲笑的だったり、批判的だったりすると、 やはり不調は起きやすくなります）


  4. 身体活動は少しずつ増えていますか？　自分の身体の動きや姿勢について、どのように考えていますか？　「痛みがあるうちは、運動などできない」「 不調の時は安静にしたほうが良い」といった思考は ありますか？　思いつくものを書き出してください。

 

 

 

７日目のワーク

日付 ___/___/_____

 

  1. 最近、あなたを不安にさせたり、動揺させたりしたことはありますか？　心当たりがあれば、できるだけ詳しく書いてください。そして、ネガティブな感情や、その根底にあると思われるものをできるだけ詳しく考えてください。


  2. 今日の読書で、自分の不調とメンタルのつながりについて、 どれぐらい理解が深まりましたか？　（心身のつながりを信じることは、回復に不可欠な要素です）。


  3. あなたの周囲の人たちは、 自分のネガティブな感情にどのように対処してきましたか？　あなたがネガティブな感情に対処する方法は、 その周囲の人たちから影響を受けていませんか？　もし影響があるとすれば、そのストレス対策は健全に機能していると考えられますか？


  4. もし 体の不調がなくなったら、どんな運動をしたいですか？　やってみたいことを挙げてください。

 

 

 

マインドボディワーク第2週目

２週目は、1週目の復習をしつつ、 さらに未解決の問題を 掘り下げていきます。あなたが長年にわたって抱いてきた感情的な問題をより深く探求していきましょう。

 

また、この週は、1週目で取り上げた課題図書を 読む必要ありません。ただし、 心と体の関係性を頭に叩き込みたい時は、同じ本を再読しても問題ありません。

 

繰り返しになりますが、このワークは、1日15～30分ぐらいで行ってください。 それ以上かけると、逆にこのワークがストレスになってしまうので、そこは注意してください。

 

 

８日目のワーク（第1週の復習）

  1. 1週目のワークで書いたものを見直してください。 あなたが抱く感情や思考には特定のパターンがありますか？　あなたの頭の中によく 浮かぶ思考や感情を、まとめてみましょう。 また、これをもとに2週目で目指したい身体的＆心理的な目標も書き出してください（「不調を 30%減らす」「 怒りの発生頻度を減らす」 などです）。


  2. この ワークは、あなたの活動レベルに影響を与えましたか？　もしポジティブな変化が あったなら、 それも書き出してみて、その変化を自分で褒めてあげてください)。


  3. 先週、あなたの生活で他にポジティブなことは起きましたか？　それもいくつか考えて書き出してください。

 

 

9日目のワーク

日付 _____/____/_____

  1. 今日の気分はどうでしたか？　今日は何が嬉しかったですか？　今日起きたポジティブなことに目を向け、 思いついたものを全て書き出してください。


  2. あなたの仕事（または、育児、介護、趣味）はどのようなものですか？　それについて、あなたが興奮したり刺激を受けたりするポジティブなことは何ですか？　その感情や、過去とのつながりがあれば書いてください。


  3. あなたの仕事（または、育児、介護、趣味）について、何が一番腹が立ち、イライラさせられますか？


  4. 全体として、仕事（または、育児、介護、趣味）の充実度は期待を上回っていますか？　もし期待を下回っているなら、 何か具体的な対策は考えていますか？

 

 

10日目のワーク

日付 ___/_____/_____

  1. あなたの人生で、いま何か問題は起こっていますか？


  2. その問題に、どのように対処していますか？　また、 その問題は自分の不調のレベルと結びいていますか？


  3. あなたが過去に犯した失敗の中で、何度も思い起こされる ものはありますか？　もしあるならば、それを詳しく説明してください。


  4. あなたの不調を解決するために、一時的な緩和しかもたらさないような器具や治療（マッサージとか鍼灸とか）を使っていますか？　もし使っているなら、それらをやめることに対してどれぐらい抵抗がありますか？

 

 

11日目のワーク

日付 ___/___/____

  1. 今日起きた出来事の中で、最もストレスやネガティブな感情を感じたものは何ですか？


  2. 今までにかかった病気を振り返ってみて、ストレスや特定の出来事と関係があると思われるものはありますか？　もしあるなら、どのように関係しているかを考えてください。


  3. その過去の病気の時期に戻れるとしたら、どのように対処しますか？


  4. その対処を取っていたら、過去の病気にどのような違う結果が起きたと思いますか？　（心身症に悩む人は、「あの時、心身のつながりについてもっと知っていれば」という罪悪感に苦しむケースが多い。そのため、このような感覚を明確にするのが重要となる）。

 

 

12日目のワーク

日付 ___/____/_____

  1. 最近、 自分と仲が良い人ともめた問題は何ですか？　そのトラブルについて、あなたはどのように感じていますか？


  2. 過去にも、似たようなトラブルが 起きた事はありますか？　もしあるなら詳しく書いてください。


  3. そのトラブルで味わった感情と、身体の不調にはどれぐらい関係があると思いますか？


  4. このワークをしている間に、SNSやテレビの ニュースなどで、健康にまつわるトピックを見かけましたか？　その中で、マインドボディワークの 考え方を支持する、または否定するようなものはありましたか？　もしあったなら、 そのニュースについてあなたが どう感じたかを考えて書き出してください。




13日目のワーク

日付 ___/____/____

  1. 今週、 あなたが怒ったことはなんですか？


  2. 今までの人生で、一番腹が立ったことはなんですか？　詳しいエピソードを書き出してください。


  3.  両親に本気で腹を立てたのはいつですか？


  4. あなたが怒ったとき、相手はどう反応しましたか？


  5. 「怒りの感情を受け入れる」には、 何をすればいいと思いますか？　思いつくアイディアを書き出してください。

 

 

 

14日目のワーク

日付 ___/____/____

  1. 今日／今週、あなたが責任を負う必要のある問題や出来事終わりましたか？　それについて、どのように感じましたか？　


  2. あなたは責任感のある人ですか？　そう思う理由は なんですか？　「 責任感がある」とは、あなたにとってどういう定義になりますか？


  3. 責任を負うことによって、どのようなプレッシャーを感じますか？　責任を負うことの中で、 最もフラストレーションがたまるポイントは何ですか？（この質問には、時間をかけて考えてください）


  4. 責任を負うプレッシャーから、一時的に感情的な休息を取るには何ができますか？　プレッシャーから解放されるための時間を取ることができますか？　具体的な方法を考えて、紙に書き出してください。
