このシリーズでは、私のような陰キャが、いかに人生をうまく生き延びていくかをまとめております。今回からは、陰キャの要因の11番めに挙げた「自閉症スペクトラム」の対策を見てみましょうー。

 

ここで言う「自閉」ってのは、他人とのコミュニケーション全く取れないレベルのものではなく、「高機能自閉スペクトラム症（HFA）」と呼ばれる状態を対象にしております。一般的なコミュニケーションはできるんだけど、感覚がやたらと過敏だったり、注意力をコントロールできなかったり、感情のコントロールが苦手だったりするせいで、学校や職場で問題が起きがちなんですよね。

 

これはなかなか解決が難しい問題なんですが、最近の研究では、脳の「可塑性（変化する力）」を利用して、社会生活での困難をやわらげるアプローチも提案されつつあります。以下では、それぞれの特性に対応したトレーニングを見ていきますんで、この問題にお悩みの方は以下をお試しください。

 

 

 

HFA対策1. アイコンタクトトレーニング

まずは、他人の表情を読み取る力を鍛えるトレーニングです。HFAの人ってのは、他人の「目を見る」のがめっちゃ苦手で、どうしてもギクシャクしちゃうことが多め。そのせいで、うまいことコミュニケーションが進めなかったりするんですよ。

 

この問題に対しては「ソーシャルスキル・トレーニング（SST）」と呼ばれる心理療法が有効でして、SSTの効果を調べたデータ(R)では、こいつによってASDの若者たちのコミュニケーション力が改善したそうな。

 

つまり、HFAの人にとって、アイコンタクトってのは自然な行動ではなく、後天的に覚えるスキルなんですよね。なので、無理に“普通”を目指すのではなく、「どこまでなら自分にとって快適なアイコンタクトを取れるか？」を知るための実験だと思って、以下のステップに取り組んでみてください。

 

 

ステップ0：自分の“快適距離”を確認する

まず最初に、「自分はどれくらいの時間、相手の目を見られるのか？」を知っておくのが大事。無理に長時間アイコンタクトを保とうとするのは逆効果なので、はじめに自分の“限界ライン”を把握しておきましょう。方法は以下のようになります。

 

  1. 鏡に向かって自分の目を見て、「どのくらいの時間、違和感なく見ていられるか」をストップウォッチで計測する。

  2. 1〜3秒も耐えられない場合は、「相手の眉間」「鼻の付け根」などを目の代替ポイントに設定するのもOK。

 

 

ステップ1：ミラー練習（自分の目に慣れる）

続いて、視線に対する「拒否反応」を減らすためのトレーニングを行いましょう。SSTでは以下のような練習で、まずは自分の視線に慣れるところからはじめます。

 

  1. 鏡の前に座り、自分の目を2〜3秒見る（最初は0.5秒でもOK）
  2. 視線を外す → 深呼吸 → 再び目を見る（これを5セット）
  3. 慣れてきたら、目線を動かさず「自分にひとこと話しかける」練習へ（例：「おつかれさま」）

 

練習の目安は「1日3分 × 週5日」で、この段階では「他人の目を見る」のではなく、「視線という刺激に慣れる」ことを目的にしましょう。自分の視線に慣れると、他人との目のやり取りにも抵抗が減りますんで。

 

 

ステップ2：アイコンタクト＋会話のテンプレ練習

ここでは、「目を見る＋話す」の同時処理に慣れるためのトレーニングを行います。やり方は、誰か信頼できる相手に協力をお願いして、会話の冒頭5秒だけ、相手の目を見ることを意識するだけです（それ以降は眉間・鼻を見る）。

 

会話の内容はなんでも良いので、「こんにちは、最近どうですか？」「今日は何か面白いことありましたか？」みたいに適当な雑談をしてください。終わったら、「視線を保てた時間」「どんな気分だったか」をメモして、トレーニングを客観視して終了です。

 

こちらの目安は「1日1〜2回（各3分以内）× 週3〜5日」ぐらい。ポイントとしては、“最初の5秒だけ見る”という制限が重要でして、これによってアイコンタクトが苦手な人でも負担が減り、集中力も持続しやすくなります。会話の内容よりも、「視線と発声をセットにする」練習だと思って取り組んでください。

 

 

ステップ3：動画＋視線模倣トレーニング

今度は、自然なアイコンタクトを“真似”してみるトレーニングです。HFAの人は「会話のタイミングと視線のタイミングのズレ」が出やすいので、他人の動画をまねることで、会話中に「いつ目を見るか」「いつ視線を外すか」というテンポを身体に落とし込む練習になります。スポーツの「型を覚える」みたいなイメージですな。

 

やり方は簡単で、

 

  1. YouTubeなどで、インタビュー動画（1対1で会話しているもの）を視聴する（NHKの「プロフェッショナル 仕事の流儀」みたいな落ち着いた対談が良い）

  2. 動画を再生して、「話している人の目の動き」に注目する。たとえば、「話し始めるときに相手を見て、途中で少し視線を外してるなぁ」みたいな感じ。

  3. 気になったタイミングで一時停止し、 「あ、ここで相手を見たな」「今は下を見てるな」と気づくようにする。この時には、「話すときは目を見るか？外すか？」「聞くときは目を見るか？どこまで見ているか？」をチェックすると観察しやすくなります。

  4. 動画で見た動きを自分で再現します（できれば鏡の前で）。たとえば、〇〇さん、最近のご活動は？」（相手をしっかり見る）→「自分は、最近ちょっと忙しくて……」（少し視線を外す）みたいな感じっすね。この時は、「相手を見るときにちょっと緊張するな」「視線を外したら話しやすくなった」といったように、自分がどう感じたかも確認してください。

  5. 最後に、このトレーニングで気づいたことを書き出しておきましょう。「話すときに目を見るのは最初の2〜3秒がちょうどいい」「ずっと相手を見るより、ときどき外すと気が楽」みたいな感じです。

 

トレーニングの目安は「週2〜3回、1回10分」って感じ。「動画を見て → 真似して → 振り返る」作業を繰り返すので、「視線の筋トレ」だと思ってやって見て下さい。繰り返すことで“自然な目の使い方”が身につきますんで。

 

 

ステップ4：実践とフィードバックのループ

最後に、ここまでのトレーニングを実生活で試してみましょう。やり方は以下のようになります。

 

  1. 日常生活の中で、「相手の目を見る→すぐ外す」を数秒だけ実践する。

  2. 実践後は以下のような項目をチェック。

    1. 　- 視線の時間は何秒？
    2. 　- 見ている間に緊張した？
    3. 　- 相手の反応に変化はあった？

 

出来れば、スマホのメモやノートに「今日の視線チャレンジログ」をつけておくと、習慣化が進んで良い感じです。

 

HFAの人がアイコンタクトを苦手に感じるのは当然なので、最初は無理をせず「今日は1秒長く目を見られた」ぐらいのノリで進めてください。その際は、「どうしても無理な場面では眉間を見る」みたいに、自分なりの“逃げ道”を用意しておくのも大切であります。

 

 

HFA対策2.会話スクリプト＋ロールプレイ 

HFAの特性を持つ人にとって、「即興の会話」はとても大きなストレスになりがち。なにせ目的がないコミュニケーションが苦手なので、「会話がうまく続かない」「何を話していいかわからない」みたいな問題が起きやすいんですよね。

 

そこでおすすめなのが、「会話スクリプト＋ロールプレイ」というトレーニング法で、この方法では、よくある日常の会話をあらかじめ“型”として覚え、それを何度も練習して体にしみ込ませることを目的としております。これをやっておくと、いざというときにスムーズに言葉が出てくるようになり、コミュニケーションの不安が減って良い感じです。

 

「話すのが怖い」「失敗したくない」と感じるのは当たり前なので、だからこそ事前に準備しておくことが安心材料になるんですな。以下のようにトレーニングを進めてください。

 

 

ステップ1：自分がよく出くわす会話シーンをリストアップ

まずは、「自分がよく話すことになりそうな場面」を洗い出しましょう。無理に“社交的なシーン”を選ぶ必要はないので、「挨拶だけ」「一言だけ」でもOKです。

 

  • 例：
    • 仕事の朝礼での「おはようございます」
    • コンビニで「レジ袋いりません」
    • 「最近、寒くなりましたね」みたいな雑談
    • オンライン会議で「聞こえてますか？」

 

 1週間の生活を思い出して、10パターンほど書き出してください。

 

 

ステップ2：会話のスクリプトを「3ステップ構造」で書く

続いて、くわしい会話のスクリプトを用意しておきましょう。会話にはいろんなパターンがありますが、どんな会話も、基本は以下の3つの流れで出来ております。

 

  1. 開始（Opening）：話しかける／返事をする
  2. 展開（Body）：情報を共有／相手に話を振る
  3. 終了（Closing）：締める・終わらせる

 

この流れに従って、ステップ１で想定した会話のスクリプトを書いてみましょう.

 

  • 例：「エレベーターで上司に会ったとき」
    • 開始：「お疲れさまです」
    • 展開：「今日は寒いですね。こういう日って集中しづらいですよね」
    • 終了：「じゃ、また会議で」

 

こんな感じで、いくつかの会話テンプレを用意しておくと、いざというときにも安心っすね。

 

 

ステップ3：ロールプレイをする（できれば他人と）

次は、できるだけ他人と会話の“模擬演習”をしてみましょう。とはいえ、いきなり知らない人と話すのはハードルが高すぎるので、以下の順で進めるのがおすすめです。

 

  • ロールプレイの段階
    • 1人で声に出して読む（録音するとベスト）
    • 親しい人に手伝ってもらって、実際にやってみる
    • うまくいかなかった部分を修正して再チャレンジ
    • そのシチュエーションが実際に来たら、練習どおりに話してみる

 

ってことで、最初は「1人で音読 → 録音して聞き返す」だけでもOK。自分に負担がかからないように、あくまでラクなところからスタートしましょう。

 

 

ステップ4：うまくいった・いかなかったを記録する

ロールプレイ後、または実際の会話が終わったら、「なにがよかったか・改善点は何か」をメモしておくと、どんどん精度が上がって良い感じです。

 

  • 記録テンプレ（例）：
    • 話しかけるのに成功したか？
    • 返事は自然だったか？
    • もっと言えたことがあるか？ → ○○を言ってみたかった
    • どう感じたか？ → 緊張した / 思ったより自然だった

 

 

ステップ5：徐々に「応用スクリプト」へ

慣れてきたら、少し長め・応用的なスクリプトにも挑戦してみましょう。たとえば、以下のような感じです。

 

  • 例：「趣味を聞かれたとき」
    • 開始：「うーん、ちょっとマニアックかもしれませんが…」
    • 展開：「〇〇っていうジャンルが好きで、週末はよく△△してます」
    • 相手にふる：「〇〇さんは、お休みの日は何をしてるんですか？」

 

応用スクリプトを作ると時は、トピックごとに「話すネタ」と「ふるネタ」の2つを用意しておくと便利。これも準備しときましょうー。

 

 

オマケ：AREメソッドで雑談を広げる

会話のスクリプトは基本的に「3ステップ構造」ですが、雑談を長めに展開したい時には「AREメソッド」を意識してみてください。

 

これは「Anchor（アンカー）」→「Reveal（リビール）」→「Encourage（エンカレッジ）」で構成される会話の展開法で、「3ステップ構造」よりも話をふくらませやすい特徴があります。最初は「3ステップ構造」で簡単な会話に慣れさせて、コミュニケーションが苦じゃなくなってきたら「AREメソッド」をお使いください。

 

 

ステップ1：Anchor（アンカー）

まずは、話をする相手との共通点・状況・環境をきっかけに使い、話しかけてみますます。

 

  • 例：
    • 「このイベント、人が多いですね」
    • 「この資料、かなり情報量ありますよね」
    • 「今日はいい天気ですね。暑すぎるくらいです」

 

こんな感じで、いまいる場所や周囲の状況をネタに、相手に話しかけるのがアンカーのコツです。

 

 

ステップ2：Reveal（リビール）

続いて、自分の情報を少し相手に開示して、相手との心理的な距離を縮めていきます。

 

  • 例：
    • 「実はこういう場ってまだ慣れてなくて…」
    • 「自分、こういうテーマにはちょっと興味あって」
    • 「この会場、前にも来たことあるんですよ」

 

こんな感じで、自分のなり開示パターンを考えてみましょう。

 

 

ステップ3：Encourage（エンカレッジ）

最後に相手の話を引き出して、自然な“会話のキャッチボール”に持ち込んでください。

 

  • 例：
    • 「〇〇さんはどう感じましたか？」
    • 「普段からこういうイベント、参加されてるんですか？」
    • 「興味のある分野とかありますか？」

 

こんな感じで、相手への問いかけを準備しておくのがエンカレッジのポイントであります。

 

いまいちわかりにくいかもなので、最後に「AREメソッド」の定番フレーズ集も置いておきます。これを参考にしつつ、「よくある場面 × 自分なりのARE」パターンを5～10個用意しておくと、かなり安心できるんじゃないかと。話すときは完璧を目指さず、「伝わればOK」くらいの感覚で十分なんで。

 

シチュエーションAnchor（共通の話題）Reveal（自己開示）Encourage（問いかけ）
職場の朝「今日は寒いですね」「寒いと布団から出るのが大変でした」「〇〇さんは朝、得意なほうですか？」
昼休み「今日のお弁当、美味しそうですね」「自分はいつもコンビニ頼りです」「自炊とかされるんですか？」
エレベーター「この時間、よく混みますよね」「つい階段を使おうか迷いました」「〇〇さんは何階まで通ってるんですか？」
会議の前「この会議、人数多いですね」「ちょっと緊張してしまいます」「〇〇さん、こういう場って慣れてますか？」
会議の後「今日の発表、すごく分かりやすかったです」「自分だったらあんなに話せないです」「どうやって準備されたんですか？」
雑談：天気「急に雨が降ってきましたね」「傘を忘れてしまって大変でした」「〇〇さんは雨の日、どうしてますか？」
雑談：週末の予定「今週末は天気がいいみたいですね」「久しぶりに外出しようかと」「〇〇さんは週末、どんな風に過ごされますか？」
雑談：趣味「最近ちょっと読書にはまってます」「時間があるとつい本屋に寄ってしまって」「〇〇さんは読書されますか？」
雑談：テレビ・映画「昨日のドラマ、観ましたか？」「あの展開、ちょっと意外でした」「〇〇さんはどんなジャンルが好きですか？」
休憩室で「このコーヒー、意外と美味しいですね」「普段はブラックなんですが、今日は甘いのにしてみました」「〇〇さんはいつもどんな飲み物を飲まれますか？」
通勤・通学の話「今朝、電車が少し遅れてましたね」「自分はいつもギリギリで焦ります」「〇〇さんは何時頃に家を出てるんですか？」
飲み会の席「このお店、雰囲気いいですね」「こういうところ、実は初めてで」「〇〇さんはよく来られるんですか？」
Zoom会議前「音、聞こえてますか？」「最近マイクの調子が悪くて」「〇〇さんは何使ってますか？（ヘッドセットなど）」
褒めるきっかけ「そのネクタイ、素敵ですね」「自分も青系の色が好きで」「どこで買われたんですか？」
ランチ誘い「今日は外で食べようかと」「新しいお店を見つけたんです」「一緒にいかがですか？」

 

 

ということで、今回はHFAのためのトレーニングでした。HFAは決して“治すべき障害”ではなく、「脳の設計思想が違う」というだけの話なので、そこに注意しつつトレーニングに取り組んでいただければと。

 

今回ご紹介したトレーニングは、そうした“違い”を社会の中でうまく活かすためのツールキットのようなもの。自分の特性を否定するのではなく、「こういう仕様の自分だから、こう整えるとやりやすくなる！」と理解するだけでも、日々のストレスはかなり軽減されるんじゃないかと。
