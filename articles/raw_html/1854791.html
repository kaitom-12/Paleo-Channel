「パレオな男」では長らく認知行動療法をおすすめしていて、このブロマガでも簡易バージョンを紹介したことがありました。とにかく認知行動療法は使いやすいツールセットの宝庫なので、覚えておくと何かと便利であります。個人的にも「10代の自意識パンパンだった頃に知っておきたかったなぁ……」と思う知識のひとつっすね。

 

 

で、認知行動療法における数あるツールの中で、「あ、そう言えばまだ紹介してなかった！」と最近気づいたのが「ソーシャルサポート分析」であります(R)。

 

 

これは文字どおり「社会的に見て自分はどんなリソースを持ってるの？」ってポイントを調べる技法で、家族、友人、隣人、同僚など、周囲の環境にある自分なりの「強み」みたいなものを掘り下げていく感じになります。認知行動療法のツールとしては「自動思考キャッチトレーニング」と並ぶ定番のツールで、専門機関のカウンセリングでもまずこれを指示されるケースは多いはず。

 

 

社会的なネットワークが心と体の健康に欠かせないのは有名な話で、たとえば「社会的関係の質は主観的幸福の最大の予測因子だ！」なんてデータ(R)があるぐらい。ソーシャルサポートが大きい人ほど、幸福感を味わう頻度が多く、逆に悲しみの頻度は少なく、人生の満足度が高いんですよね。

 

 

というわけで、「ソーシャルサポート分析」の手法を以下にまとめておきますので、認知行動療法に取り組んでいる方のみならず、メンタルを安定させたい方は試しに実践してみていただければ幸いです。

 

 

 

ソーシャルサポート分析の4ステップ

ステップ1：問題または目標の特定

まずは、自分がいま達成しようとしている目標、または対処しようとしている問題を書き出します。たとえば、

 

  • すぐストレスに負けちゃうのをどうにかしたい
  • 会社で働くのに必要な情報を十分に手に入れてない
  • 年収を1.3倍ぐらいにしたい

 

などなど、いま悩んでいることや達成したいことをシンプルな文章にまとめて書いてみてください。

 

 

ステップ2:ソーシャルサポート分類

次に、自分のソーシャルネットワークには、どんな強みがあるのかを掘り下げていきます。ここではソーシャルサポートを４つのタイプに分類してまして、

 

  1. 感情サポート
  2. 情報サポート
  3. 手段サポート
  4. 所属サポート

 

というそれぞれのカテゴリについて考えてみましょう。具体的な考え方は以下のようになります。

 

1．感情サポート

感情サポートは、自分の周囲にいる人のなかで、共感、関心、愛情、愛、信頼、受容、親密さ、励まし、思いやりなどの感情を提供してくれる人々を意味します。なんとなく「自分には価値があるんだなー」と思わせてくれる人なら誰でもOKですが、なんも思いつかない時は以下の質問について考えてみてください。

 

  •  プライベートな悩みや不安を共有できる人は誰ですか？
  •  誰と一緒にいる時に素を出せますか?
  •  あなたに本気で興味を持っている人は誰ですか?
  •  寂しくなったときに話す人は誰ですか?
  •  あなたに対して心から感謝しているのは誰だと思いますか？
  •  プレッシャーや緊張にさらされているときに、誰を頼ればリラックスできますか?
  •  あなたが必要としているときに慰めてくれるのは誰でしょうか?
  •  あなたの最悪の面も最良の面も含めて完全に受け入れてくれるのは誰ですか?
  •  あなたの感情を無批判でオープンに理解してくれるのは誰ですか？
  •  あなたを心から愛していると思う人は誰ですか？
  •  何が起こっているかに関係なく、あなたのことを気にかけてくれそうな人は?

 

 

2．情報サポート

 情報サポートは、自分の周囲にいる人のなかで、アドバイス、ガイダンス、提案、有用な情報などを提供してくる人を意味します。要するに、問題の解決や目標の達成に役立つデータをくれる人ですね。なんも思いつかない時は以下の質問について考えてみてください。

 

  •  問題を対処するために、誰に相談すればいいでしょうか?
  •  現在の目標を達成するためのアドバイスを頼めそうな人は誰ですか?
  •  あなたがミスをしないために役立つ提案をしてくれるのは誰ですか?
  •  目標を達成するのに役立つ有益な洞察を共有してくれるのは誰でしょうか?（例えば、すでに同じ目標を達成した人とか）

 

 

3．手段サポート

手段サポートは、金銭的な支援、物質的な支援、またはサービスなどを提供してくれる人のことです。自分の問題や目標に対処するために、具体的な援助をしてくれるような人たちですね。なんも思いつかない時は以下の質問について考えてみてください。

 

  •  自分が抱える実際的な問題について誰に助けを求めることができますか?
  •  自分でやるのが困難だったり、負担になったりする現実的な問題を手伝ってくれるのは誰でしょう?

 

 

4．所属サポート

 所属サポートは、あなたに社会的な帰属感を与えてくれる人たちを意味します。仲の良いグループだったり、趣味のコミュニティだったり、そんな風に「自分は社会の一部なんだなー」って感覚を生み出してくれるそうな人のことですな。なんも思いつかない時は以下の質問について考えてみてください。

 

  •  誰と過ごすのが好きでしょうか？
  •  定期的に一緒に外に出て何かをする人々は誰でしょうか?
  •  一緒に遊べる人は誰でしょうか?
  •  情熱や興味を共有している人は誰ですか?
  •  あなたと同じことを楽しんでいる人は誰ですか?

 

 

 

ステップ3:ソーシャルサポートの活用分析

 続いて、ステップ2で確認したソーシャルサポートを「いまの問題や目標にどう使えばいいか？」ってのを考えていきます。具体的には、

 

  1. ステップ1で並べた問題や目標からひとつを選ぶ
  2. その問題や目標には、どのタイプのサポートが必要なのかを判断する（たとえば、「会社で必要な情報が足りない」なら手段サポートが必要だな、とか）
  3. そのサポートをしてくれそうな特定の人物をあげる（「他部署の同僚」とか）
  4. 最後に、その人物がどのように助けてくれそうか？を考える（「彼は長年経理部門で働いてきたので、必要な情報をくれるはず」とか）

 

といった流れになります。いずれのステップも紙に書き出した方が効果は高まりますんで、適当なノートなんかに記入していただくといい感じです。

 

 

 

ステップ4:ソーシャルサポートへの関与

で、最後にステップ3で書き出したリストを見つつ、「この人に助けてもらうにはどうすればいいだろう？」と考えてみれば終了です。目の前にある問題や目標を達成するために、どのような具体的なステップをとることができるか？ってあたりを考えて、具体的なアクションステップに落とし込んでください。なんも思いつかない時は以下の質問について考えてみると、思考が働きやすくなるはず。

 

  • 目の前の問題または目標のなかでも、もっとも取り組む必要がある要素はなんですか？
  • 目の前の問題または目標を解決するために、翌週からソーシャルサポートでリストアップした人に手伝ってもらうために何ができますか?
  • ソーシャルサポートを使うにあたり、どうすれば最初のステップを実践できますか？

 

 

 

まとめ

そんなわけで、ソーシャルサポートを活用するための4ステップでした。おもしろいことに認知行動療法の世界では、ステップ2の「ソーシャルサポート分類」を行うだけでも、ある程度までメンタルが改善することが知られてたりします。それぐらいソーシャルサポートの実感は大事だってことなんで、試しにステップ2だけをやってみるのもアリじゃないかと思うわけです。
