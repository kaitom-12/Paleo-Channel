性格を変えるのは確かに難しいが……

その昔は「人間の性格は生涯を通じて変わらない！」って考え方が普通だったんですが、ここ数年は「やっぱ時間が経つにつれてヒトの性格って変わるんじゃない？」って話もよく見かけたりします。

 

 

多くの場合、性格の変化は人生のライフイベントと一緒に起きることが多くて、

 

  • 学生のころはめちゃくちゃ社交的だった人が、結婚したら急に外交的になった
  • 若いころはトガッてた人が、社会人になったら一気に丸くなった

 

みたいなエピソードはよく聞くところでしょう。もちろん人間の性格がある程度まで遺伝で決まってるのは事実なんだけど、そこには結構な「遊び」があるんじゃないか？って考え方が主流になりつつある感じですかねー。

 

 

ってことで、近ごろアリゾナ大学が主導で「性格は2週間で改善できる！」ってデータ(R)を発表していて、これがタメになる内容でありました。

 

 

 

誠実性と開放性は伸ばせるのか？

性格改善の研究というと、以前に「セラピーを使うと4週間でネガティブさが減る」みたいな報告があったように神経症傾向に関するものがメインだったんですけど、この研究では、

 

  • 誠実性
  • 開放性

 

という2つのパーソナリティをどこまで伸ばせるか？が主題になってます。このブロマガをお読みの方なら、どちらも人生の成功に欠かせない2大要素なのはご存じでしょう。

 

 

ってことで、研究では255人の人を対象に、こんな介入をしてます。

 

  1. グループの半分に「誠実性と開放性のどっちを改善したいですか？」と尋ねる
  2. 選んだ性格を伸ばすために必要なアクションを決めさせる
  3. 2週間、定期的に研究者から「性格改善」に特化したリマインダーを送る
  4. 第三者（参加者の友人とか親類）チェックとビッグファイブテストで、参加者の性格が変わったかをチェックする

 

ちなみに、今回の研究では「誠実性」または「開放性」を根っこから変えようとしたわけじゃなくて、それぞれのパーソナリティが持つ複数の側面のひとつだけを改善する方向でデザインされてます。どういうことかというと、ひとくちに「誠実性」や「開放性」と言っても、

 

  • 誠実性＝慎重さ、効率的、自己を律する能力、達成を目指す意思
  • 開放性＝型にはまらない、新しさや複雑さへの欲求、新たな体験にオープンである、美しいものをこのむ

 

といった複数の要素で構成されてるわけです。これらすべてにまとめてアプローチするのは得策じゃないので、まずは特定の要素を抜き出して個別に片付けていこうってことですね。

 

 

なので、研究チームがフォーカスしたのは大きく2つで、

 

  • 自己規律は改善できるか？
  • 新たな体験へのオープンさは改善できるか？

 

のみに焦点をしぼっております。確かに、ターゲットをはっきり定めたほうが成果は出やすいでしょうからね。

 

 

 

アリゾナ大学式2週間の性格改善法

続いて、この研究で採用された「性格改善テクニック」がどんな内容だったかをまとめると、以下のような感じです。

 

  1. 改善したい性格に沿った「具体的な行動」をひとつ決める。例えば、「自己規律」を伸ばしたいなら「もっとジムに行く」、「体験へのオープンさ」を伸ばしたいなら「新たな料理にトライする」など）
  2. その行動を「イフゼン・プランニング」に落とし込む。「夕食が終わったらジムに行く」や「仕事から帰ったら新たなレシピを試す」など
  3. その「イフゼン・プランニング」のメリットとデメリットを思いつくだけ書き出す（例「メリット＝ジムに行くと健康になり見た目も良くなる」「デメリット＝ジムに行くと趣味に使う時間が減る。月会費も痛い」）
  4. 朝9時と夜8時に、「イフゼン・プランニング」の実行をうながすリマインダーを送る（MobileCoachっていうリマインダーアプリを使用）

 

この作業を2週間続けたわけっすね。1日に2回送られるリマインダーの内容はいくつかに分かれていて、それぞれ次みたいな意図を持たせたとのこと。

 

  • シンプルなリマインド：「こんにちは、◯◯さん。自分がもっと自己規律（または体験にオープン）のある人間になるための目標を覚えていますか?　あなたが設定した今日の「イフゼン・プランニング」は「◯◯◯◯◯◯」っです。リマインダーとして送ります」

 

  • 達成度のフィードバック＝ 「◯◯さん！ あなたはすでに「イフゼン・プランニング」を◯◯回も達成しました！」

 

  • メリットの意識づけ＝ 「◯◯さん、おはようございます。自分が望む行動を実行した場合、短期的および長期的にどのようなメリットがあるかを具体的に想像してみてください」

 

  • エビデンスにもとづいたメリットの強調＝ 「◯◯さん、こんにちは。ご存じでしょうが、自己規律の能力は学校や会社でのパフォーマンス向上に大きく関係しています。その効果量はIQよりも強いぐらいです！」「◯◯さん、おはようございます。行動に対するオープンさが、私たちの幸福度に大きな影響を与えることを知っていますか?　過去の調査によると、新たな行動を起こしやすい人ほど、平均して幸福度が高い傾向がありました！」

 

  •  自己決定した短期的なメリットの強調：「自分で決めた『イフゼン・プランニング』から、どのようなメリットを得たいのかちゃんと覚えていますか? 　リマインダーとして再び確認してみましょう（自分の決めた「イフゼン・プランニング」を達成した場合のメリットを確認）」

 

  • 障害への意識づけ：「◯◯さん。自分のコントロールや、新しい行動を起こすことは、時には難しいこともあります。あなたが望む行動を妨げる要因は何でしょうか? また、それらをどのように克服することができるでしょうか?」

 

  • シンプルな励まし：「◯◯さん、おはようございます。あなたは今日のイフゼン・プランニングを『◯◯』のように設定しました。私たちはあなたの目標を達成を願い、大きな進歩を期待しています」

 

ってことで、このリマインダーこそが本研究のキモでしょうね。「ヤバい集中力」でも取り上げた目標達成の技法が詰め込まれていて、いかにも効果がありそうですもんね。

 

 

さて、それでは2週間後の経過がどんなもんだったかといいますと、

 

  • 自己規律をトレーニングしたグループは……
    • 自己規律が向上した (b = 0.37,95% CI [0.21, 0.52], SE = 0.08, p < .001) 
    • 誠実性もちょっとだけ上がった (b = 0.19, 95% CI [0.06,0.31], SE = 0.06, p = 0.005) 

 

  • 新たな体験へのオープンさをトレーニングしたグループは…
    • 体験へのオープンさが向上した(b = 0.35, 95% CI [0.16, 0.53], SE = 0.09, p = 0.002)
    • 開放性には変化がなかった(b = -0.04, 95% CI [-0.20, 0.12], SE = 0.08, p = 0.61)
    • 外向性が上がった (b = 0.20, 95% CI [0.02, 0.40], SE = 0.09, p =0.04) 

 

だったそうです。b = 0.37とか0.35って数値をどう見るかは難しいんだけど、ざっくり言えば「劇的なレベルじゃないものの期待が持てるぐらい」の変化だとお考えください。主観では「ちょっと新たな習慣に抵抗がなくなったかなぁ……」の変わり方で、周囲からもなんとなく変わったかなーぐらいの印象だと思います。

 

 

もちろん、これは短期研究なので長期的にも変化が定着するかはわからんのですが、いちおう6週間のフォローアップでは、トレーニングをしたグループの性格はそのまま残り続けたそうなんで、セルフコントロール能力が足りなくて悩んでいるような方は試してもいいんじゃないかと。

 

 

ってことで、この研究でわかった性格改善の方法をまとめると、

 

  1. まずは自分が変えたい特性を具体的に絞り込む（ビッグファイブの構成要素につついてはコチラを参考にどうぞ）
  2. その特性を持った人がやりそうな行動をひとつだけ選ぶ（「知らない人に話しかける」とか「もっと深呼吸する」とか）
  3. その行動でイフゼン・プランニングを作る（「朝最初にすれ違った人に話しかける」とか「イラッとしたら深呼吸する」とか）
  4. その行動を実践すると「どんな良いことがあるのか？」「どんな悪いことがあるのか？」をリストアップする
  5. 上のリマインドを参考に、1日2回ずつランダムで自分にリマインダーを送る

 

みたいになりましょう。最後のリマインダーをどうするかが難点ですが、twittbotにランダムでつぶやかせればいいかなーと思ったのと、ランダム通知系のアプリもいくつかあるようなんで、こちらを使うのもアリでしょうか。

 

 

いずれにせよ、このテクニックは使えそうなんで、自分でもやってみるつもりです。いかにうまくリマンダーを設定するかが鍵になりそう……。
