「CERG（サーグ）式トレーニング」の続きです！(#1,#2,#3)

 

 

これは、CERG（サーグ）という研究チームが提唱する運動ルーチンで、「コンディションが整った肉体を作る！」って目的のためにデザインされたもの。バキバキの肉体を作る目的ではなく、体だけでなく脳がうまく働き、メンタルがつねに安定し、すぐに疲れたりしないような体調を手に入れるのが、このメニューのゴールになります。

 

 

で、このメニューの基本プログラムは前回終わったんですが、今回からは、その続きで「第8週〜10週」のメニューを見てみましょう。ここでは、1〜7週までのトレーニングでは飽き足らない人や、さらなる上のコンディションを目指したい人などは、ぜひここからのトレーニングも続けてみてください。

 

 

 

 

第11週

では、CERG式トレーニングの11週目です。ここでも相変わらず「トレーニングチューブ」を使いますんで、持っていない方は用意しておきましょう（ダンベルでも可）。

 

 

月曜日 CERG式ヘルスブースター#3

  1. まずは、最大心拍数の60％ぐらいで走って10分間のウォームアップをしましょう。できれば傾斜のある場所や坂道で行うほうが、心拍数が早く上がるため、膝へのダメージが少なくなります。

  2. 1分間の全力ランニング。終わった後にヘトヘトになる負荷を保つ。

  3. 1分間のアクティブレスト。

  4. ステップ2と3を全部で10回くり返す。

  5. 5分間のクールダウン。

 

 

水曜日 フレンズ・チャレンジ

好きな友達を誘って、いつもは使わないような大きな筋肉を使い、ダイナミックな動きをするアクティビティ（ウォーキング、ジョギング、水泳、クロスカントリースキー、スカッシュ、フットサルなど）を選び、会話が可能な強度で60分以上行う。

 

 

金曜日 ファンラン＋体幹トレーニング

  • 有酸素運動フェーズ
    1. 10分間のウォームアップで汗をかく。

    2. ウォームアップより少し強めの強度で、30分間のランニング、または好きなアクティビティを、ノンストップで30分間続けられるぐらいの強度で行う。

 

  • 体幹トレーニングフェーズ：以下のメニューを2周する。シリーズ間の休憩は2分、各エクササイズの間の休憩は30秒。
    1. 腹筋を10回くり返す。

    2. バードドッグ：リンク先動画の動きを左右10回ずつ行う。

    3. チューブローイング：リンク先動画の動きを15回行う。

    4. チューブデッドリフト：リンク先動画のように、チューブを使ってデッドリフトを12回行う。

    5. チューブサイドレイズ：リンク先動画の動きを12回行う。

    6. アップライトロウ：リンク先動画の動きを12回行う。

    7. チューブショルダープレス：リンク先動画の動きを12回行う。

    8. チューブフロントレイズ：リンク先動画の動きを12回行う。

 

 

 

 

第12週

月曜日 CERG式ヘルスブースター#1

月曜日は、「4x4（フォー・バイ・フォー）」をさらに発展させたバージョンのインターバルトレーニングを行います。さらにレベルは上がりますが、まちがいなく効果的ですんで。

 

  • 有酸素運動フェーズ
  1. まずは、最大心拍数の60％ぐらいで走って10分間のウォームアップをしましょう。できれば傾斜のある場所や坂道で行うほうが、心拍数が早く上がるため、膝へのダメージが少なくなります。

  2. 最大心拍数の85～95％程度を目安に4分間のランニングを行う。もし4分間ずっと同じ負荷を保てない場合は、さすがにやりすぎになるので、次回はもう少しゆっくり行うようにしましょう。

  3. 3分間のアクティブレストで乳酸を取り除く。ウォーキングや軽いジョギングでOK。

  4. 1分間の全力ランニング。終わった後にヘトヘトになる負荷を保つ。

  5. 1分間のアクティブレスト。

  6. 1分間の全力ランニング。

  7. 1分間のアクティブレスト。

  8. 1分間の全力ランニング。

  9. 3分間のアクティブレスト。

  10. 最大心拍数の85～95％程度を目安に4分間のランニングを行う。

  11. 3分間のアクティブレストで乳酸を取り除く。ウォーキングや軽いジョギングでOK。

  12. 1分間の全力ランニング。

  13. 1分間のアクティブレスト。

  14. 1分間の全力ランニング。

  15. 5分間のクールダウンで、次の体感トレーニングフェーズに備える。

 

 

  • 体幹トレーニングフェーズ：以下のメニューを2周する。シリーズ間の休憩は2分、各エクササイズの間の休憩は30秒。

    • アブドミナル・プランク：
      • ヒジを立てて行うプランクを1分行ってから、20秒の休憩を入れる。
      • 腕を伸ばしたプランクを1分行ってから、20秒の休憩を入れる。
      • 右手と左足を伸ばすプランクを1分行ってから、20秒の休憩を入れる。
      • 左手と右足を伸ばすプランクを1分行ってから、20秒の休憩を入れる。

   

    • ヘビーサイドプランク：リンク先動画のプランクを、左右20秒ずつ、30秒の休憩をはさみながら、できる限り多く行う。

    • バックプランク：尻を上げた状態を30～45秒キープ。15秒の休憩をはさみながら、2～3回くり返す。

    • カーフ・レイズ：かかとをできるだけ下げ、つま先で立ち上がる運動を10回繰り返す。

    • チューブデッドリフト：リンク先動画のように、チューブを使ってデッドリフトを12回行う。

    • トランクローテーション：リンク先動画の動きを左右10回ずつ行う。

    • 斜め腹筋：リンク先動画の動きを左右10回ずつ行う。

好きな友達を誘って、いつもは使わないような大きな筋肉を使い、ダイナミックな動きをするアクティビティ（ウォーキング、ジョギング、水泳、クロスカントリースキー、スカッシュ、フットサルなど）を選び、会話が可能な強度で60分以上行う。

第13週

13週目は、インターバルトレーニングと体幹トレーニングのレベルをさらに上げてみましょう。

 

 

月曜日 4x4（フォー・バイ・フォー）

  1. 月曜日は、まいどおなじみ「4x4」を行います。まずは、最大心拍数の60％ぐらいで走って10分間のウォームアップをしましょう。できれば傾斜のある場所や坂道で行うほうが、心拍数が早く上がるため、膝へのダメージが少なくなります。


  2. その後は、以下のルーチンを最大心拍数の85～95％で行いましょう。

    1. 4分間、息が切れるほど走る。
    2. リラックスウォーキング3分。
    3. 4分間、息が切れるほど走る。
    4. リラックスウォーキング3分。
    5. 4分間、息が切れるほど走る。
    6. リラックスウォーキング3分。
    7. 4分間、息が切れるほど走る。
    8. 5分間のクールダウン。

 

 

  • 体幹トレーニングフェーズ：以下のメニューを2周する。シリーズ間の休憩は2分、各エクササイズの間の休憩は30秒。

    • カーフ・レイズ：かかとをできるだけ下げ、つま先で立ち上がる運動を10回繰り返す。
    • チューブデッドリフト：リンク先動画のように、チューブを使ってデッドリフトを12回行う。

    • チューブローイング：リンク先動画の動きを15回行う。

    • チューブデッドリフト：リンク先動画のように、チューブを使ってデッドリフトを12回行う。

    • チューブサイドレイズ：リンク先動画の動きを12回行う。

    • アップライトロウ：リンク先動画の動きを12回行う。

    • チューブショルダープレス：リンク先動画の動きを12回行う。

    • チューブフロントレイズ：リンク先動画の動きを12回行う。

    • スプリット・スクワット：リンク先動画の動きを、片足10回ずつ行う。

    • バックエクステンション：リンク先動画の動きを12回行う。

    • ディップス：リンク先動画の動きを12回×2セット行う。

    • チューブバイセップカール：リンク先動画の動きを12回×2セット行う。

    • トランクローテーション：リンク先動画の動きを左右10回ずつ行う。

    • 斜め腹筋：リンク先動画の動きを左右10回ずつ行う。

    • チューブローイング：リンク先動画の動きを15回行う。

    • チューブプレス：リンク先動画の動きを12回行う。

第14週

ってことで、ついにラストの14週目です。ここまでくれば、大半の人はコンディションがかなり良いところまで来ているはず。ここから後の週は、自分の体力に応じて負荷をあげていってくださいませ。

 

 

月曜日 CERG式ヘルスブースター#2

 

  • 有酸素運動フェーズ
  1. まずは、最大心拍数の60％ぐらいで走って10分間のウォームアップをしましょう。できれば傾斜のある場所や坂道で行うほうが、心拍数が早く上がるため、膝へのダメージが少なくなります。

  2. 17:13インターバルを5分間行う。これは、「17秒の全力ランニング → 13秒のアクティブレスト」を10回繰り返すというもの。このインターバルを6回ほど繰り返すと、心拍数は最大値の85～95％に近くなるはず。

  3. 3分間のアクティブレストで乳酸を排出する。

  4. 17:13インターバルを5分間行う。

  5. 5分間のクールダウンで、次の体幹トレーニングに備える。

 

 

  • 体幹トレーニングフェーズ：以下のメニューを2周する。シリーズ間の休憩は2分、各エクササイズの間の休憩は30秒。

    • アブドミナル・プランク：
      • ヒジを立てて行うプランクを1分行ってから、20秒の休憩を入れる。
      • 腕を伸ばしたプランクを1分行ってから、20秒の休憩を入れる。
      • 右手と左足を伸ばすプランクを1分行ってから、20秒の休憩を入れる。
      • 左手と右足を伸ばすプランクを1分行ってから、20秒の休憩を入れる。

   

  • ヘビーサイドプランク：リンク先動画のプランクを、左右20秒ずつ、30秒の休憩をはさみながら、できる限り多く行う。

  • バックプランク：尻を上げた状態を30～45秒キープ。15秒の休憩をはさみながら、2～3回くり返す。

  • 腕立て伏せを、できる限り多くの回数を行う。1分間の休憩の後、もう1セット、できる限り多く腕立て伏せを行う。
  • チューブデッドリフト：リンク先動画のように、チューブを使ってデッドリフトを12回行う。

  • トランクローテーション：リンク先動画の動きを左右10回ずつ行う。

  • バードドッグ：リンク先動画の動きを左右10回ずつ行う。
