ステップ5. 外向的なスキルを「演じる」技術を磨く

過去のパーソナリティ研究によると、外向的なスキルは生来の特性ではなく「演じる」ことが可能だったりします(R)。外向的なスキルを「演じる」ことは、内向的な特性を活かしつつ、必要な場面で外向的に振る舞うための強力なツールでして、内向人間の幸福度を高める効果があったりするんですよ(R)。

 

その方法としては、ペルソナの設定、テンプレート化、時間管理などのテクニックが提唱されてまして、これらを意識しつつ、徐々にその行動を自分の一部として取り込んでいくのが基本になります。私も大勢の人と会わねばならない時は、意識してこの“外向スイッチ”をオンにしてますね。

 

では、具体的に内向的な人が外向的な場面で必要なスキルを「演じる」ための方法論を見てみましょう。

 

 

1. 「ペルソナ」を設定する

「ペルソナ」ってのは、特定の場面で演じる自分のキャラクター像を意味します。これは「自分ではない誰かになる」って話ではなくて、「自分の中にある状況に適した側面を強調した自分」を作り上げることを意味します。といってもわかりづらいでしょうから、まずは以下のような感じでペルソナを設定してみましょう。

 

  1. キャラクターを定義する：自分がなりたいイメージを具体化します。たとえば、「明るい営業パーソン」「説得力のあるプレゼンター」などです。いくつか思いついたら、そのキャラクターの特性を書き出してみましょう（例：明るい笑顔、大きな声で話す、アイコンタクトを保つ）。

  2. 成功事例を参考にする：成功している外向的な同僚や有名人を観察し、「この振る舞いを取り入れたい」と思う部分を取り入れましょう。たとえば、スティーブ・ジョブズのプレゼンスタイルや、営業の得意な同僚の会話術とか。

 

 

例：営業職のキャラ設定

Aさんは内向的な性格だが、新しく始めた営業職では顧客との直接的な対話が必要。そこで、自分の「営業パーソンとしてのキャラクター」を定義し、成功事例を参考に行動を改善することにした。

 

  • キャラクターの定義
    • Aさんは、自分を「お客様の悩みに共感し、解決策を提案するプロフェッショナル」というキャラクターに設定。具体的な特性として以下をリストアップした。
      • 温かみのある笑顔で接する。
      • 顧客の話をよく聞き、悩みを引き出す。
      • 声のトーンをやや明るめにし、説得力を持たせる。

 

  • 成功事例を参考にする
    • Aさんは、営業のベテランである同僚Bさんを観察し、以下の行動を真似ることにした。
      • 顧客との会話の冒頭に、必ず簡単な雑談を取り入れる（例：「週末はいかがお過ごしでしたか？」）。
      • 相手の話を聞く際に、頻繁に相づちを打ち、ペンを使ってメモを取ることで関心を示す。
      • 提案時には視覚資料を使い、複雑な内容を簡潔に伝える。

 

 

2. 振る舞いの「テンプレート」を作る

ペルソナを作ったら、自分が取りたい行動をテンプレにしておきましょう。なんせ内向的な人は社交的なアクションに慣れていないので、良いパフォーマンスを発揮するには、反射的に使える動作やフレーズをテンプレート化しておかないと、とっさに上手く振る舞えなかったりするもんで。

 

その際には、自分が作ったペルソナにふさわしい振る舞いのテンプレートを用意し、場面ごとに活用する方向で考えてみましょう。以下では、「プロフェッショナルで明るい営業パーソン」ってペルソナをベースにしたテンプレート作りと実践方法を解説してみます。

 

 

1. ペルソナの特徴をリストアップする

まず、ペルソナがどのような印象を与えるべきかを明確にします。具体的な特徴を以下のようにリストアップしましょう。

 

  • ペルソナの例
    • 表情：常に親しみやすい笑顔を意識する。
    • 声のトーン：明るく元気だが押し付けがましくない適度な声量。
    • 話し方：簡潔で分かりやすく、少しユーモアを交える。
    • 姿勢：背筋を伸ばし、動作をきびきびと行う。
    • 目標：相手に安心感と信頼感を与える。

 

 

2. シチュエーションごとにテンプレートを作る

次に、自分がよく遭遇する場面を想定し、それぞれに合った具体的な振る舞いをテンプレート化します。

 

シチュエーション1：初対面の自己紹介

  • 握手：相手の目を見て笑顔で握手し、「お会いできて光栄です」と一言添える。
  • フレーズ：
    • 「初めまして、〇〇（自分の名前）です。〇〇（役職）を担当しています。」
    • 「今日は〇〇についてお話しできるのを楽しみにしています。」
  • 身体の動き：軽く前かがみになって相手に関心を示す姿勢を取る。

 

 

シチュエーション2：会議やプレゼンテーション

  • 始めの挨拶：
    • 「皆さんこんにちは。まずはお集まりいただきありがとうございます。」
    • 「今日は〇〇についてお話ししますので、どうぞリラックスしてお聞きください。」
  • 話し方のテンプレート：
    • 短いフレーズで区切る：「まず、〇〇をお伝えします。その後、具体例をご紹介します。」
    • 要所で相手の反応を確認：「この点について何かご質問はありますか？」
    • ボディランゲージ：ジェスチャーでポイントを強調する（例：手を広げる、頷く）。

 

 

シチュエーション3：ネットワーキングイベント

  • アイスブレイク：
    • 「こちらにいらっしゃるのは初めてですか？」
    • 「〇〇さんのところでお名前をお聞きしました。お会いできて嬉しいです。」
  • 話題の切り出し方：
    • 「最近、この業界で注目していることは何ですか？」
    • 「今回のイベントで一番興味を引かれたセッションはどれでしたか？」
  • 会話を終えるフレーズ：
    • 「お話できて光栄でした。ぜひまたお話ししましょう。」
    • 「名刺を交換してもよろしいですか？」練習法

 

 

3. 時間制限を設ける

外向を演じるのは有効な手法ではあるものの、内向人間が外向的な行動を取るとエネルギーを一気に消耗してしまうのが難点。そこで、意識的に「時間制限」を設定することで負担を軽減しておきましょう。

 

時間管理の具体的な方法は、こんな感じです。

 

  • 事前に時間を決める：
    • 「このミーティングでは30分間だけ積極的に発言する」といった具体的な目標を設定。
    • ネットワーキングイベントで「3人と話したら次の休憩に入る」と自分にルールを課す。

 

  • バッファタイムをスケジュールに組み込む：
    • 外向的な行動を取った後にリカバリータイムを確保する。たとえば、会議後に10分間の休憩を設ける。
    • リフレッシュ方法：散歩、瞑想、静かな音楽を聴くなど。

 

  • イベント後のセルフケア：
    • イベント後に、自分をリフレッシュするアクティビティを用意しておく。例：お気に入りの本を読む、短い昼寝を取る、リラックスできる香りを使う。

 

 

4. 「演じる」をゲームにする

内向人間は「演じる」って行為をストレスに感じがちなので、強引にでも楽しむ意識を持つのが大事。そのためには、「ゲーム感覚を取り入れる」のが割と効果的なので、以下のようなポイントもぜひ押さえておきましょう。

 

  • 小さい目標設定：「今日はどれだけ笑顔を引き出せるかチャレンジしてみよう」など、目標を軽く設定して取り組む。

  • 自分を褒める：外向的に振る舞えた際には、達成感を感じ、自己評価を高めるように自分を褒めておきましょう。例：「今日は3人と話せた！成長しているな。」
  • 「プロフェッショナルモード」をスイッチオン：仕事や特定のイベントでは、「ここから普段の自分とは異なるプロフェッショナルなモードに切り替えるのだ！」と言い聞かせるだけでも効果があったりする。「今からプロとして振る舞う時間だ」見たいに、言い聞かせるフレーズを用意しとくといいでしょう。

 

ってことで、ステップ５は以上です。まー、内向人間が外向を演じるのは大変なんだけど、演じる行為を何度も繰り返すことで、それが「新しい自分の一部」として馴染んでくるはずですんで。別に内向的な性格がガラリと変わるわけじゃないものの、最初は意識的だった行動も、成功体験を積み重ねるたびに徐々に自然なものになっていくはずであります。お試しをー。

 

 

 

 

ステップ6. 外向的な環境で成功した内向的リーダーを模範にする

最後のステップは、内向的な特性を持つリーダーが外向的な環境で成功した例を学び、自分の行動や考え方に取り入れるというものです。これによって、内向人間は自身のモチベーションを高め、成功への具体的な道筋を描けるようになりますんで(R)。このステップを実践する具体的な方法は、以下のようになります。

 

 

1. 成功した内向的リーダーをリサーチする

まずは内向的なリーダーの特性や行動を深く掘り下げて、自分に取り入れるべきヒントを見つけてみましょう。具体的には、内向的なリーダーとして有名な人の自伝や伝記を読んでみてくださいませ。

 

  • ラリー・ペイジ： Googleの創業者として、静かな思考力と計画性で成功を収めた。「 How Google Works（エリック・シュミット共著）」がおすすめ。
  • マリッサ・メイヤー: ヤフーCEO時代に、内向人間ならではの冷静な判断力でチームを率いたことで有名。特に、彼女の会議の進行方法やデータ重視の決断スタイルが参考になる。「ＦＡＩＬＩＮＧ　ＦＡＳＴ　マリッサ・メイヤーとヤフーの闘争」がいいかも。
  • ビル・ゲイツ：世界的に有名な内向型リーダーの一人。内向的な性格を活かして、ソフトウェアの開発とビジネス戦略を追求した。「ビル・ゲイツ I」「ビル・ゲイツ II」などがおすすめ。

 

内向的なリーダーを研究したら、みんなが共通して持っている特性やスキルを抽出し、自分に取り入れられる部分をピックアップしてみましょう。

 

  • 例：
  • 深い思考力と集中力：みんな長期的ビジョンや複雑な問題の解決策を考える時間を確保し、それを活かして大きな成果を上げているなぁ……。
  • 一貫した価値観：自分の特性を無理に変えず、内向的な強みを社会的に役立つ形に変換しているなぁ……。
  • 効果的なチーム運営：チームメンバーの個性を理解し、それに基づいてリーダーシップを発揮しているなぁ……。

 

 

2. 自分に合ったリーダーシップスタイルを定義する

続いて、リサーチをもとに、内向的な特性を活かした自分だけのリーダーシップスタイルを明確にしてみましょう。具体的にはこんな感じです。

 

  1. 自分の内向的な特性を書き出す（例: 誠実さ、観察力、分析力）。
  2. それらをどのようにチームやプロジェクトに活用できるか考える。例: 「観察力を活かして、チームの動向を把握し、適切なタイミングでサポートする。」
  3. 内向的リーダーの行動を模範にしつつ、自分の価値観や個性を加味する。例: 「ラリー・ペイジのデータ重視の方法に、自分の直感的な判断を組み合わせる。」
  4. 最後に、具体的な目標を設定する。　例：「次の会議でチーム全体の意見を引き出し、まとめ役を務める」など、小さなリーダーシップ行動を目標にする。

 

 

3. 模範となる行動を観察し、試してみる

ここまでの作業が終わったら、成功したリーダーの具体的な行動を日常に取り入れてみます。

 

  • 例：ラリー・ペイジの「深い思考力」を取り入れる:
    • ミーティング前にデータや議題を徹底的にリサーチし、準備する。
    • 重要な決断を下す際は、複数の選択肢を分析し、最適解を選ぶ。
    • 自分のアイデアやプロジェクトが10倍良くなるにはどうすればいいかを考える。具体的には、現在の業務や計画をさらに改善する方法を探る。

 

  • 例：ビル・ゲイツの「静かな説得力」を真似る:
    • 会議では、大勢の前で話すよりも、個別のフォローアップで影響力を発揮する。たとえば、 「プレゼン後に個別に話しかけて、相手の意見を引き出しつつ、自分の提案を補足する。」
    • 内向的である自分を無理に変えようとせず、その特性を周囲に説明し、協力を得る。職場で「集中のためにこの時間は一人で考えたい」などを伝える練習をする。
    • ブログやSNSで自分の意見や観察を発信することで、存在感を高める。

 

  • 例：マリッサ・メイヤーの「冷静な判断力」を模倣する:
    • データを収集し、ロジカルに物事を整理して説明する習慣を持つ。たとえば、 「チーム内でトラブルが発生した際、感情的にならず、事実と解決策にフォーカスする。」
    • 緊張感のある状況でも冷静さを保つ訓練をする。たとえば、週に一度、緊張する場面をシミュレーションして練習する。

 

 

ってことで、「内向的なリーダーを模範にする」ステップは以上です。このような“ロールモデル戦略”ってのは心理学の世界では割とメジャーな手法でして、「内向人間でもちゃんと成功できている！」って事実を学んでみるだけでも、あなた自身の特性を活かしながら成功の道を歩むことができるようになったりします。重要なのは、内向的なリーダーたちが、どのように自分のパーソナリティを曲げずに課題に適応し、成果を出したのかを学び、それを日々の行動に取り入れることっすね。ここで挙げた以外にも、ザッカーバーグとか、ガンジー、リンカーン、バフェット、アインシュタインみたいに、内向で成功した人は山ほどいますんで、自分と気が合いそうな人を選んで各自の人生を掘り下げてみてはいかがかと思うわけです。。
