「美容の世界は、なぜここまで嘘が多いのか？」の続きです！(#1,#2,#3,#4,#5,#6,#7)

 

このシリーズでは、とかく「正しいもの」を選ぶのが難しい美容の世界において、

 

  • なぜ美容の世界にはヤバい情報があふれてしまうのか
  • その情報をかいくぐって良いものに到達するにはどうすればいいのか

 

といったあたりを掘り下げております。でもって、前回は「現代人の美容にありがちな３つの問題」を掘り下げましたんで、今回は「アンチエイジング成分の“当たり”と“ハズレ”」を見ていきましょう。

 

 

美容の世界では、毎年のように新しい名前の成分が登場しまして、そのたびに「今度こそ効果バツグンなのでは……」とかつい思わされてしまうわけです。

 

が、そんなにきくものがポンポン出てくるなら苦労はないわけで、実際のところ“効く成分”ってのはほんの一握りしかなかったりします。そこで今回は、世に出回る数百の美容成分をふるいにかけたうえで、

 

  • アンチエイジングに効く“本物の成分”
  • 実は“気休め”な成分の見分け方
  • 「これだけはやっとけ」3選

 

をチェックしていきましょう。美容アイテム選びで困ったら、とりあえずここからどうぞ。

 

 

ポイント1. レチノイドこそ最強の成分である

現状、アンチエイジング系の成分において、科学的にもっとも強力なのはレチノイド（ビタミンA誘導体）であります。もはやこのブロマガではおなじみですが、ここではまた伝えてなかったところを中心に、あらためてそのメリットのほどを見ていきましょう。

 

まず前提として、「レチノイド」ってのは、ビタミンAおよびその誘導体の総称のことで、分類としては以下のようになっております。

 

分類例主な用途備考
第1世代レチノール、レチナール化粧品（OTC）効果は穏やかだが、肌への刺激も軽い
第2世代トレチノイン（レチノイン酸）医療用（処方薬）効果が強く、FDAも“しわ改善”で認可
第3世代アダパレン、タザロテン医療用（主にニキビ治療）安定性が高く、皮膚刺激がやや少なめ

 

でもって、なぜレチノイドが「最強」と呼ばれるのかと言いますと、アンチエイジングをうたう成分の中で、もっとも一貫した臨床効果を示してきたからです。その効果を簡単にまとめておくと、

 

  • 色素沈着の改善
    • 肌のターンオーバーを促すことで、シミや色むらが薄くなる

 

  • 肌の水分保持能の向上
    • 表皮の厚みが増し、乾燥に強い肌になる

 

  • 表皮のターンオーバー促進
    • 古い角質を排出 → 肌のトーンが明るく見える
    • 毛穴づまりやニキビの予防にも有効

 

  • 真皮のコラーゲン増加
    • トレチノインは線維芽細胞を刺激し、コラーゲン合成を促進
    • これにより、しわ・たるみの改善が起こる

 

これらの効果は、1980年代から今日に至るまで、無数の臨床試験で再現されてまして(R)、もはや疑っても意味がないレベルだったりします。これらの報告を受けて、米国FDA（食品医薬品局）も「トレチノインはしわ改善に有効な唯一の外用薬」と言い切ってまして、市販の化粧品成分で、ここまでの効能が医学的に保証されているものは非常に珍しいっすね。アンチエイジング成分の中では圧倒的なエビデンスレベル（Level A）を持ってるんで、まずは信頼していただければと。

 

が、一方で、レチノイドは副作用が大きいのが難点でして、ここが多くの人がつまずくポイントになっております。代表的な副作用としては、

 

  • 皮むけ
  • 赤み・乾燥・ヒリつき
  • 一時的なニキビの悪化
  • 光感受性の増加（＝日焼けしやすくなる）

 

などがありまして、私も使用当初は皮むけに悩まされたもんです。この点で、とくにレチノイン酸（トレチノイン）は強力なので、医師の指導のもとで慎重に使用することが前提になったりしますね。

 

とはいえ、強力じゃないから意味がないってわけでもありませんで、たとえば以下の成分は、効き目とマイルドさのバランスが割と良いのでお勧め。

 

成分名特徴
レチノール（Retinol）効果は穏やかだが、長期使用で実感しやすい。安定性はやや低い。
レチナール（Retinaldehyde）肌で1段階変換すればトレチノインになる。効果と副作用のバランスが良い。
グラナクチブレチノイド（HPRなど）最近注目の低刺激型レチノイド。データはまだ少なめだが、期待大。

 

これらのレチノイドを使う際のポイントは「継続と処方設計」でして、

 

  • 濃度は0.1〜1％程度で効果が期待される（とくに0.5%以上）
  • 同時に保湿成分（セラミド、ヒアルロン酸）が入っていると副作用対策になる
  • タイミングは夜のみ使用で、朝は必ず日焼け止めを使う

 

みたいになります。ここらへんを守らずに使うと、かつての私のように皮膚が赤くなってヒリヒリしまくるのでご注意あれ。

 

特に敏感肌の人がレチノイドを使う時には注意が必要で、おすすめの導入ステップとしては、

 

  1. 週2〜3回から開始
  2. ヒリつきが出たら「保湿＋お休み」で調整
  3. 肌が慣れてきたら、毎晩へステップアップ
  4. 紫外線防止はマスト

 

といった手順を守るようにしてくださいませ。敏感肌じゃない人でも、週2〜3回から開始するのは守ってもいいかもですね。

 

ちなみに、よく「20代でもレチノイドを使うべきですか？」と聞かれることがありますが、若いうちはまだターンオーバーは万全なので、ニキビ対策をしたいわけでもなければ特に使う必要はないでしょう。30代で「シワが気になるな…」とか思った場合や、40代以降になって「ハリがなくなったな……」とか思い出した人が使えば十分であります。

 

 

 

ポイント2. 紫外線対策こそ、最高のアンチエイジング

って、これは前回でも強調したポイントですが、「紫外線を浴びた部分と浴びてない部分ではシワの量に2倍以上の差が出る！」なんて話もあるぐらい「老化対策」においては最も重要なんで、何度でも取り上げておきます。

 

といっても、同じことばっか言っても仕方ないので、前回の話に加えて、以下の点を補足しておきます。

 

  • 日焼け止めは「毎日使ってこそ」意味がある：紫外線は「夏の晴れた日」にだけ降り注ぐわけではなく、曇りの日でもUVの8割は透過するし、冬場でもUVAはガンガンに降り注ぐし、室内でも窓ガラスを通ってUVAが侵入するしで、「日差しが強い日だけ塗る」では不十分なのだとお考えください。正直、日差しを“感じたとき”だけ日焼け止めを塗る人は、すでにスキンケアの戦いに負けますんで。

 

  • 日焼け止め選びで見るべきは「SPF」だけじゃない：ドラッグストアに並ぶ日焼け止めには、よく「SPF 50+」や「PA++++」って表記がありますが、アンチエイジングが目的なら重要なのはPA値の高さであります。というのも、SPFはUVBをブロックして日焼け・赤みを防ぐ力を表すのに対して、PAはUVAをブロックしてシワ・たるみを防ぐ力を意味してるからです。

    なので、目安としては、毎日のベース用には「SPF30＋ / PA+++以上」を使い、屋外レジャーや運動時には、「SPF50＋ / PA++++」をお使いいただくのが良いでしょう。

 

  • 紫外線吸収剤と散乱剤はどっちでもいい：日焼け止めの成分は、その防御手段により大きく2種類に分かれまして、

    ・吸収剤（ケミカル）＝オキシベンゾンなど。肌に馴染んで軽いつけ心地で、テクスチャ重視派にむいている。
    ・散乱剤（ミネラル）＝酸化チタン、酸化亜鉛など。白浮きしやすいが、低刺激なので敏感肌や赤ちゃんなどにむいている。

    みたいになります。ここで多くの人は「吸収剤ってなんか危険じゃないの…？」みたいな心配をするわけですが、近年の吸収剤入り日焼け止めは、すべて厳格な安全性審査を通っているのでご安心を。このポイントに悩むぐらいなら、使用回数や塗布量にこだわるほうが圧倒的に重要ですんで。

 

  • 日焼け止めを正しく使う：日焼け止めは、正しい使い方を知らないと効果がほぼゼロになるので注意してください。使用量の目安としては、顔だけで1円玉2枚分（約0.8〜1.0g）ぐらいで、顔＋首で 約1.5g以上を使うようにしましょう。少なすぎるとSPF表記の1/3程度しか効果が出なくなりますんで。

    再塗布のタイミングは2〜3時間おきが理想で、メイクの上からなら、スプレータイプやクッションタイプでもOKであります。

 

ってことで、スキンケアの世界にはさまざまな成分が登場しますが、ここまで強固に老化防止の効果が証明された手段は紫外線対策以外にないとお考えください。日焼け止めを使ってないなら、他のスキンケアにお金をかける意味がないですんで、くれぐれもご注意あれ。

 

 

 

ポイント3. ビタミンCは「条件付き」の有効成分

ビタミンC（アスコルビン酸）もまた、「美白・ハリ・毛穴」に効く万能成分として、長年にわたって人気を集めている成分。たとえば、パッケージによくある謳い文句としては、

 

「シミ・そばかすを防ぐ」

「ハリとツヤのある肌に」

「毛穴が目立たなくなる」

 

みたいなものがありまして、そのほとんどがビタミンCの作用を根拠にしております。

 

で、これらの宣伝文句は決してウソじゃなくて、ビタミンC（アスコルビン酸）には以下の作用が確認されております。

 

  • 抗酸化作用 → 紫外線や大気汚染などで発生する活性酸素を除去し、細胞のダメージを減らす

  • メラニン合成の抑制（＝美白効果）→ チロシナーゼという酵素の働きを抑えて、色素沈着を予防

  • コラーゲン生成のサポート → 真皮の線維芽細胞に働きかけ、ハリ・弾力を維持

  • 毛穴・ニキビ跡の改善 → 皮脂分泌の調整や、赤みの抑制にも効果が示唆されている

 

これらの結果は割とよくて非常に期待が持てるわけですが、実は科学的に見ると、ビタミンCってのは割と使いこなしが難しい問題児だったりもします。というのも、ビタミンCってのは、条件を満たさないと効果が激減しちゃう性質を持ってるんですよ。

 

この成分には2つの致命的な課題がありまして、

 

課題１．酸化しやすく超不安定

ビタミンC（アスコルビン酸）は空気、光、水に非常に弱く、開封後すぐに酸化してしまうことが多め。もし酸化すると、色が黄色〜茶色っぽく変化して効果が失われるだけでなく、むしろ肌に刺激や酸化ストレスを与えちゃうんですな。

 

 

課題２．肌に浸透しづらい

水溶性のビタミンCは、皮膚の“バリア機能”を突破しづらいという欠点もあったりします。特に角質層は脂質が多く、親水性の成分が中に入りにくい構造になってるんで、「せっかく高濃度の美容液を塗っても、肌の奥に届かない…」という事態が多発してしまうんですな．

 

いずれも難しい問題ですが、ではどうすればビタミンCのポテンシャルを最大限に活かせるのかと言いますと、研究と実務の両面から見た「必須条件」は以下のようになります．

 

条件1. 濃度は10〜20％が目安

  • 多くの臨床研究では、10%以上の濃度で効果が確認されている
  • 5%未満では美白やコラーゲン合成の効果が統計的に有意でないケースも
  • 逆に20%以上になると、**刺激（ピリピリ感・乾燥）**が出ることもあるため、慎重に

 

条件2. pHは5以下（理想は2.5〜3.5）

  • ビタミンCは酸性環境で安定しやすく、皮膚に浸透しやすいため、高濃度ビタミンC美容液は刺激性があるほどpHが低い設計になっている
  • そのため、pHが高すぎると浸透せず、意味のない化粧水になってしまう

 

条件3. 酸化対策が施されていること

  • 空気に触れない「エアレスポンプ容器」
  • 光を遮断する「遮光ボトル（茶色・銀色）」
  • 酸化防止のために「ビタミンEやフェルラ酸などの抗酸化剤」を配合している処方

 

ということで、これらの対策がされていない製品は、もはや“ただの水”を買ってるだけになる可能性もあるんで注意してください。

 

もっとも、上記の問題を防ぐために、最近はアスコルビン酸の代わりに「安定型ビタミンC誘導体」を使った製品も増えております。代表例としては、

 

  • アスコルビルグルコシド＝安定性◎、効果は穏やか。敏感肌向け。
  • テトラヘキシルデカン酸アスコルビル（VC-IP）油溶性で肌なじみが良く、美白効果が期待される。
 

みたいな感じですね．ただし注意点として、安定型のビタミンC誘導体は効果がマイルドなことが多く、「即効性」や「強いシミへのアプローチ」には不向きな場合もあるんで注意してください。

 

 

 

ポイント4. 「気休め」成分たちの特徴

さて、現時点で信頼に足る成分はこの３つですが、ここまで紹介した以外にも、アンチエイジングをうたう成分は山ほど存在しております。たとえば、

 

  • ペプチド
  • 幹細胞エキス
  • プロバイオティクス
  • プラセンタ
  • 植物エキス各種

 

みたいな感じですね。しかし、これらのほとんどはin vitro（試験管内）レベルのデータしかないか、製品として有効な濃度が不明なまま売られていることがほとんどなんで、まずは「気休め」ぐらいのもんだとお考えください。ここでは、「効果がありそうで、実はよく分かっていない成分たち」を、科学的な観点から整理していきましょう。

 

 

気休め成分１．植物エキス

アロエベラ・カモミール・緑茶・ローズヒップ・ヒアルロン酸配合◯◯エキスなど、ナチュラル志向で人気の成分ですね．主に抗酸化・抗炎症といった作用を“期待”されるケースが多めでしょう、

 

しかし、実際のところは、

 

  • 多くはin vitro（試験管内）データのみ

  • 成分の濃度や肌への浸透性は化粧品の処方により大きく変わる

  • 同じ植物でも収穫時期・抽出方法で効果がバラバラ

 

みたいな感じでして、聞こえはいいけど、実力は追いついていないものが多い印象っすね．

 

 

気休め成分２．幹細胞エキス

植物幹細胞培養液、アップルステムセル、ヒト脂肪由来幹細胞培養液など、“細胞レベルで若返る！”というインパクト強めなコピーで話題になってる成分であります．

 

しかし、現状としましては、

 

  • 幹細胞そのものは使われていない（使えない）
  • 実際に入っているのは幹細胞の“培養液”由来の抽出物
  • 成分内容は不明瞭なことが多く、ヒトでの有効性はほぼ未検証

 

といった状態でして、ほとんどSFみたいなもんだとお考えください．

 

 

気休め成分３．プラセンタ（胎盤エキス）

成長因子・アミノ酸などを含むとされ、医療系美容での利用歴が長く、年齢層高めに人気の成分っすね．こちらもよく耳にする成分ですけども、実際のところは、

 

  • 含有成分が安定していない

  • 医療用注射と化粧品では効果のスケールが違いすぎる

  • 外用では皮膚バリアを通過しない可能性が高い

 

みたいになってまして、ヒト研究のデータが乏しく、“なんとなく効いてる気がする”以上のものが証明されていなかったりします。

 

 

気休め成分４．プロバイオティクス（スキンケア応用）

近ごろ「肌の常在菌バランスを整える」目的で注目されていて、ヨーグルト・バイオ技術などのイメージが“効きそう感”を演出してるおかげで、ジワジワと人気が出てきております。

 

こちらも現状は割と厳しくて、

 

  • 腸内と違い、皮膚には免疫バリアがあり生菌が働きづらい

  • 多くの製品は“死菌”や“抽出物”を使っており、定義が曖昧

  • ヒトの皮膚における臨床効果のエビデンスは極めて限定的

 

といった問題を抱えております。コンセプトは面白いんだけど、まだ発展途上すぎる感じっすね。

 

 

気休め成分５．ペプチド（合成アミノ酸鎖）

「ボトックスのようにシワを抑える」「肌を再構築する」などの主張で人気な成分ですね。こちらもなかなか現状は厳しくて、

 

  • 肌に塗布した場合の浸透性や安定性に疑問が残る

  • 多くはin vitro（細胞レベル）の研究止まり

  • 製品の処方により効果が大きく異なる

 

といったあたりが現状になりますね。ごく一部のペプチド（ナイアシンアミドとの併用など）を除けば、「思ったほど効かない」ものが多い印象なので、こちらも注意したいところです。

 

ということで、「気休め」系の成分を簡単に見てみました。まあ「気休めの成分」と聞くと、つい「無意味」「詐欺」「使うべきでない」といったニュアンスを感じるかもしれませんが、個人的にはそこまでは思ってなくて、「気休めだから悪いのではなく、過剰に信じすぎるのが問題」ぐらいのスタンスでおります。

 

個人的には、化粧品は科学であると同時に、感情にも効かねばならないプロダクトだと考えてまして、たとえ“気休め”成分でも、上手い具合に自分の気分を上げてくれるのであれば、それも決して悪ではなかろうと思うわけです。そもそもスキンケアの世界なんて“たぶん効かない”成分であふれているのが普通なので、あくまで“過大な期待”をせずに、「肌に合えばOK！」ぐらいのノリで付き合うといいんじゃないかと。ではまた！
