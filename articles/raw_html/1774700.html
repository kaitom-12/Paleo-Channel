こないだコレステロール系サプリのエビデンスをまとめたんで、今回は趣味的に「ダイエットに効く！」と言われてる成分について、現時点でどれぐらいの証拠があるのかをチェックしてみました。

 

 

まぁパレオな男をお読みの方であれば、私がダイエットサプリに好意的じゃないのはご存じでしょうが、あらためて現状を確認しておくのも悪い話ではありますまい。

 

 

ってことで、以下に市場に出まわるダイエットサプリのメリットとデメリットを並べていきます。

 

 

 ダイエットサプリエビデンスレベルまとめ

  • カフェイン

    • 説明：コーヒーやお茶にふくまれるアルカロイドの一種。神経中枢に働いて食欲を減らし、代謝も高めるとされる。
    • 効果：2018年のメタ分析(R)では、そこそこの体重減少効果が確認されている（0.29）。ただし、長期的に使うと効果は減ルため、長期的に使えるかといえば怪しい。
    • エビデンスレベル：高い。
    • 安全性：一部に依存症や頭痛などの副作用が確認されている。
    • 用法：1日 250-300 mg 

 

 

  

  • 緑茶カテキン

    • 説明：緑茶にふくまれるカテキンの一種（EGCGとか）。代謝を高める効果があるとされる。
    • 効果：複数のメタ分析(R,R) により、プラシーボに比べて有意に体脂肪が減る効果が確認されている（12週間で-1.31 kg）。普段からカフェインを使わない人の方が効果は高い。
    • エビデンスレベル：超高い。
    • 安全性：一部にカフェインによる副作用が報告されているが、基本的には安全
    • 用法：1日 400-500 mg のEGCG

  

 

 

 

  • インゲン豆抽出物

    • 説明：インゲン豆にふくまれるファセオラミンがアミラーゼを抑制し、体重が減るとされる。
    • 効果：6件をまとめたメタ分析(R)では、体重の減少効果は認められなかった
    • エビデンスレベル：高い。
    • 安全性：短期の服用は安全だが、一部に胃腸不良の副作用が報告されている。
    • 用法：非推奨

 

 

 

 

  • ビターオレンジ

    • 説明：日本ではダイダイと呼ばれる柑橘系フルーツの一種。皮から抽出した成分に、代謝アップと食欲の抑制効果があると言われる。
    • 効果：いまのところ動物実験がメイン。初歩研究(R)では1日975mgを飲んだ被験者に体重の減少が見られたが、この実験では同時に1日528 mgのカフェインも使われているため判断が難しい。
    • エビデンスレベル：低い。
    • 安全性：シネフリンという刺激物をふくむため、人によっては心疾患リスクが上がりかねない。高血圧の人はひかえるべき。
    • 用法：1日50㎎

 

 

 

 

  • 7-keto DHEA

    • 説明：副腎皮質ホルモン様物質の一種で、代謝をあげて脂肪を燃えやすくすると言われる。
    • 効果：23人対象の研究(R)では、8週間で体脂肪と体重の減少が報告されている。ただし代謝の向上レベルはベースラインに比べて1.4％の増加率でしかなく(R)、わざわざ飲むべきかは疑わしい。
    • エビデンスレベル：低い。短期研究がちょろっとしかない
    • 安全性：長期の安全性を調べたデータはない。副腎皮質ホルモン様物質なんで、とり続ければ何らかの副作用が出そうではある
    • 用法：1日200㎎（100㎎×2回）

 

 

 

  • カルシウム

    • 説明：おなじみの重要なミネラル。新陳代謝に欠かせないため、不足すると肥満の原因になると思われる。
    • 効果：初期研究(R)では体重が減るとの報告もあるが、追試では効果が確認されていない。ただし、乳製品からカルシウムを摂取した場合は、肥満のリスクが減る可能性はある。
    • エビデンスレベル：低い。
    • 安全性：サプリの長期使用は前立腺癌を高め、心疾患リスクも増やす可能性がある(R)。
    • 用法：副作用を見ると推奨できない（乳製品はアリ）

 

 

 

 

  • カラルマ（スリマルマ）

    • 説明：インド原産の食用多肉植物。昔から食欲の抑制に使われてきた。
    • 効果：50人を対象にした研究(R)では、1日1gを2ヶ月飲み続けた参加者は食欲が減り、ウエストサイズも減った。ただし、体重と体脂肪には有意差がなかった。
    • エビデンスレベル：低い。
    • 安全性：長期的な安全性は確認されていない。
    • 用法：1日 500mg-1g 

  

 

  

 

  • エフェドラ

    • 説明：マオウから抽出したw刺激物。交感神経を刺激して代謝を上げる。
    • 効果：数十を超す研究で、体脂肪と体重の減少が報告されている(R,R,R,R,R,R,R,R)。ただし、現時点では処方薬としてしか手に入らないし、海外からの個人輸入もほぼ不可能。
    • エビデンスレベル：高い。
    • 安全性：高血圧や脳卒中のリスクがとても高い。
    • 用法：非推奨。

 

 

 

 

  • フォルスコリン

    • 説明：昔からダイエットに使われてきたハーブの一種。脂肪を燃やす酵素とホルモンを刺激すると言われる。
    • 効果：3ヶ月におよぶ小規模研究(R)では、1日500mgを飲んだグループは有意に体脂肪が減り、筋肉の量が増えていた。女性を対象にした実験(R)でも、同じように有意差が確認されている。ただし、いずれも肥満体の人だけを対象にしている上、体脂肪の減少率はとても低いため、使い物になるかどうかは不明。効果が確認されなかったデータも少なくない。
    • エビデンスレベル：中程度。
    • 安全性：低血圧リスクが報告されている。
    • 用法：1日50mg

 

 

 

 

  • グルコマンナン

    • 説明：コンニャクに多くふくまれる水溶性食物繊維
    • 効果：2016年のメタ分析でダイエット効果が否定されている。
    • エビデンスレベル：高い。
    • 安全性：水と一緒に飲まないとノドに貼りつく可能性がある。
    • 用法：1日1g

 

 

 

 

  • グリーンコーヒー豆抽出物

    • 説明：グリーンコーヒー豆からポリフェノールを抽出したもの
    • 効果：2011年のメタ分析(R)では、プラシーボに比べて有意に体重が減る効果が確認されている（-2.47 kg）。ただし個人差が非常に大きいため、ダイエット目的で使うべきかは判断しづらい。
    • エビデンスレベル：高い。
    • 安全性：短期的には確立されているが、長期研究がない。
    • 用法：1日 400-500 mg 

 

 

 

  • フーディア

    • 説明：多肉植物からエキスを抽出したもの。食欲を抑える効果があるとされる。
    • 効果：健康な女性を対象にした研究(R)では、1日1100mgを飲んでも有意差が確認されなかった。
    • エビデンスレベル：低い。
    • 安全性：血圧の上昇が報告されている。
    • 用法：非推奨

 

 

  

 

 

  • ヒドロキシクエン酸

    • 説明：クエン酸の誘導体で、体脂肪を効率よく使えるようになるとされる。
    • 効果：12週間で効果がでたとの報告(R)がある一方で、肥満の男性には意味がなかったとのデータ(R)もあり、現時点では判断不能。
    • エビデンスレベル：中程度。
    • 安全性：短期的には確立されているが、長期研究がない。
    • 用法：1日 1500 mg （500㎎×3回）

 

 

 

 

  • Lカルニチン

    • 説明：お肉に多くふくまれるアミノ酸の一種。脂肪の燃焼効率を上げると言われる。
    • 効果：現時点で体重の変化に関するまともなエビデンスはない（筋トレならある）。
    • エビデンスレベル：低い。
    • 安全性：安全だと思われる。
    • 用法：1日 1000-1500 mg 

 

 

 

  • チャ・デ・ブグレ

    • 説明：ブラジル原産の樹木。食欲を抑制してくれると言われる。
    • 効果：まともなデータがない。
    • エビデンスレベル：超低い。
    • 安全性：まともなデータがない。
    • 用法：不明

 

 

 

 

まとめ

そんなわけでいろいろまとめてみましたが、まぁ普通に考えると「緑茶カテキンの圧勝！」みたいな感じになりましょうか。あとは2番手でカフェインが続くぐらいで、他は使う理由がないかなぁ、みたいな。

 

 

といっても、決して緑茶カテキンに劇的な作用が認められてるわけでもないので、抗酸化パワーのついでに肥満リスクの低減効果も得られたらいいなーぐらいの気持ちで飲むのが正解と言えましょう。どうぞよしなに。
