たとえば、こんな経験は誰にでもあるでしょう。

 

いつものカフェで友人たちとおしゃべりをしようと思ったら、場の空気がやけに重いのに気づかず明るい話題をふってしまい、「あ、しまった！」と後悔した――。

 

このような、いわゆる“場の空気を読む能力”は、言うまでもなく世の中を生き抜くための重要なスキル。この能力がなかったら、会議でひとりだけズレた発言をして場を凍らせたり、初対面の相手に不快な印象を与えてしまったりといった失敗が、頻発するでしょうからね。

 

が、「空気を読む」と言われても、いまいちどんな能力なのかがわからないのが難しいところです。一般的には、「共感力の高さ」とか「協調性の高さ」みたいに思われがちですが、いまいち確定した定義がないので、いざ「空気を読む能力を鍛えたい！」と思っても、どうして良いかわからず困っちゃうんですよね。

 

といったところで、新たに出た研究(R)では、このつかみどころのない「空気を読む」って能力に真正面から取り組んでいて面白かったんで、ぜひ内容をチェックしておきましょう。

 

 

 

空気を読む能力とは、つまりどういうことか？

で、まず研究チームは、「空気を読む能力」に「適応的パーソナリティ調整」という名前をつけております。これは「場に応じて自分の性格を調整できる能力」のことでして。「自分の性格を場に合わせて表現できるかどうか？」ってのを、空気を読む人の重要なスキルだと考えてるわけですな。これはなかなか示唆的ですな。

 

というと、「え？性格って変えられるの？」と思った方もいるかもですが、実は人の性格がどう表に出るかってのは、6〜7割が“その時々の状況”に左右されているってデータがあったりするんですよ(R)。つまり、私たちはみんな意外と日々「性格の使い分け」をしてるってことですな。

 

この理論をチェックすべく、研究チームは以下のような実験をしております。

 

 

実験1：性格を“シフト”できる人はパフォーマンスも高い！

これはマンチェスター大学のチームが行った実験で、まず1つ目では、被験者たちに2つのタスクをやってもらってます。

 

  1. ミニ・ネットワーキングイベントを行い、その際に「5分間でその場で最も目立つ人物になれ！」と指示される。
  2. 集中力が問われる個人作業をやってもらい、その際に「9分間で黙々とテストを採点せよ！」と指示される。

 

ご覧のとおり、この2つは求められる性格特性が真逆であります。前者は外向性が大事で、後者は内向的な集中力が求められますからね。

 

その上で、参加者の行動を録画して専門家がチェックしたところ、「性格を場に合わせて変えられた」人は、どちらの課題でもパフォーマンスが良かったらしいんですよ。要するに、「目立てる場では目立ち、黙々と作業する場では静かになれる人」が、やっぱり強かったってことです。当たり前のことですが、やっぱ「常に同じ自分を貫くぞ！」って戦略でうまくやるのは難しいんでしょうな。

 

 

実験2：スタンドアップ・コメディアンに学ぶ“適応力”

2つ目の実験は、「スタンドアップ・コメディ」の現場で行われたものです。プロ＆アマのコメディアンたちに、観客の前で実際にパフォーマンスを披露してもらい、その様子を心理学の専門家＋業界のプロが分析したんだそうな。

 

ここで分析に使われたのは、ご存じ「ビッグファイブの性格分類」であります。専門家が「良いパフォーマンスにはこの性格が重要だ！」と評価したポイントと、コメディアンが実際に見せた行動がどれくらい一致していたかをスコア化して、「適応的パーソナリティ調整インデックス」として測定したんですな。

 

結果、適応的パーソナリティ調整のスコアが高い人ほど、観客からの評価が高く、舞台での成功率もバッチリだったとのこと。こちらでも空気を読んで性格を変えられる能力の高さが、やはりパフォーマンスに結びついてますね。

 

ちなみに、うまくいく性格のパターンはこんな感じだったらしいです。

 

  • 怒りっぽさが低い（3.67点）
  • 知的好奇心が高い（7.54点）
  • 自己規律が高い（6.95点）
  • 従順性は平均的（4.6点）
  • 主張力（アサーティブネス）は高い（7.58点）

 

要するに、舞台でウケるためには、「自分らしさ」を表現するだけじゃなくて、「場に応じた自分」をうまく表現できるかどうかがカギってことですね。

 

で、ここで面白いのは、適応的パーソナリティ調整のスコアは、「性格の自己評価」や「セルフモニタリング（自分の見せ方を意識する力）」とはまったく別物だったところです。なんでも適応的パーソナリティ調整の能力ってのは、

 

  • 他人からどう見えるか？
  • その見せ方が「場に合っているか」？

 

という、きわめて“実戦的”な能力を指してまして、そして何より自己評価よりも「適応的パーソナリティ調整」スコアのほうが「パフォーマンス」をよく予測するってのが、今回の研究のキモなんですな。

 

 

もちろん、我々がスタンダップコメディの舞台に立つことはあんまないでしょうが、

 

  • 取引先でのプレゼン
  • 上司への報告
  • 子どもとの会話
  • 飲み会の空気読み

 

みたいな日常で起きるタスクのすべてが、「適応的パーソナリティ調整」を発揮するチャンスなんですよ。これは鍛えておきたい能力ですなぁ。

 

 

 

自分の空気を読む能力をどうチェックするか？

こうなると、「どうすれば自分の適応的パーソナリティ調整を判断できるのか？」ってのが気になるでしょうが、残念ながらこれについては、現時点ではまだ標準化された自己診断ツールはないのが残念なところです。ただし、この研究を読む限り、以下のように【実践ベースでチェックする方法】が有効なんじゃないでしょうか。

 

 

空気読み能力チェック１．「場とふるまいの一致度」を書き出してみる

まずは日常の場面ごとに、「求められるふるまい」と「自分の実際のふるまい」がどれくらい一致していたかを振り返ってみるのが良いでしょう。具体的には、「シチュエーション」「求められる性格特性」「自分の行動」「一致度（5点満点）」を以下のように記録してみてくださいませ。

 

  • 【記録例】
    • 会議での報告→論理性・簡潔さ→感情的・長め→★★☆☆☆
    • 飲み会での雑談→明るさ・外向性→積極的に話した→★★★★☆
    • 子どもとの会話→優しさ・共感力→つい説教調に…→★☆☆☆☆

 

こうした振り返りの記録を3〜5日分ぐらい集めてみると、自分が「場に合った性格表現」が得意な場面や不得意な場面が見えてくるでしょう。これは、なんとなく普段から自分もやってたんですけど、あらためて記録してみたいっすね。

 

 

空気読み能力チェック２． フィードバックを求める

さらには、場面ごとに、親しい人に以下のように聞いてみるのも手でしょう。

 

  • 「いまの私は、場の空気に合ってたかなー？」
  • 「あの時、ちょっと浮いてたと思います？」

 

もちろん相手を選ぶ必要があるんだけど、できれば複数人（仕事仲間／家族／友人など）からフィードバックをもらうことで、主観と客観のギャップが見えてくるでしょう。

 

 

空気読み能力チェック３．「真逆の性格」をあえて演じてみる

今回の研究によれば、「適応的パーソナリティ調整」が高い人は「性格を柔軟にシフト」できるとのこと。そこで試してみたいのが、わざと普段の自分と反対の性格を演じる練習であります。

 

  • いつも控えめな人 → プレゼンでハキハキ話してみる
  • いつもおしゃべりな人 → 会議では沈黙を保つ訓練をしてみる
  • せっかちな人 → 意図的にゆっくり相手の話を聞く

 

これは一種の「性格の筋トレ」みたいなもんで、こういった作業をやってみると、自分がどのくらい柔軟にふるまえるかの目安になりますし、「適応的パーソナリティ調整」の土台になる「抑制力」や「自己モニタリング力」も養えるはずであります。

 

というわけでいろいろ書いてきましたが、とりあえずは自己モニタリングが一番大事なのは間違いないので、「場とふるまいの一致度を書き出してみる」をやっていただくのが良いかと思います。

 

 

そのうえで「いかに適応的パーソナリティ調整力を鍛えるか？」ってのがポイントになりますけども、これについては、個人的な仮説として、

 

  • 「今この場に、どんな性格が求められているか？」と意識する習慣を持つ
  • メタ認知（＝自分の行動を観察する力）を高める瞑想などを取り入れる
  • 周囲の反応をフィードバックとして受け取る力を育てる

 

ってあたりを行っておくと、「空気を読む能力」を鍛えられるんじゃないかと。簡単にいえば、「場を見る力」と「それに応じて自分のふるまいを調整する力」を日々意識することが大事ってことですね。

 

 

 

空気読み能力トレーニング．シチュエーション読解

以上をふまえて、「適応的パーソナリティ調整力」を鍛える方法を考えてみると、空気を読むには「人の性格を読み解く力」と「場に求められている役割を察する力」を育てるのが必須。これを土台にしないと、ガッツリと空気を読む能力は育てられないので、まずはこいつを養うようにしましょう。

 

 

ステップ①：「3つの観察視点」で“場”を切り取る

まず最初に、「場の空気を読む」時に絶対に必要になる、3つの視点を押さえておきましょう。

 

  1. 行動＝誰がどんな行動をしていたか？（例： Aさんが発言をリード、Bさんは腕組みして黙っている）

  2. 感情＝どんな感情が場に流れていたか？ （例：緊張感あり、笑いなし、全体的にピリついていた）

  3. 目的＝この場の目的は何だったか？ （例：意見の集約、リスクの洗い出し）

 

この３つを察知できるようになるのが、「場の空気」を読む能力を鍛えるための一歩。これら３つをふまえたうえで、今日やったコミュニケーション（会議・ランチタイム・オンラインミーティングなど）を振り返り、箇条書きで書き出してみるとよいでしょう。

 

 

ステップ②：「理想の性格タイプは誰か？」を探す

次に、上で切り取ってみた“場”の記録を振り返りつつ、「この場で“最もうまく立ち回っていた人”は誰だったか？」を思い起こしてください。その人物のふるまいや話し方から、どんな性格特性が発揮されていたか？を考えてみましょう。

 

  • 例：
    • Aさん：明るくテンポよく話を進めていた → 外向性・開放性が高そう
    • Bさん：的確に話をまとめ、感情を表に出さない → 誠実性・感情安定性が高そう

 

ここで大事なのは、その人の「元の性格」ではなく、「場に合っていた性格表現」に注目すること。その場でどんな性格を表現していたのかをチェックしてみてくださいませ。

 

 

ステップ③：自分とのギャップを内省する

最後に、自分のふるまいを振り返ってみましょう。具体的には、以下のポイントをチェックしてみてくださいませ。

 

  • チェックリスト：
    • 私はその場でどんな性格を出していたか？（ビッグファイブでざっくりでもOK）
    • 理想の性格表現と比べて、ギャップはどこにあったか？
    • もし同じ場面があったら、どう“性格を調整”すればよかったか？

 

たとえば、「あの場では“聞き役”より“仕切り役”の方が求められてたな…」みたいな感じでして、ここらへんを内省し続けることで、適応的パーソナリティ調整力は向上していくはずであります。

 

 

というわけで、今回の研究を一言でまとめるなら、性格を「固定的なもの」と考えるのではなく「文脈に合わせて柔軟に使いこなす力」が大切！ってのが、今回の研究のポイントでした。性格を調整できる力ってのは、例えるなら“性格の筋トレ”のようなもの。こいつを鍛えればどんな場でも自分を活かせる力になりますんで、ぜひ意識しときたいですなぁ。
