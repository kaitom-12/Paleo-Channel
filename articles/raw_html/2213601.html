脳の最適化ってのは、文字通り、自分の脳が万全に働いている状態のこと。脳の神経系と身体の間のコミュニケーションがスムーズに行われ、「なんか元気！」や「なんか生き生きしてる！」みたいな感覚が強い状態を目指そうって話であります。

 

このようなテーマは今までも取り上げてきましたが、「体に良いことをたくさんやってるのに成果が出ない！」という方は、「脳と身体の連携」がうまく取れていないケースが多いんですよ。

 

ってことで前回からは、「いまのところ効果ありそうなバイオハック」を整理してまして、今回もその続きです。

 

今回ご紹介するのは、「カロリーを減らさずに、カロリー制限と同じ効果を得る物質」。ある程度のカロリー制限には、寿命の延長、老化の抑制、代謝の改善など、さまざまな恩恵があることが分かってるんですが、「空腹を感じ続ける生活なんて無理…」というのが多くの方の本音でしょう。私も空腹をひたすら我慢するのはご勘弁願いたい派です。

 

そこで登場するのが、「カロリー制限ミメティクス（Caloric Restriction Mimetics：CRM）」という考え方で、サプリや薬物を使って、カロリー制限を擬似的に再現しようって考え方ですな。今回は、その中でも代表的な3つの成分──ラパマイシン・スペルミジン・メトホルミンについて見ていきましょう。

 

 

 

バイオハック３. ラパマイシン：細胞の“暴走”を抑える抗老化スイッチ

まずは、アンチエイジング系の話題で頻出する「ラパマイシン」から。ここ数年、「長寿薬」として最も注目されている薬のひとつですね。

 

もともとは臓器移植の拒絶反応を抑えるための免疫抑制剤として使われてきた薬なんですが、近年では「mTOR（エムトア）経路を抑制することで老化を遅らせる」って作用が注目されてまして、海外のアンチエイジング系サイトで“本命”あつかいされてたりするんですよ。

 

ラパマイシンのキモは、mTORという細胞の“成長スイッチ”をオフにすること。mTOR（mechanistic target of rapamycin）ってのは、ざっくり言えば「栄養があるから、どんどん増殖しよう！」って指令を体に出すスイッチで、若いうちはこれが大活躍するんですよ。若いうちは、筋肉を作ったり、臓器を成長させたり、免疫細胞を増やしたりと、肉体を成長させてナンボですからね。

 

が、このスイッチが年を取っても入りっぱなしだと、以下のような問題が起きるんですよ。

 

  • 細胞が過剰に成長する → がん化のリスク上昇！
  • 成長ばかりしていると、壊れた細胞を壊す、掃除する、再構築する機能が働かず、体が修復されない → 老化の促進！
  • 修復機能が働かないのでオートファジー（細胞の掃除機能）が停止 → 老廃物の蓄積！

 

要するに、mTORが“成長だけ”をうながしすぎると、体が「いまは掃除しなくていい！」と考え出して、オートファジーの抑制が発生するんですな。

 

もちろん、この状態は一時的なら問題ありません。たとえば、トレーニング後に筋肉が合成される、成長期に細胞が増えるみたいな「成長モード」は必要ですからね。しかし、その一方で、現代人は常に“成長モード”になりがちな傾向もありまして、どういうことかと言いますと、

 

  • 常に栄養過多になることが多い（1日3食＋間食＋プロテイン）
  • そのせいで、インスリン・IGF-1（成長因子）が常に高めになり、mTORも慢性的にオンになる
  • その結果、壊れたミトコンドリアや細胞が蓄積し、がん化しやすい細胞が排除されずに増え、慢性炎症が高まったりする

 

みたいなメカニズムが働くからです。怖いですなぁ。

 

そのため近年は「老化ってのは『mTORが暴走した結果』なのでは？」って説がかなり強まってきてまして、そのスイッチを抑えてくれるラパマイシンは「細胞レベルのアンチエイジング剤」として期待されているわけですね。

 

ただ、実際にラパマイシンで寿命が延びるのかと言いますと、動物実験しかないのが現状であります(R)。このタイプの実験では、ラパマイシンを与えたマウスの寿命が10〜30％延びたという報告がいくつもありまして、しかも高齢になってから飲み始めても効果があった例もあったりして、なかなか期待が持てるんですよね。

 

あくまで人間での長期的なデータはないのが難点ですが、現時点では「可能性は高いが、確実性はない」というのが専門家の一致した意見でしょう。個人的にも「自分でラパマイシンを飲むか？」と言われると、もうちょっと様子を見させてください！って感じですね。

 

また、ラパマイシンは作用が強いだけに、副作用がそれなりに強めなのも悩ましいところです。たとえば、

 

  • 免疫力の低下
  • 傷の治りが遅くなる
  • 睾丸の萎縮（←動物実験）
  • 感染症リスクの増加

 

みたいな心配があるんですよね。本来は免疫抑制剤なので、ウイルスやがんに対する抵抗力が下がる可能性があるのは辛いっすね。気になる方は、個人輸入サイトから購入できますんで、あくまで自己責任でよろしくお願いします。

 

 

 

バイオハック４. メトホルミン：糖尿病薬から寿命延長の星へ

次に紹介するのが、糖尿病治療薬として長年使われてきたメトホルミン（Metformin）。元はといえば、2型糖尿病のための血糖コントロール薬なんですが、最近の研究(R)では、

 

  • 体重減少のサポート
  • 抗老化（アンチエイジング）効果
  • 認知症・がん・不妊などへの予防的効果

 

といった、“副次的なご利益”がいろいろと報告され始めてるんですよ。ということで今回は、今わかっている範囲で「メトホルミンの可能性と限界」についてざっくり整理してみましょう。

 

まずメトホルミンがどんな薬なのかをざっくり言うと、「血糖値を下げることで、代謝全体を安定させる薬」です。1950年代から使われてきた歴史ある薬で、世界で2億人以上が服用しているとされており、医療現場では「コスパ最強の糖尿病薬」として知られております（1錠あたり数円〜十数円程度）。

 

その「副次的な効果」をまとめておくと、

 

  1. 体重を減らす（かもしれない）；一部の研究(R)では、糖尿病がなくても体重が減る報告されております。ある研究(R)では、1年で肥満者の体重の7%以上が減ったとされてまして、インスリン感受性の改善／食欲の抑制／腸内細菌の変化 が関わってるんじゃないかなーと考えられてるんですな。ただし、「飲めば確実に痩せる薬」ってわけではなく、食事改善＋運動の“下支え”として効く可能性があるぐらいに考えておくと良いでしょう。


  2. 老化を遅らせる（かもしれない）：動物実験(R)では、寿命が延びた／がんが減ったといったデータが報告されていて、かなり良い感じです。ヒトでも似たような報告はありまして、2019年のメタ分析(R)でも、メトホルミンを使っている糖尿病患者のほうが死亡率が低かったり、がんや心疾患の発症率も減ったなんて報告が合ったりするんですな。その理由としては、メトホルミによってAMPKの活性化 → mTORの抑制 → オートファジーの促進ってメカニズムが働くのだと考えられております。その結果として、DNA損傷からの保護、幹細胞の若返り促進、テロメアの保持みたいなメリットを得られる（かもしれない）んですな。つまり、細胞の“寿命スイッチ”にじわじわ効いてくる可能性があるわけです。


  3. PCOS（多嚢胞性卵巣症候群）と不妊への効果がある（かもしれない）：PCOSはインスリン抵抗性とホルモンバランスの乱れが原因で起きる問題のひとつ。メトホルミンはインスリン感受性を改善することで、排卵を促進、妊娠率が上がったという報告もあったりします（ただし効果は限定的）。


  4. 認知症・がんにも効く（かもしれない）：これもまだ研究途中ですが、興味深い報告が続々と出ております。たとえば、メトホルミンを使っている人は、認知症の発症リスクが下がるという観察研究(R)があり、逆に服用を中断すると認知症リスクが上がるというデータも。また、乳がん、膵臓がん、子宮内膜がんなどの進行を抑える可能性も指摘(R)されてまして、まだメカニズムは不明ながら、「がん細胞が糖を使えないようにする」作用があるのかもですな。

 

みたいになりまして、こちらもなかなか有望じゃないかと思うわけです。少なくともラパマイシンよりは確実に良さそうっすね。

 

が、いくら「夢の長寿薬っぽい」とはいえ、もちろん注意点もあったりします。ここらへんはぜひ押さえておいてくださいませ。具体的な注意点としては、

 

  • 吐き気、下痢などの消化器症状（特に初期）
  • ビタミンB12の吸収阻害 → 長期的には神経症状のリスクも
  • 稀に乳酸アシドーシス（極端な代謝障害）
  • アスリートや筋トレ勢には向かない（最大酸素摂取量が低下する可能性）
  • 腎機能が弱い人には使用不可

 

みたいになります。基本的には処方薬なので、それだけに作用は大きいものとお考えください。

 

逆に、メトホルミンが向いている人をまとめて見ると、こんな感じになります。

 

  • 血糖値がやや高め（空腹時90〜100）で気になる
  • 肥満・内臓脂肪型の体型で生活習慣病リスクがある
  • 家族に糖尿病やがんが多い
  • 老化予防のために、安全性の高い選択肢を試したい

 

といった層には、検討する価値ありかもしれません（もちろん医師と相談のうえで）。

 

ってことで、メトホルミンは決して派手な薬じゃないんだけど、体の基本的な代謝を整えることで、結果的にいろんなところが良くなる可能性は高そうであります。「これで老化を止められるか？」というと、まだ断言はできないんだけど、「最も現実的で、安全性が高く、エビデンスもそこそこ揃ってる“長寿の第一歩”」として、メトホルミンはかなり優秀なポジションにいると思っております。こちらも個人輸入サイトから購入できますんで、気になる方はどうぞ。

 

ちなみに、メトホルミンと同様の活性成分を含むハーブとしては、「ゴートルー」や「フレンチライラック」なんてのもあったりします。効果はだいぶマイルドですが、ナチュラルにAMPK経路を刺激したい方はこちらをどうぞ。

 

 

 

バイオハック5．スペルミジン：ラパマイシンの自然な代替

「オートファジーを促す自然成分」といえば、スペルミジンも外せないでしょう。もともとは体内でも合成されているポリアミンという物質のひとつなんですが、食事やサプリで補うことで「細胞の若返りスイッチが入るかも？」と言われてまして、アンチエイジング業界でじわじわと注目度が高まってきてるんですよ。

 

第一に、スペルミジンはEP300って酵素を抑制することで、オートファジーを誘導する作用が知られております(R)。スペルミジンが体内の掃除機スイッチを入れてくれる可能性は割と高くて、そのおかげで以下のようなメリットが報告されてたりします。

 

  •  心臓と血管を若く保つ：老化の大敵のひとつが、血管年齢の上昇。スペルミジンはこの点でも有望で、血管の内皮機能を改善し、動脈の柔軟性を保つ効果が動物モデルで報告されております(R)。「スペルミジン摂取量が多い人ほど、心疾患リスクが低い」という疫学データもあるんで、こちらも有望っすね。


  • 認知機能を守る：スペルミジンには、加齢による認知機能の低下を防ぐ可能性もありまして、一部の研究では、記憶力が低下した動物にスペルミジンを投与したところ、顕著な改善が見られたと言われてまして、アルツハイマーなどの神経変性疾患にもアプローチできるかも？と言われております。

 

  •  ミトコンドリア機能のサポート：エネルギーの源であるミトコンドリアも、年齢とともに機能が落ちていくんですが、動物研究ではスペルミジンによりミトコンドリアの能力が向上し、酸化ストレスの軽減が見られたそうな。スペルミジンが細胞の“エネルギー効率”を改善してくれるかもしれないわけっすね。

 

  • 寿命延長の可能性：最大の注目ポイントが「寿命が延びるかもしれない」という説で、マウスや線虫などの実験(R)では、スペルミジンの経口投与によって寿命が有意に延びたと報告されております。もちろんヒトでの確証はまだこれからなんですが、「細胞内の環境を整えることで、全体の老化スピードを遅くできる」って可能性はあるかもですなぁ。
