その際には、 以下のようにまとめています。

 

  • 効果レベル： そのストレス解消法がどれぐらい効果的かを５点満点で採点。 点数が高い方が効果は高くなる。
  • 難易度： そのストレス解消法を使うのが どれだけ難しいか。低、中、高の3段階で評価。
  • 使用場面：そのストレス解消法が解決してくれるネガティブな感情の種類。大きく4つのネガティブ感情に分類している。

    • 抑うつ： 涙もろい、悲しみ、意欲の喪失、活動性の欠如、楽しみの喪失、失望、罪悪感、傷心など。

    • 怒り： 怒りに満ちた行動と、そのような行動に伴う苦痛。怒りの反芻思考などもふくむ。

    • 不安： 心配、恐怖、社交不安、パニック、頭痛、緊張、心臓の高鳴り、息切れなど。

    • 衝動： 薬物乱用、強迫的な繰り返し（ゲーム依存、 スマホ依存など）、自傷行為、あるいは不健康な反復行動など。

第三部：高度な対処スキル

それでは、最後にメンタル改善の「大物」を登場させましょう。この第三部では、ストレスに効く対策のなかで最も強力な対策、つまり、ストレスの原因から気をそらすだけでなく、根本の原因をがっつりと変える変えるような対処法を取り上げます。その代わりに、これらのスキルは難易度がめっちゃ高いのが困ったものでして、フルに使いこなすにはセラピストを頼ったほうがいいかもしれません。

 

 

 

戦略化

  • 効果：5点
  • 難易度：中～高（解決しようとしている問題による）
  • 使用例：抑うつ、怒り、不安、衝動
  • 基本的な考え方：自分のコントロール下にあるものを把握し、それを使って自分の状況を改善しようとする方法を提案する。

 

ここまで取り上げてきたテクニックは、いずれもつらい感情から目をそらす のがメインの戦略でした。 ただし、 問題の目が深い場合は、これだけでは充分じゃないケースがよくあります。目をそらすだけでは実際の問題や障害を解決できないので、 結局同じ問題に悩み続けることになるんですよね。なので、 深いストレスにお悩みの方は、実際に根本的な問題を解決する方向に意識を向けるのが重要になります。このような考え方を、心理学では「戦略化」 と呼びます。

 

そのためには、以下のような手順を踏むと良いでしょう。

 

  1. まずは、問題をできるだけ明確に定義しましょう。「この状況をやわらげるためには、何が変われば いいのか？」を自問して、可能性がある解決策を全てリストアップしてください。

    リストができたら、 その解決策を見つつ、「実際に自分ではコントロールしようがない解決策を除外する」か「自分でコントロールできそうな解決策に変換する」というどちらかの作業を行いましょう。例えば、他人の行動が問題の場合、その人を強制的に変えることはできませんが、違うことをするように頼むことはできますんで。



  2. 自分でコントロールできる解決策をすべて比べて、最もうまくいきそうなものを選びます。その解決策は、すぐに実行に移せなくても構いません。解決策の候補が頭に浮かんでいるだけでもストレス解消の効果はあるので、気にせずに、最もうまくいきそうなものを選びましょう（ただし、この解決策は、 自分の中で「いつか必ず実行できる」と信頼していないと 効果がなくなるので、そこは注意してください）。



  3. 戦略化を行う際は、他人を巻き込んだ方がうまくいくことが多いので、 その点もチェックしてみて下さい。「 今の自分と似たような問題を経験をしたことがある人がいないか？」「私に助言してくれそうな人は誰か？」「自分が賢明だと思う人物は誰か？」 などと考えてみて、適当な人が見つかったら、その人物にあなたの問題を説明し、戦略を立てるのを手伝ってもらってください。 どの研究を見ても、自分1人でうだうだ考えるよりも、他人と戦略を立てた方が確実に効果が上がることがわかっていますので。

    ちなみに、誰かにアドバイスを求める場合は、相手がなんらかの提案をしてきた後、その提案をせっかちに否定しないように注意してください。ストレスにさらされていると、たいていの人は最善の解決策を見抜く能力が低下し、他人のアドバイスを拒否してしまうことがよくあるんですよ。 なので、ストレス化にあるときは、 どんなアドバイスでも、とりあえず受容してみるのが大事。

 

 

戦略化のガイドライン

  • 自分がコントロールできること、影響を与えられることに集中する： 良い戦略化は、常に自分が本当に影響を与えることができるものだけをターゲットにします。 例えば、 あなたが職探しをしていて数通の履歴書を送ったのに、どの雇用主からも返事がないとしましょう。 ここで、もしあなたの目標が「仕事を得ること」だとしたら、これは自分にはコントロールできないことです。 しかし、もし あなたの目標が、「毎日見つけた求人の中からベスト3に応募すること」なら、これは自分でコントロールできることです。


  • 理想的な状態に到達する方法は1つではない： ストレスがかかった人の多くは、目標に達するためにうまくいっていない特定の戦略にこだわってしまいがち。 例えば、 あなたが「トレッドミルで走る！」 という戦略を立てたのに、 なかなかジムに行けないくて ストレスを感じたとしましょう。 しかし、ここで「 自分の本当の目的は、トレッドミルで走ることではなく、カロリーを消費して活動的になることだ！」と思い出すことができれば、他の方法（屋外で散歩やランニングをする、ワークアウトビデオを使う、ショッピングモールでウォーキングをする）に 気づくことができるでしょう。 ストレスによる近視眼に惑わされないように、他にどうすれば望ましい状態に到達できるのか？自分の力の及ぶ範囲で、同じ結果を得られる方法はないか？と 自問してみてください。


  • 他の人に助けを求めるが、助けてもらう権利があるとは思わないこと： 自分が相談した相手がこちらを助けてくれるかどうかは、常に他の人が決めることだと思っておかないと、 断られたときにストレスが激動するので注意しましょう。


  • 最初のうちは解決策をジャッジしない： ストレス状態で解決策を考えようとすると、多くの人は、欠陥のある アイディアを ぐに排除し始めようとしがち。 それだと、新しいアイデアの創出を妨げることになるので、 解決策を出している間は、その内容の良し悪しをジャッジしないように気をつけてください。

 

 

 

 

思考ワーク

  • 効果：5点
  • 難易度：高（セラピストの助けが必要なことがある）
  • 使用例：抑うつ、怒り、不安、衝動
  • 基本的な考え方：自分の思考が気分にどのように影響するかを認識し、役に立たない思考を役に立つ思考に置き換えることを学ぶ。

 

「思考ワーク」ってのは、認知行動療法（CBT）の 最重要テクニックである「認知の再構成」を簡略化したバージョンです。おそらくCBTの最も中心的なスキルで、このテクニックでは、自分の考え方を変えることを学びます。つまり、自分に悪い影響を与えている思考に気づき、それをより有益な思考に置き換えるわけですね。 そうすることで、この新しい考え方がやがて習慣となり、否定的な考えに悩まされることが少なくなりますんで。


認知行動療法には複雑なやり方がいっぱいありますが、最もシンプルで楽な思考ワークのやり方は、以下のようなものです。

 

 

最もシンプルな思考ワークの手順

  1. ネガティブな感情が湧いたら、その感情を特定し、1から10までの尺度で評価する。

  2. 感情が変わる直前に何を考えていたか、自分に問いかけてみる。

  3. 直前に考えていた思考を検証する。これは本当に論理的な思考だろうか？ この思考が正しいという証拠はあるだろうか？

  4. 直前に考えていた思考よりも、もっと役に立ち、 ネガティブな感情につながりにくい新しい思考を考えてみる。

  5. 新しく考えた思考について、どのような感情を抱き抱くかを考える。その感情を、1から10の尺度で評価する。

  6. このエクササイズを1日に3回まで、あるいはネガティブな感情に大きく悩まされたときに行う。

 

シンプル思考ワークの例

  • 状況： テキストメッセージを送ったが、すぐに返事が返ってこない。
  • 最初の思考： 彼らは私のことなど気にしていない。
  • 最初の感情： 不安3/10、怒り7/10
  • 新しい思考： メールが返ってこないのは少し不満だが、 向こうにもいろいろな事情がある。
  • 結果の感情： イライラ 3/10 と 心配 5/10

 

  • 状況：クレジットカードの支払いを滞納し、高額な手数料を請求された。
  • 最初の思考：私はバカだ。
  • 最初の感情：怒り 6/10
  • 新しい思考：完璧な人間なんていない。でも、携帯電話にリマインダーをセットして、二度と同じことが起きないようにしよう。
  • 結果の感情：がっかりした 2/10

 

  • 状況：付き合っていた人が、もう会いたくないと言い出した。
  • 最初の思考： 人に会おうとしても無駄だ。いつも断られる。
  • 最初の感情： 落ち込む 8/10
  • 新しい思考： 今は傷つくが、そのうち治る。いつも拒絶されるわけではない。癒す時間を作ってから、また頑張ろう。
  • 結果の感情：悲しい 4/10

 

上記の例からも お分かりのように、新しい思考を作り出しても、気分に 完全に回復することは絶対にありません。しかし、 その代わりに、より適切な感情を感じられるようになるのが このワークのポイントであります。 これは私もいまだに日常的にやってますね。

 

 

 

根底にある信念の改善

  • 効果：5点
  • 難易度：高（セラピストの助けが必要な場合もある）
  • 使用例：抑うつ、怒り、不安、衝動
  • 基本的な考え方：自分自身と世界についての信念を調べ、自分を惨めにさせている信念を、役立つ信念に置き換えることができるようにする。

 

一般に、人間が経験する不必要な ネガティブな感情は、（世界や自分自身、あるいは他の人々について）私たちが持っている不合理な信念にまでさかのぼることができます。 この点で、有名なのは論理療法（REBT）で、 不合理な信念には、以下のようなものがあります。

 

不合理な信念の例

  • 「ひどい化」信念： 実際には、そこまででもないのに、絶対にひどいことだと思い込む傾向のことです。REBTによると、 人生の中で「本当にひどい！」 ということはほとんどないので、そのような言葉は、 最大級の悲劇に対して使うように指導されます。

    例 「あいつは 最低の人間だ！」

 

  • 「我慢できない」信念： 自分はこの状況に耐えられない！我慢できない！という信念です。 言い換えると、物事が思い通りに進まないときに、「 このままでは自分は全く幸福を得られない！」と思い込んじゃう傾向のことっすね。

    例 「もし彼女にふられたら、この先やっていけない！」

 

  • 「天罰」の信念：自己や他者や人生の状況を過度に批判するタイプの信念です。例えば、嫌な人物に「 レイシストだ」 みたいにレッテルを貼るようなやつですな。

    例 「人は私が正しいと思うことをするべきだ、さもなくばバカだ」

 

  • 「べき」信念： これはわかりやすいですね。「べき」の信念は、自分（または誰か他の人）は何か恣意的なルールに従う義務があり、それ以外のことをするのは絶対に考えられない考えます。

    例「みんな私に敬意を持って話さなければならない」

 

このような不合理な信念は、不幸、フラストレーション、神経症につながっちゃうので、 改善するに越したことたことはなし。一方で、 メンタル改善のメリットが大きい有益な信念には、 以下のようなものがあります。

 

  • 適度な評価：否定的な状況を「オール・オア・ナッシング」ではなく、程度の差はあるが連続的に評価するようにする。

    例 「これは悪い状況だが、 完全にひどいことではない」

 

  • 寛容の表明：人間は、さまざまな不快や不運を許容することで、さらに成長することを 意図的に思い出す。

    例 「 こいつは気に入らないが、耐えられる」

 

  • 誤りの受け入れ： すべての人間には欠点があり、欠点があるからといって無価値になるわけではないことを受け入れる。人間はとても複雑なので、その人の総合的な価値を評価することはおそらく不可能であることも考慮する。

    例 「彼の意見には賛成できないが、それでも尊厳を持って扱われるべき人間である」

 

  • ノールール思考：自分や他人が常に守らなければならない絶対的なルールなど存在しないことを受け入れること。

    例 「弱さを見せてはいけないと思って育ったからといって、そのような生き方を続ける必要はない」

 

  • 無条件自己＆他者受容：自分自身や他人の価値は、「何かをしたか？」や「 何を達成したか？」では決まらない。 つまり、「自分や他人を評価」したり「自分や他人の価値を評価」したりといった試みは不要だという考え方になる。

    ちなみに、相手を受け入れるということは、相手の行動を否定しないということではないことに注意してください。誰かがあなたを不当に扱った場合は、それに応じて自分の行動を調整する作業が必要になりますんで。 つまり、あなたの 言いなりになる必要は無いが、相手を罵倒したり非難したりする必要もないってことですね。例えば、あなたを虐待する人と付き合っているのなら、ただやめるように言い、それでもやめないなら関係を終わらせればOK。相手を変えるのはあなたの仕事ではありませんのでね。
