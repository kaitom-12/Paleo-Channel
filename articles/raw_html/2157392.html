女性向けの科学的な筋トレメニューを考えてみようじゃないか！の続きでーす(#1)。

 

 

このシリーズでは「女性の筋トレはどうすればいいのか？」をまとめてまして、前回は「筋トレにおいて男女の違いはあるのか？」について考えてみました。そこで今回はさらに具体的なトレーニングメニューをお伝えしていこうと思います。前回も言ったとおり、女性と男性では、そこまで筋肉の反応に差があるわけじゃないので、いままで取り上げてきた男性用筋トレメニューでも使えるんですが、筋トレに挑みたい女性の方は、こちらも使ってみてください。

 

 

 

 

女性と筋肉増強のための特別な配慮

ってことで、具体的なメニューをまとめる前に、男女ともに共通する筋トレの大原則をまとめておきましょう。前回も書いたとおり、女性向けのワークアウトの基本は男性とほぼ変わらないんですが、いくつか特別な注意点があるのでまとめておきます。

 

 

注意点1. 上半身のトレーニングを重視

前回も触れたように、女性は上半身が弱い傾向が大きめ。それに加えて、女性は下半身の引き締めを重視するケースが多いため、オーバーヘッドプレスやベンチプレスを避けがちだったりします。が、これだと腕が強化されないままになってしまうので、意識して上半身の筋肉群を鍛えておきましょう。

 

 

注意点2. ハムストリングスの筋力トレーニングを取り入れる

一般的に、女性は男性に比べてハムストリングス（太ももの裏の筋肉）が弱い傾向が大きめ。ここが弱いままだと、他の筋トレのパフォーマンスが下がりがちだし、女性によく見られるヒザ関節のダメージを増加させる要因になっちゃうんですよ。この問題を防ぐためにも、脚のトレーニングに加えて、ハムストリングス専用の多関節エクササイズも加えておきたいところです。

 

 

注意点3.負荷のかかるエクササイズを必ず行う

これも前述したとおりで、女性は男性よりも骨がスカスカになりやすい傾向がありまして、このトラブルを予防するには、骨と筋肉に十分な負担をかけておく必要があります。基本的には、スクワットや デッドリフトなど、下半身の複数の筋肉をまとめて鍛えられるトレーニングメニューをガッツリ取り入れるのがおすすめです。

 

 

注意点4. ジムにはこだわらない

女性の場合、ジムで高負荷のトレーニングをしなくても、自重エクササイズだけでも十分に筋肉が成長したりします。いきなりジムでやらずとも、自重かダンベルを使っても骨と筋肉に十分な負担はかけられるし、そっちのほうが精神的にも楽でしょうから、あまりジムにこだわらないことをおすすめします。

 

 

注意点5.有酸素運動を取り入れる

これは当然ですが、筋トレだけでは有酸素トレーニングの効果は得られないので、週に2～3回のセッションをお勧めします。また、これらのセッションには、HIIT（高強度インターバル・トレーニング）とおだやかなペースの有酸素運動の両方を含めてください。高負荷と低負荷の有酸素運動をどちらも行うことで、より大きなアンチエイジング効果を得られますんで。

 

 

 

 

女性のためのベストな筋トレプランの例

では、具体的な筋トレメニューの話に移りましょう。上記の点をふまえて、ここからのメニューは、以下のような点を重視しております。

 

  • 多関節トレーニング（一度に多数の筋肉を刺激するトレーニング）に集中し、各セッションの最後に単関節トレーニング（特定の筋肉を刺激するトレーニング）を取り入れる。

 

  • ハムストリングスのトレーニングにも重点を置き、太ももと尻のエクササイズに十分なボリュームを取る。

 

  • 上半身のトレーニングも重視し、さらに運動能力を高めるためのボディ・エクササイズにも取り組む。

 

  • 有酸素運動の日は、2種類の有酸素運動と体幹トレーニングを行う。

 

ってことで、これらのポイントを守っておけば、良い感じにエクササイズに取り組むことができるはず。実践の際は、まずは「必ず正しいフォームで行う」ってのを第一に意識してください。

 

 

 

1日目：筋トレ

  1. バックスクワット（ダンベルスクワットでもOK）　8回4セット　セット間に2分の休憩

  2. ダンベルショルダープレス 　8回3セット 　セット間に2分の休憩

  3. ダンベルワンハンドローイング　8回3セット（片腕ごと） 　セット間に1分30秒の休憩

  4. ダンベル・ローマニアン・デッドリフト　10-12回3セット 　セット間に1分30秒の休憩

  5. レッグアブダクション（マシンがないときはバンドなどで代用）　12-15回3セット　セット間に 1分の休憩


この筋トレの後、以下のサーキットトレーニングを3周する。

 

 

  • サーキット：
  1. ロープクランチ（マシンがないときはリバースクランチで代用）　10回

  2. ロープ・プッシュダウン（マシンがないときはダンベルエクステンションで代用）　10回

  3. ロープ・パロフ・プレス（マシンがないときはプランクショルダータップで代用）　10回

  4. ロピー・フロント・プルダウン（マシンがないときはダンベルプルオーバーで代用）　10回

  5. ボディ・スクワット　10回

 

 

2日目：低負荷有酸素運動

  • 自宅かジムで、45～60分の有酸素運動を一定のペースで行う（早歩きまたは軽いサイクリングなど）

  • 最大心拍数の60～70％を保つ

  • 時間があれば、ヨガやピラティスなどの強度が低い運動も追加する。

 

 

3日目：アクティビティ

友人などと60分ぐらいのスポーツを行う。仲間がいない場合は、低負荷有酸素運動の後に、短いウェイト・サーキットかHIITを行う。

 

 

4日目：筋トレ

  1. ベンチプレス（バーベルがない場合は腕立て伏せで代用）　6回4セット　セット間に2分の休憩

  2. バーベル・ヒップスラスト（バーベルがない場合はダンベル・ヒップスラストか自重ヒップスラスト代用）　8回4セット　セット間に2分の休憩

  3. シーテッド・バックロー （マシンがないときはベントオーバー・ダンベルローで代用）　10-12回3セット　セット間に1分30秒の休憩

  4. レッグプレス（マシンがないときはダンベル・スプリットスクワットで代用）　10-15回5セット　セット間に1分30秒の休憩

 

この筋トレの後、以下のサーキットトレーニングを3周する。

 

  • サーキット：
  1. ウォーキング・ランジ　10-20回

  2. フラッターキック 50回

  3. ダンベル・オーバーヘッド・トライセップス・エクステンション　10回

  4. ステップアップ 　20回

  5. ダンベル・カール　10回

 

 

5日目：休息または低強度のグループクラス

完全に休むか、ヨガやピラティスなどの軽度なエクササイズを行う。

 

 

6日目：筋トレ

  1. トラップバー・デッドリフト（バーがない場合はシングルレッグRDLで代用）　6回3セット 　セット間に 2分の休憩

  2. インクライン・ダンベルベンチプレス　8回3セット 　セット間に 2:00レスト

  3. プリー・スクワット　10-12回3セット 　セット間に1分30秒の休憩

  4. ラットプルダウン（マシンがないときはダンベル・プルオーバーで代用）　10-12回3セット 　セット間に1分30秒の休憩

  5. ロープ・ラテラル・レイズ（マシンがないときはダンベル・ラテラル・レイズで代用）　12-15回2セット　セット間に1分30秒の休憩

 

これらの筋力トレーニングの後、以下のサーキットを3回行う。

 

  • サーキット：
  1. 腕立て伏せ　10回

  2. ロープ・フェイス・プル（マシンがないときはダンベル・リバースフライで代用）　10回

  3. リバース・ランジ　10-20回

  4. ロープハイロウ（マシンがないときはチェスト・サポート・ダンベルロウで代用）　10回

  5. ホロー・ロックス　30秒

 

 

 

7日目：ジムでの有酸素運動と無酸素コンディショニング

この日は、激しめの有酸素運動を行いましょう。以下は、一例です。

 

  • エアロバイク　20分

  • 階段登り　5分（できるだけ多くの階段を登る）

  • 好きなHIIT

 

ってことで、女性向けトレーニングの具体例は以上です。これをそのままやってもいいし、もちろん好きにアレンジしても構いません。ここから、週ごとに少しずつ重量を加えていくと、確実に筋肉が育っていくはずであります。
