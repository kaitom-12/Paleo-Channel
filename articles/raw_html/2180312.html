このシリーズでは、「やるのは大変だけど実践すれば効果は抜群」でおなじみの心理セラピーである「スキーマ療法」の基本を述べてまして、現在は「解決編」に入っております。スキーマ対策については、「自分でできるスキーマ療法ワークブック」という名著が存在しますが、これはガッツリスキーマを正す趣旨で書かれていまして、実践が大変なところもあったりします。

 

そこでこのシリーズでは、スキーマ療法の研究で有名なマシュー・マッケイ先生らの調査をベースに、もうちょい手軽だけど、十分な効果を見込めるエクササイズをご紹介します。まぁトラウマレベルのスキーマであれば、「自分でできるスキーマ療法ワークブック」に取り組むべきでしょうが、中程度の対人トラブルや社交不安の方であれば、いい具合に使っていただけるのではないかと。

 

さて、前回から「スキーマ感情と向き合う」作業をはじめてまして、スキーマが引き起こすやっかいな感情に対して、現実と想像の２方向から自分の身をさらしていく方法をチェックしてきました。今回もその続きで、エクスポージャーの効果をさらに高める手法をチェックしていきましょう。

 

 

 

ステップ16. スキーマ感情と向き合う（続き）

トレーニング16.2 　エクスポージャーの記録

エクスポージャーの練習をした場合は、想像を使ったエクササイズにせよ、現実を使ったエクササイズにせよ、やったことはすべて記録しておきましょう。これをやっておくとモチベーションを維持するのに役立つし、自分が特に苦手とする感情を理解できますからね。

エクスポージャーで記録する項目は、以下のとおりです。

 

  1. 感情：エクスポージャーで経験している感情を書く。


  2. トリガー：自分のネガティブな感情を引き出した原因を書く。


  3. 想像 or 現実：実行したエクスポージャーが、想像のものか、それとも現実のものかを書く。


  4. 結果：以下のポイントから、実感できたものをものを書く。

    1. ネガティブな感情を観察しているうちに、より自分の感情を受けいれ、回避しなくなったと感じたか?

    2. ネガティブな感情の影響力や質には変化があったか？　あるいは、ネガティブな感情が他のものに変化したか？

    3. ネガティブな感情に慣れることはできたか?

    4. エクスポージャーを行った結果、衝動に駆られて行動したか？　スキーマ対処行動を使用したか？　それとも、価値観に基づく意図で行動できたか?

    5. ネガティブな感情との関係に、何か変化はあったか?（たとえば、「ネガティブな感情の波を眺めるのがより心地よくなった」とか）

 

 

エクスポージャーの記録例

  • 感情 → トリガー → 想像  or 現実 → 結果
    • 怒り／挫折感 → 自分の仕事の速さを自慢する同僚 。 → 想像 → 気持ちに変化はなく、少し不安。同僚にやり返したい気持ちが、どうやって盛り上がるのかを理解した。

    • 怒り／挫折感 → 私がミスをしたときに、同僚が同情するふりをした。 → 想像 → 気持ちに変化はない。

    • 怒り／挫折感 → ボーイフレンドが私の買った服を批判した。 → 想像 →  少し動揺がやわらいだ。

    • 傷ついた／拒絶された → ボーイフレンドが遅刻した。 → 想像 → 長く続けていくうちに、その感覚に少し慣れ、より受け入れられるようになった。

    • 怒り／挫折感 → 同僚が上司と親しいことを自慢する。 → 想像 → 自分のなかにわきだす批判的な思考に気づき、失敗の感覚をより受け入れやすくなり、感覚は悲しみに変わった。

    • 怒り／挫折感 → 同僚は売り上げが自慢だ。 → 現実 → スキーマ対処行動に抵抗し、価値にもとづく行動ができた。

    • 失敗の予感 → 上司が私のミスを批判してきた。 → 現実 → スキーマ対処行動が発動し、上司に言い訳をしてしまい、そのことによって落ち込んだ。エクスポージャーがうまくいかず、結局は辛い感情を避けた。

    • 怒り／自分に何か問題があるように感じる → 同僚がこちらを疑うかのような目でこちらを見てきた。 → 現実 → 感覚をより受容できるようになるまで、長い時間のエクスポージャーができた。自分のネガティブなジャッジにラベルを貼った。スキーマ対処行動は発動せず。同僚に何か問題があるのかを尋ねることができた。

    • 失敗の予感 → ボーイフレンドが怒っている。 → 想像 → 感情を認識するのが遅くなった。

    • 傷ついた／拒絶された → 彼氏がデートをキャンセル。 → 現実 → スキーマ対処行動に入る前に、彼氏に電話すると伝えられた。ネガティブな感情がやわらぐまで、長時間エクスポージャーできた。落ち着いた気分で新しいデートを予定できた。

 

上記の事例のように、ひとつのトリガーに複数のネガティブな感情がわき上がるのはよくある話（「怒り/失敗」「傷つき/拒絶」みたいな）。たいていは、複数の異なるスキーマ感情が現れるものなんで、そんな時は、「自分はおかしいのでは……」とか思わずに、それぞれの感情について受容と忍耐の能力を鍛えていくようにしつつ、スキーマ対処行動の代わりに、価値観にもとづく行動の量を増やすように仕向けていきましょう。

 

 

 

ステップ17. 受け入れ

エクスポージャーに慣れてきたら、今度は自分のスキーマ感情を受け入れる作業をやっていきましょう。スキーマが引き起こす感情はつらいもんですが、ほとんどの人は、成長過程で避けられない傷を抱えているものなんで、生きていることの葛藤の一部として受け入れるしかないんですよ。

 

ってことで、ネガティブな感情を受け入れるためのトレーニングを見てみましょうー。

 

 

トレーニング17.1 受容と慈悲の瞑想

受け入れのメンタルを鍛えるのにも、瞑想は役立ってくれます。ここで取り上げる「受容と慈悲の瞑想」は、

 

  1. 抵抗することなくスキーマの感情を観察する
  2. スキーマの感情は、生きていく上で必要なこととして受け入れる
  3. 感情の痛みに直面している自分自身に優しい感情を抱く

 

ってあたりのメンタルを養うのに役立つんですよ。ここから、具体的なスクリプトを紹介しますが、これを読み上げたものを録音して使うか、半眼で文章を読みながら行ってください。

 

椅子に座り、そっと目を閉じるか、半眼を維持しましょう。それから、深い呼吸を何度か行い、呼吸に意識を集中してください。

それでは、あなたにとって重要な人間関係の中で、あなたのスキーマのひとつが発動した瞬間を思い出してください。誰かに裏切られた、見捨てられた、欠陥を指摘された、 恥ずかしさを感じたような瞬間です。

 

そのスキーマが発動した瞬間の、最も核心的な感覚を思い出しましょう。そのスキーマがもたらす感情は、体のどこに変化をもたらしていますか?

 

今日1日を振り返って、その気持ちが今日何回ほどわいてきたかを思い出してみてください。 さらに、この1週間では、何回あったでしょうか?　過去1カ月ではどうでしょうか?　また、この感覚を初めて抱いたときのことを思い出せるかどうかも考えてみてください。

 

その感覚を思い出しながら、様々な人間関係の中で、同じような感覚を味わったことがないかを考えてみましょう。そして、この感覚がもたらす痛みに寄り添い、呼吸を整えてください。この体験から逃げ出したい衝動がわきあがったら、その衝動に気づき、この体験と一緒にいられるかどうか確かめてください。

 

その感覚に立ち向かって抵抗することなく、この感覚を完全に体験するのはどんな感じでしょう?　自分に対する思いやりと優しさを持って、その感覚を100%を体感することを自分に許せるでしょうかか？

 

自分の体験と一緒にいるだけのスペースを、心の中に作ることができますか?この経験は、抵抗したり避けたりしなければならないものですか?　それとも、この痛みはあなたが扱うことができるもの、つまり何も判断せずにただ経験することができるものなのでしょうか?

 

続いて、スキーマが引き起こす思考、感情、感覚、衝動がわき上がってきたとしても、それらを「泣いている赤ん坊」のようにみなし、ただ優しさをもってそれらすべてを観察してみましょう。

 

そして、この痛みを自分の中に招き入れ 、自分の一部分として受け入れることができるかどうかを確かめてみてください 。何も正そうとする必要はなく、何も変える必要もありません。

 

ここまでの瞑想が終わったら、ゆっくり目を開きましょう。

 

ってことで、「受容と慈悲の瞑想」のやり方は以上です。

 

ちなみに、私の体験談を申し上げますと、この瞑想をしてみると、すぐに羞恥心、虚無感、誰かから批判されることへの恐れといったおなじみの感情に襲われたりしました。が、ここで瞑想の指示どおりに、不快感に抵抗せずにただ観察していたところ、似たような不快感を味わったのが4歳ぐらいまでさかのぼれる事実に思い当たってビビりました。「自分はどんだけ長いあいだ同じ不快感に悩んでいたのか……」みたいな。

 

でもって、これをやってると、確かに自分のスキーマ感情が「泣いてる子ども」みたいに感じられるから不思議なもの。ついでに「自分もなかなかがんばってきたもんだ」なんて感覚もわいてきまして、人生で経験してきたことを深掘りできた感じがしております。

 

先行研究でも、このタイプの瞑想は、だいたい4回ぐらい行うことで自分の感情にオープンになり、自分の葛藤に対して思いやりを持てるようになると言われてますんで、まずはそれぐらいやってみるのがおすすめです。ではまたー。
