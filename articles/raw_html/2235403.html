このシリーズでは、年をとっても脳と体が元気に動きまくる“スーパーエイジャー”の最新研究をもとに、いくつになってもピンピンした状態を保つための知見を考えております。

 

で、そのために本シリーズでは、スーパーエイジャー研究で有名なトポル先生が提唱する『Lifestyle+（ライフスタイル・プラス）』を掘り下げてまして、前々回から「運動」の話に入っております。「スーパーエイジャーレベルの運動を目指すには、どうすればいいのか？」ってポイントですな。

 

でもって前回は、心肺機能、筋力・骨の機能を高めるエクササイズについて見てみたんで、今回はその続きであります。

 

 

 

能力3．バランスを伸ばしたい人

バランス能力ってのは、

 

片脚で立てるか？
段差でふらつかないか？
方向転換で体勢を崩さないか？
つまずいたときに立て直せるか？

 

みたいな、日常の行動の自由度を左右する、かなり実用的な能力のひとつ。こいつが衰えちゃうと、外出が怖くなり、活動量まで落ちやすくなるんで、ぜひどうにかしておきたいところです。

 

バランスを伸ばしたい人は、まず「片脚で支える」「重心を移動させる」「方向転換に慣れる」の3つを意識するといいでしょう。体幹の筋力を保つように意識すると、姿勢、腰痛予防、移動能力などが改善しますんで、脚力・体幹・可動性とセットで考えるのがおすすめであります。

 

また、バランスを鍛えるためには、有酸素運動や筋トレだけでは不十分なことが多くて、横方向の動き、片脚で支える動き、重心を移す動き、急に止まる動きなどを取り入れる必要があることも覚えておいてください。私もこの点は完全に甘く見ていたので、最近はバランスも意識して暮らしております。

 

で、この能力については、いきなり難しいことをやる必要はなし。転倒を防ぐための運動で転んだら本末転倒なので、かなり慎重にレベルを上げるのが吉です。

 

レベル対象運動例目安
レベル0ふらつきが不安な人椅子や壁につかまりながら立つ、左右に重心移動1日1〜3分
レベル1片脚立ちが苦手な人支えあり片脚立ち、つま先立ち、かかと上げ左右10〜20秒ずつ
レベル2片脚で少し立てる人支えなし片脚立ち、かかとつま先歩き左右20〜45秒を目指す
レベル3前後左右の動きが少ない人横歩き、後ろ歩き、8の字歩き、ゆっくり方向転換週3〜5回、3〜5分
レベル4足腰の支える力も伸ばしたい人ステップアップ、ランジ、片脚ヒップヒンジ週2〜3回
レベル5かなり慣れている人軽いジャンプ、ダンス、太極拳、スポーツ、登山回復と安全を見ながら

 

レベル0：まず「ふらつかずに立つ」ことを目指す

片脚立ちが怖い人、最近つまずきが増えた人、段差や暗い道が不安な人は、まずここからでOK。バランス能力を一気に伸ばそうとはせず、安全な環境で、体重移動に慣れることを目指してください。

 

具体的には、以下のような運動から始めましょう。

 

  • 壁や椅子に手を添えて立つ
  • 両足で立ったまま、左右にゆっくり重心を移す
  • 前後に少しだけ重心を移す
  • 椅子から立つ・座る動作をゆっくり行う
  • キッチン台や洗面台の前で、軽くつま先立ちをする

 

この段階では「支えを使う」のが正解。バランス練習は、怖さが強いと体が固まり、かえって動きが悪くなりますからね。目安は1日1〜3分で、歯磨き中、電子レンジ待ち、コーヒーを淹れる前などに実践するぐらいで十分でしょう。

 

レベル1：支えありの片脚立ち

次は、片脚で自分を支える能力を伸ばしましょう。「片脚立ちテスト」はバランス能力を見る方法の定番で、60歳以上なら30秒以上、40〜50代なら45秒以上がひとつの目標になります。また、10秒の片脚立ちができない人では、全死亡リスクが高くなりますんで、ここもチェックしておいてください。

 

ただし、これはいきなり「支えなしで45秒立て！」という話ではなく、最初は支えありでOKです。

 

  • 壁に指を軽く添えて片脚立ち
  • 椅子の背もたれに手を置いて片脚立ち
  • 洗面台に手を添えて片脚立ち
  • 左右10秒ずつから始める

 

みたいにしてみてください。ここでは手に体重を預けすぎないことを目指しましょう。最初はしっかり支えてもいいんだけど、慣れてきたら「指先だけ添える」ぐらいにして、少しずつ自分の足で支える割合を増やすのが吉であります。

 

レベル2：支えなしの片脚立ち

支えありで安定してきたら、次は支えなしの片脚立ちに進みましょう。このレベルの目安は、以下のように考えるとわかりやすいっすね。

 

段階目標判断
第1目標左右10秒最低限の確認ライン
第2目標左右20〜30秒日常の安定感を作るライン
第3目標40〜50代なら45秒、60代以上なら30秒トポル先生が紹介する目安

 

このレベルでやることとしては、

 

  • 壁や椅子の近くに立つ
  • 片脚を少しだけ浮かせる
  • 目線は正面に置く
  • 足裏のどこに体重が乗っているかを感じる
  • ふらついたらすぐ支える

 

みたいになります。ここで無理に我慢しないのが大事で、バランス練習は、限界まで粘るよりも、安定したフォームで何度もくり返すほうが安全なんで。

 

レベル3：横方向・方向転換を入れる

片脚立ちに慣れたら、次は「動きながらのバランス」に進みます。現実の世界で起きる転倒ってのは、ただ静かに立っているときよりも、

 

  • 曲がる
  • 振り返る
  • 段差を越える
  • 人や物を避ける
  • 急に止まる
  • 足元が少し悪い場所を歩く

 

みたいな場面で起きやすいんで、静止状態だけでなく、動きながらの安定性も鍛えたいわけです。

 

このレベルでは、以下のような運動を取り入れるのがおすすめです。ちなみに、トポル先生は、バランス改善の方法として「片脚立ち」や「かかとつま先歩き」を推奨してますんで、合わせて取り入れてみてください（個人的には「片脚立ち」がいいかなーって印象）。

 

運動狙いやり方
横歩き横方向の安定性左右に5〜10歩ずつ、ゆっくり移動
かかとつま先歩き足裏感覚と細かい姿勢制御前に出した足の「かかと」を、後ろ足の「つま先」にくっつけるようにして、一直線上を歩く。平均台の上を歩くように、足を一直線に並べて進むイメージ
8の字歩き方向転換への慣れ椅子やペットボトルを2つ置き、8の字に歩く
ゆっくりターン振り返り・方向転換急に回らず、3〜4歩かけて向きを変える

 

レベル4：脚力とセットで鍛える

バランス能力を高めるためには、脚力、体幹、股関節、足首の可動性を鍛えるのも大事。筋力低下は移動能力やバランスに関わるんで、バランスを伸ばしたい人ほど、片脚立ちだけでなく、下半身の筋トレも入れたほうが吉であります。

 

ここで実践すべきは、以下のような運動です。

 

  • スクワット
  • ステップアップ
  • ランジ
  • ヒップヒンジ
  • カーフレイズ
  • 片脚ヒップヒンジ

 

なかでも個人的なおすすめはステップアップで、低い段差に片脚で乗り、ゆっくり上がって、ゆっくり下りるだけでOK。これでも、脚力、片脚のサポート、足首の安定、段差への対応をまとめて練習できますんで。これについては、最初は、

 

  • 低い段差で行う
  • 壁や手すりの近くで行う
  • 左右5回ずつから始める
  • 膝や腰に痛みが出るなら中止する

 

ぐらいで十分であります。

 

レベル5：複雑な動き・スポーツを取り入れる

レベル4が普通の日常になってきた人は、さらにバランスを「動ける体を保つ能力」へと展開させていきましょう。ここでの候補は、

 

  • 太極拳
  • ダンス
  • 軽いジャンプ
  • ラダー運動
  • 登山
  • ハイキング
  • 卓球、テニス、バドミントンなどの軽いスポーツ

 

などでしょう。私が近ごろダンスやトレランにいそしんでるのも、バランスを鍛えるのに役立つからってところもあったりします。

 

この段階では、単に片脚で立つだけではなく、

 

  • 前後左右に動く
  • リズムに合わせて動く
  • 相手やボールに反応する
  • 足場の変化に対応する
  • 体をひねりながら姿勢を保つ

 

といった能力を使うことを意識してくださいませ。ただし、転倒リスクがある人がいきなりジャンプやスポーツを始めるのは危険なので、レベル0〜4が安定してからでOKです。

 

 

バランス運動の強度はこう上げる

ということで、以上をざっくりまとめると、バランス運動ってのは、回数を増やすよりも、条件を少しずつ難しくするのが基本だとお考えください。

 

難しくする方法例注意点
支えを減らす両手で支える → 片手 → 指先だけ → 支えなし必ず壁や椅子の近くで行う
時間を伸ばす10秒 → 20秒 → 30秒 → 45秒フォームが崩れる前に終える
動きを足す片脚立ち → 横歩き → 方向転換 → ステップ運動速さより安定を優先
環境を変える室内 → 屋外の平地 → 芝生 → 緩い坂不安定な場所は上級者向け
認知負荷を足す歩きながら数える、方向を変える、リズムに合わせるふらつくなら戻す

 

ちなみに、よく「目を閉じて片脚立ちをする」って方法もよく耳にしますが、これはかなり難度が上がるのでご注意あれ。転倒リスクがある人にはおすすめしません。こいつをやる場合は、必ず壁や机のそばで、数秒だけにしておいたほうがいいでしょう。

 

 

2週間の自己実験

バランスを伸ばしたい人は、まず以下のどれかを2週間だけ試してみてくださいませ。

 

タイプ2週間の実験見るポイント
ふらつきが不安支えあり片脚立ちを左右10秒ずつ、毎日怖さ、ふらつき、足裏の安定感
歩行中心の人横歩き10歩×左右、かかとつま先歩き10歩を週3〜5回方向転換、足首の安定、つまずきやすさ
脚力も弱い人椅子スクワット8回＋支えあり片脚立ち左右10秒を週3回立ち上がりやすさ、段差の不安、膝や腰の痛み
少し慣れている人片脚立ち30秒＋8の字歩き＋ステップアップを週3回ふらつき、疲労、翌日の脚の重さ

 

ここでの判定基準はシンプルでして、

 

  • 片脚立ちの時間が少し伸びる
  • 靴下を立って履くのが少し楽になる
  • 方向転換でふらつきにくくなる
  • 段差への不安が少し減る
  • 歩いているときの足元の怖さが減る

 

このあたりが改善していれば、その運動は自分に合っている可能性がありますね。逆に、ふらつきが増える、膝や腰が痛む、怖さが強くなる、翌日に脚が重すぎるなら、レベルを下げてください。

 

いずれにせよ、心肺機能や筋トレと違って、かなり短時間でも始められるのがバランス練習のいいところ。なので、

 

  • 歯磨き中に支えあり片脚立ち
  • 電子レンジ待ちで左右の重心移動
  • 廊下でかかとつま先歩き
  • 散歩の途中でゆっくり方向転換
  • 階段の前でステップアップを数回

 

みたいに、生活の中に混ぜることを心がけるだけでも、それなりのメリットを得られるはずであります。お試しをー。

 

 

 

能力4．姿勢・可動性を伸ばしたい人

ここで言う「姿勢・可動性」ってのは、ざっくり言えば、

 

背中が丸まりすぎないか？
肩・股関節・足首がちゃんと動くか？
歩幅が狭くなっていないか？
深くしゃがめるか？
長時間座った後でも、スムーズに動き出せるか？

 

みたいな能力のこと。この能力が低下しちゃうと、歩幅が狭くなり、腰や肩が固まり、日常動作そのものがだんだんつらくなっちゃうんですな。

 

ってことで、姿勢・可動性を伸ばしたい人は、まず 「座りっぱなしを切る」「背骨・股関節・足首を動かす」「体幹と背中で姿勢を支える」 の3つを意識するとよいでしょう。特に、1日の座位時間が長い人、PC・スマホ時間が長い人、腰痛や肩こりがある人、歩幅が狭くなった人、深くしゃがみにくい人は、姿勢・可動性を優先したほうがいいでしょう。

 

姿勢・可動性のトレーニングは、いきなりヨガやピラティスを完璧にやる必要はありません。むしろ最初は、「同じような姿勢が続いている状態を減らす」だけでも十分です。

 

レベル対象運動例目安
レベル0座る時間が長い人30〜60分に1回立つ、軽く歩く、肩を回す1回1〜2分
レベル1肩・腰・股関節が固まりやすい人肩甲骨回し、胸椎回旋、股関節回し、足首回し毎日3〜5分
レベル2歩幅が狭い、しゃがみにくい人動的ストレッチ、ランジ、深めのスクワット練習週3〜5回、5〜10分
レベル3姿勢を保つ力も弱い人体幹トレ、ローイング、ヒップヒンジ、グルートブリッジ週2〜3回
レベル4全身をなめらかに動かしたい人ヨガ、ピラティス、太極拳、全身のフロー運動週1〜3回、20〜30分
レベル5運動・趣味・外出の質を上げたい人筋トレ、速歩、登山、スポーツ、ダンスと組み合わせる目的に合わせて調整

 

レベル0：まず「座りっぱなし」を減らす

姿勢・可動性が落ちやすい人が最初にやるべきなのは、座りっぱなしを減らすことであります。ここでの目的は、体を鍛えるというより、

 

関節と筋肉を“固まりっぱなし”にしないこと

 

みたいに考えてもらえるといいでしょう。具体的には、以下ぐらいで十分です。

 

  • 30〜60分に1回立つ
  • 立ったついでに10〜20歩だけ歩く
  • 肩を5回まわす
  • 背伸びをする
  • 椅子から立つ・座るを3〜5回だけ行う
  • 昼休みに3〜5分だけ外を歩く

 

この段階では、とにかく同じ姿勢を続ける時間を短くするのが大事。姿勢の問題は、1回のエクササイズ不足というより、「1日中ほぼ同じ姿勢でいること」から起きやすいんで。

 

レベル1：肩・背中・股関節・足首を動かす

座りっぱなしを少し減らせるようになったら、次は関節を大きく動かしましょう。姿勢・可動性で優先したいのは、主に以下の4カ所であります。

 

部位固まると起きやすいこと運動例
肩甲骨・肩肩こり、腕が上げにくい、猫背肩回し、肩甲骨寄せ、壁スライド
胸椎背中の丸まり、首肩のこわばり胸椎回旋、背伸び、四つ這い回旋
股関節歩幅低下、腰のこわばり、しゃがみにくさ股関節回し、ランジ、ヒップヒンジ
足首つまずき、深くしゃがめない、歩行の不安定さ足首回し、カーフレイズ、足首前方移動

 

これらは、最初は1日3〜5分でOKなんで、

 

  • 肩回し：前後5回ずつ
  • 胸椎回旋：左右5回ずつ
  • 股関節回し：左右5回ずつ
  • 足首回し：左右5回ずつ

 

ぐらいをやっとけばいいでしょう。この時、決して痛みを我慢して伸ばさないように注意。姿勢・可動性の運動は「大きく、なめらかに、痛みなく」が基本ですんで。

 

レベル2：日常動作に近い可動域を取り戻す

関節を動かすことに慣れてきたら、次は日常動作に近い形で可動域を使いましょう。具体的には、

 

  • しゃがむ
  • 立ち上がる
  • 股関節を折る
  • 腕を上げる
  • 歩幅を広げる
  • 床に近づく

 

といった動きを意図的に増やすわけです。ここで定番なのは、以下のような運動であります。

 

運動狙いやり方
椅子スクワットしゃがむ・立つ動作椅子に座るようにお尻を引き、ゆっくり立つ
ランジ股関節、歩幅、片脚支持前後に足を開き、浅く沈む
ヒップヒンジ股関節を折る、腰を守る背中を丸めず、お尻を後ろに引く
壁スライド肩・背中・胸の可動性壁に背中をつけ、腕を上下に動かす

 

このレベルでは、柔らかさだけでなく、動ける範囲を実際に使うのがポイント。たとえば、股関節が少し柔らかくなっても、日常でしゃがまなかったら、その可動域は使われないことになっちゃうので。肩が少し動くようになっても、腕を上げる動作をしなければ、動作として定着しないんですよ。なので、姿勢・可動性を伸ばすなら、広げた可動域を、日常動作や軽い筋トレで使うところまでセットにしたいわけです。

 

レベル3：体幹・背中・お尻で姿勢を支える

このレベルでは、姿勢の改善を狙っていきましょう。姿勢が悪いと肩こりや腰痛だけでなく、歩行やバランスにも影響が出ちゃいますんで。

 

姿勢を保ちたいなら、ストレッチだけでなく、体幹・背中・お尻を鍛える必要があるんで、以下のような運動が大事になってきます。

 

  • ローイング
  • グルートブリッジ
  • ヒップヒンジ
  • プランク
  • サイドプランク
  • バードドッグ
  • 軽いデッドリフト系

 

特におすすめしやすいのは、以下の3つです。

 

運動鍛えるところ役立つ場面
ローイング背中、肩甲骨まわり猫背、肩こり、長時間PC作業
グルートブリッジお尻、股関節まわり腰の負担、歩幅、立ち上がり
バードドッグ体幹、背中、バランス姿勢保持、腰痛予防、歩行の安定

 

ここでの目安は、週2〜3回。最初は各種目8〜12回を1〜2セットで十分。ここでも、「限界まで追い込む」より、姿勢を崩さずにできる範囲で行うのが大事になります。

 

レベル4：ヨガ・ピラティス・太極拳で全身をつなげる

ある程度、関節が動き、体幹や背中も使えるようになってきたら、今度は全身をなめらかに動かす運動を入れてください。ここで候補になるのが、

 

  • ヨガ
  • ピラティス
  • 太極拳
  • 動的ストレッチ
  • 全身を使うフロー運動

 

あたりです。前屈のようなストレッチ、ピラティス、ヨガは柔軟性を助けてくれますんで、使い方としては、

 

  • 肩・背中・股関節を動かすためにヨガを使う
  • 体幹を安定させるためにピラティスを使う
  • 重心移動とバランスも兼ねて太極拳を使う
  • 筋トレ前の準備として動的ストレッチを使う

 

みたいに考えるのがいいでしょう。目安は、週1〜3回、20〜30分。寝る前に長くやると、人によっては眠りやすくなることもありますが、きついポーズを取ると逆に目が冴える場合があるので、睡眠への影響も見ておくといいでしょう。

 

レベル5：速歩・筋トレ・趣味の動作とつなげる

最後のレベルでは、姿勢・可動性を単独の運動で終わらせず、実際の生活や趣味につなげていきましょう。たとえば、

 

  • 姿勢よく歩きたい → 股関節・足首の可動性＋速歩

  • 腰痛を悪化させず動きたい → ヒップヒンジ＋グルートブリッジ＋痛みのない歩行

  • デスクワークを長く続けたい → こまめに立つ＋胸椎運動＋背中の筋トレ

  • 楽器や絵を続けたい → 肩甲骨・胸椎・体幹＋屋外歩行

  • 山歩きやキャンプをしたい → 股関節・足首＋坂道歩き＋脚トレ

 

という感じです。これは前回でも整理した通り、「将来やりたいこと」から必要な能力を逆算する発想を使ってまして、たとえばデスクワークを長く続けたいなら、姿勢保持力、股関節の可動性、首肩の柔軟性、血流が必要になりますし、姿勢よく歩きたいなら、体幹、背中の筋力、股関節、足首の動きが重要になりますからね。

 

 

姿勢・可動性の難易度の上げ方

姿勢・可動性トレーニングは、ただ時間を増やせばいいわけじゃないんで、以下のように少しずつ条件を上げると安全であります。

 

難しくする方法例注意点
頻度を増やす週3回 → 毎日3分痛みが出るなら戻す
可動域を広げる浅いスクワット → 深めのスクワット関節に痛みがない範囲で行う
動作をゆっくりにする反動で動く → 3秒かけて動くコントロールできる範囲で行う
筋力を足す股関節回し → ランジ、ヒップヒンジフォーム優先。重さは後でよい
全身動作にする単独ストレッチ → ヨガ、ピラティス、太極拳きつすぎるポーズは避ける

 

姿勢・可動性の運動でやりがちなミスは、痛いところまで伸ばすことです。健康寿命が目的なら、柔軟性の記録を競う必要はなし。日常で使う範囲を痛みなく動かせるのが目標なんで、痛みが出るほどまではやらないようにお願いいたします。

 

 

2週間の自己実験

ってことで、姿勢・可動性を伸ばしたい人は、まず以下のどれかを2週間だけお試しあれ。

 

タイプ2週間の実験見るポイント
座位時間が長い30〜60分に1回立つ＋肩回し5回腰の重さ、肩こり、集中力、夕方の疲労感
肩・背中が固い肩甲骨回し＋胸椎回旋を毎日3分肩こり、腕の上げやすさ、呼吸のしやすさ
股関節・足首が固い股関節回し＋足首回し＋椅子スクワットを週3〜5回歩幅、しゃがみやすさ、階段、つまずきやすさ
姿勢を保つ力が弱いローイング＋グルートブリッジ＋バードドッグを週2〜3回猫背感、腰の不安、長時間座った後の動き出し

 

ここでの判定基準は、

 

  • 長く座った後の腰の重さが減る
  • 肩や背中が動かしやすい
  • 歩幅が少し広がる
  • しゃがむ動作が少し楽になる
  • 階段や床から立つ動作がスムーズになる
  • 運動後に痛みが増えない

 

あたりをチェックしてみるといいでしょう。このあたりが改善していれば、その運動は自分に合っている可能性があります。逆に、関節痛が増える、腰が重くなる、肩が痛む、翌日にだるさが強いなら、可動域・回数・強度を下げたほうがいいです。
