「『自分はまだダメだ…』を武器にする技術」の続きです！(#1,#2,#3)

 

このシリーズでは、私たちの人生の満足度を下げちゃうインポスター症候群について触れてまして、今回は「インポスター症候群」の話です。ざっくり言うと「自分の成功を実力と認められず、偶然や運の結果だと思い込んでしまう心理現象」のことで、こいつをこじらせると、いつまでも達成感を得ることができず、人生の満足度がダダ下がりしちゃう可能性が高まるんで、心当たりのある方はぜひ注意しておきたいところです。

 

ということで、今回はその第4弾。インポスター症候群の対策として、「“助け合い”をデザインする」を見てみましょう。

 

 

 

知識と身体のギャップが生む「自信の空洞」

皆さまは、こんな場面に出くわしたことはないでしょうか。

 

  • SNSで健康情報を発信している人が、実は睡眠時間が毎日3時間
  • マインドフルネスに詳しい人が、なんだかイライラしていることが多い
  • 「継続が大事！」と語る習慣化コーチが、毎週発言内容を変える

 

いわゆる「言ってることとやってることが違う問題」でして、こういう人ってのは誰にでも見抜かれてしまい、信頼度がガタ落ちになっちゃうのはわかりやすい話でしょう。「言っていること」と「やっていること」にズレがある専門家の言うことを、あんま信じたくないですもんね。

 

ただ、これが他人の話だけなら、単にその人を避ければいいだけなんですが、ここで困っちゃうのが「言ってることとやってることが違う問題」は私たち自身の中にも発生するんですよ。たとえば、

 

  • 「SNSは時間のムダだから制限すべき」と思ってるのに、つい毎朝タイムラインを30分見てしまう
  • 「筋トレは週2回はやるべき！」と他人に言ってるのに、ここ3週間一度も行っていない
  • 「メンタルの安定には早寝が大事」と言っておきながら、夜0時すぎてもスマホを触ってしまう
  • 「自分を褒めることが大事」とブログに書いたのに、自分へのダメ出しが止まらない

 

こんな感じで、知識はあるんだけど自分ではやれていなかったりとか、「こうすれば良い」と分かっているんだけど実践は続かなかったりとか、こういったギャップは誰でも一度は経験するものでしょう。

 

このとき、私たちの心の奥から湧いてくるのが「インポスター感」であります。「自分は嘘つきなんじゃないか」「本当は中身がないのに、知ってるふりをしているだけなんじゃないか」みたいな感覚がわいちゃう状態っすね。

 

これは仕方がないことではあるし、知識と実践にギャップがあるからこそ私たちは努力をするとも言えるんですが、栄養学のエキスパートであるアラン・アラゴン先生いわく、 

 

完璧さを目指す必要はない。だが、“言葉と行動が一致している”ことは強力な自信の源になる。

 

とのこと。もちろん、すべての知識を完璧に実践できている人間なんて存在しないんだけど、少なくとも自分が発信していることについては実践している、という感覚があるかどうかが大事だってことですね。確かに、言ってることとやってることが違ったら、自分でも自分の言葉に信用が持てなくなっちゃいますもんね。

 

 

 

インポスター症候群は「知識と身体の不一致」から生まれる

このような「言ってることとやってることが違う問題」が、インポスター症候群の感覚を生む理由をもうちょっと掘り下げてみましょう。この問題には、毎度おなじみ心理学者バンデューラが提唱した「自己効力感（self-efficacy）」が大きく関わっております。「私はこの行動を達成できる！」という感覚のことでして、この感覚が高いと困難な課題にも挑戦しやすくなり、そのおかげで芋づる式にいろんなことに成功しやすくなるわけですな。逆に、自己効力感が低いと「やっても無理！」ってあきらめが先に立っちゃうんで、挑戦や学習を避けるクセがついてしまうんですよ。

 

かように自己効力感は大事な要素なわけですが、バンデューラ先生は、自己効力感を高めるのに必要な要素として4つのポイントを挙げております。

 

  1. 達成経験（自分ができたという過去の体験）
  2. 代理経験（似た他者の成功を見る）
  3. 言語的説得（他者からの励まし）
  4. 生理的・情緒的状態（疲労、不安の有無）

 

このうち、最も影響力が高いのが達成経験で、この感覚ってのは、

 

  • 毎朝5分のストレッチを1週間継続できた
  • 初めて論文を最後まで読んで、自分の言葉で要約できた
  • 苦手だった営業トークで1件の受注を取れた
  • 過去の自分なら後回しにしていたタスクを、その日のうちに終わらせた
  • ブログを初めて投稿して、読者から「参考になった」とフィードバックをもらった

 

みたいなことを意味しております。つまり「自分でやってみて、できた！」という身体的な実感が大事だよってことですね。

 

ここで重要なポイントは、

 

  • 知識だけでは、自己効力感は生まれない。
  • 自己効力感は、行動（身体）を通じて初めて確信に変わる。

 

ってことでして、知識を行動に落として、身体で確かめるプロセスをふまないと、自己効力感ってのは成長しないんですよね。

 

これは当然の話で、たとえば運動を指導してる人が寝不足で不健康な状態だったら説得力が下がるのは当然のこと。知識はあるのに行動が伴わないと、「理論上は正しいと理解していても、自分の身体がその理論を実践していない……」みたいな違和感が他人の中にも自分の中にも発生するんですよ。このギャップが積み重なると「私は口だけではないか？」って内的な批判が生じ、これがインポスター感情を生んでいくわけですね。

 

逆に、完璧でなくても自分の言葉を身体で検証している姿勢があれば、クライアントや読者は自然と信頼を寄せるはず。そこに自身の能力への信頼が生まれ、「私はこれを実践している」と言える小さな自負が、確かな自信へと育っていくわけであります。

 

なので、インポスター感が強い人ってのは、たいてい知識だけはあるケースが多めだったりします。むしろ知識のレベルは高いし、人にもアドバイスできることが多いんですよね。しかし、そこに自分の実践が伴っていないのが問題で、「自分ではやれていない……」って後ろめたさが常に頭のどこかにあるため、これがやがて「自分はウソをついているのでは？」という感情に変わっていくんですよ。一言で言えば、「他者と自分への信頼を生むのは、実践している姿勢である！」ってことでして、これを肝に銘じておくだけでも、自己効力感は高めやすくなるんじゃないでしょうか。

 

 

 

「一貫性の回路」で自己効力感を取り戻す

【指示】「一貫性の回路」で自己効力感を取り戻すの導入文を書く

 

 

ステップ1：言葉を行動に翻訳する

上でも見たとおり、インポスター感情の正体は「できてない自分」に対する自己矛盾であります。この矛盾を解消するには、「言ってることが少しでもできている状態」を作り、脳に「自分はちゃんとやれている」って感覚をしみ込ませていくしかないんですよね。

 

そのためにまず必要なのが、知識（言ってること）を具体的な日常行動に翻訳することです。といっても、ここでは難しいことをする必要はなく、「簡単すぎて笑ってしまうレベルの行動」でいいので、あんま気張らずに取り組んでみてください。

 

①：「言ってること」を洗い出す

まずは自分が日頃、他人に言っていること・正しいと信じていることを10個程度書き出してみましょう。たとえば、

 

  • 睡眠が一番大事です
  • 加工食品はなるべく避けましょう
  • 運動は週2回以上が理想
  • 朝のルーティンが1日の集中力を左右する
  • SNS時間を減らすとストレスも減る

 

みたいな感じっすね。この時点では行動化できていなくてもOKであります。

 

 

②：「行動翻訳式」で具体化する

続いて下記のフォーマットで、1つずつ「何をすれば“やってること”になるか」を明確にしましょう。

 

「〇〇（言ってること）を体現するには、私は今日・今週、何をどのくらいやれば“やった”ことになるか？」

 

たとえば、

 

言ってること翻訳された行動工夫ポイント
睡眠が大事23時以降スマホ操作をしないアラーム設定＋ベッドに本だけ置く
加工食品を避けるコンビニ弁当の代わりにおにぎり＋卵全てを変えようとしない
運動すべき歯磨きの後にスクワット10回タイミングに紐づける
SNSを減らす朝8時までSNSを開かないブロックアプリを使う

 

みたいな感じですね。重要なのは、「自分がこれなら“やった”と思える最低限の行動」にまで落とすことで、それを「見える化」できるように定義するのがポイントであります。

 

 

③：「1行タスクリスト」で日常に落とし込む

さらに、翻訳された行動をチェック可能な形で並べた「1行タスクリスト」を作成。冷蔵庫やスマホ壁紙など、目につく場所に配置しときましょう。

 

  • □ 昨晩23時以降スマホを見なかった？
  • □ 今日の食事で加工食品を避けられた？
  • □ 歯磨き後にスクワット10回やった？
  • □ 朝8時までSNSを開かなかった？

 

その上で、寝る前のタイミングで良いので、行動が一致した体験を1日1分で振り返ってください。メモアプリや紙などに、以下のポイントを記しておいてください。

 

  • 【一致できたこと】：例：夜スマホを見なかった
  • 【なぜできたか】：例：アラームで気づけた
  • 【気づき】：例：寝つきがよくなった

 

こんな感じで、「言ってること」を「小さな行動」に翻訳することで、インポスター感を“実践している感覚”に置き換えることが可能になります。完璧でなくてよいんで、地道に1つでも一致した行動を積んでいきましょう。

 

 

ステップ2：完璧を目指さず線を引く

インポスター症候群に陥る人の多くは、「あれもやってない！」「これも語る資格がない！」みたいに、 “実践していないこと”に対して罪悪感を抱く傾向があったりします。しかし、これはあくまで完璧主義の罠なので、ぜひ注意しておきたいところです。

 

ここで必要なのは、自分が語る範囲と、語らない範囲に「明確な境界線」を引くことであります。この線引きができていれば、「私が語っていることは、私が実際にやっていることだ！」という一貫性が保たれ、 インポスター感は自然に弱まっていきますんで。

 

具体的には、以下の作業をやってみてください。

 

 

①：自分の「語っていること」を書き出す

まずは、SNS、ブログ、セッション、講義などであなたが発信している主張・アドバイス・価値観をリストアップします。 できれば直近30日以内のアウトプットから抽出してくださいませ。

 

例：

  • 「朝の集中力が生産性を決める」
  • 「筋トレはメンタルにも効く」
  • 「ジャンクフードは依存性があるので控えよう」
  • 「週1回はデジタルデトックスをしよう」

 

その上で、このリストを「やっている」「やっていない」で分類しましょう。この時には、毎週できているか／最近やれていないかで2つに分けるようにしてください。

 

さらに、この作業で「自分が実践できていること」がわかったら、「自分が最も価値提供できる」「語っていて違和感がない」と感じるテーマを1〜3個に絞りましょう。これがあなたの「語っても良いゾーン」になります。このゾーンを明確にすることで、「これは私がやっているから自信を持って伝えられる」という自己一致感が生まれますんで。

 

 

②：「語らないゾーン」を明確化し、断る準備をする

一方で、まだ実践できていない・深掘りできていない分野については、あえて「語らない」ことを決めるのが重要になります。その際には、たとえばこんな表現を用意しておきましょう。

 

  • 「その領域はまだ勉強中なので、信頼できる方をご紹介しますね」
  • 「私の専門からは外れるので、お役に立てるかわかりませんが…」
  • 「今のところは習慣改善が主なテーマなので、そちらの視点でならお話できます」

 

相手に断りを入れるのはドキドキするかもですが、こんな感じで自分がカバーしない領域を明言することは、むしろ信頼を生んでくれますんでご安心ください。「全部できる」「何でも詳しい」よりも、「ここなら任せて」と言える人のほうが強い印象を与えるものなんですよ。というか私も「自分はここまでが守備範囲だ！」「それ以降は連携だ！」みたいな線引きをしていて、クライアントに信頼してもらうようにしております。

 

逆に、「これも言いたい」「これもカバーしておきたい」と無制限に広げると、 自分の“非実践”がどんどん増え、「私は何もやれていない」という感覚に変わっちゃうんで注意したいところです。完璧を目指すと、どこかで必ず自己不一致が生まれますんで、ぜひ「これはやっているから語る」「これはまだだから語らない」と判断できるようにしといてくださいませ。ではまた！
