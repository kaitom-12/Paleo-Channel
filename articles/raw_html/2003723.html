サーモンのトルティエール

トルティエールってのはいわゆるミートパイです。ここではパイ生地にキャッサバ粉（タピオカの原料）を使うのがポイントで、キャッサバ粉ってのは昔からビフィズス菌やロゼブリアなどの善玉菌の成長を刺激することがわかってるんですよ。キャッサバ粉の生地はいろいろと使い勝手がいいんで、作り方を知っておくと何かと便利でしょう。

 

また、サーモンも腸内に良い優良な油を含んでますんで、ぜひ定期的にお食べください。

 

  • 準備時間：20分
  • 調理時間：1時間
  • 量：4～6人分

 

材料

  • キャッサバ粉　1カップ 
  • チキンストック　3カップ
  • エクストラバージンオリーブオイル　大さじ3
  • 玉ねぎ　中1個（角切り）
  • ウィンターセイボリー（タイムでも可）　小さじ1
  • にんにく　1かけら （みじん切り）
  • サーモン　450g2本（スモークサーモンでも可）
  • 塩　小さじ3/4
  • ラードまたは無塩のグラスフェッドバター　0.5カップ
  • アップルサイダービネガー　小さじ1.5カップ
  • グリーンバナナ　大3本（ジャガイモ中4個でも可）

 

作り方

  1. キャッサバ粉と塩ひとつまみをボウルに入れて混ぜる。そこにラードを加えて泡立て器などで混ぜ、オートミールのような状態にする。 

  2. アップルサイダービネガーと氷水を大さじ1ずつ加えて生地に混ぜる。生地がまとまりやすくなったらストップ。 

  3. ラップで生地を包んで、パイの準備をしている間、冷蔵庫に入れて冷やしておく。 

  4. グリーンバナナ（またはジャガイモ）の皮をむき、2センチ四方の大きさに切る。これをチキンストックを入れた鍋に入れて中火でプランタンが柔らかくなるまで煮る（約15分） 

  5. グリーンバナナを煮る間に、フライパンでオリーブオイルを中火で加熱。ここに玉ねぎを加えてかき混ぜつつ、茶色くなるまで加熱（約8分）。 

  6. グリーンバナナを火から下ろして水気を切る（水気は取っておく）。フォークやポテトマッシャーでグリーンバナナをつぶし、マッシュポテトのようにする（水気が足りない場合は、水分を戻す）。 

  7. 残りの塩小さじ1/2をグリーンバナナに加え、さらにセイボリーとニンニクのみじん切りを加える。

  8. 水を切ったサーモンの塊をグリーンバナナと混ぜ合わせ。キャセロール皿にサーモンとバナナを入れ均等になるように皿に広げ、室温まで冷ます。

  9. オーブンを200℃に予熱。

  10. ステップ3で作ったパイ生地を伸ばし、キャセロール皿の大きさや形に合わせてパイの上に設置。パイ生地にいくつかの切り込みを入れて空気が抜けるようにしておく。

  11. パイ生地に焼き色がつくまで45分焼いて終了

 

 

 

鶏胸肉のタラゴンソース添え

腸内環境には適切な量のタンパク質が必須。ということで、魚に加えて鶏胸肉も押さえておきたいところです。ここではタラゴンソースを使ってますが、別にローズマリー、オレガノ、タイム、バジルでも可。いずれのスパイスもファイトケミカルが豊富なんで、こちらも定期的に摂取したいっすね。

 

  • 準備時間：20分
  • 調理時間：30分
  • 量：4人分

 

材料

  • エキストラバージンオリーブオイル　大さじ3
  • エシャロット　大2個（薄くスライスしておく）
  • マッシュルーム　450g（薄くスライスしておく）
  • 塩　小さじ1.5 
  • タラゴン　小さじ2 
  • キャッサバ粉　大さじ3 
  • 皮を取り除いた鶏胸肉4枚（約1.2kg）
  • チキンストック　1.5カップ
  • ニンニク　1片（潰しておく）
  • レモン汁　大さじ1

 

 

作り方

  1. フライパンにオリーブオイル（大さじ2）を入れて中火にかける。そこにエシャロットとマッシュルームを加えて柔らかくなるまで加熱。軽く焼き色をつけたら、スプーンで小さなボウルに移す。

  2. 皿の上で、塩、タラゴン、キャッサバ粉を混ぜたら、鶏の胸肉に塗る。

  3. さきほど使ったフライパンに残りのオリーブオイル（大さじ1）を入れて中火にかける。そこに鶏肉を加えてキツネ色になるまで加熱。

  4. 中弱火にしてフタをし、内部温度が70℃に達するか、肉を刺したときに透明な肉汁が出るまで約10分加熱。火が通った鶏肉を皿に移す。 

  5. チキンストックをフライパンに注いで強火で沸騰させ、にんにく、レモン汁、焼き色をつけたエシャロットとマッシュルームを加えてソースを作る。できたソースを鶏肉にかけて終了。

 

 

 

カンパチのグリルとポレンタ

カンパチなどに含まれるタンパク質は、腸内環境に良い影響が多め。ここではカンパチを使ってますが、好みに応じてタラなどをお使いください。また、当然ながら葉菜とキノコ類も優良食品なので、ガンガンに摂取していただけると幸いです。

 

  • 準備時間：30分
  • 調理時間：45分
  • 量：4人分

 

材料

  • チキンストック　1/4カップ
  • 辛口の白ワイン 大さじ5
  • エクストラバージンオリーブオイル　小さじ5
  • コーンミール　1カップ
  • カンパチの切り身　約450g
  • 塩　小さじ1
  • コショウ　小さじ1/4
  • にんにく　 2片（みじん切り）
  • レモン汁　大さじ3 
  • 唐辛子のみじん切り　小さじ1 
  • パセリのみじん切り　1/2カップ
  • 好きな葉物野菜やキノコ類　16カップ（ケール、ほうれん草、ビートグリーン、マッシュルーム、ルッコラなど）

 

作り方

  1. フライパンにチキンストック、白ワイン、オリーブオイル（大さじ1）を入れて中火で煮立たせる。コーンミールをゆっくりと入れて、ダマにならないようにしっかりとかき混ぜたら弱火にする。そのままフタをせずによくかき混ぜな、濃くてクリーミーになるまで煮る。最後に小さじ1/2の塩を混ぜたら、皿に乗せておく。

  2. 小さなボウルにレモン汁（大さじ1）、オリーブオイル（大さじ1）、パセリのみじん切り、トウガラシ（使用している場合）を入れる。

  3. カンパチに大さじ2のオリーブオイルを塗り、残りの小さじ0.5杯の塩とコショウを振りかけて、軽く焦げ目がつき中に火が通るまで焼く（片面3～4分ほど）。焼き終わったら皿に乗せてレモン汁をかける。

  4. フライパンに残りのオリーブオイル（大さじ1）を入れて中火で熱し、ニンニクを加えて30秒ほど加熱。葉物野菜と残りのレモン汁（大さじ2）を加え、しんなりするまで1～2分加熱。

  5. コーンミールソース（ポレンタ）、カンパチ、葉物野菜を合わせて終了。

 

 

 

ブルーベリーとクルミのサラダ

クルミは腸内環境への影響が最高のナッツなんで、サラダなどで食べておきたいところ。サーモンやチキンなどと一緒にお召し上がりください。

 

  • 準備時間：なし
  • 調理時間：10分
  • 量：2人分

 

材料

  • くるみ　1/2カップ
  • アボカド　 1/2個（皮をむいて種を取り、1.5センチ四方に切る）または好きなチーズ　50g
  • エキストラバージンオリーブオイル　大さじ2
  • バルサミコ酢　大さじ1
  • 胡椒と塩　ひとつまみ
  • ルッコラ　2カップ
  • ケール　2カップ
  • レッドオニオン　 3スライス
  • ブルーベリー　100g
  • ドライイチジク　3個（1.5センチ四方に切る）

 

作り方

  1. ルッコラ、ケール、レッドオニオン、オレンジ、ドライイチジク、クルミをゆっくりと混ぜ合わせ、その上にアボカドかチーズをのせる。

  2. 小さなボウルにオリーブオイル、バルサミコ酢、コショウ、塩を入れて混ぜてドレッシングを作る。

 

 

 

ポテトサラダ

ポテサラは、腸内細菌の大好物であるレジスタントスターチが豊富なので、やはり食べておきたいところです。カシュークリームチーズが作るのがめんどうま場合は、普通にサワークリームを使うのも可であります。

 

  • 準備時間：なし
  • 調理時間：20分＋冷却時間30分
  • 量：8人分

 

材料

  • ジャガイモ　1500g 
  • マヨネーズ 　1/2カップ
  • カシュークリームチーズ　1/2カップ （またはココナッツミルクヨーグルト）
  • アップルサイダービネガー　大さじ2
  • シーソルト　小さじ1 
  • パプリカ　小さじ1/2
  • こしょう　小さじ1/4
  • セロリ　大4本（薄切り）
  • オレンジまたは赤ピーマン　1/2個（角切り）
  • 赤玉ねぎ1/4個（角切り）
  • パセリ　1/4カップ（みじん切り）

 

作り方

  1. 大きめの鍋にジャガイモを入れて水を注ぎ、強火で沸騰させる。フタをしてジャガイモが柔らかくなるまで煮詰める（約20～30分ぐらい）。

  2. ジャガイモの水を切りったら冷たい流水で洗って十分に冷やす。ジャガイモの皮をむき、2センチ四方の角切りにして、大きなボウルに入れる。 

  3. 小さなボウルにマヨネーズ、カシュークリームチーズ、アップルサイダービネガー、塩、パプリカ、コショウを入れて混ぜる。 

  4. マヨネーズをかけたジャガイモを大きなスプーンの先で崩し、皿にセロリ、ピーマン、玉ねぎ、パセリを加えて混ぜる。 

  5. 冷蔵庫で冷たくなるまで、少なくとも2時間は冷やす。
