最新の性格テスト『HPCS』の続きです(#1)。

 

前回は、アラバマ大学のチームが作った優秀な性格テストである「HPCS」を紹介しました。このテストは、類似のもののなかでは精度が高くて使い勝手も良いので、自分の性格を理解するだけではなく、仕事や社会的な場面での行動やパフォーマンスを改善するためにも使えるのが良いところです。

 

ってことで今回は、HPCSを使って具体的な改善目標を作り、主に仕事のパフォーマンスを改善する方法を考えてみましょうー。

 

 

ステップ1：HPCSの結果を分析する

まずは前回のHPCSのスコアを確認し、自分の特性を理解しましょう。当然ながら、得点が高い特性は自分の強みとして活用可能だし、得点が低い特性は改善の余地があるエリアとして注目すべきであります。

 

それが終わったら、特性ごとに詳細をざっくり確認しましょう。

 

  • 神経症傾向：ストレス耐性や感情の安定性を評価。

  • 外向性：社交性やリーダーシップの傾向を評価。

  • 誠実性：計画性や目標志向性を評価。

  • 協調性：他者への共感力やチームワーク力を評価。

  • 開放性：創造性や新しい経験への意欲を評価。

 

その上で、自分の特性をひとつの文章にまとめてください。たとえば、以下のような具合です。

 

  • アウトプット例

    「神経症傾向が高く、ストレス管理が課題。外向性は中程度で、状況によって変化しやすい。誠実性は高く、目標設定が得意。」

    「外向性が高く、社交性とリーダーシップに優れる一方、神経症傾向も高く、感情の波が激しいことが課題。誠実性が中程度で、計画性にやや課題がある。」

    「誠実性と協調性が高く、責任感が強く、他人との関係を築くのが得意。一方で、外向性が低く、大人数の場面での主導権を握ることに苦手意識がある。」

    「外向性が中程度で、社交性は状況によって発揮される。誠実性が高く、タスクを計画的に進められるが、神経症傾向が高いため、失敗への不安が足かせになることがある。」

 

 

ステップ2：WOOPで目標を設定する

次に、自分の性格特性を活かし、課題を改善する具体的な目標を設定していきます。

 

ここで最もよく使われるのは「WOOP」で、目標設定のプロセスで現実的な課題（障害）を考慮し、それを乗り越えるための計画を明確化し、それによってゴールの達成率を高める手法です。ニューヨーク大学のガブリエル・エッティンゲン博士が編み出した、定番のテクニックですね。

 

というわけで、HPCSの結果を使ってWOOPで目標を設定してみましょう。

 

 

1. W：Wish（望み）

HPCSの結果から、どの性格特性を活かしたい、または改善したいのかを考え、それを「望み」として定義します。

 

具体的には、以下のような方向で考えてみてください。

 

  • 得点の高い特性を活かす：例えば、外向性が高いなら「リーダーシップを発揮したい」。開放性が高い場合は、「新しいアイデアを提案して、プロジェクトに革新をもたらしたい」とか。

  • 得点の低い特性を改善する：例えば、神経症傾向が高いなら「ストレス耐性を高めたい」。誠実性が低い場合は、「計画を立ててタスクを優先順位に従って実行できるようになりたいとか。

 

その上で、上記で考えたポイントを言語化して、具体的で現実的な望みにしましょう。抽象的すぎると目標がぼやけるため、目指す状態をはっきりさせてください。

 

1. 神経症傾向に関連する望み

  • 良い例：「仕事の締め切りが近づいても焦らず計画的に対応できるようになりたい。」
  • 悪い例：「プレッシャーに強くなりたい。」

 

2. 外向性に関連する望み

  • 良い例：「職場で月に1回、同僚とランチミーティングを開いて交流を深めたい。」
  • 悪い例：「人付き合いを良くしたい。」

 

3. 誠実性に関連する望み

  • 良い例：「1日に優先度の高いタスクを3つだけ選び、確実に完了させたい。」
  • 悪い例：「もっと計画的になりたい。」

 

4. 協調性に関連する望み

  • 良い例：「会議中に少なくとも1回、他人の意見をポジティブにフィードバックしたい。」
  • 悪い例：「周囲ともっと協力できるようになりたい。」

 

5. 開放性に関連する望み

  • 良い例：「3カ月以内に新しい趣味を始め、毎週1回は取り組む時間を作りたい。」
  • 悪い例：「新しいことに挑戦したい。」

 

HPCS特性別の例

  • 1. 神経症傾向（Neuroticism）
    • 得点が高い場合：「ストレスの多い仕事の場面で冷静に対処したい。」
    • 得点が低い場合：「困難な状況でも周囲に安心感を与えられる存在になりたい。」
  • 2. 外向性（Extraversion）
    • 得点が高い場合：「リーダーとして新しいプロジェクトを立ち上げたい。」
    • 得点が低い場合：「少人数のチームで、メンバーと深い信頼関係を築きたい。」
  • 3. 誠実性（Conscientiousness）
    • 得点が高い場合：「長期的なプロジェクトを計画通りに進め、チームの目標達成をサポートしたい。」
    • 得点が低い場合：「計画的にタスクを進めて締め切りを守りたい。」
  • 4. 協調性（Agreeableness）
    • 得点が高い場合：「チーム内で対立があった場合に、仲裁役を担って円滑に解決したい。」
    • 得点が低い場合：「異なる意見を持つ相手とも、建設的な議論ができるようになりたい。」
  • 5. 開放性（Openness）
    • 得点が高い場合：「新しいスキルを身につけ、3カ月以内にそのスキルを仕事で活用したい。」
    • 得点が低い場合：「業務の効率を上げるために、現実的な改善案を3つ提案したい。」

 

 

2. O：Outcome（結果）

続いて、先ほど作った「望み」がかなったときに得られるポジティブな結果を想像しましょう。この段階では、達成後の具体的な利益や感情を思い描くことが重要であります。

 

その際のポイントは、以下の3つになります。

 

  1. 成功の具体的なイメージを描く：目標達成後の姿を、できるだけ具体的に思い浮かべます。
    例：「ストレスを管理できるようになり、重要なプレゼンでも落ち着いて話せる」「時間管理を改善し、毎日の仕事を予定通り終わらせて、定時に帰宅できるようになる」

  2. 成功によるメリットを明確にする：目標達成が自分の生活や仕事にどう役立つかを具体化します。
    例：「締め切りを守れることで、チームからの信頼を得られる」「プレッシャーに強くなり、ストレスの多い状況でも冷静に仕事を進められることで、上司からの評価が向上する」

  3. ポジティブな感情を意識する：達成後の気分や充実感をリアルにイメージします。
    例：「目標を達成して、自信を持てるようになる」「締め切りを守り、プロジェクトがスムーズに進むことで、達成感と自信を持てるようになる」

 

HPCS特性別の例

  • 1. 神経症傾向（Neuroticism）
    • 「ストレスの多い会議でも冷静さを保ち、意見を的確に伝えられるようになる。」
    • 「仕事でのミスが減り、効率よくタスクを進められるようになる。」
    • 「落ち着いた気持ちで毎日を過ごせるようになり、自分に余裕を感じられる。」
  • 2. 外向性（Extraversion）
    • 「新しいプロジェクトのチームリーダーとして、メンバーを上手にまとめ、目標を達成する。」
    • 「職場での存在感が増し、上司や同僚から信頼される機会が増える。」
    • 「自分のアイデアや行動が評価され、自信と満足感が得られる。」
  • 3. 誠実性（Conscientiousness）
    • 「毎日、優先タスクを確実に終わらせ、締め切りを守れるようになる。」
    • 「業務の質が向上し、上司や同僚からの信頼が厚くなる。」
    • 「仕事が計画通りに進み、達成感や安心感を得られる。」
  • 4. 協調性（Agreeableness）
    • 「チームメンバーの意見を取り入れながら、プロジェクトをスムーズに進められる。」
    • 「周囲との関係が円滑になり、働きやすい環境が整う。」
    • 「他者から感謝され、協力関係を築ける喜びを感じられる。」
  • 5. 開放性（Openness）
    • 「新しいアイデアを提案し、職場での問題を解決するための革新的なプロセスを導入する。」
    • 「業務の効率が上がり、自分の独創性が周囲に認められる。」
    • 「自分のクリエイティビティを活かせた満足感と成長の実感が得られる。」

 

 

3. O：Obstacle（障害）

今度は、目標達成を妨げる可能性がある障害や課題を事前に洗い出します。これにより、現実的な計画が立てやすくなりますんで。

 

その際のポイントは、以下の3つになります。

 

  1. ２つの障害をリストアップする：障害を考える時は、2パターンの障害を必ずチェックするようにしましょう。詳しくは以下の2つです。

    内的障害：自分の性格や行動パターンが妨げになる場合。例：「時間がなくて継続できない」「すぐに気が散る」
    外的障害：環境や状況の要因。例：「スケジュールが詰まりすぎて、新しい取り組みを始められない」

  2. 主な障害を選ぶ：考えついたなかでも、最も大きな障害を特定します。例：「瞑想を始める計画を立てたが、時間がなくて忘れがち」

  3. 障害の影響を考える：その障害が起きた場合、自分がどう感じ、どう行動してしまうかを想定しましょう。例：「時間がないと感じたら、瞑想を後回しにしてしまう」

 

HPCS特性別の例

  • 1. 神経症傾向（Neuroticism）
    • 障害の例
      • 内的障害：「感情の揺れが激しく、挫折感を抱きやすい」目標に対して途中で不安を感じ、諦めたくなる。
      • 外的障害：「ストレスフルな環境にいると、自分を落ち着けるのに時間がかかる」急なトラブルやプレッシャーがあると、計画どおりに行動できなくなる。
    • 障害の影響
      • 行動：ストレスや不安を感じて、目標に向けた行動を後回しにする。
      • 感情：「どうせうまくいかない」と考え、自信を失う。

 

  • 2. 外向性（Extraversion）
    • 障害の例
      • 内的障害：「社交の場に行き過ぎて、疲れてしまう」社交活動に夢中になるあまり、他のタスクを後回しにする。
      • 外的障害：「社交の場に誘われる頻度が高く、予定が詰まりすぎる」自分のスケジュールを管理できなくなる。
    • 障害の影響
      • 行動：予定を詰め込みすぎてエネルギー切れになり、必要なタスクを遂行できなくなる。
      • 感情：忙しすぎて焦燥感や自己管理の失敗を感じる。

 

  • 3. 誠実性（Conscientiousness）
    • 障害の例
      • 内的障害：「計画を立てても忘れっぽく、実行できない」優先順位を決めるのが苦手で、目標を途中で放置する。
      • 外的障害：「急な予定変更があると、対応に混乱する」想定外の事態に直面すると、行動計画が崩れる。
    • 障害の影響
      • 行動：タスクが山積みになり、どこから手を付けるべきか分からなくなる。
      • 感情：計画どおり進まないことに対してフラストレーションを感じる。

 

  • 4. 協調性（Agreeableness）
    • 障害の例
      • 内的障害：「他人の意見を優先しすぎて、自分の時間がなくなる」他者の要求を断りきれず、自分の目標を後回しにする。
      • 外的障害：「人間関係のトラブルに巻き込まれる」職場や家庭での対立があると、集中力を欠いてしまう。
    • 障害の影響
      • 行動：他人に気を遣いすぎて、自分のタスクを疎かにする。
      • 感情：「もっと自分の意見を主張すればよかった」と後悔する。

 

  • 5. 開放性（Openness）
    • 障害の例
      • 内的障害：「新しいアイデアに興味を持ちすぎて、優先順位を見失う」多くのことに手を出し、途中で飽きてしまう。
      • 外的障害：「周囲から現実的でないと指摘され、モチベーションが下がる」アイデアが実現不可能だと感じ、取り組む意欲を失う。
    • 障害の影響
      • 行動：タスクが中途半端に終わり、成果が得られない。
      • 感情：「自分の創造性が認められていない」と感じ、失望する。

 

 

4. P：Plan（計画）

最後に、障害を乗り越えるための具体的な計画を立て、実行可能な行動を決定してください。計画はシンプルで、具体的であるように心がけましょう。

 

その際のポイントは、以下の3つになります。

 

  1. 障害に対する対策を考える：障害が発生したときの対応策を具体的に決めます。例：「瞑想の時間を作るために、朝の5分間だけ取り組む」

  2. If-Thenプランを作る：障害が発生したときにどう行動するかを、毎度おなじみIf-Thenプランニングで計画してみましょう。例：「もし忙しくて瞑想の時間が取れないなら、昼休みに5分だけ深呼吸をする」

  3. 実行のタイミングを決める：計画をいつ、どこで、どのように実行するかを明確にします。例：「平日の朝7時に、リビングで瞑想を行う」

 

HPCS特性別の例

  • 1. 神経症傾向（Neuroticism）
    • 障害に対する対策：「ストレスを感じやすく、感情が不安定になりがち。」だから「ストレスを感じたとき、5分間静かな場所に移動してリラックスする。」
    • If-Thenプラン：「もしストレスを感じたら、すぐに深呼吸を3回行い、自分を落ち着かせる。」
    • 実行のタイミング：「仕事中、ストレスを感じたときにトイレや空いている会議室に行き、静かな環境で3分間目を閉じてリセットする。」

 

  • 2. 外向性（Extraversion）
    • 障害に対する対策：「活動的すぎて疲れがたまり、リカバリーが疎かになりがち。」だから「イベント後は1時間だけ一人の時間を作る。」
    • If-Thenプラン：「もしイベント後に疲れを感じたら、翌日は予定を減らしてリカバリーに充てる。」
    • 実行のタイミング：「イベントの次の日は夜に予定を入れず、早めに就寝する。」

 

  • 3. 誠実性（Conscientiousness）
    • 障害に対する対策：「計画を立てても実行を忘れることがある。」から「タスクを紙に書き出し、目立つ場所に貼る。」
    • If-Thenプラン：「もしタスクを忘れそうになったら、スマホのリマインダーを使って通知を設定する。」
    • 実行のタイミング：「毎朝仕事を始める前に、その日の優先タスクを手帳に書き出し、デスクの前に置く。」

 

  • 4. 協調性（Agreeableness）
    • 障害に対する対策：「自分の意見を主張するのが苦手で、他者に合わせすぎてしまう。」から「会議で自分の意見を1回は発言することを目標にする。」
    • If-Thenプラン：「もし意見を求められたら、まず自分の考えを述べた後に他者の意見を取り入れる。」
    • 実行のタイミング：「週に1回のチームミーティングで、自分の意見を発言するタイミングを決めて準備する。」

 

  • 5. 開放性（Openness）
    • 障害に対する対策：「新しい挑戦に対する興味はあるが、実際に始めるまでに時間がかかる。」から「最初の一歩を小さくするため、オンラインコースを登録だけしておく。」
    • If-Thenプラン：「もし新しい挑戦に尻込みしたら、『とりあえず5分だけやってみる』と決める。」
    • 実行のタイミング：「毎週土曜日の午前中、新しい趣味やスキルに5分だけ取り組む時間を確保する。」

 

 

HPCSを活用したWOOP目標設定の実践例

HPCS結果：外向性が高い、神経症傾向が中程度。

目標：新しいネットワークを構築しつつ、ストレスをコントロールする。

 

  • WOOP設定
    • Wish（望み）：「月に1回、社交イベントに参加して、1人と新しい関係を築く。」
    • Outcome（結果）：「職場外での人間関係が広がり、新しい視点を得られる。自分の社交性に自信が持てる。」
    • Obstacle（障害）：「イベント参加前に緊張して行くのが億劫になる。」
    • Plan（計画）：「もし参加が億劫に感じたら、最初の10分間だけ滞在するつもりで出かける。」
